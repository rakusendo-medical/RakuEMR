# Claude Code 向け実装指示書:看護計画モジュール ワイヤーフレーム

本ドキュメントは、精神科病院向け電子カルテ(EMR)の「看護計画モジュール」の主要画面を、React/TypeScript/MUI で**ワイヤーフレームレベル**で実装するための指示書である。Claude Code に投入して実装を依頼することを想定する。

---

## 0. あなた(Claude Code)へのゴール設定

ダミーデータで動作する、クリック可能なワイヤーフレームを作成してほしい。美麗なデザインよりも、**情報構造の正しさ・画面間遷移の自然さ・現場での使いやすさの検証**を優先する。本実装は将来本番コードに引き継ぐ前提の出発点であり、**構造は妥協せず、見た目は中忠実度で構わない**。

---

## 1. 技術前提

- React 18+ / TypeScript (strict mode) / Vite
- MUI v5(`@mui/material`, `@mui/icons-material`, `@mui/x-date-pickers`)
- Zustand(状態管理)
- React Router v6(画面遷移)
- date-fns(日付操作)
- Node 20+
- npm(yarn/pnpm不可)

**既存EMRと将来的に統合する前提のため、`src/features/carePlan/` 配下にモジュールを閉じる。** 外部からのインターフェースは `routes.tsx` と store 経由のみとする。

---

## 2. 参照ドキュメント

同一プロジェクトルートに `nursing_care_plan_user_stories.md` を配置している。用語定義・ロール・ステータス遷移・ユーザーストーリー(US-xx)・画面候補(S-xx)はすべて同ドキュメントに従う。**本指示書で触れていない細部はユーザーストーリー側を参照すること。**

| ステータス | 色 | ラベル |
|---|---|---|

|---|---|

| 中 | warning (橙) |

## 9. Zustand ストア(`store.ts`)

単一ストア `useCarePlanStore` に以下を持たせる。

**State**:
- `nurses: Nurse[]`
- `currentNurseId: UUID`(担当Ns切替で変更)
- `patients: Patient[]`
- `carePlans: CarePlan[]`
- `problemItems: ProblemItem[]`
- `evaluations: Evaluation[]`
- `templates: Template[]`
- `nandaMaster: NandaDiagnosis[]`
- `changeLogs: ChangeLog[]`

**Actions(抜粋)**:
- `createCarePlan(patientId, longTermGoal): CarePlan`
- `activateCarePlan(carePlanId): void`(draft → active)
- `addProblemItem(carePlanId, item): ProblemItem`
- `updateProblemItem(itemId, patch): void`
- `closeProblemItem(itemId, reason, closedAt): void`
- `createEvaluation(problemItemId, data): Evaluation`
- `copyFromTemplate(templateId, targetCarePlanId, selectedItems): void`
- `switchNurse(nurseId): void`

各 action 実行時に `changeLogs` に1件追加すること。

## 10. スタイリング方針

- MUI デフォルトテーマを使用し、`theme.ts` で以下のみ拡張:
  - 医療系のやや彩度低めのプライマリ(`#2e7d9a` など青緑系)
  - 余白は `spacing(2)` (16px) を基本とし、カード内は `spacing(1.5)` で情報密度を確保
- フォントは MUI デフォルト(Roboto)でよい。日本語は system-ui にフォールバック。
- 画面幅は 1200px を想定し、`<Container maxWidth="xl">` で囲む。
- アイコンは `@mui/icons-material` から意味の明確なもののみ使用。装飾目的のアイコンは避ける。

## 12. 完了基準(Definition of Done)

2. TypeScript strict でビルドが通る(`npm run build`)。
