# 看護計画モジュール ユーザーストーリー一覧

本ドキュメントは、精神科病院向け電子カルテ(EMR)の「看護計画」モジュール設計のための、プロダクトオーナー側仕様整理である。

> **更新方針**: 本ドキュメントは実装済み画面を正として記述する。未実装の機能は `〔将来拡張〕` として末尾に分離している。

---

## 0. 前提(Context)

- 対象:精神科病院の電子カルテ看護計画モジュール。
- 利用ユーザー:看護師のみ(医師の代行記載は本フェーズでは非対象)。
- 開発スタック:React / TypeScript / MUI / Zustand(既存EMRフロントエンドに統合)。
- 本フェーズで扱う主要機能は「立案・編集・月次評価・タスク一覧・引用コピー」である。
- 将来拡張:医師記載、師長承認フロー、病棟別ダッシュボード、処方連携、長期目標見直し・新計画切替、印刷出力は別フェーズ。

---

## 1. 用語定義(Domain Vocabulary)

| 用語 | 定義 |
|---|---|
| 看護計画(Care Plan) | 患者に紐づく計画の総体。1患者1現行計画が原則。 |
| 長期目標(Long-term Goal) | 看護目標・退院目標を包含する1件のテキスト。患者ごとに1つ。 |
| 問題点(Problem Item) | 長期目標配下の最小単位。領域分類・優先度・看護診断・目標・OTE具体策・立案日・評価履歴を持つ。評価の単位でもある。 |
| 看護診断(NANDA診断) | NANDA-I 由来のマスタから選択。問題点内の1属性。 |
| 目標(短期目標) | 問題点ごとの解決後の姿(状態記述)。 |
| 具体策(OTE) | Observation(観察)/ Therapy(援助)/ Education(指導)の3区分。各区分ごとに複数行のフリーテキスト。 |
| 月次評価 | 月1回、問題点単位で実施。達成度・所見を記録し、次のステータスを確定する。 |
| 受け持ちNs | 患者担当の主責看護師。立案・評価の主体。 |

---

## 2. ロール(Role)

- **受け持ちNs**:原則として立案・評価の主体。
- **看護師(全員)**:代行記載可能。読み書きともに権限上同等。

---

## 3. ステータス遷移(Lifecycle)

### 3.1 問題点(Problem Item)のライフサイクル

```
[下書き] ──(立案確定)──▶ [有効] ──(評価:修正して継続)──▶ [評価中]
                             ▲                                  │
                             └──────(評価:継続)────────────────┘
                             │
                             └──(評価または編集ダイアログ)──▶ [クローズ]
                                                              (解決/中止/変更)
```

### 3.2 計画全体(Care Plan)のライフサイクル

```
[下書き] ──(立案確定)──▶ [有効]
```

> 長期目標見直し・新計画切替は将来拡張。

### 3.3 UX 言語化

- **下書き**:立案途中。ダッシュボードでは「計画未立案」として表示。
- **有効**:現行計画として画面トップに表示。
- **評価中**:評価で「修正して継続」を選択した際に遷移。ダッシュボードで「評価中のまま」として警告表示。
- **クローズ**:解決・中止・変更のいずれかの理由で終了。再利用は「引用コピー」経由で行う。

## 4. エピック & ユーザーストーリー

### E1. 計画立案(Planning)

- **US-1.1** 受け持ちNsとして、担当患者の看護計画を新規作成できる。初期状態は下書き。
- **US-1.2** 受け持ちNsとして、長期目標を1つ入力して保存できる。テンプレートから疾患別の長期目標を選択・挿入することもできる。
- **US-1.3** 受け持ちNsとして、長期目標配下に問題点を複数追加でき、各問題点に領域分類・優先度・看護診断(NANDA)・目標・OTE具体策を入力できる。
- **US-1.4** 受け持ちNsとして、NANDA-Iマスタから看護診断を検索して選択できる(キーワード検索+領域絞り込み+よく使うものをサジェスト)。看護診断を選択すると領域分類が自動セットされる。
- **US-1.5** 受け持ちNsとして、OTE具体策をO/T/E区分ごとに複数行のフリーテキストで入力できる。
- **US-1.6** 受け持ちNsとして、下書きを「立案確定」できる。立案日は確定日で自動セットされる。確定時に全問題点の次回評価期限が1ヶ月後に自動設定される。
- **US-1.7** 受け持ちNsとして、計画立案を途中保存(下書き)して後で再開できる。

### E2. 計画閲覧(View)

- **US-2.1** 看護師として、患者の現行看護計画(長期目標 → 問題点一覧)を一望できる。
- **US-2.2** 看護師として、各問題点の現在ステータス・最終評価日・次回評価期限を確認できる。期限超過は赤字、残7日以内はオレンジで視覚的に識別できる。

### E3. 問題点の編集・追加

- **US-3.1** 看護師として、既存問題点の内容(目標・OTE)を編集できる。
- **US-3.2** 看護師として、既存の有効計画に新しい問題点を追加できる(長期目標は変更せず)。
- **US-3.3** 看護師として、問題点を「解決」「中止」「変更」のいずれかの理由でクローズできる。

### E4. 月次評価(Monthly Evaluation)

- **US-4.1** 看護師として、問題点単位で月次評価を入力できる(達成度・所見)。評価画面には前回評価のサマリーが参照表示される。
- **US-4.2** 看護師として、評価と同じ画面で問題点の目標・OTEを見直して修正できる。
- **US-4.3** 看護師として、評価完了時に問題点のステータスを「継続」「修正して継続」「解決でクローズ」「中止でクローズ」「変更でクローズ」のいずれかに確定できる。
- **US-4.4** 看護師として、対象患者の全問題点を1画面で縦に並べて連続評価できる。
- **US-4.5** 看護師として、月次評価の完了後に評価結果を看護記録に転記できる。転記内容には評価日・評価者・長期目標・各問題点の達成度と所見が含まれる。

### E5. タスクリスト / ダッシュボード

- **US-5.1** 看護師として、「計画未立案」の担当患者一覧を見られる。
- **US-5.2** 看護師として、「今月評価が必要な患者」一覧を評価期限の近い順に見られる。期限までの残日数が表示される。
- **US-5.3** 看護師として、「評価期限超過」の患者が視覚的にアラート表示(赤)される。超過日数が表示される。
- **US-5.4** 看護師として、「評価中のまま」(修正して継続を選択後、未対応)の患者一覧を見られる。
- **US-5.5** 看護師として、ダッシュボード上部のサマリーカードで各カテゴリの件数を一目で確認でき、クリックで該当セクションにスクロールできる。
- **US-5.6** 看護師として、担当看護師を切り替えて他の看護師の担当患者一覧を確認できる。

### E6. テンプレート・引用コピー

- **US-6.1** 受け持ちNsとして、他患者の計画から問題点をコピーして自患者に追加できる。
- **US-6.2** 受け持ちNsとして、同一患者の過去計画から問題点をコピーできる。
- **US-6.3** 看護師として、精神科向け標準テンプレートから問題点をコピーして立ち上げられる。計画立案時はテンプレートの長期目標もあわせて引用できる。
- **US-6.4** 看護師として、コピー時、患者固有の記述を含みうる項目(目標の具体文言・OTE本文など)に編集推奨アラートが表示される。
- **US-6.5** 看護師として、コピー元の情報(テンプレート名/患者/過去計画)がデータとして記録される。

### E7. 他機能連携

- **US-7.1** 看護師として、月次評価の完了時に評価結果を看護記録に転記できる(US-4.5 と同一機能)。転記は任意で、「転記しない」を選択することもできる。
