#### [us-01] 右サイドバー3パネルのデザイン刷新（ver0.16）

淡色1枚の縦積みパネルから、**白背景カード**（ヘッダーバー付き）に刷新。各パネルは選択中病棟スコープ。

- **入院者情報（ダッシュボード型）**
  - **病床稼働バー**: `稼働ベッド / 総ベッド` ＋ プログレスバー ＋ **稼働率（%）** と **本日日付（M/D 時点）** を併記
  - **患者 / 在院者 / 不在者 の3列**: 各列に人数と男女内訳（1行表示）
  - **状態別チップ（3等分・均等配置）**: **隔離 / 拘束 / 観察**。※ **外出は「不在者」列と重複するためチップからは除外**
  - **平均年齢**: 男 / 女 / 全（歳）
- **入院予定者**: 氏名 ＋ 病室バッジ ＋ 予定日 ＋ `[詳細]`（入院指示）/ `[手続き]`（病室確定済のみ・filled）
- **不在者**: 氏名 ＋ `外出中` チップ ＋ `[詳細]`（外出外泊画面へ）
- 淡色背景の低コントラストを是正し、文字色を濃く調整（design-rules §13.4）

#### [us-01] 入院オーダー・病室割当のライフサイクル（ver0.17）

参考システム（アルファ）は病室割当まで踏み込まない運用のため、本画面は参考システムに準拠せず当院の運用に合わせて表示を整理する（整合が取れなくてよい）。

**入院オーダー時の仕様**

1. **病棟は必須（validation）** — 医師は入院オーダー登録時に病棟を必ず指定する。実装は空値を取れない `Select`（既定は対象患者の病棟／`ward1`）＋ `required` で構造的に担保（[AdmissionOrderDialog](../../src/components/admission/AdmissionOrderDialog.tsx)）。これにより「病棟未割当」は発生しない。
2. **病室の割当状況を色＋アイコン＋文言で判別（病室未割当バッジ）** — 入院予定者パネルの各行に表示。
   - **割当済み**（オーダー時に病室決定）: 青系 ＋ 病室アイコン ＋ `N号室`
   - **未割当**（看護師が病室を決めるまで）: アンバー系 ＋ ？アイコン ＋ `病室未割当`
3. **入院予定の把握** — 各行に予定日を表示。病棟は各パネルのヘッダー（`第1病棟` 等）＝**選択中病棟スコープ**で示す（両病棟の一括表示は行わない＝PM 確定 2026-07-06）。

**用語の整理**

当院の未割当は「病室未割当」または「病棟未割当」のいずれかだが、病棟必須化により後者は発生しない。用語を明確化するため未割当は「**病室未割当**」に統一し、「未割当者」パネル／導線は廃止する。

**入院フロー**

```text
入院オーダー登録（病棟＝必須 / validation）
├─ 病室決定済 → [入院予定者] 病棟・病室（N号室バッジ）・予定日
└─ 病室未決定 → [入院予定者] 病棟・[病室未割当バッジ]・予定日
        │
        ▼ 入院手続き完了（＝入院済み＝病室確定）
   [本入院] ベッドグリッドに配置
        │
        ▼ 外出 / 外泊
   [不在者]
```
