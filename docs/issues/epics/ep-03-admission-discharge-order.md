# [病床管理] 入退院指示

## 概要

主治医による入院・退院の指示発行を、紹介元／紹介先医療機関と紹介経路の情報を含めて記録できるようにする。「指示」と「確定」の二段階運用で、地域医療連携に必要な情報を指示時点で確定させる。

## ゴール

- 主治医がカルテ画面から入院指示・退院指示を発行できる
- 紹介元／紹介先・紹介経路を指示と紐づけて記録できる
- 指示が事務側の入退院手続きにシームレスに連携する
- 「指示」（病棟確定待ち）と「確定」（即時状態変化）を運用に応じて使い分けできる

## スコープ

含む

- 入院指示の発行（紹介元医療機関・紹介経路・入院形態・入院理由・指示内容を含む）
- 退院指示の発行（紹介先医療機関・紹介経路・転帰・退院理由・カルテ記載を含む）
- 「指示」段階での発行（外来患者のまま、未来日付可、病棟が後から確定）
- 「確定」段階での発行（過去・当日のみ、即時状態変化）
- 指示後の変更・中止（削除理由ダイアログ）
- 確定時のオーダ一括中止（外来専用／入院専用、移動・給食、リハビリ）
- 紹介元・紹介先医療機関の検索／治療歴からの複写
- 食事開始・食事終了日の自動設定とずれた期間の食無し／臨時欠食指示自動生成

含まない

- 入退院手続きの確定処理（別エピック）
- 紹介元／紹介先医療機関マスタの保守
- 入院取消・退院取消（入退院歴エピックで扱う）

## 主要画面要素

### 入院指示画面

- 入院日（日付未定可）
- 食事開始日（自動設定／変更時の食無し or 臨時欠食自動生成）
- 病室情報（仮病棟設定可、空床照会ダイアログ）
- 備考、入院時文書（入院形態に応じて表示）
- 紹介元医療機関（検索／治療歴から複写）、紹介経路、入院決定理由（文章生成・文例）
- 入院後の診療、指示内容（カルテ記載）
- 指示箋を印刷するチェック
- 操作ボタン: 入院確定／指示

### 退院指示画面

- 退院日、転帰
- 食事終了日（退院日変更で自動連動／食事を伴わない退院は編集不可）
- 備考、退院時文書（退院後診療区分: 不要／通院／転院）
- 紹介先医療機関（検索／治療歴から複写）、紹介経路、退院決定理由
- 退院後の診療、カルテ記載
- 指示箋を印刷するチェック
- 操作ボタン: 退院確定／指示

### 入退院確定時のオーダ確認ダイアログ

- 指示一覧（中止／継続選択、リハビリは転帰区分必須）
- その他（入院専用オーダ、退院確定で自動削除）
- 中止アイコンによる個別中止（伝票毎に削除理由 or オーダ中止ダイアログ）
- 中止箋・削除箋を印刷するチェック

### 削除理由ダイアログ（指示の中止／取り消し時）

- 分類（マスタで定義、診療録に表示、必須）
- 理由（任意、診療録に表示）
- 削除指示箋を印刷するチェック

## 完了条件

- 全子ストーリーがクローズ
- 紹介元／紹介先・紹介経路が指示と一体で記録される
- 指示が確定すると事務側の入退院手続き候補に表れる
- 指示後の変更・中止が監査可能な形で残る

## 関連

- 業務領域: 病床管理
- 想定ロール: 主治医
- 依存: 患者基本情報、医療機関マスタ（紹介医療機関）、紹介経路マスタ、転帰区分マスタ、期限管理マスタ、表示ラベルマスタ、帳票定義情報マスタ、伝票定義情報マスタ、区分マスタ（削除理由・転帰区分_リハビリ）
- オプション機能: 医療観察法、地域連携（逆紹介）、外部精神科システム連携
