# [隔離拘束] 隔離拘束歴

## 概要

患者の隔離・拘束履歴を時系列で参照できるようにする。誤入力等への対応として履歴の削除も可能とするが、継続・変更指示の有無で削除順序の制約が変わる。

## ゴール

- 患者ごとの隔離・拘束履歴を開始日時降順で確認できる
- 誤登録等への対応として履歴を削除できる（操作者・操作時刻の監査が残る）
- 継続・変更指示の整合性を壊さない削除順序ルールを画面で強制する

## スコープ

含む

- 患者情報／入院歴または病床管理画面からの隔離・拘束歴ダイアログ表示
- 履歴の削除（削除理由ダイアログ経由）
- 削除順序の制約チェックとエラー表示

含まない

- 指示の発行（別エピック）
- 観察記録の入力（別エピック）

## 主要画面要素

### 隔離・拘束歴ダイアログ

| 項目 | 内容 |
| --- | --- |
| 開始日時 | 隔離拘束の開始日時 |
| 終了日時 | 隔離拘束の終了日時。継続方式により表示が変わる |
| 状態 | 隔離拘束種別（隔離／拘束／隔離拘束、開始／継続／変更／解除） |
| 削除アイコン | 削除実行（削除理由ダイアログを経由） |
| 並び順 | 開始日時の降順 |
| 閉じるボタン | ダイアログを閉じる |

### 終了日時の表示ルール

- **「開始」による継続指示**: 前指示の終了時間が新規開始時間の1分前
- **「継続／変更」による継続指示**: 前指示の終了時間と新規指示の開始時間が同時刻

### 削除順序ルール

- **継続・変更を使わない運用**（隔離拘束変更=しない、または「開始」「解除」のみ使用）
  - 「開始」と「終了（解除）」がペアで削除される
  - 継続された開始記事が終了日時以降に存在する場合は削除不可
- **継続・変更を使う運用**
  - 最終指示から逆順でのみ削除可能
  - 削除する履歴以降に変更・継続指示がある場合はエラー（先に後続指示を削除する必要あり）

## 完了条件

- 子ストーリーがクローズ
- 履歴削除が監査ログに残る
- 一覧画面・カルテ・入院歴・病床管理いずれの入口からも本ダイアログへ遷移できる
- 削除順序ルールがUI側でブロックされ、エラーメッセージが分かりやすい

## 関連

- 業務領域: 隔離拘束
- 想定ロール: 主治医、病棟看護師長
- 依存: 隔離拘束指示、観察記録、削除理由マスタ
