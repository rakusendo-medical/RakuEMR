# [外来] 外来 EMR 刷新（カルテ画面統一）

## 概要

外来 EMR の旧画面デザインを刷新し、入院 EMR と **同一のカルテ画面コンポーネント** を共有する設計を確立する。色テーマとタブ可視性で外来／入院を区別し、利用不可機能はグレーアウト + Tooltip で表現する。

参考システム由来の構造を踏襲しつつ、`docs/design-rules.md` v1.1 に従って UI/UX を統一する。

## ゴール

- **画面統一**: 外来／入院で同一の「カルテ画面」コンポーネントを使う（mode 切替で振る舞いを変える）
- **mode 自動判定**: 患者属性（外来／入院ステータス）+ 遷移元（外来一覧／病棟マップ等）から決定
- **グレーアウト + Tooltip**: 利用不可なタブ・アクションは disabled + 「外来では利用しません」等の説明
- **配色一貫**: 外来 = 緑系（success）／ 入院 = 青系（primary）。design-rules.md に明記
- **既存 EP との整合**: 入院系 EP（ep-01〜10）の振る舞いを保ったままカルテ画面を統一段階移行する

## スコープ

### 含む

- 外来一覧（受診患者の表示・絞り込み・選択ベースアクション）
- カルテ画面（タブ式 TOP・mode 判定対応）
- 外来⇄入院 統一カルテ画面（mode='outpatient'/'inpatient'）
- 患者情報サブタブ（基本情報／属性／保険／連絡先／病名／エピソード／メモ）
- 診療録（タブ内・記載・履歴）
- フローシート（タブ内・既存 ep-10 と共有）
- 指示簿（タブ内）
- 指示状況（タブ内）
- スケジュール（タブ内）
- オーダー管理（処方／注射／検査／処置／テキスト）

### 含まない

- 入院 EMR の既存 EP（ep-01〜14）の振る舞い変更（後続段階で順次刷新）
- マスタ管理画面（別エピック）
- 受付・会計の業務 UI（外部システム連携で扱う想定）

| タブ | 外来 | 入院 | 備考 |
| --- | --- | --- | --- |
| 診療録 | ○ | ○ | 既定タブ。クリニカルノート閲覧／記載 |

凡例：○ = 表示・操作可、△ = 表示するが disabled

## mode 判定ロジック

1. **患者属性ベース（既定）**: 患者が外来受診中なら `outpatient`、入院中なら `inpatient`
2. **遷移元ベース（オーバーライド）**:
   - 外来一覧（`/outpatient`）から遷移 → `outpatient`
   - 病棟マップ（`/`）／入院患者一覧（`/patients`）から遷移 → `inpatient`
3. **両者が矛盾する場合**: 遷移元を優先（業務文脈を尊重）

## デザインルール統合

- `docs/design-rules.md` §11（新設予定）: mode 切替 + グレーアウト + Tooltip パターンを言語化
- 外来テーマ = `color="success"`、入院テーマ = `color="primary"` を踏襲
- ステータス Chip は `§7.1 ステータス Chip + アイコン併用` に従う

## 完了条件

- 配下ストーリー（us-32〜）が全てクローズ
- 外来一覧 → カルテ画面 → 各タブの遷移が確立
- mode 自動判定が患者属性 + 遷移元で動作
- グレーアウト + Tooltip で利用不可機能を一貫して表現
- design-rules.md §11 に mode 切替パターンが記載
- 入院 EP（ep-01〜10）のリグレッションがない（段階 3 で確認）
