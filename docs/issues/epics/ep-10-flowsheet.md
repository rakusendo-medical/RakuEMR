# [看護] 看護実施

## 概要

フローシートを中心に、バイタル計測・ケア記録・看護記録・サインなど、病棟看護師の日々の実施記録業務を担うエピック。個別入力（フローシート上）と一括入力（病棟・病室単位）の両系統を整備し、フローシートパターンで患者状態に応じた表示項目切替もサポートする。

## ゴール

- フローシートを起点に、患者ごとの実施状況・行動制限・オーダ予定を一画面で扱える
- 個別／一括の両入力でバイタル・ケア・看護記録を効率的に登録できる
- 患者状態に応じたフローシートパターンを切り替えて、不要項目を出さない
- バイタル・フローシート・サインの更新履歴を追跡できる

## スコープ

含む

- フローシート画面の7日分表示・参照（バイタルグラフ・予定オーダ・実施確認・検査結果グラフ・移動状況・看護記録・サイン）
- フローシート編集（ケア内容・服薬等、パターン適用に応じた項目）
- バイタル個別入力・更新・履歴表示（時間・BP上下・R・P・T・S・W・記録者）
- サイン入力（深夜・日勤・準夜の3勤務帯、変更・削除可）
- フローシートからの看護記録新規作成・参照（看護記録ダイアログ）
- フローシートパターンの新規適用・変更・削除・履歴参照
- 一括バイタル入力（病棟・病室単位）
- 一括睡眠活動入力（病棟・病室単位）
- 一括看護記録（病棟・病室単位）
- 入力切替タブ（フローシート／隔離拘束／睡眠・活動／観察）

含まない

- 看護診断・看護計画・看護評価（別エピック）
- 隔離拘束観察記録（隔離拘束エピックで扱うが、フローシート上の入力切替タブからアクセス可能）

## 主要画面要素

### フローシート画面

- 入力切替タブ: フローシート／隔離拘束／睡眠・活動／観察（観察は医療観察法対象者のみ）
- 表示日: 入力日を最終日として7日分（入院患者: 操作日含む前1週間／外来患者: 操作日と記録記載のある過去日合計7日）
- 表示日調整リンク: 当日／＜／＞／＜＜（7日前）／＞＞（7日後）
- 在院日数表示
- パターンボックス（全パターン／適用パターン名で表示切替）
- フローシートアイコン（編集ダイアログを開く）／バイタルアイコン（バイタル編集を開く）
- 移動状況表示部: 病室／隔離／拘束／行動制限（その他）／外出・外泊（オレンジ背景で期間表示、ホバーでツールチップ）
- 体温表（バイタル測定値グラフ、クリックで拡大）
- 予定オーダ（オーダ種名1文字表示、未実施=赤字／実施済=グレー、背景オレンジ=実施あり）
- 「一覧」リンクで操作日1ヶ月の指示状況ダイアログ（参照のみ）
- 予定オーダクリックで実施確認表ダイアログ（未実施オーダ実施可）
- 検査結果（過去実施検査の結果グラフ表示、項目はフローシート画面の[設定]で指定）
- 看護記録欄（新規作成リンク、タイトルクリックで看護記録ダイアログ）
- サイン欄（深夜・日勤・準夜）
- 未来日入力不可設定時は未来時間枠が非活性

### フローシート編集ダイアログ

- 適用パターンのケア項目を入力
- 体重はバイタル編集ダイアログで入力（ここでは入力不可）
- 投薬者の初期表示（空白／ログオン者）はマスタで設定
- 禁則文字: `#` `@` 等
- 更新履歴一覧（登録日時・職員・区分、降順）／履歴クリックでフローシート履歴ダイアログ（参照のみ）

### バイタル編集ダイアログ

| 項目 | 内容 |
| --- | --- |
| 時間 | HH:mm（必須） |
| BP（上） | 血圧（上） |
| BP（下） | 血圧（下） |
| R | 呼吸数 |
| P | 脈拍 |
| T | 体温 |
| S | SpO2 |
| W | 体重 |
| 記録者 | 登録時に操作者自動入力 |

複数行を時間順に関係なく入力でき、表示時は時間順に自動ソート。時間未入力行は削除扱い。更新履歴一覧で過去の登録・更新を時系列降順で確認可能（時間単位で操作=登録／更新を判定）。

### サイン入力ダイアログ

- 深夜・日勤・準夜の勤務帯ごと
- 初期表示はログオン者（マスタでログオン者以外も表示可）
- 登録・更新・削除（削除は確認ダイアログ）
- 未来日勤務帯はマスタ設定で選択不可

### フローシートパターン変更ダイアログ

- 開始日とパターンを指定して適用
- 適用日以降のケアメニュー入力データは削除される（確認メッセージあり）
- 同日内で複数パターン適用可（日内パターン数分の行）
- 履歴参照: フローシートパターン編集履歴ダイアログ

## 完了条件

- 全子ストーリーがクローズ
- 個別／一括の入力結果が同一データモデルに帰着し、片方の更新がもう片方の表示に即時反映される
- フローシートパターン切替で表示項目と入力可能項目が連動する
- 行動制限有無、オーダ予定、検査結果がフローシート上から確認できる
- バイタル・フローシート・サインに更新履歴が時系列で残る
