# [看護] 看護評価

## 概要

看護計画に対する評価運用を担うエピック。評価項目の事前立案、定期評価の登録・参照、特記報告／カルテ記事連携を扱う。立案なしでも初期選択評価項目で評価登録できる柔軟性を備える。

## ゴール

- 評価登録時に使用する評価項目を計画ごとに立案できる
- 立案した項目に沿って定期評価を登録・参照・更新・削除できる
- 評価結果を特記報告・カルテ記事として連携できる
- 立案を省略しても初期選択評価項目で評価できる

## スコープ

含む

- 評価項目の立案（評価項目選択ダイアログ）
- 定期評価の登録（評価レベル・評価内容・添付ファイル）
- 定期評価の更新・削除
- 立案なしの評価登録（初期選択評価項目）
- 特記報告での報告先連携
- カルテ記事作成連携

含まない

- 看護計画（別エピック）
- 看護診断（別エピック）

## 主要画面要素

### 評価画面

- 計画明細毎の評価項目領域
- 評価項目選択アイコン（白抜き=未登録、登録済=色変）
- 評価レベルの評価点数合計
- 評価内容詳細（評価レベル、レベルコメント、添付ファイル、評価内容、備考）
- 添付ファイルアイコン（クリックでダウンロード）

### 評価項目選択ダイアログ

- 選択可能な項目一覧（マスタ保守／定期評価項目セット／定期評価項目マスタを参照）
- 評価項目を選択して [設定] で立案

### 評価入力ダイアログ

- 評価レベル（マスタ管理）／評価内容／添付ファイル
- 特記報告チェック → 特記報告ダイアログで報告先（初期: 主治医）と種別（[作]作成／[確]確認／[両]両方）を設定。所見に計画明細・評価内容が取り込まれる
- カルテ記事作成チェック → ログオン者の標準診療種類に応じたカルテ記事作成ダイアログ（看護記録の場合はフリー形式に評価内容取込）。チェック時は特記報告は非活性

## 完了条件

- 全子ストーリーがクローズ
- 立案した評価項目が定期評価入力画面で選択肢として表れる
- 過去の定期評価を時系列で参照できる
- 特記報告／カルテ記事作成連携が機能する
