# [隔離拘束] 観察記録

## 概要

行動制限下の患者に対する観察記録を、患者個別（フローシート上）／病棟一覧上の一括（隔離拘束一覧の記録タブ）の両方で運用できるようにする。観察頻度の高い病棟業務に対応し、状態色・連携・記事タグなどの記録支援機能を備える。

## ゴール

- 患者個別の詳細な観察記録をフローシートから残せる
- 病棟一覧から複数患者の観察を効率的に一括入力できる
- 個別／一括どちらの入力経路でも同一データモデルに収まり、更新が双方向に反映される
- 観察項目が指示種別（隔離／拘束／その他）に応じて切り替わり、回数（分割数）も区分ごとにマスタで制御できる

## スコープ

含む

- フローシート／隔離拘束タブでの個別観察記録の作成・更新
- 隔離拘束一覧／記録タブからの一括観察記録（区分単位／時間・回数単位）の入力
- 観察記録ダイアログの状態選択・内容入力（文例ウィザード／内容一括入力／記事タグ）
- 連携設定（看護記録連携・報告先指定）
- 観察回数の追加（[追加] による1時間あたりの分割数増）
- 同一時間帯で隔離と拘束が重複する際の拘束優先表示
- 開放時間アイコンの表示と一括入力時の解放時間ハイライト

含まない

- 行動制限指示そのもの（別エピック）
- 履歴参照（別エピック「隔離拘束歴」）
- 隔離拘束一覧の指示タブ機能（別エピック「隔離拘束一覧」）

## 主要画面要素

### フローシート／隔離拘束タブ（個別）

- 共通情報欄（フローシート共通）
- 診察記事[絞込設定]（伝票定義情報マスタの隔離拘束記事カウント対象を絞込）
- 観察記録マトリクス（1時間枠×観察回数）
  - 入力対象外: グレー背景、未記入: 白背景、登録済: 状態色
  - 入力可能枠ホバーで時間・制限内容（隔離拘束／その他）・回数のツールチップ
  - 未来日入力不可設定時は未来時間枠が非活性
- 開放時間アイコン（隔離・拘束開始指示で開放時間設定時のみ）
- 凡例

### 観察記録ダイアログ（個別／一括共通の入力ダイアログ）

| 項目 | 内容 |
| --- | --- |
| 日付・患者 | 選択時間枠の日時／患者番号・氏名・年齢・病棟 |
| 選択 | 登録対象チェック（[全選択] あり） |
| 時間 | 1時間を観察回数で分割した開始時間が初期表示 |
| 状態 | 隔離拘束状態マスタ（色／生成文）に基づく選択。状態選択で状態色設定＋処方処置に状態コメント自動記載 |
| 内容 | 観察所見（最大3000文字）。文例ウィザード／タグ一覧から記事タグ登録／タイトルの[入力]で内容一括入力ダイアログ |
| 連携 | [未連携]/[連携あり]→連携設定ダイアログ（看護記録連携、報告先・作成依頼／確認依頼／両方） |
| 削除 | 行を削除（観察回数減） |
| 追加 | 1時間の記録回数を増やす（追加すると当該時間内の開始・終了時間が自動再計算） |

### 隔離拘束一覧／記録タブ（一括）

- 検索条件: 日付、病棟、入院形態（条件設定ダイアログ）、診察記事絞込（絞込設定ダイアログ、伝票定義情報マスタの隔離拘束カウント対象が選択状態の伝票がデフォルト）
- 一覧列: 患者情報（区分・開始日時～終了日時、カルテアイコン）、診察（[未]/[診察記事数]）、隔離回数枠／拘束回数枠／その他回数枠、隔離拘束状態（時間枠ごと）、開放時間アイコン、凡例
- 区分単位の一括入力: タイトルの回数枠クリック → 一括入力ダイアログ（区分・時間・回数の患者のみ表示）
- 患者個別の入力: 時間枠クリック → 観察記録ダイアログ（個別）
- 表示対象患者は「指示」タブとは異なり「観察記録の記録対象」条件が追加される

### 表示対象患者の条件（記録タブ）

| 条件 | 区分 |
| --- | --- |
| 隔離・拘束の指示あり | 隔離／拘束／隔・拘 |
| 入院病棟が行動制限判定対象 ＋ 観察記録の記録対象 | その他 |
| 行動範囲の指示あり：責任レベルが行動制限判定対象 ＋ 観察記録の記録対象、または、行動制限項目が観察記録の記録対象 | その他 |

## 完了条件

- 全子ストーリーがクローズ
- 個別／一括どちらの入力経路でも同じデータモデルに記録される
- 個別画面の更新が一括画面の表示に即時反映され、その逆も成立する
- 観察項目（回数・状態色・連携項目）が指示内容に応じて切り替わる
- 一括入力時に未来日不可設定が反映され、入力可能患者のみ表示される
