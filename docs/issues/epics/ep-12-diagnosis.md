# [看護] 看護診断

## 概要

看護計画画面から呼び出す看護診断ダイアログで、領域診断の一覧から候補を選定し、診断項目の編集を経て確定する。確定した診断は看護計画明細として連携される。検索・セット・履歴の3機能を備え、過去診断の継続活用も可能とする。

## ゴール

- 患者状態を踏まえた看護診断を体系的に作成できる
- 過去の診断履歴・看護診断セットを再活用できる
- 診断確定から看護計画明細生成までを一連で完了できる

## スコープ

含む

- 看護診断ダイアログでの診断作成・確定
- 検索／セット／履歴の3タブ機能
- 診断候補の設定・クリア
- 診断詳細（大分類・小分類・項目）の編集・追加・削除
- 適用日指定による看護計画明細生成

含まない

- 看護計画の長期目標管理（別エピック）
- 看護評価（別エピック）

## 主要画面要素

### 看護診断ダイアログ

| 機能 | 内容 |
| --- | --- |
| 検索 | キーワード検索（診断指標、複数AND条件）、空文字で全件、「候補のみ表示」「診断候補のクリア」可 |
| セット | 看護診断セットマスタから選択、セット内表示、候補のみ表示、候補クリア |
| 履歴 | 過去登録診断の参照・編集（変更・削除・追加） |
| 診断閲覧 | 領域診断一覧、選択アイコンで候補化、項目件数表示 |
| 診断詳細内容編集 | 大分類・小分類・項目。項目は編集・削除・追加（編集／削除／確定／中止アイコン） |
| 診断確定 | 詳細内容を看護診断として確定 |
| クリア | 候補内容を破棄、マスタから再取得 |
| 閉じる | 候補を保存して閉じる（×等での閉じはチェック内容破棄） |
| 適用日／適用ボタン | 選択診断から看護計画明細を作成 |
| 候補のみ表示 | 候補診断のみ閲覧表示 |
| 診断候補のクリア | 候補内容を初期化（全候補クリア） |
| 前回診断候補選択情報 | 前回候補選択日時・操作者の表示 |

### 診断項目アイコン

| アイコン | 動作 |
| --- | --- |
| 編集 | 項目をテキストエリアに変更 |
| 削除 | 項目を削除 |
| 確定 | テキストエリア編集の確定 |
| 中止 | 編集内容を破棄 |

### 診断候補の設定操作

- チェックボックス選択／項目編集／項目削除／項目追加 のいずれかで候補化
- 「閉じる」で候補確定、別の閉じ方では破棄

## 完了条件

- 子ストーリーがクローズ
- 検索・セット・履歴の3タブで等価に診断候補を選定できる
- 確定後、看護計画明細として連携される
- 過去診断履歴の編集・更新・削除が監査可能

## 関連

- 業務領域: 看護
- 想定ロール: 受け持ち看護師
- 依存: 看護診断マスタ、看護診断セットマスタ、看護計画
