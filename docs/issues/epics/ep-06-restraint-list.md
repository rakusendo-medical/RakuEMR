# [隔離拘束] 隔離拘束一覧

## 概要

隔離拘束およびその他の行動制限下にある患者を一覧化し、看護師長等の管理者が病棟全体の状況を把握できるようにする。指示状況・カルテ記事・看護記録・指示受けサインの管理と、行動制限一覧性台帳の出力を担う。

## ゴール

- 行動制限下の患者を病棟横断で一覧把握できる
- 指示・カルテ記事・看護記録・指示受けサインの状態を一覧から確認・操作できる
- ガバナンス警告（精神保健指定医以外による指示、12時間超過）を可視化する
- 法令・規程要請の「行動制限一覧性台帳」を一覧画面から出力できる

## スコープ

含む

- 行動制限下患者の一覧表示（指示タブ）
- 検索条件指定（期間／病棟／終了者除外／入院形態フィルタ）
- 一覧からのカルテ記事作成・編集（開始／終了）
- 一覧からの看護記録作成・編集（開始／終了、カルテ済が前提）
- 指示受けサインの登録・変更・削除（一次／二次）
- 行動制限一覧性台帳の Excel 出力

含まない

- 行動制限指示そのもの（別エピック「隔離拘束指示」）
- 観察記録の一括入力（別エピック「観察記録」、隔離拘束一覧の「記録」タブ）

## 主要画面要素

### 隔離拘束一覧画面（指示タブ）

- 切替タブ: 指示／記録（初期は指示）
- 検索条件
  - 期間（初期: 操作日〜操作日）
  - 病棟（初期: 全病棟）
  - 終了者を表示しないチェック
  - 入院形態（条件設定ダイアログで指定、その他患者用）
- 操作ボタン: 表示／印刷（行動制限一覧性台帳）

### 隔離拘束患者一覧（指示タブ）

| 列 | 内容 |
| --- | --- |
| 患者番号 | クリックで転棟・転室ダイアログ |
| 氏名（年齢） | カルテアイコンで標準診療種類画面へ |
| 入院形態 | ヘッダクリックで並び替え（入院形態→病棟→病室→ベッド） |
| 区分 | 隔離／拘束／隔・拘／その他 |
| 開始日時 | 精神保健指定医以外で12時間超過時赤字 |
| 開始指示医 | 精神保健指定医=黒字、以外=赤字 |
| カルテ（開始） | [未]→作成ダイアログ／[済]→編集ダイアログ |
| 看護（開始） | カルテ済の場合のみ作成可 |
| 指示受け（開始） | 上段一次／下段二次、サイン入力ダイアログ |
| 終了日時 | 継続・変更指示で「-」表示 |
| 終了指示医 | 開始と同じ色分けルール |
| カルテ（終了） | 開始と同じ |
| 看護（終了） | 開始と同じ |
| 指示受け（終了） | 開始と同じ |

並び順初期値: 病棟→病室→ベッド昇順

### 表示対象患者の条件

| 条件 | 区分 |
| --- | --- |
| 隔離・拘束の指示あり | 隔離／拘束／隔・拘 |
| 入院病棟が行動制限判定対象 | その他 |
| 行動範囲の指示あり（責任レベルが行動制限判定対象 or 行動制限項目が観察記録の記録対象） | その他 |

### サイン入力ダイアログ

- 職員名選択（ログオン職員初期表示）、登録／更新／削除

### 行動制限一覧性台帳（Excel）

- 期間の開始日に該当する月を対象月として出力
- 患者単位で累計時間・継続最大時間を集計（タグ: 隔離累計時間／隔離継続最大時間／拘束累計時間／拘束継続最大時間 を日次01〜31で展開）
- レイアウトはマスタ保守／文書キャビネット／行動制限／行動制限一覧性台帳で設定

## 完了条件

- 全子ストーリーがクローズ
- 一覧から指示・観察記録・サインへの遷移が可能
- 台帳出力フォーマットが院内規程を満たす
- ガバナンス警告（赤字表示）が業務運用上有効に機能する

## 関連

- 業務領域: 隔離拘束
- 想定ロール: 病棟看護師長、病棟看護師
- 依存: 隔離拘束指示、観察記録、職員マスタ、病床管理マスタ（行動制限判定）、責任レベルマスタ、行動制限項目マスタ、文書キャビネットマスタ
