# [看護] 看護計画

## 概要

長期目標を軸に看護計画を期間単位で立案・運用するエピック。長期目標配下に複数の「看護計画明細」を持ち、登録・更新・削除を行う。同一期間に複数計画を持たせない制約を満たし、看護記録・看護診断との連携を提供する。

## ゴール

- 長期目標として看護計画を期間単位で新規作成・更新・削除できる
- 長期目標内に複数の明細を登録・更新・削除できる
- 同一期間に複数計画が並立しないことを保証する
- 看護診断・テンプレート・看護記録と連携できる

## スコープ

含む

- 看護計画（長期目標）の新規作成・更新・削除
- 期間管理（継続中チェック・終了日入力）
- 「前回の計画を引き継ぐ」での履歴コピー
- ラベルパターン（パターン1／2）の選択
- 計画明細の追加（[新規追加]／[テンプレートより追加]／[看護診断より追加]）
- 計画明細の更新・削除・並び替え
- 看護記録の作成（FOCUS連携時の自動関連付け含む）
- 評価画面への遷移（最終評価日リンク）

含まない

- 看護診断ダイアログの内部仕様（別エピック）
- 看護評価（別エピック）
- アセスメント機能

## 主要画面要素

### 看護計画画面

- 表示する計画の選択（期間プルダウン、[表示]、[保守]）
- 問題点タブ
- 看護記録の作成リンク
- 長期目標表示（マスタで名称・表示有無を制御）
- 計画明細領域（追加・並び替え・修正）
- 最終評価日（または「評価無し」、クリックで評価画面）

### 看護計画新規入力ダイアログ

- 期間開始日
- 長期目標
- ラベルパターン（パターン1／2）
- 継続中チェック
- 終了日（継続中外し時に入力）
- 「前回の計画を引き継ぐ」チェック（履歴がある場合のみ表示）

### 看護計画編集ダイアログ

- 既存項目の更新
- [更新] / [削除]

### 看護記録ダイアログ（看護計画から）

- FOCUS形式時: タイトルに「No と診断」、A欄に介入を自動設定
- 同看護計画の場合は自動関連付け

## 完了条件

- 全子ストーリーがクローズ
- 期間重複時にエラー表示し保存させない
- 明細単位の更新履歴が確認できる
- 最終評価日リンクから評価画面へ遷移できる
