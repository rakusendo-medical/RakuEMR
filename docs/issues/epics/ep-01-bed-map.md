# [病床管理] 病棟マップ

## 概要

病棟ごとの病床配置と入院患者の在床状況を一画面で把握し、ベッドの割り当て・移動・カルテ参照といった日常運用を病棟マップ上から完結できるようにする。

## ゴール

- 病棟運用に必要な情報（在床患者・空床・未割当患者・入退院予定・外出泊・稼働率等）を一画面で確認できる
- 病床操作（割り当て／移動）と患者操作（カルテ遷移）の起点となる
- 他エピックの機能（入退院手続き、空床照会、外出外泊、入退院情報）への入口を提供する

## スコープ

含む

- 指定病棟の患者一覧・空床表示
- 病床移動（病棟内・病棟間、新規・変更・削除）
- ベッド未指定患者へのベッド割り当て
- 患者カルテへの画面遷移（および隣接患者への遷移）
- 患者ステータスの一覧上での可視化（隔離・拘束・外出泊・要報告・預り金 等の凡例表示）

含まない

- 入退院手続きの確定処理（別エピック「入退院手続き」）
- 入退院指示の発行（別エピック「入退院指示」）
- 隔離拘束の指示・観察（隔離拘束系エピック）

## 主要画面要素

- 病棟選択はタブ形式で対応
    - 既に仮実装済み
- 空床照会ボタン（カレンダー形式の空床照会ダイアログを開く）
    - 既に仮実装済み
- 未割当者一覧（病棟・病室・ベッドのいずれかが「仮」の患者）
- 入退院予定一覧（入院／退院をタブ切替、選択で入院手続き／退院手続き画面へ遷移）
- 不在者一覧（外出・外泊中）
- 入退院情報（表示病棟の入院患者情報サマリ）
- ベッドマス（在床患者氏名・性別・主治医等を表示、使用不可ベッドはグレー網掛け）
- 患者ステータスアイコン凡例（隔離・拘束・外泊・外出・要報告・預り金など）

## 完了条件

- 全子ストーリーがクローズ
- 病棟看護師長が朝礼前に病棟マップだけで在床確認・割当作業を完了できる
- 主要操作（移動／割当／遷移）がベッドのコンテキストメニューから3クリック以内で実行できる

- 依存: 患者基本情報、病床マスタ（病棟・病室・ベッド）、入退院オーダ
