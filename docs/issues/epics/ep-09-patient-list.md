# [共通] 患者情報

## 概要

入院患者の一覧画面を提供し、日付・病棟・主治医・担当職員フィルタで日々の業務開始時に必要な患者集合を素早く取り出せるようにする。一覧から各機能（カルテ、報告、診察終了等）への入口を担う共通基盤エピック。

## ゴール

- 入院中の患者集合を一覧で参照できる
- 担当職員・主治医・病棟フィルタで自分の関与する患者をすぐ表示できる
- 検索条件をセッション中保持して再表示の手間を減らす
- 一覧から各機能（カルテ、報告一覧、診察終了等）へ遷移できる

## スコープ

含む

- 入院患者の一覧表示と検索条件指定
- 担当職員（1〜10）による絞り込み（全てに一致／いずれかに一致）
- 主治医・診察医・病棟・日付による絞り込み
- 一覧からのカルテ画面遷移、診察終了の操作、報告一覧遷移
- 検索条件の保持（ログアウトまで）

含まない

- 病床配置の可視化（別エピック「病棟マップ」）
- カルテ詳細・看護記録の編集
- 外来患者一覧（別画面）

## 主要画面要素

### 検索条件

| 項目 | 内容 |
| --- | --- |
| 日付 | 表示対象日（カレンダーダイアログで選択） |
| 病棟 | プルダウン（初期は全病棟） |
| 主治医 | プルダウン（ログオン職員=医師時は自分が初期選択） |
| 職員 | 担当職員1〜10での絞り込み。条件設定で職員選択ダイアログを開き「全てに一致／いずれかに一致」を指定。複数選択時は「、」区切り、超過分はツールチップ |
| 診察医登録分も表示 | チェック時、主治医に加え診察医として登録されている患者も含む |

### 一覧列

| 列 | 内容 |
| --- | --- |
| 病棟・病室 | タイトルクリックで病棟・病室順に並び替え（順序は病床管理マスタ） |
| 患者番号 | クリックでカルテ画面へ |
| 氏名（年齢） | 性別アイコン・氏名・年齢・患者状態色・カルテアイコン（標準診療種類画面へ遷移） |
| 入院日 | 入院開始日と入院日数。ヘッダクリックで日数降順並び替え |
| 入院形態 | 入院形態と開始日（直近、形態変更後の値） |
| ICD10・病名 | 主病名（ウィンドウ幅1100px未満で非表示） |
| 責任レベル | ウィンドウ幅1100px未満で非表示 |
| 報告 | 報告記事ありで報告アイコン表示、クリックで報告一覧へ |
| 主治医 | ヘッダクリックで主治医順並び替え |
| 終了 | 診察終了状態アイコン／クリックで診察終了・解除（ツールチップで職員名・時刻） |

### 検索条件の保持

- ログアウトまで検索条件は保持される
- 別メニューから戻ると前回検索条件で再表示される

## 完了条件

- 子ストーリーがクローズ
- 担当職員フィルタが「全てに一致／いずれかに一致」で動作する
- 一覧から各機能への遷移が確立する
- 画面幅変動時に列の表示・非表示が自動切替される

## 関連

- 業務領域: 共通
- 想定ロール: 病棟看護師、主治医
- 依存: 患者基本情報、職員マスタ（担当職員1〜10）、病床管理マスタ、報告一覧、診察終了状態、診療種類マスタ
