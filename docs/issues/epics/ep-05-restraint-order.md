# [隔離拘束] 隔離拘束指示

## 概要

精神科病棟等で必要となる隔離・拘束について、開始・解除・継続・変更の各操作を主治医が指示として記録できるようにする。法令・院内規程に基づく行動制限の起点を担うエピック。指示と同時に告知書（隔離拘束指示箋）の印刷もサポートする。

## ゴール

- 主治医が隔離・拘束（および両者併用）の開始／解除／継続／変更を指示として記録できる
- 指示時点の理由・期間・拘束部位・開放時間が一貫したフォーマットで記録される
- 指示と同時に告知書を印刷でき、内容も指示時に編集可能とする
- 指示が一覧画面・観察記録・履歴・スケジュールに即時反映される

## スコープ

含む

- 隔離指示（開始・解除）／拘束指示（開始・解除）／隔離拘束指示（開始・解除）
- 継続・変更指示（マスタ設定有効時、隔離・拘束・隔離拘束それぞれ）
- 拘束部位の入力（拘束・隔離拘束系の開始／継続／変更）
- 開放時間の入力（最大9件、テンプレート対応）
- 期限管理対象の隔離拘束時文書チェック
- 告知書（隔離拘束指示箋）の印刷と内容編集

含まない

- 観察記録の入力（別エピック「観察記録」）
- 一覧台帳の出力（別エピック「隔離拘束一覧」）
- 履歴参照（別エピック「隔離拘束歴」）
- カルテ記事の他の指示種類（別領域）

## 主要画面要素

### カルテ画面の指示リンク（診療録）

- 開始／解除: [隔離開始] [隔離解除] [拘束開始] [拘束解除] [隔離拘束開始] [隔離拘束解除]
- 継続／変更: [隔離継続] [隔離変更] [拘束継続] [拘束変更] [隔離拘束継続] [隔離拘束変更]（マスタ設定で有効化）

### カルテ記事作成ダイアログ（隔離拘束指示）

- 開始日時／終了日時
- タイトル（隔離／拘束／隔離拘束 × 開始／継続／変更／解除）。タイトル変更で表示項目が連動
- 拘束部位（拘束・隔離拘束の開始／継続／変更指示時のみ、マスタ管理、解除指示には記載されない）
- 現在開放閉鎖区分（後方互換のみ残置、2017年以降は入力不要）
- 開放時間（開始・継続・変更指示時のみ、最大9件、テンプレート読込・追加・削除可、開始時間以前は不可）
- 文書チェック（タイトル「開始」時のみ表示、隔離拘束区分・入院形態に応じて期限管理マスタが定義する文書）
- 告知書を印刷するチェック（マスタで表示・名称・初期チェックを制御）

### 隔離拘束指示箋印刷ダイアログ

- 指示日、開始日時、面接フォーム、内容（カルテ所見が初期表示、文例機能あり）
- 印刷／閉じる（閉じるは印刷せず指示のみ確定）
- 再印刷時は内容変更不可

## 完了条件

- 全子ストーリーがクローズ
- 開始・解除・継続・変更が同一ダイアログで扱える
- 拘束部位・開放時間がカルテ記事に反映される（解除記事に拘束部位は記載しない）
- 指示が以下に即時反映される
  - 患者ヘッダー（隔）（拘）（隔拘）アイコン表示（カルテ再表示後）
  - フローシート／隔離拘束タブの状態表示と観察記録入力可
  - 隔離・拘束歴ダイアログ
  - 患者スケジュール
  - 病床管理画面・隔離拘束一覧画面のアイコン表示

## 関連

- 業務領域: 隔離拘束
- 想定ロール: 主治医
- 依存: 患者基本情報、カルテ記事、拘束部位マスタ、隔離拘束時文書マスタ（期限管理）、開放時間テンプレート、表示ラベルマスタ、帳票定義情報マスタ、面接書式マスタ
- オプション/前提: 電子カルテ運用での操作（オーダリング運用時は病床管理／移動からの開始・解除を別途検討）
