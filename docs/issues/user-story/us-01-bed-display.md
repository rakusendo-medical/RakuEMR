# [病床管理] 病床表示

## ユーザーストーリー

- **As a** 病棟看護師長
- **I want** 担当病棟の病床配置と在床患者を一画面で確認したい
- **So that** 申し送り前に在床状況と空床を即座に把握できる

## 受け入れ基準

### 病棟を選択して在床患者が表示される

- **Given** 病棟マップを開いている
- **When** 病棟プルダウンから病棟を選択し「表示」を実行する
- **Then** 当該病棟のベッド配置がレイアウト通りに表示され、稼働中ベッドには在床患者の氏名等の基本情報が表示される

### 使用不可ベッドが視覚的に区別できる

- **Given** 病棟マップで病棟を選択している
- **When** 病棟内に使用不可（または存在しない）ベッドがある
- **Then** 当該ベッドはグレー網掛けで表示される

### 患者ステータスがアイコンで一覧把握できる

- **Given** 病棟マップを表示している
- **When** 患者に隔離・拘束・外出・外泊・要報告・預り金などのステータスが付与されている
- **Then** 各ベッドマス内に該当アイコンが表示され、画面上の凡例で意味が確認できる

### ベッドから操作メニューを呼び出せる

- **Given** 病棟マップを表示している
- **When** 患者名をクリックする
- **Then** 画面下部に患者情報と操作リンク（移動・カルテ遷移など）が表示される

### 関連機能の入口が同一画面から呼び出せる

- **Given** 病棟マップを表示している
- **When** 空床照会／未割当者一覧／入退院予定一覧／不在者一覧／入退院情報のいずれかを選択する
- **Then** 該当機能のダイアログ・画面に遷移する（空床照会はカレンダー形式の空床状況、入退院予定は入院／退院をタブ切替）

> 空床照会の反映ルール（未確定の入退院指示を予定日基準で反映する）は [入院指示](./us-08-admission-order.md) を参照。

## 補足

- 表示項目はマスタ管理（性別・年齢の表示有無、主治医表示有無など）を後続課題で検討
- 別メニュー表示後に再度病棟マップに戻った際、前回表示していた病棟が初期表示される挙動を踏襲するか別途検討
