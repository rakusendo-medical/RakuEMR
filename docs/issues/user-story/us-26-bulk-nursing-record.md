# [看護] 一括看護記録

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 病棟・病室・記録日を指定して、複数患者の看護記録（SOAP／経時記録）を勤務帯・時間・本文・連携・公開設定とともに一括入力したい
- **So that** 同様の所見が複数患者にまたがる場合に、効率的に記録できる

## 受け入れ基準

### 検索条件で対象を絞り込める

- **Given** 一括入力メニューから看護記録画面を開いている
- **When** 日付・病棟・病室を指定して [表示] をクリックする
- **Then** 該当範囲の患者リストが表示される

### 記事タイトルと記事形式を設定できる

- **Given** 一括看護記録画面を表示している
- **When** 記事タイトルを入力し、記事形式（SOAP／経時記録）を選択する
- **Then** 入力形式の初期値はマスタ保守／医療機関情報／その他／部門側記事形式に従う。記事タイトルは全患者共通

### 勤務帯を一括設定できる

- **Given** 患者リストの勤務帯欄を表示している
- **When** タイトル部の勤務帯をクリックして勤務帯設定ダイアログを開き、任意の勤務帯を選択し [設定] する
- **Then** 一覧の勤務帯が一括設定される（個別変更は可）。勤務帯はマスタ保守／医療機関情報／看護の日勤／準夜／深夜開始時間で判定

### 時間を一括設定できる

- **Given** 患者リストの時間欄を表示している
- **When** タイトル部の時間をクリックして時間設定ダイアログを開く
- **Then** 現在時刻が初期値で表示される。時間を変更または初期値のまま [設定] すると一覧時間が一括設定され、勤務帯も自動連動。空白のまま登録するとエラー

### 本文を一括入力できる

- **Given** 患者リストに同形式の患者が複数存在する
- **When** タイトル部 [入力] をクリックして一括入力ダイアログを開き、本文を入力（テンプレート [呼出] ／文例ウィザード使用可）し [登録] する
- **Then** 同じ書式を選択している患者の本文に一括反映される

### 個別に本文を編集できる

- **Given** 一括入力後、特定患者だけ本文を調整したい
- **When** 該当行の本文欄で [文例] または直接入力する
- **Then** 当該患者のみ個別編集される

### 連携を設定できる

- **Given** 患者行の連携欄で [未連携] または [連携有] をクリックする
- **When** 連携設定ダイアログで連携先（フローシート／申し送り／病棟日誌／報告先など）にチェックして [登録] する
- **Then** 連携が反映され、一括登録時に該当連携先で記事が表示される

### 公開／非公開を切り替えできる

- **Given** 各患者行の公開チェックを操作する
- **When** チェック有り／無しで登録する
- **Then** 公開有り: 全職員参照可。無し: 記載職員のみ参照可

### 選択チェックで対象患者のみ登録できる

- **Given** 患者リストに入力済み複数患者がいる
- **When** 選択チェックを入れた患者で [登録] する
- **Then** チェック有り患者の看護記録のみ登録される。[全て選択] [クリア] で一括操作可

### 記録状態の表示と新規作成可否

- **Given** 患者リストの記録欄を確認している
- **When** 表示日付の看護記録回数を表示する
- **Then** 該当日付に記録がなければ [未] と表示。1回以上ある場合は数値が表示され、クリックすると新規作成可（背景白に変化）

### 個別看護記録と一括記録のデータが同一モデルに保存される

- **Given** 一括看護記録で記事を保存した
- **When** 同患者の部門記録簿または個別看護記録を表示する
- **Then** 一括で入力した記事が同じく時系列に表れる

### 未来日時入力がマスタ設定で制御される

- **Given** プロパティ`validate.future`／`confirm.future` が設定されている
- **When** 未来日時で記録を登録しようとする
- **Then** エラーまたは確認メッセージが表示される

## 補足

- 一括入力時のテンプレートは点数表分類マスタ／看護記録で管理
- 氏名タイトル部クリックでかな順並び替え可能
- 個別記録と一括記録の連携設定UIは共通
