# [看護] フローシート表示

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートで7日分のバイタル・ケア内容・行動制限有無・オーダ予定・検査結果を一画面で参照したい
- **So that** 患者の状態と本日やるべきことを時間軸に沿って把握できる

## 受け入れ基準

### 7日分のフローシートを表示できる

- **Given** 病床管理または看護記録メニューからフローシート画面を開いている
- **When** 表示日を指定して [表示] をクリックする
- **Then** 入院患者は操作日を含む前1週間、外来患者は操作日と記録記載のある日付の合計7日が表示される（外来で記録が7日に満たない場合は入院期間も表示）

### 表示日を素早く調整できる

- **Given** フローシート画面を開いている
- **When** 表示日調整リンク（当日／＜／＞／＜＜／＞＞）をクリックする
- **Then** それぞれ当日／1日前／1日後／7日前／7日後を起点とした7日表示に切り替わる

### 入力切替タブで関連記録に遷移できる

- **Given** フローシート画面を開いている
- **When** 入力切替タブ（フローシート／隔離拘束／睡眠・活動／観察）を選択する
- **Then** 該当タブに切り替わる（観察は医療観察法対象者のみ表示）

### 移動状況が一覧で確認できる

- **Given** 入院患者のフローシートを表示している
- **When** 移動状況表示部を確認する
- **Then** 病室／隔離／拘束／行動制限（その他）／外出・外泊の期間がオレンジ背景で表示される。期間にホバーで開始日時～終了日時のツールチップが出る（外来患者は移動状況非表示）

### バイタルがグラフで表示される

- **Given** バイタル登録がある日付の体温表を表示している
- **When** 体温表をクリックする、または実施点にホバーする
- **Then** 当日のバイタル測定値の拡大図表示／実施点の測定値ツールチップ表示が行われる

### 予定オーダの実施状況が色で判別できる

- **Given** 対象日にオーダ指示がある
- **When** 予定オーダ欄を確認する
- **Then** オーダ種名が1文字（薬／注／検／処／画／心／E）で表示され、未実施=赤字、実施済=グレー、実施済オーダがある場合は背景オレンジで表示される

### 「一覧」から1ヶ月の指示状況を参照できる

- **Given** フローシートを表示している
- **When** 予定オーダ欄タイトル部の「一覧」をクリックする
- **Then** 指示状況ダイアログが開かれ、操作日の1ヶ月分のオーダ状況を参照できる（参照のみ、新規指示やDOは不可）

### 実施確認表で未実施オーダを実施できる

- **Given** フローシートで未実施オーダがある日付を表示している
- **When** 予定オーダ欄をクリックして実施確認表ダイアログを開き、未実施オーダをクリックして実施操作を行う
- **Then** オーダが実施済となり、フローシート上で実施済表示（グレー＋背景オレンジ）に切り替わる

### 検査結果グラフを表示できる

- **Given** 検査結果欄に登録済み伝票名が表示されている
- **When** 伝票名をクリックする、または [設定] でグラフ表示する検査項目を指定する
- **Then** 検査結果グラフ表示ダイアログが開かれる（結果ステータス「待ち」の伝票名は非表示）

### 未来日入力不可設定時は未来枠が非活性となる

- **Given** プロパティ`validate.future`に未来日登録不可が設定されている
- **When** 未来日のフローシートアイコン／バイタルアイコンを表示する
- **Then** 当該枠はグレー表示・クリック不可となる

## 補足

- 検索条件は別メニューから戻ると前回表示日で再表示される（実装挙動）
- 表示時間幅（24h／勤務帯単位）の切替は別ストーリーで検討
- パターンボックス（表示切替）の操作は フローシートパターン ストーリーで扱う
