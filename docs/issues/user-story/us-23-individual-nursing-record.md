# [看護] 個別看護記録

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 看護記録をSOAP／経時記録の形式で新規作成・更新・削除し、連携先（フローシート、申し送り、病棟日誌、報告先など）を設定して時系列で参照したい
- **So that** 個別の観察・思考プロセスを記録に残し、関連する記事をたどって経過を追える

## 受け入れ基準

### 看護記録ダイアログを複数経路から開ける

- **Given** 患者を選択している
- **When** 部門記録簿の [看護記録] ／カルテ画面の [看護記録（実施）] ／フローシートの [新規作成] のいずれかをクリックする
- **Then** 看護記録ダイアログが開かれ、新規作成できる

### 看護記録を新規作成できる

- **Given** 看護記録ダイアログを開いている
- **When** タイトル（最大20文字）／記載日・勤務帯／記録形式（SOAP／経時記録）／本文／連携／タグ／記録者を入力し [登録] する
- **Then** 看護記録として登録される。登録後は部門記録簿の時系列に追加される

### 記録形式に応じて定型文が切り替わる

- **Given** 看護記録ダイアログで記録形式を選択する
- **When** SOAP／経時記録を切り替える
- **Then** 1 つの本文入力欄に形式の定型文が挿入される。SOAPは「S・O・A・P」の見出し4行、経時記録は行頭に時刻（HH:mm）を付けた行形式（[時刻行を追加] で現在時刻の行を挿入できる）。SOAP各欄・経時の行構造といった構造化入力は現時点では実装スコープ外（将来、多職種の部門診療録全てを対象にした共通の仕組みとして検討余地を残す）

### テンプレート・文例で入力支援できる

- **Given** ダイアログの本文を編集している
- **When** テンプレートを選択して [呼出] をクリックする
- **Then** テンプレートダイアログが開かれ、内容入力後 [決定] で本文に反映される（カーソル位置）。文例ウィザード／タグ／一括入力ダイアログも利用できる

### 連携先を設定できる

- **Given** 看護記録ダイアログを編集している
- **When** 連携欄でフローシート／申し送り／病棟日誌／面接実施／報告先などにチェックする
- **Then** 該当画面・機能から当看護記録を参照できる。フローシート連携にチェックがない場合はフローシートに表示されない

### 報告先・報告種別を指定できる

- **Given** 連携の報告先で [検索] をクリックする
- **When** 報告先職員を選択し、報告種別（[作]作成／[確]確認／[両]両方）を指定する
- **Then** 報告先で記事を表示した際に対応するボタンが表示される

### 記事を更新・削除できる

- **Given** 部門記録簿で既存の看護記録を表示している
- **When** タイトルをクリックして編集ダイアログを開き、内容を更新または削除する
- **Then** 更新／削除が反映され、操作者・操作日時が監査用に記録される（記事表示切替「全て」で履歴記事を確認可能）

### 関連記事を時系列で連鎖閲覧できる

- **Given** 既存の看護記録に「関連付け」を設定している
- **When** 部門記録簿で記事の関連付けを表示する
- **Then** 関連記事が時系列で連鎖表示され、経過を追って閲覧できる

### 未来日時入力がマスタ設定で制御される

- **Given** プロパティ`validate.future`または`confirm.future`が設定されている
- **When** 現在日時より未来の記載日時で登録しようとする
- **Then** エラーメッセージで登録不可、または確認メッセージで進行を選べる

## 補足

- 削除は物理／論理いずれかを実装時に確定
- 関連記事は同一患者内に限るかは別途検討
- 記録形式の初期値はマスタ保守／医療機関情報／その他／部門側記事形式で設定
- 公開/非公開設定（「記事を公開する」チェック）は参照範囲の使い方が定まらないため削除（2026-08-24）。必要になれば再検討
