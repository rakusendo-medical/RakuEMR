# [看護] 定期評価

## ユーザーストーリー

- **As a** 受け持ち看護師
- **I want** 定期評価を登録・参照・更新・削除し、必要に応じて特記報告やカルテ記事として連携したい
- **So that** 立案した評価項目に沿って計画の達成度を継続的に記録・確認し、関係者に共有できる

## 受け入れ基準

### 評価画面から評価入力ダイアログを開ける

- **Given** 評価画面を表示している
- **When** 立案済の評価項目をクリックする
- **Then** 評価入力ダイアログが開かれる

### 評価レベル・評価内容・添付ファイルを登録できる

- **Given** 評価入力ダイアログを表示している
- **When** 評価レベル、評価内容、（必要に応じて）添付ファイルを入力して [登録] する
- **Then** 評価が登録され、評価画面に反映される。評価レベルの評価点数合計も更新される

### 評価レベルが未登録の評価項目では内容のみ登録できる

- **Given** 評価項目で評価レベルが未登録の場合
- **When** 評価入力ダイアログを開く
- **Then** 評価内容と添付ファイルのみが表示される

### 立案なしで初期選択評価項目で評価登録できる

- **Given** 評価項目を立案していない
- **When** 評価画面の評価領域をクリックする（背景薄青色＋ハンドカーソル）
- **Then** マスタの初期選択評価項目で評価入力ダイアログが開かれ、登録可能。登録後は評価項目選択アイコンが登録済になる

### 特記報告で関係者に評価を報告できる

- **Given** 評価入力ダイアログを開いている
- **When** [特記報告] にチェックして登録する
- **Then** 特記報告ダイアログが開き、所見に計画明細と評価内容が取り込まれる。報告先（初期: 主治医、[検索] で職員選択可）と種別（[作]作成／[確]確認／[両]両方）を指定して報告できる

### カルテ記事作成連携ができる

- **Given** 評価入力ダイアログを開いている
- **When** [カルテ記事作成] にチェックして登録する
- **Then** ログオン者の標準診療種類に応じたカルテ記事作成ダイアログが表示される（標準診療種類が看護記録の場合は看護記録ダイアログがフリー形式で評価内容を本文に取り込んだ状態で開く）。チェック時 [特記報告] は非活性

### 添付ファイルをダウンロードできる

- **Given** 評価詳細に添付ファイルがある
- **When** 添付ファイルアイコンをクリックする
- **Then** 添付ファイルがダウンロードされる

### 過去の評価を時系列で参照できる

- **Given** 過去の定期評価が登録されている
- **When** 評価画面を開く
- **Then** 評価実施日順に過去評価が表示され、評価レベル・コメント・評価内容・備考・添付ファイル・評価点数合計が確認できる

### 評価を更新できる

- **Given** 既存の評価を表示している
- **When** 評価をクリックして評価入力ダイアログを開き、内容を変更して [更新] する
- **Then** 評価画面に変更が反映される

### 評価を削除できる

- **Given** 既存の評価を表示している
- **When** 評価入力ダイアログで [削除] をクリックする
- **Then** 確認メッセージ後、評価が削除される

## 補足

- 評価サイクル（毎週／毎月など）の運用ルールは別途整理
- 報告先選択時の「作成依頼／確認依頼／両方」は職員選択ダイアログで指定
- 病床管理画面からも定期評価への入口があるが本ストーリーは看護計画／評価画面からの導線を対象（病床管理経由のフローは別途整理）
