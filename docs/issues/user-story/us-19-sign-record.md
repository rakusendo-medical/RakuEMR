# [看護] サイン記載

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 深夜・日勤・準夜の3勤務帯ごとにフローシート記録のサインを登録・変更・削除したい
- **So that** 勤務帯ごとの記録責任者を明示し、紙運用を電子化できる

## 受け入れ基準

### 勤務帯を選んでサイン入力ダイアログを開ける

- **Given** フローシートを表示している
- **When** 対象日の勤務帯（左から深夜・日勤・準夜）をクリックする
- **Then** サイン入力ダイアログが開かれ、ログオン者が初期選択された状態で表示される

### サインを登録できる

- **Given** サイン入力ダイアログを表示している
- **When** サイン入力者を選択して [登録] をクリックする
- **Then** 当該勤務帯のサインとしてフローシート上に表示される

### サインを変更・削除できる

- **Given** 登録済みサインの勤務帯をクリックしてダイアログを開いている
- **When** [更新] または [削除] をクリックする
- **Then** 更新時はサイン者が変更される。削除時は確認ダイアログの後、サインが削除される

### 未来日入力不可設定時は未来勤務帯を選択できない

- **Given** プロパティ`validate.future`に未来日登録不可が設定されている
- **When** 翌日以降の勤務帯を表示する
- **Then** クリック不可となる

### ログオン者以外の選択可否がマスタで切り替えできる

- **Given** マスタ保守／医療機関情報／その他／実施者ロックを設定している
- **When** サイン入力ダイアログのプルダウンを確認する
- **Then** 設定が「ログオン者のみ」の場合は自分のみ表示。「ログオン者以外も」の場合は所属区分の職員並び順で他職員も表示される

### 同一勤務帯のサインを上書きしない

- **Given** すでに別職員のサインが登録されている勤務帯がある
- **When** 別職員でサインを登録しようとする
- **Then** 既存サインは「変更／削除」の対象であり、勝手に上書きされない（更新ボタンの明示操作が必要）

### スクロール位置が保持される

- **Given** フローシート画面でスクロール後にサイン入力した
- **When** 操作を終えてダイアログを閉じる
- **Then** フローシート画面のスクロール位置が変更前の位置に戻る
