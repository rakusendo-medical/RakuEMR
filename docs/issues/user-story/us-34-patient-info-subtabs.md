# [外来] 患者情報サブタブ

## ユーザーストーリー

- **As a** 外来看護師（および主治医・受付）
- **I want** カルテ画面の「患者情報」タブで、基本情報・属性・保険・連絡先・病名・エピソード・メモ をサブタブで切り替えて閲覧／編集したい
- **So that** 診察中に患者の各情報を素早く参照・更新でき、編集単位ごとに保存できる

## 受け入れ基準

### 患者情報タブにサブタブが表示される

- **Given** カルテ画面の「患者情報」メインタブを選択している
- **When** タブ内を表示する
- **Then** 上部に Chip 風の小型サブタブが 7 つ（基本情報／属性／保険／連絡先／病名／エピソード／メモ）が表示され、既定で「基本情報」が選択される

### 基本情報サブタブで主訴・アレルギー・感染症等を編集できる

- **Given** 「基本情報」サブタブを表示している
- **When** タブ内を確認する
- **Then** 主訴／アレルギー（薬剤・食物含む）／感染症・既往（肝炎／梅毒／HIV）／服薬・基礎疾患（他科薬／喘息／その他）／問診表／現在の状態（授乳／妊娠／フレイル）／その他（宗教／メモ）／預かり金 の各セクションが表示・編集可能になる
- **Given** 「なし／あり／不明」の TriState を持つ項目を表示している
- **When** 「あり」を選択する
- **Then** 詳細入力 TextField が条件表示される

### サブタブは Chip 風の小型タブで階層を視覚的に区別する

- **Given** メインタブとサブタブが同時に表示されている
- **When** 各タブのデザインを確認する
- **Then** メインタブは標準サイズ／太字、サブタブは Chip 風の小型表示で、階層が視覚的に区別される

### 編集中の未保存変更は保持される（タブ内で）

- **Given** 「基本情報」で変更を加えた状態
- **When** 「保険」サブタブに切り替え、再度「基本情報」に戻る
- **Then** 変更内容は保持されている（メモリ内）

### 編集単位ごとに保存できる

- **Given** いずれかのサブタブで変更を加えた
- **When** タブ内のアクションバーで「保存」をクリックする
- **Then** 該当サブタブの内容のみが保存され、他サブタブの未保存変更は影響を受けない

### 未保存変更があるサブタブからカルテ画面外に離脱しようとすると確認される

- **Given** あるサブタブに未保存変更がある
- **When** 「一覧に戻る」または別メインタブをクリックする
- **Then** 「保存していない変更があります」確認ダイアログが表示され、「破棄して戻る／編集に戻る」を選択する

### 一部サブタブは外来／入院で表示が変わる

- **Given** mode='outpatient' で患者情報タブを表示している
- **When** サブタブを確認する
- **Then** 「エピソード」（経過記録）は外来／入院共通で表示される
- **Given** mode='inpatient' で患者情報タブを表示している
- **When** サブタブを確認する
- **Then** 入院専用情報（入院日・病棟・受け持ち看護師）が「属性」サブタブに表示される
