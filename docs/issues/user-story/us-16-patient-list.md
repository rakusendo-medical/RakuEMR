# [共通] 入院患者一覧

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 入院患者を一覧表示し、担当職員・主治医・病棟で絞り込みたい
- **So that** 業務開始時に自分の関与する患者だけをまとめて確認できる

## 受け入れ基準

### 入院患者を一覧で確認できる

- **Given** 入院患者一覧画面を開いている
- **When** 日付・病棟・主治医を指定して [表示] をクリックする
- **Then** 該当条件下の入院患者が、病棟・病室／患者番号／氏名（年齢）／入院日（日数）／入院形態／ICD10・病名／責任レベル／報告／主治医／終了 列で一覧表示される

### 担当職員で絞り込みできる

- **Given** 入院患者一覧を表示している
- **When** [条件設定] をクリックして職員選択ダイアログで担当職員を指定し、「全てに一致」または「いずれかに一致」を選んで [登録] してから [表示] する
- **Then** 担当職員1〜10にいずれかの選択職員が登録されている患者で絞り込まれる

### 担当職員指定だけでは絞込が反映されない

- **Given** 担当職員を選択した
- **When** [表示] をクリックしないままでいる
- **Then** 一覧は絞り込まれない（[表示] クリックが必須）

### 検索条件はログアウトまで保持される

- **Given** 検索条件を指定して [表示] した
- **When** 別メニューを表示後に再度入院患者一覧画面を開く
- **Then** 前回の検索条件で一覧が再表示される

### ログオン職員が医師の場合は初期表示が自分の主治医患者

- **Given** ログオン職員が医師である
- **When** 入院患者一覧画面を初期表示する
- **Then** 主治医=ログオン職員、全病棟で絞り込まれた一覧が表示される

### 診察医登録分を含めて表示できる

- **Given** 主治医での絞り込みを行っている
- **When** 「診察医登録分も表示」にチェックする
- **Then** 主治医に加え、診察医として登録されている患者も表示される

### 一覧から各機能に遷移できる

- **Given** 入院患者一覧で患者を表示している
- **When** 患者番号／カルテアイコン／報告アイコンをクリックする
- **Then** それぞれカルテ画面／標準診療種類画面（職員マスタ設定）／報告一覧画面に遷移する

### 一覧で診察終了の操作ができる

- **Given** 一覧の終了欄を確認している
- **When** 「終了」欄をクリックする
- **Then** 診察終了・解除が切り替わる。ツールチップで処理職員と時刻が確認できる

### 並び替えができる

- **Given** 一覧を表示している
- **When** 病棟・病室／入院日／主治医のヘッダをクリックする
- **Then** 当該列で並び替えられる（病棟・病室は病床管理マスタ順、入院日は日数降順）

### ウィンドウ幅で表示列が自動切替される

- **Given** ウィンドウ幅が変動する
- **When** 1100px 以上／1200px 以上／1100px 未満で表示する
- **Then** 1200px 以上で全項目、1100px 以上で「ICD10・病名」まで、1100px 未満では「ICD10・病名」「責任レベル」が非表示となる

## 補足

- 担当職員の登録は患者情報／属性の担当職員1〜10で行う（別ストーリー）
- 担当職員選択時、選択数が表示領域を超えた場合は「…」と表示し、ホバーでツールチップ表示
- 診察終了状態の患者は一覧および各画面でアイコン表示
