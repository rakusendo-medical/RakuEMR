# [病床管理] 退院指示

## ユーザーストーリー

- **As a** 主治医
- **I want** 退院指示を発行する際に紹介先医療機関と紹介経路を入力したい
- **So that** 退院後の連携先と経路を指示時点で確定させ、退院サマリ・診療情報提供書発行を効率化できる

## 受け入れ基準

### 退院指示画面を開ける

- **Given** 入院患者のカルテを表示している
- **When** 診療録の [退院指示] をクリックする
- **Then** 退院指示画面が開かれ、退院日・転帰・食事終了日・退院時文書・紹介先医療機関・紹介経路・退院決定理由・退院後の診療・カルテ記載を入力できる（[退院指示] は入院患者のみ表示される）

### 退院日変更で食事終了日が自動連動する

- **Given** 退院指示画面を開いている
- **When** 退院日を変更する
- **Then** 食事終了日が医療機関情報マスタの食事時間設定に従って自動更新される

### 食事を伴わない退院日付では食事終了日を編集できない

- **Given** 食事を伴わない退院となる退院日が入力されている
- **When** 食事終了日項目を表示する
- **Then** 食事終了日は編集不可となる

### 食事終了日を入院期間内で個別調整できる

- **Given** 食事終了日を退院日と異なる時刻にする必要がある
- **When** 入院期間内で食事終了日時を変更する
- **Then** 食事終了日時から退院日時までの間に「食無し」指示（マスタ切替で「臨時欠食」）が自動生成される

### 紹介先医療機関を検索または治療歴から複写できる

- **Given** 退院指示画面を開いている
- **When** [検索] をクリックして検索ダイアログから選択する、または [治療歴から複写] をクリックする
- **Then** 紹介先医療機関欄に値が設定される（複写元は当該入院期間の紹介元医療機関）

### 紹介経路をプルダウンから選択できる

- **Given** 退院指示画面を開いている
- **When** 紹介経路欄を選択する
- **Then** 「退院後通院なし／退院後自院通院／退院後自院入院／退院後他院通院／退院後他院入院／医療観察入院処遇中の転院」から選択できる

### 退院時文書の診療区分により後続業務が変わる

- **Given** 退院時文書の診療区分（不要／通院／転院）を選択している
- **When** 区分を選択する
- **Then** 区分に応じた退院時文書がチェック一覧として表示される。通院選択時は通院精神の指示が出される。退院時文書の診療区分は患者情報／入院歴／退院時の退院区分に反映される（不要→退院、通院→退院後通院、転院→退院後転院）

### 「指示」段階で発行できる

- **Given** 退院指示画面で必要項目を入力している
- **When** [指示] ボタンをクリックする
- **Then** 退院指示が登録される。患者は入院患者のまま、病棟側で退院手続きの確定が必要

### 「退院確定」で即時状態変化させられる

- **Given** 退院指示画面で必要項目を入力している
- **When** [退院確定] ボタンをクリックする
- **Then** 患者状態が外来患者となる。未実施の入院専用オーダおよび移動・給食オーダがあれば退院確定時のオーダ確認ダイアログが表示される。未来日付では確定不可

### 外出中の患者は退院確定できない

- **Given** 患者が外出中である
- **When** [退院確定] を実行しようとする
- **Then** 確定できない（病床管理画面で帰院処理を行ってから確定）

### 退院確定時のオーダ確認ダイアログでオーダを一括中止できる

- **Given** 退院確定でダイアログが表示されている
- **When** 指示一覧で中止対象を選択し、リハビリオーダ含む場合はリハビリ転帰区分を選択する
- **Then** 退院確定で選択オーダが中止される。「その他」（入院専用オーダ）は退院確定後に自動削除される。リハビリ転帰区分の「継続」は選択不可

### 入院定時オーダの中止日がマスタ設定に従う

- **Given** 退院確定で入院定時オーダを中止する
- **When** マスタ保守／医療機関情報／処方の中止日設定を取得する
- **Then** 「当日以降」設定時は退院日当日が中止日（前日まで実施）、「翌日以降」設定時は退院日翌日が中止日（退院日まで実施）として記録される

### 退院指示の更新・中止ができる

- **Given** 「指示」段階で登録済みの退院指示がある
- **When** 退院指示画面から [変更] または [中止] をクリックする
- **Then** 変更時は内容を修正して更新できる。中止時は削除コメントダイアログで分類と理由を入力すると指示が取り消される（移動削除箋・食事指示削除箋の印刷可）

> 「地域連携オプション利用時は逆紹介設定が表示される」AC は、地域連携（逆紹介）オプションが不要のため削除。

## 補足

- 退院日の初期表示はマスタ保守／医療機関情報の「入退院指示日初期設定」で制御
- 治療歴で退院前に「退院紹介医療機関名」を登録していた場合、退院指示時に紹介先医療機関に初期設定される
- 紹介先が無いケース（自宅退院単独など）は紹介経路で「退院後通院なし」を選択
- 医療観察法オプション利用時は紹介経路に「医療観察入院処遇中の転院」が追加。転院先指定が統計集計対象
