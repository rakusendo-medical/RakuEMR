# [病床管理] 病床移動

## ユーザーストーリー

- **As a** 病棟看護師長
- **I want** 病棟マップ上で患者の病床を別の病床に移動したい
- **So that** 病室変更や病棟間移動を、紙運用や事務連絡を介さずに即時反映できる

## 受け入れ基準

### 患者を選択して移動ダイアログを開ける

- **Given** 病棟マップで在床患者の氏名をクリックしている
- **When** 操作リンクから「移動」を選択する
- **Then** 転棟・転室ダイアログが新規登録モードで開かれる

### 同一病棟内・病棟間でベッドを変更できる

- **Given** 転棟・転室ダイアログを表示している
- **When** 移動先の病棟・病室・ベッドと移動日時、配膳先変更日時を入力し登録する
- **Then** 患者の在床ベッドが移動先に変更され、移動元は空床になる

### 未来日の移動（移動予定）が登録できる

- **Given** 移動日時に未来日時を指定して登録している
- **When** 移動予定時刻に至っていない
- **Then** 患者は移動前の病床に表示され続け、移動アイコンが付与される。移動予定時刻経過後に病棟マップを再表示すると、移動先病床に反映される

### 不在者（外出・外泊中）も移動登録できる

- **Given** 患者が外出・外泊中である
- **When** 移動操作を実行する
- **Then** 通常と同様に移動登録できる

### 移動予定（未実施）の内容を変更・取消できる

- **Given** 既存の移動情報を再表示している
- **When** ダイアログ履歴欄から未実施（状態: 未）の移動を選択し更新、または取消を実行する
- **Then** 該当移動が更新される、または取消として履歴に残る（物理削除はできない）。予定の取消では病床は変化しない

### 実施済（済）の移動履歴は取消・更新できない

- **Given** 実施日時を過ぎた移動（状態: 済）、取消済みの移動（状態: 取消）、または入院（最初の病室）行がある
- **When** ダイアログ履歴欄を操作する
- **Then** これらの行は取消・更新の対象にできない。実施済の移動を修正したい場合は、取り消すのではなく新しい移動を登録して対応する

取消・更新の可否（状態 × 種別）:

| 状態 | 種別 | 取消 | 更新 |
| --- | --- | --- | --- |
| 済 | 入院 | 不可 | 不可 |
| 済 | 転室 | 不可 | 不可 |
| 済 | 転棟 | 不可 | 不可 |
| 未 | 転室 | 可 | 可 |
| 未 | 転棟 | 可 | 可 |
| 取消 | （いずれの種別も） | 不可 | 不可 |

※ 種別「入院」（最初の病室行）は入院時点で実施済となるため、状態「未」の入院行は発生しない

### 移動予定を含めて満床の病室へは登録・更新できない（後負け）

- **Given** 移動先病室の空き枠が、在床患者と他患者の登録済み移動予定で全て埋まっている
- **When** 転棟・転室ダイアログで当該病室を選択して登録または更新しようとする
- **Then** エラーが表示され、登録・更新は実行できない。1 つの病床に複数の患者は割り当てない（先に割り当てた患者を優先し、後からの割り当てを拒否する）

### 食事締め時間を過ぎた登録・更新では確認が出る

- **Given** 食事締め時間を過ぎた状態で登録または更新を実行する
- **When** 確定操作を行う
- **Then** 確認メッセージが表示され、OK で続行できる

### オーダリング利用時は隔離・拘束チェックが追加される

- **Given** オーダリング運用時に転棟・転室ダイアログを開いている
- **When** ダイアログを表示する
- **Then** 隔離・拘束の登録用チェック項目が追加で表示される

## 補足

- 病床競合の取り扱いは「後負け」で統一する: 移動予定・移動キャンセルによって 1 つの病床に複数の患者が割り当てられる状況を作らない（定数超過の入院は法令上禁止のため）。参考システムの「対象の病床に 2 人の患者を表示する」仕様は採用しない（ヒアリング結果に基づく決定）
- 移動履歴の取消・更新は「未実施の予定のみ可」で統一する: 実施済（済）の移動は事実の記録として取消・更新とも不可とし、修正は新しい移動の登録で行う。予定の取消は病床を動かさず履歴に取消状態で残す。物理削除はいかなる場合も禁止
- 予定の更新は同一履歴行の上書きとする（更新前の内容を履歴として保持するかは将来検討）
- 指示箋（移動箋・食事箋）の印刷オプションあり。表示有無・名称・帳票レイアウトはマスタで設定可能（移動削除箋は削除機能の廃止に伴い廃止済み）
- 移動の理由区分（治療都合・本人都合等）の入力要否は別途検討
- 「再度別の病室に移動する場合は変更ではなく新規登録」が運用ルール。UI上の誘導要否は別途検討
