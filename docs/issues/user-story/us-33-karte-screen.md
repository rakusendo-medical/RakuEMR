# [外来] カルテ画面（タブ式 TOP・mode 切替）

## ユーザーストーリー

- **As a** 外来看護師／主治医（および将来は入院看護師・主治医）
- **I want** 患者ごとのカルテ画面で、診療録／フローシート／指示簿／指示状況／看護過程／患者情報／スケジュール をタブで切り替えて閲覧したい
- **So that** 同じ患者が外来→入院→外来と動いても同じ操作感で診療情報にアクセスできる

## 受け入れ基準

### カルテ画面はタブ式 TOP として動作する

- **Given** 外来一覧（または病棟マップ）から患者を選択して遷移した
- **When** カルテ画面を表示する
- **Then** 上部に患者ヘッダー、下部にメインタブバー（診療録／フローシート／指示簿／指示状況／看護過程／患者情報／スケジュール の 7 つ）が表示され、既定で「診療録」タブが選択される

### mode は患者属性 + 遷移元から自動判定される

- **Given** 外来一覧から患者を選択した
- **When** カルテ画面を表示する
- **Then** mode='outpatient' として動作し、テーマカラーは緑系（success）になる
- **Given** 病棟マップから患者を選択した
- **When** カルテ画面を表示する
- **Then** mode='inpatient' として動作し、テーマカラーは青系（primary）になる
- **Given** 患者属性（外来／入院ステータス）と遷移元が矛盾する
- **When** カルテ画面を表示する
- **Then** **遷移元を優先** して mode を決定する

### 利用不可なタブはグレーアウト + Tooltip で説明される

- **Given** mode='outpatient' でカルテ画面を表示している
- **When** 「看護過程」タブを確認する
- **Then** タブは表示されているが disabled 状態で、ホバーすると Tooltip 「外来では利用しません」等の説明が表示される
- **Given** 利用不可タブを操作しようとする
- **When** 該当タブをクリックする
- **Then** クリックは無効化され、タブ切替は発生しない

### 外来モードで表示されるアクション

- **Given** mode='outpatient'
- **When** 画面下部のアクションバーを確認する
- **Then** 「オーダー入力」「患者予約」「印刷」「終了（カルテを閉じる）」が表示される。「入退院指示」「隔離拘束指示」は **非表示** または disabled

### 入院モードで表示されるアクション

- **Given** mode='inpatient'
- **When** 画面下部のアクションバーを確認する
- **Then** 「入退院指示」「隔離拘束指示」「看護ケア記録」「オーダー入力」「印刷」「終了」が表示される

### 戻るリンクは遷移元へ戻る

- **Given** 外来一覧から遷移した（mode='outpatient'）
- **When** 「一覧に戻る」をクリックする
- **Then** 外来一覧 (`/outpatient`) に戻る
- **Given** 病棟マップから遷移した（mode='inpatient'）
- **When** 「一覧に戻る」をクリックする
- **Then** 病棟マップ (`/`) に戻る

### 患者ヘッダーには mode に応じた識別が表示される

- **Given** mode='outpatient'
- **When** 患者ヘッダーを確認する
- **Then** 患者属性とともに「外来」Chip（緑系）が表示される
- **Given** mode='inpatient'
- **When** 患者ヘッダーを確認する
- **Then** 「入院」Chip（青系）と病棟・病室番号が併記される
