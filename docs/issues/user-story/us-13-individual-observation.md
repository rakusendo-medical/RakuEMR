# [隔離拘束] 個別観察記録

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 行動制限下の患者個人の観察記録をフローシートから作成・更新したい
- **So that** 患者ごとの観察事項を時間軸に沿って詳細に残し、指示の継続要否判断や指定医評価に役立てられる

## 受け入れ基準

### フローシート／隔離拘束タブで観察マトリクスを表示できる

- **Given** 患者カルテのフローシートを開いている
- **When** 「隔離拘束」タブを選択する
- **Then** 1時間枠×観察回数のマトリクスが表示される。入力対象外はグレー、未記入は白、登録済は状態色で区別される

### 観察可能な時間帯のみ入力できる

- **Given** マトリクス上の枠にカーソルをあてる
- **When** 入力可能な時間帯にホバーする
- **Then** 対象時間が薄青枠で表示され、時間と制限内容（隔離拘束／その他）、回数がツールチップ表示される。入力対象外時間帯はホバー時にも理由が表示される

### 未来日入力が抑止される（マスタ設定時）

- **Given** マスタ保守でプロパティ`validate.future`に未来日登録不可が設定されている
- **When** 操作時間より未来の時間帯枠を表示する
- **Then** 当該枠はグレー背景・非活性となり、クリックできない

### 観察記録ダイアログで状態と内容を登録できる

- **Given** 入力可能な時間枠をクリックして観察記録ダイアログを開いている
- **When** 「選択」欄にチェック、状態を選択、内容を入力して [登録] する
- **Then** 観察記録が登録される。フローシートの当該枠が選択した状態色で表示され、状態に紐づく定型文が処方処置として自動記載される

### 観察回数を追加・削除できる

- **Given** 観察記録ダイアログを開いている
- **When** [追加] をクリックする、または既存行を [削除] する
- **Then** 1時間の記録回数が増減し、未登録時間の開始・終了が自動再計算される（追加時1回目開始・最終回数終了は除く）

### 内容入力に文例・記事タグ・一括入力が使える

- **Given** 観察記録ダイアログの内容欄を編集している
- **When** [文例] をクリック、またはタイトルの [入力] をクリック、または [タグを登録する] をクリックする
- **Then** 文例ウィザード／一括入力ダイアログ／タグ一覧ダイアログが開かれ、対応する内容を入力・反映できる

### 連携設定で看護記録・報告先と紐づけできる

- **Given** 観察記録ダイアログの連携欄を表示している
- **When** [未連携] または [連携あり] をクリックして連携設定ダイアログを開き、看護記録連携や報告先（作成／確認／両方）を指定して [登録] する
- **Then** 連携項目が設定され、部門記録簿の看護記録検索で当該観察記録が表示対象となる

### 同一時間帯で隔離と拘束が重複する場合は拘束が優先表示される

- **Given** 患者に隔離指示と拘束指示が同時間帯で重複している
- **When** マトリクスを表示する
- **Then** 拘束が優先されて状態色が表示される

### 開放時間がアイコンで可視化される

- **Given** 隔離・拘束の開始指示で開放時間が登録されている
- **When** 隔離拘束タブを表示する
- **Then** 開放時間に該当する時間枠に開放時間アイコンが表示され、ホバーで開放時間がツールチップ表示される

### 部門記録簿の看護記録に観察記録が連携表示される

- **Given** 観察記録を登録した
- **When** 部門記録簿／看護記録を表示する
- **Then** タイトル「観察記録（隔離拘束）」または「観察記録（その他）」で観察記録が記載され、選択状態の定型文が処方処置として表示される

## 補足

- 観察項目セット・状態色・回数（分割数）はマスタ管理（隔離拘束状態マスタ／医療機関情報マスタの観察回数）
- 報告先選択ダイアログは利用中のオプションにより連携項目が変動
- 隔離拘束フローシートに戻る際、ダイアログ操作前のスクロール位置を保持する挙動を踏襲
