# [病床管理] 入院歴・退院歴

## ユーザーストーリー

- **As a** 病棟事務
- **I want** 患者の入退院履歴を参照・更新し、入院形態変更や入退院取消の是正操作も同一画面で行いたい
- **So that** オーダ起点の自動取り込みを基本としつつ、例外時には履歴を正しく保てる

## 受け入れ基準

### 入院歴／退院歴をタブ切替で参照できる

- **Given** 患者の入院歴画面を開いている
- **When** 入院時／退院時タブを切り替える
- **Then** それぞれ入院日・指示医・病棟・入院形態・入院決定の理由（入院時）／退院日・指示医・退院区分・転帰・退院決定の理由・退院後処置・帰住先（退院時）が表示される。初期表示時は最新の入院歴が選択される

### 履歴一覧から詳細を表示できる

- **Given** 入院歴画面を開いている
- **When** 左側の入院履歴（期間のリンク）をクリックする
- **Then** 右側に当該期間の詳細情報が表示される（入院日・形態変更日の昇順、最新が画面最下部）

### オーダ確定で履歴が自動生成される

- **Given** 入退院指示が確定し入退院手続きが完了している
- **When** 自動連携が実行される
- **Then** 入院歴に対応するレコードが自動追加される

### 入院決定理由・退院決定理由を更新できる

- **Given** 入院歴画面を開いている
- **When** 入院決定の理由／退院決定の理由を編集して [登録] をクリックする
- **Then** 内容が更新される（最大3000文字、変更日時・操作者が記録される）

### 退院後処置・帰住先を更新できる

- **Given** 退院時タブを表示している
- **When** 退院後処置（最大1000文字）または帰住先（住居区分マスタ参照）を入力し [登録] する
- **Then** 内容が更新される

### 入院形態変更を追加できる

- **Given** 最新の入院歴を選択している
- **When** [形態変更] をクリックして入院情報編集モードで新しい入院形態と移動日時を設定し [登録] する
- **Then** 入院形態変更が新たな履歴として追加され、前形態の最終日（移動日）は形態変更日時の1分前が自動設定される。診療録にも履歴が作成される

### 入院形態変更の日時を更新できる（現在入院中のみ）

- **Given** 現在入院中の患者で、入退院日以外の入院歴を選択している
- **When** 入院日（形態変更日時）を編集して [登録] する
- **Then** 形態変更日時が更新される（入退院日自体は変更不可）

### 入院形態変更を取り消せる

- **Given** 入院形態変更の入院歴を選択している
- **When** [変更取消] をクリックする
- **Then** 入院時文書が追加されていれば削除確認メッセージが出る。削除コメントダイアログで分類と理由を入力すると形態変更が取り消され、入院時文書が削除される。診療録にも取消記事が記載される

### 入院取消・退院取消ができる（直近入院歴のみ）

- **Given** 直近の入院歴を表示している（現在入院中）
- **When** [入院取消] または [退院取消] をクリックする
- **Then** 期限管理文書（入院時文書／退院時文書）の削除確認後、削除コメントダイアログで理由を入力すると取り消される。入院確定オーダ・食事療法は連動して取り消される

### 入院固有オーダがある場合は取消前に削除が必要

- **Given** 患者に入院定時・行動範囲等の入院固有オーダが残っている
- **When** 入院取消を実行しようとする
- **Then** 取消は実行できず、先に該当オーダを削除する必要がある

### 関連履歴へ遷移できる

- **Given** 入院歴画面を開いている
- **When** 食事歴／移動歴／隔離歴のリンクを選択する
- **Then** 該当履歴画面に遷移する

## 補足

- 取消・形態変更時の削除コメント分類はマスタで管理。診療録に分類と理由が表示される
- 期限管理文書（入院時文書／退院時文書）は取消で削除されるため、必要な文書は事前にダウンロードする旨の注意喚起がUI上に必要
- 形態変更で表示される入院時文書チェックは選択した入院形態によって内容が変わる
- 外部精神科システム連携時は精神科入院有無・問診結果・退院後の所在の項目が追加表示
