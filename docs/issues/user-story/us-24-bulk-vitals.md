# [看護] 一括バイタル入力

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 病棟・病室・種類・記録日を指定して一括入力画面でバイタルを複数患者分まとめて入力したい
- **So that** ラウンド時に複数患者のバイタルを連続して効率的に登録できる

## 受け入れ基準

### 検索条件で対象を絞り込める

- **Given** 一括入力画面を開いている
- **When** 病棟／病室／種類（ケア項目、例: 基本昼）／記録日を指定して [表示] をクリックする
- **Then** 該当患者リストが表示される。種類は表示する記録項目（血圧（昼）／呼吸数（昼）／脈拍（昼）等）を決める

### フローシートパターン項目に従って入力可能項目が制限される

- **Given** 一括入力画面に患者が表示されている
- **When** 各患者のフローシートパターン適用状況に応じて項目を表示する
- **Then** パターンで定義された項目のみ入力可能となる。患者に設定されていない項目は背景グレーで入力不可

### 「入力対象患者のみ」でフィルタできる

- **Given** 一括入力画面を表示している
- **When** [入力対象患者のみ] にチェックして [表示] する
- **Then** フローシートパターン（または未適用）に対象項目が設定されている患者のみ表示される（チェックの初期表示・名称はマスタで設定）

### 値入力枠が項目タイプに応じて切り替わる

- **Given** 患者リストに各種ケア項目が表示されている
- **When** 項目タイプ（テキストボックス／ラジオボタン／コンボボックス／チェックボックス（複数 or 単項目））に応じた入力枠を表示する
- **Then** タイプ別に適切なUI（テキスト入力／コンボ／パターン項目ダイアログによる複数チェック等）が表示される

### 値入力で更新チェックが自動で付く

- **Given** 一括入力画面で項目に値を入力する
- **When** いずれかの値を入力する
- **Then** 当該患者の「更新」チェックが自動で付き、行の背景が薄青色になる

### [全て選択] [クリア] で更新チェックを操作できる

- **Given** 患者リストに複数患者が表示されている
- **When** [全て選択] または [クリア] をクリックする
- **Then** 全患者の更新チェックが ON／OFF される

### 設定ボタンで更新チェックされた値を一括登録できる

- **Given** 値を入力済みで更新チェックが付いている
- **When** [設定] ボタンをクリックする
- **Then** 当該入力項目が登録される。プルダウンリストの登録済項目は背景色薄赤になる

### クリアボタンで登録済項目を削除できる

- **Given** 更新チェックがあり、登録済項目を選んでいる
- **When** [クリア] ボタンをクリックする
- **Then** 当該登録済項目が削除される

### 入力時間外の項目は入力不可となる

- **Given** 入力可能時間が設定された項目を表示している
- **When** 操作時刻が入力可能時間外である
- **Then** 当該項目の背景がグレーで入力不可となる

### 「フローシートへサインする」チェックで一括サイン登録できる

- **Given** 種類にサイン項目が含まれている
- **When** [フローシートへサインする] にチェックして [設定] する
- **Then** 登録時間に該当する勤務帯のサインがフローシートに登録される（チェックの表示有無・名称・初期チェックはマスタで設定）

### 入力結果がフローシート・個別バイタル参照と整合する

- **Given** 一括入力でバイタルを保存した
- **When** 同患者のフローシート／個別バイタル画面を開く
- **Then** 一括で入力した値がそのまま反映されている。個別履歴一覧にも一括入力分が表示される

### 患者番号クリックで個別フローシートに遷移できる

- **Given** 患者リストに患者が表示されている
- **When** 患者番号をクリックする
- **Then** 当該患者のフローシート画面に遷移する

## 補足

- 入力速度を上げるためのキーボードショートカット仕様は別ストーリーで検討
- 種類はマスタ保守／ケア項目マスタで管理
- 表示項目の前後に項目がある場合、`<<` `<` `>` `>>` ナビゲーションで切替可能
