# [看護] フローシートパターン

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートパターンを切り替えて表示・入力項目を変更し、適用履歴も追跡したい
- **So that** 患者の状態に応じて必要なケア項目だけを扱い、不要項目を画面から排除できる

## 受け入れ基準

### パターンを新規適用できる

- **Given** フローシート画面を開いている
- **When** [パターン変更] をクリックしてフローシートパターン変更ダイアログを開き、[新規] の行に開始日とパターンを入力して [登録] する
- **Then** 適用日以降のケアメニューに入力されていたデータは（確認メッセージの後）削除され、新パターンが適用される

### 同日内に複数パターンを適用できる

- **Given** 同日内で複数のパターンを適用する必要がある
- **When** ダイアログで複数行に同日のパターンを設定する
- **Then** 日内のパターン数分の行で表示・登録される

### 適用パターンに応じた項目が表示される

- **Given** パターン適用済みのフローシートを表示している
- **When** 適用日以降のフローシートアイコンをクリックする
- **Then** フローシート編集ダイアログには適用パターンのケア項目のみが表示・入力可能となる

### パターンを変更・削除できる

- **Given** 既存パターンが適用されている
- **When** フローシートパターン編集ダイアログで適用中のパターンを変更または削除する
- **Then** 変更・削除が反映される（適用日以降のデータ取り扱いは新規適用と同様）

### パターン履歴を参照できる

- **Given** パターンが複数回変更されている
- **When** [パターン変更] からダイアログを開き [履歴] をクリックする
- **Then** フローシートパターン編集履歴ダイアログが開かれ、過去の適用パターン履歴が確認できる

### パターン未適用の場合の表示切替

- **Given** パターン未適用の状態でフローシートを表示している
- **When** パターンボックスを確認する
- **Then** 「全パターン」または「パターンなし」状態として扱われ、フローシート編集ダイアログの履歴のパターン名は「パターンなし」と表示される

### マスタで複数パターンを管理できる

- **Given** 院内で運用するケアパターンが複数存在する
- **When** マスタ保守／フローシートパターンマスタにパターンを設定する
- **Then** 複数のパターンが選択肢として登録され、患者ごとに割り当てできる

### パターン切替時の確認メッセージ

- **Given** 適用日以降にケアメニューデータが存在する状態でパターンを変更する
- **When** [登録] をクリックする
- **Then** 「適用日以降のデータが削除される」旨の確認メッセージが表示され、OK で続行できる

## 補足

- パターンマスタ自体の編集UIは別ストーリーで検討
- パターン切替時のデータ削除は不可逆。誤操作防止の確認UI案は実装時に詳細化
