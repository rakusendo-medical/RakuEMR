# [病床管理] 入院指示

## ユーザーストーリー

- **As a** 主治医
- **I want** 入院指示を発行する際に紹介元医療機関と紹介経路を入力したい
- **So that** 地域医療連携の起点情報を指示と一体で記録し、後続の事務手続き・診療情報提供書発行で再入力を不要にできる

## 受け入れ基準

### 入院指示画面を開ける

- **Given** 患者カルテを表示している
- **When** 診療録の [入院指示] をクリックする
- **Then** 入院指示画面が開かれ、入院日・食事開始日・病室情報・入院時文書・紹介元医療機関・紹介経路・入院決定理由・入院後の診療・指示内容を入力できる

### 入院日に応じて食事開始日が自動設定される

- **Given** 入院指示画面を開いている
- **When** 入院日を入力する
- **Then** 医療機関情報マスタの食事時間設定に基づいて食事開始日時が自動設定される

### 食事開始日を変更すると食無し／臨時欠食指示が自動生成される

- **Given** 自動設定された食事開始日時より後の時間帯に変更した
- **When** 入院確定する
- **Then** 入院日時から設定した食事開始日時までの間に「食無し」指示（マスタ切替で「臨時欠食」）が自動生成される

### 食事開始日の選択肢は現在時刻に依存する

- **Given** 入院日を当日に設定する
- **When** 食事開始日の時間帯を選択する
- **Then** 現在時刻の直前以前の時間帯は選択できない（赤字表示の時間帯を選んだ場合は確認メッセージで備考タグ付き指示として登録される）

### 紹介元医療機関を検索または治療歴から複写できる

- **Given** 入院指示画面を開いている
- **When** [検索] をクリックして検索ダイアログから医療機関を選択する、または [治療歴から複写] をクリックする
- **Then** 紹介元医療機関欄に値が設定される（治療歴複写は直近入院歴の退院紹介医療機関→紹介元医療機関の優先順で取得）

### 紹介経路をプルダウンから選択できる

- **Given** 入院指示画面を開いている
- **When** 紹介経路欄を選択する
- **Then** 「直接入院／自院通院からの入院／自院入院からの入院／他院通院からの転入院／他院入院からの転入院／医療観察入院処遇中の転院」から選択できる

### 病室情報の空床照会ができる

- **Given** 入院指示画面を開いている
- **When** [空床照会] をクリックする
- **Then** 空床照会ダイアログがカレンダー形式で病棟の空床状況を表示する（青色: 使用中、白色: 空床、灰色: 使用不可、表示のみ）

### 空床照会は未確定の入退院指示も反映する

- **Given** 他患者に対して「指示」段階（未確定）の入院指示または退院指示が登録されている
- **When** 空床照会を表示する
- **Then** 確定を待たずに以下のとおり反映される。確定済みと未確定は同じ「使用中」として表示し、色では区別しない
  - 入院指示（病室・ベッドまで指定済み）: 入院予定日**当日**から当該ベッドが使用中
  - 退院指示: 退院予定日の**翌日**から当該ベッドが空床（退院予定日当日は使用中のまま）
- **かつ** 判定は日単位で行い、入院日時・退院日時の時刻は考慮しない

### 「指示」段階で発行できる（病棟確定待ち）

- **Given** 入院指示画面で必要項目を入力している
- **When** [指示] ボタンをクリックする
- **Then** 入院指示が登録される。患者は外来患者のまま、病床管理／入退院情報の入院予定として赤字表示される。未来日・当日・過去日いずれも可。同時にカルテ記事へ「入院指示」の記事が 1 件作成される（記事には病棟・病室は記載せず、指示が出た事実と指示内容のみを記録する）

### 「入院確定」で即時状態変化させられる

- **Given** 入院指示画面で必要項目を入力している
- **When** [入院確定] ボタンをクリックする
- **Then** 患者状態が即座に「入院患者」となる。未実施の外来専用オーダがあれば入院確定時のオーダ確認ダイアログが表示される。未来日付では確定不可

### 入院確定時のオーダ確認ダイアログでオーダを一括中止できる

- **Given** 患者に未実施の外来専用オーダがある
- **When** 入院確定時のオーダ確認ダイアログで対象オーダを選択チェック（または個別の中止アイコン）し、入院確定する
- **Then** 選択したオーダが中止される（個別中止時は伝票毎に削除理由／オーダ中止ダイアログが表示される）。中止箋・削除箋の印刷チェックで関連箋を出力できる

### 入院指示の更新・中止ができる

- **Given** 「指示」段階で登録済みの入院指示がある
- **When** 診療録または指示簿の内容欄から入院指示画面を開き、[変更] または [中止] をクリックする
- **Then** 変更時は内容を修正して更新できる。中止時は削除理由ダイアログで分類（必須）と理由（任意）を入力すると指示が取り消される。削除指示箋の印刷も可

### 指示の更新でカルテ記事は追記される（新規作成しない）

- **Given** 「指示」段階で登録済みの入院指示（カルテ記事作成済み）がある
- **When** 入院指示を変更して更新する
- **Then** カルテ記事は新規作成されず、指示時に作成された記事へ更新内容が追記される。病棟・病室のみの変更はカルテ記事に反映されない（記事に病棟・病室を記載しないため）

### 指示の中止でカルテ記事は取消表示で残る

- **Given** 「指示」段階で登録済みの入院指示（カルテ記事作成済み）がある
- **When** 入院指示を中止する
- **Then** 指示時に作成されたカルテ記事が「取消」表示となる。記事自体は削除されずカルテに残る

### 確定後の状態が反映される

- **Given** 入院確定が完了した
- **When** 各画面を確認する
- **Then** カルテ記事・医師指示簿に確定内容が記録され、入院歴・治療歴に履歴が追加される。入退院情報画面では患者氏名が青字（確定）表示される。指示段階の記事がある場合は同一記事へ確定内容が追記され、新規記事は作成されない（指示なしで直接確定した場合はこのとき記事が作成される）

## 補足

- 空床照会は「予定が立った時点で反映する」方針とする（参考システム挙動準拠。確定を待つと、入院指示時にベッドの重複指定が起きる／退院予定のベッドを次の患者に割り当てられない、という運用上の不都合が生じるため）
- 病室・ベッドが未指定（病室未割当）の入院指示は、占有するベッドを特定できないため空床照会には反映しない
- 未確定の予定を反映する結果、退院指示のキャンセル等で 1 つの病床に複数患者が割り当てられる状況が起こりうる。その競合の扱いは「後負け」で統一する（[病床移動](./us-02-bed-move.md) 参照）
- カルテ記事は指示→更新→確定→中止のライフサイクルを通じて 1 記事に集約する（参考システム挙動準拠: 指示時に作成、更新・確定は同一記事へ追記、中止は取消表示で残す）
- 入院日の初期表示（空欄／操作日時）はマスタで設定
- 「指示箋を印刷する」のチェックで食事指示箋・移動指示箋を出力（マスタ設定）
- 入院形態の選択により入院時文書チェック一覧の内容が変わる（期限管理マスタ依存）
- 入院取消は入院歴画面で行う（本機能では不可）
- 医療観察法オプション利用時は紹介経路に「医療観察入院処遇中の転院」が追加。外部精神科システム連携時は精神科入院有無項目が追加
