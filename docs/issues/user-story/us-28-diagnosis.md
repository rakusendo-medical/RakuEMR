# [看護] 看護診断編集

## ユーザーストーリー

- **As a** 受け持ち看護師
- **I want** 看護診断ダイアログで検索・セット・履歴から診断候補を選定し、項目編集を経て診断を確定したい
- **So that** 看護計画の根拠となる診断情報を明示し、計画明細生成までを一連で完了できる

## 受け入れ基準

### 看護診断ダイアログを開ける

- **Given** 看護計画画面の問題点タブを表示している
- **When** [看護診断より追加] をクリックする
- **Then** 看護診断ダイアログが開かれ、検索／セット／履歴タブと診断閲覧・詳細編集領域が表示される

### 検索タブで診断指標から絞り込める

- **Given** 看護診断ダイアログの検索タブを開いている
- **When** キーワードを入力する（複数AND条件可）、または空文字のままにする
- **Then** 検索結果に該当する診断、または全診断が表示される

### セットタブで看護診断セットから選択できる

- **Given** 看護診断ダイアログのセットタブを開いている
- **When** セットコンボボックスから看護診断セットを選択する
- **Then** セットに紐づく診断情報が一覧表示される。「候補のみ表示」でさらに候補診断のみ抽出可能

### 履歴タブで過去診断を参照・編集できる

- **Given** 履歴タブを開いている
- **When** 過去登録した診断を選択する
- **Then** 当該診断の詳細欄が表示され、内容編集・削除・新規追加が可能。[更新] で履歴が変更される

### 診断候補を選定できる

- **Given** 検索タブまたはセットタブで診断を表示している
- **When** チェックボックス選択／項目編集／項目削除／項目追加 のいずれかを行う
- **Then** 当該診断が候補化される。診断名前のアイコンが選択アイコンに変わり、選択項目件数が表示される

### 候補確定の閉じ操作が区別される

- **Given** 候補を選定している
- **When** [閉じる] ボタンをクリックする、または別の閉じ方（× ボタン等）を行う
- **Then** [閉じる]: 候補が確定保存される。別の閉じ方: 操作内容は破棄される

### 診断詳細の項目を編集・追加・削除できる

- **Given** 診断閲覧で診断を選択して詳細を表示している
- **When** 編集アイコンをクリックして項目をテキストエリアに変更し、確定アイコンで保存する／削除アイコンで項目削除／[新規] で項目追加する
- **Then** 大分類・小分類・項目の各レベルで内容が反映される

### 看護診断を確定できる

- **Given** 候補診断と詳細内容を整えている
- **When** 適用日を入力して [適用] ボタンをクリックする
- **Then** 看護計画画面に看護診断が反映され、看護計画明細として連携される

### 診断登録（最終確定）操作

- **Given** 候補から最終診断を選定している
- **When** 確定する診断名を選択し、診断日を入力して [診断] をクリックする
- **Then** 当該診断が最終診断として確定される

### 診断候補のクリアが可能

- **Given** 候補が複数選定されている
- **When** [診断候補のクリア] をクリックする
- **Then** 全ての候補がクリアされる

### 前回診断候補選択情報が表示される

- **Given** 前回看護診断時に候補選択を行っている
- **When** ダイアログを開く
- **Then** 前回候補選択を行った日時と操作者が表示される

## 補足

- 診断項目の表示有無は看護診断マスタで設定（診断名横の項目表示等）
- 診断ラベル体系（NANDA等）の採用可否は別途検討
- 候補に設定された診断がマスタから削除されている場合、一覧の最後に削除診断名が追加表示される（最新情報を見るには候補クリア）
