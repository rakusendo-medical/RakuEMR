# [病床管理] 病床割り当て

## ユーザーストーリー

- **As a** 病棟事務
- **I want** 入院時にベッドが未指定の患者に病棟マップ上でベッドを割り当てたい
- **So that** 入院確定までに在床位置を確定させ、看護・配膳等の準備に支障が出ないようにする

## 受け入れ基準

### 未割当患者が一覧で表示される

- **Given** 病棟マップを開いている
- **When** 画面右側の未割当者一覧を参照する
- **Then** 入院確定指示が入力済みで、病棟・病室・ベッドのいずれかが「仮」の患者が一覧表示される

### 未割当患者を選択して転棟・転室ダイアログを開ける

- **Given** 未割当者一覧で患者を選択している
- **When** 「移動」ボタンをクリックする、または患者氏名をダブルクリックする
- **Then** 転棟・転室ダイアログが開かれる

### ベッドを割り当てて受け入れできる

- **Given** 転棟・転室ダイアログを表示している
- **When** 割り当てる病室・ベッドと移動日時、配膳先変更日時を入力し登録する
- **Then** 患者の在床ベッドが指定され、未割当一覧から消えて病棟マップに在床として反映される

### オーダリング利用時は隔離・拘束チェックが追加される

- **Given** オーダリング運用時に転棟・転室ダイアログを開いている
- **When** ダイアログを表示する
- **Then** 隔離・拘束の登録用チェック項目が追加で表示される

### 病棟・病室の指定がある場合は範囲外の割当を抑止する

- **Given** 患者に病棟・病室まで指定がある
- **When** 指定範囲外のベッドを割り当てようとする
- **Then** 警告が表示され、確認なしには割り当てられない
