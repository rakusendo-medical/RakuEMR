# [看護] フローシート編集

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 指定日のフローシートでケア内容を入力・更新・削除し、更新履歴を確認したい
- **So that** 実施記録を当日中に画面上で完了し、過去の修正経緯も追跡できる

## 受け入れ基準

### フローシート編集ダイアログを開ける

- **Given** フローシート画面を開いている
- **When** 対象日のフローシートアイコンをクリックする
- **Then** フローシート編集ダイアログが開かれる。表示・入力項目は適用中のフローシートパターンに従う

### ケア内容を新規登録できる

- **Given** フローシート編集ダイアログを開いている
- **When** ケア項目（食事・服薬・看護記録の下段〜サインの上段など）を入力し [登録] する
- **Then** 入力内容がフローシートに反映される。登録後は更新履歴一覧に登録日時・職員名・区分（登録）が記録される

### 登録済み内容を更新・削除できる

- **Given** 登録済みのフローシートを表示している
- **When** [更新] または [削除] をクリックする
- **Then** 更新時は変更内容が反映、削除時は内容が消える。削除した場合でも更新履歴の区分は「更新」として記録され、フローシート履歴ダイアログでは全項目空欄で表示される

### 体重はバイタル編集ダイアログで入力する

- **Given** フローシート編集ダイアログを開いている
- **When** 体重欄を確認する
- **Then** 体重はここでは入力できない（バイタル編集ダイアログで入力する）

### 投薬者の初期表示がマスタ設定で切り替わる

- **Given** マスタ保守／医療機関情報／その他／投薬者初期表示の設定を変更する
- **When** フローシート編集ダイアログを表示する
- **Then** 設定に応じて投薬者欄が「空白（未選択）」または「ログオン者」で初期表示される

### 禁則文字が入力できない

- **Given** テキスト項目を編集している
- **When** `#` `@` などの禁則文字を入力しようとする
- **Then** 当該文字は入力できない

### 更新履歴を時系列で参照できる

- **Given** 複数回更新されたフローシートを表示している
- **When** ダイアログ下部の更新履歴一覧を確認する
- **Then** 更新日時の降順で履歴（パターン名・登録職員名・区分）が表示される。更新日時クリックでフローシート履歴ダイアログ（参照のみ）が開く

### パターン未適用の場合の履歴表示

- **Given** フローシートパターン未適用の状態で登録している
- **When** 更新履歴一覧を表示する
- **Then** パターン名欄に「パターンなし」と表示される

### スクロール位置が保持される

- **Given** フローシート画面でスクロール後にダイアログを開いた
- **When** 編集を完了してダイアログを閉じる
- **Then** フローシート画面のスクロール位置が編集前の位置に戻る

## 補足

- 値の上下限警告（バイタルの異常値）は別ストーリーで検討（バイタル側）
- 一括入力でフローシート登録された場合でも、個別履歴に表示される
- 複数パターンが適用されている場合の入力方法は別ストーリーで扱う
