# [看護] 看護記録表示

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートから部門記録簿の看護記録を呼び出して参照したい
- **So that** バイタル・ケア記録と看護記録（叙述）を行き来して患者像を把握できる

## 受け入れ基準

### フローシート上のタイトルから看護記録ダイアログを開ける

- **Given** フローシートに看護記録のタイトルが表示されている
- **When** タイトルをクリックする
- **Then** 看護記録ダイアログが開かれ、当該記事の内容が表示される

### 部門記録簿で看護記録を時系列参照できる

- **Given** 看護記録メニューから部門記録簿画面を開いている
- **When** 患者を指定する
- **Then** 部門診療録記事が一月毎に括られて表示される（医療機関情報マスタの設定日数まで、最大9日分の直近記事を表示）

### 記載時刻が勤務帯で色分けされる

- **Given** 部門記録簿画面で看護記録を表示している
- **When** 記載時刻欄を確認する
- **Then** 日勤=青文字、準夜=緑文字、深夜=赤文字で表示される

### 記事表示切替で削除・修正記事も含めて参照できる

- **Given** 部門記録簿を表示している
- **When** 記事表示切替を「全て」に切り替える
- **Then** 削除・修正記事および未来日の予定記事も含めて表示される（赤文字タイトルは修正・削除前の元記事）。「通常」では削除・修正・未来日予定は非表示

### 記事選択及び検索で絞り込める

- **Given** 部門記録簿を表示している
- **When** 記事選択及び検索をクリックして検索条件を設定する
- **Then** 表示記事が条件に応じて絞り込まれる（カルテ記事検索機能と共通）

### 記事メタ情報が表示される

- **Given** 看護記録を参照している
- **When** 記事を確認する
- **Then** 記事タイトル、連携項目、記事タグ、操作情報（作成者の職種・氏名・日時、修正者・日時）が表示される

### ページ遷移リンクで前後の記事を辿れる

- **Given** 複数の看護記録が存在する
- **When** ページ遷移リンク（`<<` `>>` 矢印、[前へ] [次へ]、[最新へ]）をクリックする
- **Then** それぞれ前ページ／次ページ／初期表示ページに遷移する（前後ページがない場合はリンクが非活性または非表示）

### 患者状態が日付横に色表示される

- **Given** 部門記録簿を表示している
- **When** 記事履歴/患者状態欄を確認する
- **Then** 日付の横にカルテ記事入力された患者状態が5段階の色で表示される

## 補足

- 部門記録簿の他職種記録（医師記録等）との関係は別途整理
- 「いいね」「コメントする」機能は別ストーリーで扱う
- 患者状態の色分け基準はマスタで管理
