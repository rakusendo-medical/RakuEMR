# [病床管理] 入院手続き

## ユーザーストーリー

- **As a** 病棟事務
- **I want** 入院予定の患者を確定処理したい
- **So that** 入院が事実として記録され、病棟運用・会計・配膳等の後続業務が走り出せる

## 受け入れ基準

### 入院予定患者から手続き画面を開ける

- **Given** 入退院情報画面または病棟マップを表示している
- **When** 入院予定患者の氏名（赤文字）をクリックする、または日付未定者一覧から患者番号をクリックする
- **Then** 入院手続き画面が開かれ、入院指示時の入力（入院日・食事開始日・病室・文書・紹介医療機関・入院決定理由・指示内容など）が初期表示される

### 入院日・食事開始日を変更できる

- **Given** 入院手続き画面を開いている
- **When** 入院日または食事開始日（時間帯含む）を入院期間内に変更する
- **Then** 入院日時から食事開始日時までの間に「食無し」指示（マスタ設定により「臨時欠食」）が自動生成される

### 仮病棟・病室情報を実病棟に確定できる

- **Given** 病室情報が仮病棟・仮病室・仮ベッドである、または指示時から変更が必要
- **When** 病室情報を実値で設定する（医療機関情報マスタで仮病棟入院許可ありの場合は仮病棟のままでも確定可）
- **Then** 当該病室で確定される

### 空床照会から空床状況を確認できる

- **Given** 入院手続き画面を開いている
- **When** 「空床照会」を実行する
- **Then** 空床照会ダイアログがカレンダー形式で病棟の空床状況を表示する。未確定の入退院指示も反映される（入院指示は予定日当日から使用中、退院指示は予定日の翌日から空床。判定は日単位。詳細は [入院指示](./us-08-admission-order.md) 参照）

### 入院確定すると未実施オーダの確認が出る

- **Given** 患者に未実施の外来専用オーダが残っている
- **When** 入院確定を実行する
- **Then** 入院確定時のオーダ確認ダイアログが表示され、選択チェックでオーダを中止できる

### 入院確定後の状態が反映される

- **Given** 入院確定が完了した
- **When** 各画面を確認する
- **Then** 患者氏名表示が赤→黒に変わり、カルテ画面・医師指示簿に確定内容が書き込まれる

### 未来日付では入院確定できない

- **Given** 入院日に未来日付が設定されている
- **When** 入院確定を実行しようとする
- **Then** 確定できない（指示の更新は可能）

### 医師以外が食事開始日を変更すると代行依頼指示となる

- **Given** 医師以外の職員が入院確定を行う
- **When** 食事開始日時を変更している
- **Then** 当該食事療法は入院指示医による代行依頼指示として登録される（オーダ中止操作を伴う場合は代行入力認証ダイアログが表示され、認証医を選択する。複数認証時は最後の認証医が代行依頼医となる）

### 指示箋印刷チェックで食事箋・移動箋を出力できる

- **Given** 指示箋を印刷するチェックを付けて確定／更新する
- **When** 操作ボタンをクリックする
- **Then** 食事箋・移動箋が印刷される（チェック有無の初期値・名称はマスタで設定）

## 補足

- 期限管理マスタで設定された「入院時文書」がチェック一覧として表示され、管理対象を選択できる
- 再入院の場合、食事内容は前回入院時の内容が初期値となる
- 外部精神科システム連携オプション利用時は「精神科入院有無」項目が追加表示される（連携要件は別途整理）
