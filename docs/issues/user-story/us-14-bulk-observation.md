# [隔離拘束] 一括観察記録

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 行動制限下の患者一覧から複数患者の観察記録を一括入力したい
- **So that** 高頻度の観察業務を、患者ごとの画面遷移を繰り返さずに済ませられる

## 受け入れ基準

### 隔離拘束一覧の「記録」タブを表示できる

- **Given** 隔離拘束一覧画面を開いている
- **When** 「記録」タブをクリックする
- **Then** 行動制限下患者の一覧と、患者単位の3段（隔離／拘束／その他）の観察記録マトリクスが表示される

### 検索条件で対象を絞り込める

- **Given** 記録タブを表示している
- **When** 日付・病棟・入院形態（条件設定ダイアログ）・診察記事絞込を指定して [表示] をクリックする
- **Then** 該当条件下の患者一覧が表示される

### 表示対象が記録要件どおり選定される

- **Given** 患者集合に観察記録対象とそうでない患者が混在する
- **When** 一覧を表示する
- **Then** 以下のいずれかを満たす患者のみ表示される
  - 隔離・拘束指示あり
  - 入院病棟が行動制限判定対象 ＋ 観察記録の記録対象
  - 行動範囲指示あり ＋（責任レベルが行動制限判定対象 ＋ 観察記録の記録対象、または、行動制限項目が観察記録の記録対象）

### 区分別の回数枠から一括入力ダイアログを開ける

- **Given** 一覧の隔離／拘束／その他のタイトル回数枠（例: 隔離の16時1回目）を表示している
- **When** 当該回数枠をクリックする
- **Then** 観察記録（区分）一括入力ダイアログが開かれ、選択した時間・回数で記録対象となる患者のみが一覧表示される（未登録患者は「選択」チェックあり、登録済は背景色グレー＋チェックなし）

### 一括入力ダイアログで複数患者分を登録できる

- **Given** 一括入力ダイアログを表示している
- **When** 各患者の状態・内容（最大3000文字、文例ウィザード可）・連携・記録時間・記録者を入力して [登録] する
- **Then** 選択チェックされた患者全員分の観察記録が同一観察日時で登録される。一覧側の対応回数枠が状態色で表示される

### 内容を一括入力できる

- **Given** 一括入力ダイアログを表示している
- **When** 「内容」欄タイトルの [入力] をクリックして一括入力ダイアログで内容（タグ含む）を入力し [設定] する
- **Then** 表示中の入力欄全てに同一内容・タグが反映される

### 個別の時間枠クリックで個別ダイアログが開く

- **Given** 一覧の特定患者の時間枠をクリックする
- **When** 観察記録ダイアログが開かれる
- **Then** 当該患者・対象時間の観察記録ダイアログ（個別）が表示され、複数回数分を一度に入力できる

### 個別記録と一括記録のデータが同一モデルに収まる

- **Given** 同一患者に対する個別記録と一括記録が混在している
- **When** フローシート／隔離拘束タブまたは部門記録簿で参照する
- **Then** 入力経路を問わず時系列に統合表示される

### 隔離・拘束併用時は観察回数が多い方が優先表示される

- **Given** 患者に隔離・拘束が同時指示されている（例: 隔離2回／拘束4回）
- **When** マトリクスと観察記録ダイアログを表示する
- **Then** 多い方（4回）が優先表示される

### 解放時間が一括入力時に赤字で示される

- **Given** 隔離・拘束併用患者の開始指示時に解放時間が登録されている
- **When** 一括入力ダイアログで対象時間が解放時間に該当する
- **Then** 患者氏名横に解放時間が赤字で表示される（隔離・拘束併用時は拘束入力時のみ表示）

### 未来日不可設定時は記録可能な患者のみが一括対象となる

- **Given** マスタ設定で未来日入力不可が有効
- **When** 操作時間より未来の時間帯枠を一括入力で選択する
- **Then** 入力可能な患者のみが一括入力ダイアログに表示される

## 補足

- 観察回数（分割数）は区分ごとにマスタ管理（隔離診察回数／拘束診察回数／その他診察回数）
- 一括時の必須項目は個別と同じ（状態・内容）。記録者初期値はログオン職員、変更可
