# [看護] 一括睡眠活動入力

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 睡眠表で病棟・病室単位の患者リストに対して睡眠活動を一括入力したい
- **So that** 夜間ラウンドの観察結果を、複数患者まとめて短時間で記録できる

## 受け入れ基準

### 睡眠表画面を表示できる

- **Given** 一括入力メニューから睡眠表画面を開いている
- **When** 病棟・病室・日付を指定する
- **Then** 該当範囲の患者リストが時間軸で表示される。表示時間はマスタ（バイタルチェック時間（寝））を基準とした12時間表示

### ログオン職員所属に応じた病棟初期表示

- **Given** ログオン職員の所属区分が病棟名である
- **When** 睡眠表画面を初期表示する
- **Then** 対象病棟が初期表示される（それ以外はプルダウンリスト先頭の病棟）

### 個別の時間枠から睡眠・活動記録を入力できる

- **Given** 睡眠表に患者が表示されている
- **When** 任意患者の任意時間枠をクリックする
- **Then** 選択枠が薄赤色で表示され、睡眠・活動記録ダイアログが開く。フローシート画面の「睡眠・活動」と同じ入力で記録できる

### 連続時間でドラッグ登録できる

- **Given** 同じ睡眠状態を連続時間で登録したい
- **When** 開始時間枠から終了時間枠までドラッグする
- **Then** ダイアログに開始・終了時間が初期表示され、同一状態を一括登録できる

### 同一時間枠を複数患者で一括入力できる

- **Given** 睡眠表に複数患者が表示されている
- **When** 任意の時間枠（タイトル列）をクリックする
- **Then** 当該時間枠の睡眠・活動記録ダイアログが開き、患者リストに表示されている患者全員が一覧表示される。各患者の状態を設定し選択チェックで [登録] すると、選択患者の状態が一括登録される

### 入力結果がフローシートと整合する

- **Given** 一括入力で睡眠活動を保存した
- **When** 同患者のフローシート／睡眠・活動タブを開く
- **Then** 該当時間帯に睡眠活動が反映されている

### タブ間で表示条件は保持されない

- **Given** 一括入力メニュー内で別タブに移動した
- **When** 再度睡眠表タブに戻る
- **Then** 病棟・病室・日付の表示条件は保持されない（再指定が必要）

### 時間枠ホバーでツールチップが表示される

- **Given** 時間枠を選択しようとしている
- **When** 時間枠にカーソルをあてる
- **Then** 選択枠の情報がツールチップ表示される

## 補足

- 睡眠状態の選択肢（入眠／覚醒／離床等）はマスタ管理。仕様は実装時確定
- 睡眠表画面は12時間表示が原則。日中の睡眠記録など24時間運用が必要な場合は別途検討
