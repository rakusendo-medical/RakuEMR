# [隔離拘束] 隔離拘束指示受け

## ユーザーストーリー

- **As a** 病棟看護師長
- **I want** 行動制限下にある患者を一覧で把握し、指示受けサイン・記事・看護記録の状態を管理し、行動制限一覧性台帳を出力したい
- **So that** 病棟全体の行動制限状況をガバナンス基準で把握し、規程に基づく台帳提出と指示受け運用を行える

## 受け入れ基準

### 行動制限下の患者を一覧で確認できる

- **Given** 隔離拘束一覧画面の「指示」タブを開いている
- **When** 病棟・期間・終了者表示有無・入院形態（その他用）を指定して [表示] をクリックする
- **Then** 該当条件下の患者が、患者番号・氏名（年齢）・入院形態・区分（隔離／拘束／隔・拘／その他）・開始/終了日時・指示医・カルテ／看護／指示受けの状態とともに病棟→病室→ベッド昇順で一覧表示される

### 表示対象患者が要件どおり選定される

- **Given** 患者集合に複数のステータスが混在する
- **When** 一覧を表示する
- **Then** 以下のいずれかを満たす患者のみ表示される
  - 隔離・拘束の指示あり（区分: 隔離／拘束／隔・拘）
  - 入院病棟が行動制限判定対象（区分: その他）
  - 行動範囲の指示あり、かつ責任レベルが行動制限判定対象または行動制限項目が観察記録の記録対象（区分: その他）

### ガバナンス警告が色分け表示される

- **Given** 一覧に患者が表示されている
- **When** 開始指示医が精神保健指定医以外、または開始日時から12時間を超過している
- **Then** 開始指示医は赤字、12時間超過時は開始日時も赤字で表示される

### 一覧から開始／終了のカルテ記事を作成・更新できる

- **Given** 一覧の「カルテ（開始）」「カルテ（終了）」欄を確認している
- **When** [未] をクリックする、または [済] をクリックする
- **Then** [未]: カルテ記事作成ダイアログが該当指示種別の初期状態で開かれる。[済]: カルテ記事編集ダイアログで登録済記事を表示・更新できる。終了側の [未] からは隔離拘束の終了指示も発行できる

### 看護記録を作成・更新できる（カルテ済が前提）

- **Given** 一覧の「看護（開始）」「看護（終了）」欄を確認している
- **When** [未] をクリックする
- **Then** カルテ欄が [済] の場合のみ看護記録ダイアログが開かれる。FOCUS／SOAP／フリー形式で本文を入力して登録できる。カルテが [未] の場合は看護記録を作成できない。[済] クリックで編集も可能

### 指示受けサインを登録・変更・削除できる

- **Given** 一覧の「指示受け」欄を確認している
- **When** [未] または既存の指示受け者名をクリックする
- **Then** サイン入力ダイアログが開かれ、職員選択後に [登録]／[更新]／[削除] で操作できる。一次サイン（上段）／二次サイン（下段）の二段階で運用される

### 入院形態フィルタを条件設定ダイアログで指定できる

- **Given** その他区分の患者を入院形態で絞り込みたい
- **When** [条件設定] をクリックして条件設定ダイアログで入院形態を選択する
- **Then** 指定した入院形態が検索条件に反映され、入院形態欄にホバーすると全条件がツールチップ表示される

### 患者番号／カルテアイコンから関連画面へ遷移できる

- **Given** 一覧で患者を確認している
- **When** 患者番号またはカルテアイコンをクリックする
- **Then** 患者番号: 転棟・転室ダイアログ。カルテアイコン: 標準診療種類のカルテ画面（職員マスタの標準診療種類設定に従う）

### 終了日時が継続・変更指示時は「-」表示となる

- **Given** 隔離拘束に継続・変更指示が入っている
- **When** 一覧を表示する
- **Then** 終了日時欄は「-」となり、終了が確定するまで表示されない

### 行動制限一覧性台帳を Excel で出力できる

- **Given** 一覧画面で期間（開始日）と病棟を指定している
- **When** [印刷] をクリックする
- **Then** 期間の開始日に該当する月を対象月として、対象病棟の行動制限一覧性台帳が Excel で出力される。患者単位で隔離・拘束それぞれの日次累計時間・継続最大時間が集計される

## 補足

- 台帳のレイアウト・タグはマスタ管理。タグ詳細は文書キャビネットタグ一覧に従う
- 「指示」タブと「記録」タブで区分「その他」の表示患者が異なる場合がある。本ストーリーは「指示」タブのみを対象（記録タブは別ストーリー）
- ログオン職員以外をサイン入力ダイアログのプルダウンに表示する設定はマスタで制御
