# [外来] 外来一覧

## ユーザーストーリー

- **As a** 外来看護師（または外来受付）
- **I want** 当日の外来受診患者を一覧で確認し、選択した患者にカルテ・オーダー・文書登録などのアクションを実行したい
- **So that** 待機中・診察中・会計待ち・完了の状態を把握しながら受付業務とカルテ業務を行き来できる

## 受け入れ基準

### 当日の外来受診患者を一覧で確認できる

- **Given** 外来一覧画面 (`/outpatient`) を開いている
- **When** 既定状態（フィルタ「すべて」）で表示する
- **Then** 受付#／患者氏名／年齢／性別／区分（初診／再診）／診療科／担当医／予約／受付／状態／備考 列で当日受診者が一覧表示される

### ステータスで絞り込みできる

- **Given** 外来一覧画面でフィルタタブが表示されている
- **When** 「待機中／診察中／会計待ち／完了」のいずれかを選択する
- **Then** 該当ステータスの患者のみが表示される。タブには件数（`待機中 (3)` 等）が併記される

### ステータスはアイコン併用で識別できる（色覚配慮）

- **Given** 一覧に各ステータスの患者が混在している
- **When** ヘッダーのステータス集計 Chip と表内の状態列を表示する
- **Then** 待機中＝時計／診察中＝丸／会計待ち＝砂時計／完了＝チェック の各アイコンが Chip 内に併記される

### 患者を選択するとアクションバーが活性化する

- **Given** 一覧画面でアクションバーが「患者行を選択してアクションを実行できます」と表示されている
- **When** 任意の患者行をクリックする
- **Then** 行が選択ハイライトされ、アクションバーに患者名・属性が表示される。カルテ／オーダー／文書登録／通知／予約／ORCA 送信 の各ボタンが有効化される

### 状態依存ボタンが表示される

- **Given** 患者を選択している
- **When** 選択患者の状態が「待機中」または「診察中」である
- **Then** アクションバーに「会計完了」（contained・success）が表示される
- **Given** 状態が「待機中」である
- **When** アクションバーを確認する
- **Then** 「チェックイン取消」（outlined・warning）も表示される

### チェックイン取消は確認ダイアログを経る（破壊的操作）

- **Given** 待機中の患者を選択している
- **When** 「チェックイン取消」をクリックする
- **Then** 確認ダイアログ（タイトル・説明・キャンセル／取り消す）が表示され、「取り消す」を選んだときのみ操作が完了する

### 行ダブルクリックでカルテ画面へ遷移する

- **Given** 一覧で患者行を表示している
- **When** 患者行をダブルクリックする
- **Then** 該当患者のカルテ画面へ遷移する（マウス操作のショートカット）

## 補足

- 実装: `src/components/outpatient/OutpatientList.tsx`
- 状態と色のマッピングは `STATUS_CONFIG` 定数（待機中=info／診察中=warning／会計待ち=secondary／完了=success）
- 通知／予約／文書登録は別ストーリーで実装予定（本ストーリーではトーストでスタブ）
- ORCA 連携は外部システム連携。本モックではトーストで完了通知のみ
- design-rules.md §3.2 ボタン配置（MUI 標準）／§7.1 ステータス Chip／§10 破壊的操作確認ダイアログに準拠
