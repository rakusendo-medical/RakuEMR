# [看護] 個別バイタル入力

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** バイタル編集ダイアログでBP（上下）／R／P／T／S／W を個別入力し、更新履歴（日時・記録者・操作種別）を確認したい
- **So that** 計測の都度すぐに記録でき、過去の修正経緯も追跡できる

## 受け入れ基準

### バイタル編集ダイアログを開ける

- **Given** フローシート画面を表示している
- **When** 対象日のバイタルアイコンをクリックする
- **Then** バイタル編集ダイアログが開かれ、時間（必須）／BP（上）／BP（下）／R／P／T／S／W／記録者の入力欄が表示される

### バイタル測定値を登録できる

- **Given** バイタル編集ダイアログを開いている
- **When** 時間と測定値を入力して [登録] をクリックする
- **Then** 体温表に値が反映される。記録者は登録時に操作者が自動入力される

### 複数回分を任意順で入力できる

- **Given** バイタル編集ダイアログを開いている
- **When** 複数行に時間順でない値を入力して登録する
- **Then** 表示時には自動的に時間順に並び替えられる

### 時間未入力行は登録されない

- **Given** ダイアログで複数行を編集している
- **When** ある行の時間欄を空欄にして登録する
- **Then** 当該行のデータは削除扱いとなり登録されない

### 値を更新・削除できる

- **Given** 登録済みバイタルがある
- **When** バイタル編集ダイアログで値を変更して [登録] する、または全入力をクリアして [登録] する
- **Then** 更新／削除が反映される

### 更新履歴を時系列で参照できる

- **Given** 過去にバイタルを複数回更新している
- **When** バイタル編集ダイアログ下部の更新履歴一覧を確認する
- **Then** 更新日時の降順で履歴（更新者・更新内容・操作（登録／更新））が表示される。新しい時間の追加は「登録」、既存時間の値変更は「更新」として記録される

### 未来日時入力がマスタ設定で制御される

- **Given** プロパティ設定が`validate.future`（未来日登録不可）または`confirm.future`（未来日確認）になっている
- **When** 現在日時より未来の時間を入力して登録しようとする
- **Then** `validate.future`時はエラーメッセージで登録不可、`confirm.future`時は確認メッセージで進行を選べる

### スクロール位置が保持される

- **Given** フローシート画面でスクロール後にバイタル編集した
- **When** 操作を終えてダイアログを閉じる
- **Then** フローシート画面のスクロール位置が変更前の位置に戻る

## 補足

- バイタル種別ごとの入力単位・桁数仕様は実装時に確定
- 体重（W）はバイタル編集ダイアログで入力する（フローシート編集では入力不可）
