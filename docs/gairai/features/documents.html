文書・ファイル管理

トップ > 機能詳細 > 文書・ファイル管理

共通仕様

文書・ファイル管理は共通コンポーネント（FileRegistrationForm / FileViewForm）を使用し、fileTypeパラメータで文書種別を切り替えて動作します。

共通ファイル操作

操作説明
アップロード署名付きURL取得 → S3へ直接アップロード → サーバーに確定通知
ダウンロード署名付きURL取得 → ブラウザでダウンロード
プレビューファイル一覧から選択して表示

使用API

操作API
アップロードURL取得POST /patients/{patientId}/files/upload-url
ファイル一覧GET /patients/{patientId}/files?fileType={type}
ダウンロードURL取得GET /patients/{patientId}/files/{fileId}/download-url

文書種別一覧

文書種別fileType登録パス閲覧パスソート機能
問診票 questionnaire /:patientId/questionnaireRegist /:patientId/questionnairesView -
院外証明書 externalCertificate /:patientId/externalCertificateRegist /:patientId/externalCertificatesView あり
院内証明書 internalCertificate /:patientId/internalCertificateRegist /:patientId/internalCertificatesView -
紹介状 referralDocument /:patientId/referralDocumentRegist /:patientId/referralDocumentsView あり
既存カルテ existingMedicalRecord /:patientId/existingMedicalRecordRegist /:patientId/existingMedicalRecordsView -
その他ファイル otherFile /:patientId/otherFileRegist /:patientId/otherFilesView -

登録画面（共通）

コンポーネント: FileRegistrationForm

画面構成

  • ファイル選択 FileInput アップロードするファイルを選択
  • プレビュー 表示領域 選択ファイルのプレビュー

アクション

ボタン動作
アップロードファイルをアップロード。成功時は通知表示
キャンセル前の画面へ戻る

操作フロー

ファイル選択 → プレビュー確認 → アップロードボタン → 成功通知 → 前の画面へ戻る

閲覧画面（共通）

コンポーネント: FileViewForm

画面構成

  • ファイル一覧 List / Dropdown 登録済みファイルの一覧
  • ファイルプレビュー 表示領域 選択ファイルの内容表示

アクション

ボタン動作
ファイル選択一覧からファイルを選択してプレビュー
確認ファイル内容の確認完了
戻る前の画面へ戻る
