認証

トップ > 機能詳細 > 認証

ログイン画面

パス: /signin | コンポーネント: SigninPage

認証不要でアクセス可能な唯一の画面です。ユーザーID・パスワードによるログイン認証を行います。

画面構成

  • ユーザーID TextField 最大16文字
  • パスワード TextField (password) 最大64文字

アクション

ボタン動作
ログイン認証処理を実行。成功時は患者検索画面へ遷移。失敗時はエラーメッセージ表示。

操作フロー

ユーザーID入力 → パスワード入力 → ログインボタン → 患者検索画面へ遷移

認証アーキテクチャ

認証保護レイヤー

レイヤーコンポーネント役割
レイヤー1AuthInitializerアプリ起動時の認証状態初期化
レイヤー2ProtectedRoute認証状態チェック。未認証時は/signinへリダイレクト
レイヤー3ProtectedRouteNoPatientIdpatientIdの数値チェック。不正時は/patientSearchへリダイレクト

状態管理

  • 認証状態: Redux authSlice で管理
  • ユーザー情報: Redux userSlice で管理（redux-persistで永続化）
  • APIリクエスト: fetchBaseQueryWithAuth でトークンを自動付与
