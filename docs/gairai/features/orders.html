オーダー管理

トップ > 機能詳細 > オーダー管理

オーダー共通仕様

全オーダーはメインダッシュボードから新規ウィンドウで開かれます。各オーダーは登録/編集/詳細の3画面で構成されます。

オーダーステータス

ステータス説明
作成済みオーダーが登録された初期状態
完了オーダーが実施完了
取消オーダーが取り消された状態

共通操作フロー

ダッシュボードからオーダー起動 → 内容入力 → 登録（確認ダイアログ） → 詳細画面 → 完了 or 取消

処方オーダー

パス: /:patientId/:deptId/orders/prescriptions/register

登録画面 - タブ構成

タブ内容
セット定義済みの薬剤セットから選択
薬剤セット薬剤セットグループから選択
過去処方過去の処方履歴から選択
薬剤一覧薬剤マスタから検索・選択

入力項目

  • 薬剤選択 タブから選択 複数薬剤追加可能
  • 用法 SelectField 用法マスタから選択
  • 備考 TextField (multiline) 3行、自由記述

詳細画面 - アクション

ボタン動作
完了処方を完了ステータスに変更
取消処方を取消ステータスに変更
戻るウィンドウを閉じる

注射オーダー

パス: /:patientId/:deptId/orders/injections/register

登録画面 - タブ構成

タブ内容
セット定義済みの注射セットから選択
過去注射過去の注射履歴から選択
注射一覧注射マスタから検索・選択

入力項目

  • 注射薬選択 タブから選択 -
  • 用法 SelectField 注射用にフィルタ済み
  • 備考 TextField (multiline) 3行

詳細画面 - 追加機能

  • 印刷機能（注射箋PDF出力）
  • 印刷履歴表示

検査オーダー

パス: /:patientId/:deptId/orders/tests/register

登録画面 - タブ構成

タブ内容
検査セット検査セットグループから選択（チェックボックス複数選択）
過去検査過去の検査オーダーから選択

入力項目

  • 検査項目 Checkbox (複数) 検査セットから複数選択
  • 予定日 DatePicker 読み取り専用（自動設定）

テキストオーダー

パス: /:patientId/:deptId/orders/texts/register

入力項目

  • 予定日 DatePicker 読み取り専用
  • メモ TextField (multiline) 4行以上、自由記述
  • 添付ファイル FileInput PDF, JPG, JPEG, PNG対応

処置オーダー

パス: /:patientId/:deptId/orders/procedures/register

登録画面 - タブ構成

タブ内容
処置セット処置セットグループから選択
過去処置過去の処置オーダーから選択

入力項目

  • 処置項目 タブから選択 -
  • 予定日 DatePicker -
  • メモ TextField (multiline) 4行以上
  • 添付ファイル FileInput PDF, JPG, JPEG, PNG対応
  • シェーマ描画 SchemaDrawer Fabric.jsベースの描画ツール

詳細画面 - 追加機能

  • シェーマ表示（CanvasRenderer による読み取り専用表示）
  • 添付ファイルダウンロード

オーダー管理

パス: /:patientId/:deptId/orderManagement | コンポーネント: OrderManagementPage

全オーダーの処理状況を一覧表示する画面です。

画面構成

  • OrderProcessingStatusTable: 全オーダー種別のステータス一覧（読み取り専用）
  • OrderStatusLegend: ステータスの凡例表示

アクション

ボタン動作
終了前の画面へ戻る
