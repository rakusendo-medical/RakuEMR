システム概要

EMR Client は精神科・心療内科向けの電子カルテ（EMR: Electronic Medical Records）Webクライアントシステムです。 React + TypeScript で構築され、ORCA（日医標準レセプトコンピュータ）との連携機能を備えています。

主な特徴

  • Webブラウザベースのシングルページアプリケーション（SPA）
  • 患者情報の一元管理（基本情報・保険・連絡先・エピソード）
  • オーダリングシステム（処方・注射・検査・処置・テキスト）
  • カルテ記載（テンプレート対応・ファイル添付・描画機能）
  • 病名管理（ICD-10コード対応・接頭語/接尾語・履歴管理）
  • 心理検査・評価（バウムテスト・CES-D・GAF）
  • ORCA連携（患者インポート・病名インポート・オーダーエクスポート）
  • 多言語対応（i18n）
