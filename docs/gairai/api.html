API概要

ベースURL: VITE_API_URL 環境変数で設定。全APIは認証トークン付きリクエスト（fetchBaseQueryWithAuth）で呼び出されます。

RTK Queryによるデータフェッチとキャッシュ管理を採用。全31スライス、120以上のエンドポイントで構成されています。
