EMR Client ドキュメント

概要

本ドキュメントは、EMR Client（電子カルテクライアント）の機能仕様、操作マニュアル、およびAPI仕様をまとめたものです。

精神科・心療内科向けの電子カルテシステムで、患者管理、診療記録、オーダー管理、病名管理、各種文書管理、ORCA連携などの機能を提供します。
