## ユーザーストーリー

- **As a** 病棟看護師長
- **I want** 担当病棟の病床配置と在床患者を一画面で確認したい
- **So that** 申し送り前に在床状況と空床を即座に把握できる

## 画面要素（要素ツリー）

```
- 病棟マップ画面
  - ヘッダー領域
    - 病棟タブ群: 利用可能な病棟を1タブ/病棟で提示
      - 病棟タブ × N: 選択中の病棟を1つ保持。クリックで表示病棟を切替
    - 関連機能エントリ群: 同一画面から呼び出せる入口
      - 空床照会ボタン: カレンダー形式の空床状況ダイアログを開く
      - 入退院予定一覧ボタン: 入院／退院をタブ切替する一覧を開く
      - 不在者一覧ボタン: 外出・外泊中の患者一覧を開く
    - 一括入力導線 (選択ありの場合のみ): 「選択中: N室」表示 + 一括入力遷移ボタン + 解除ボタン
  - メイン領域
    - 病室カードグリッド: 表示中病棟の病室をカード形式で並べる
  - 右サイドバー領域（いずれも選択中病棟スコープ）
    - 入院予定者パネル: 入院オーダー済・入院手続き前の患者。各行に予定日と病室バッジ（病室未定＝[病室未]／病室確定＝病室番号、色＋アイコンで判別）。病室確定済の行は[手続き]导线を表示 [us-03]
    - 不在者パネル: 外出・外泊中の在床患者
    - 入院者情報パネル: 病床稼働・性別内訳（男/女）・平均年齢の集計
      - 病室カード × N: 1病室につき1枚
        - カードヘッダー
          - 号室番号: 例「101号室」
          - 病室選択チェック: 一括入力対象としてマーク
        - ベッドリスト
          - ベッドマス × N: 病室内のベッド分
            - ベッド番号アイコン: 性別で配色（男性/女性/空床/使用不可で4状態）
            - 患者氏名: 在床のみ。**③ 病床ステータス**（非占有ベッド）は氏名欄に「空床」／「使用不可」表記
            - 患者ID: 在床のみ
            - **① ステータス（Dr 観察ステータス・占有ベッドのみ）**: 患者の右に1つ色付き表示。**安定／観察中／不安定／重症**の4値（排他）。※これは Dr が患者を観察した状態であり、②バッジ・③病床ステータスとは別軸。**値は診療録作成で入力する**（issue #399・2026-09-15）: ステータスを選んで保存した最新の診療録（取消を除く）の値を「今のステータス」とし、未入力の患者は初期データ（`Patient.status`）を使う。新しく入院した患者の最初のステータスは「安定」。ステータスは診療録とともに保存される（詳細は [ep-16 us-43] AC-10〜12）
            - **② バッジ（運用フラグ・各 on/off で複数重畳）**: 操作を起点とした指示・状態を短縮アイコンで表示
              - 隔離（隔）／拘束（拘）／外出（外）／外泊（泊）の **4 種**。**要報告・預り金のバッジは設けない**（issue #399・2026-09-14 決定）
              - **起点操作（どの操作でバッジが付く/外れるか）**:
                - **隔離（隔）／拘束（拘）**: **隔離拘束指示（[ep-05 us-11]）で隔離／拘束を指示登録すると付く**。継続中（解除されていない＝終了日時なし）の指示がある間だけ点灯し、解除指示（終了）で外れる。有効な隔離拘束指示（`ISOLATION_ORDERS`＋動的分）から導出（subtype 隔離→隔／拘束→拘／隔離拘束→両方）
                - **外出（外）／外泊（泊）**: **外出外泊管理（`/outing`）で外出／外泊を新規申請すると付く**。許可中かつ未帰院の間だけ点灯し、帰院入力で外れる。許可中の外出外泊（`OUTING_RECORDS`＋動的分）から導出（外出→外／外泊→泊）
              - 各項目は 1 つずつ on/off。重畳順は凡例の並びに揃える
            - **③ 病床ステータス（非占有ベッドのみ・2値）**: **空床／使用不可**。占有（患者あり）は本値を持たず、患者の有無で判定する
              - 使用不可: グレー網掛け・クリック不可
            - **④ 救護区分（占有ベッドのみ・1つ・排他4値）**: 移送時の介助度を **1 文字バッジ**で表示。**担（担送）／護（護送）／独（独歩）／未（未入力）**。全患者に必ず 1 つ表示（未入力も表示）。値は患者情報の属性で設定（[ep-15 us-34]）。※Dr観察ステータス（①）や運用バッジ（②）とは別軸
  - フッター領域
    - 患者操作メニュー (患者選択時のみ): 画面下部に固定表示
      - 患者情報サマリ: 氏名・年齢・性別・主治医・病室・ベッド
      - 操作リンク群
        - カルテ遷移リンク
        - 病床移動リンク (us-02 へ)
    - 凡例: 4 系統に分けて表示 — **①ステータス**（安定/観察中/不安定/重症）／**③病床**（空床/使用不可）／**②バッジ**（隔/拘/外/泊）／**④救護区分**（担/護/独/未）
```

## 振る舞い

- **病棟タブ切替**: タブ選択 → 当該病棟のベッド配置に即時切替（「表示」ボタンは設けず、タブ選択のみで反映）
- **ベッドクリック (在床)**: フッターに患者操作メニューを表示。既存挙動の直接カルテ遷移は維持してよい（暫定）
- **ベッドクリック (空床/使用不可)**: 反応しない。空床操作は us-03 で扱う
- **病室選択チェック**: 一括入力対象の選択。複数室選択でヘッダーに「選択中: N室」が出る
- **凡例ホバー**: アイコンの意味を補足（任意）

## 受け入れ基準（AC）

- [ ] **AC-1: 病棟切替で在床患者が表示される**
  - **Given** 病棟マップを開いている
  - **When** 病棟タブを選択する
  - **Then** 当該病棟のベッド配置がレイアウト通りに表示され、稼働中ベッドには在床患者の氏名・患者IDが表示される

- [ ] **AC-2: 使用不可ベッドが視覚的に区別できる**
  - **Given** 病棟マップで病棟を選択している
  - **When** 病棟内に使用不可（または存在しない）ベッドがある
  - **Then** 当該ベッドはグレー網掛けで表示され、クリックしても患者操作が起動しない

- [ ] **AC-3: バッジ（運用フラグ）がアイコンで一覧把握できる**
  - **Given** 病棟マップを表示している
  - **When** 患者に隔離・拘束・外出・外泊のバッジが付与されている
  - **Then** 各ベッドマス内に該当バッジアイコンが重畳表示され、画面下部の凡例（②バッジ）で各アイコンの意味が確認できる
- [ ] **AC-3e: 要報告・預り金のバッジは表示しない（issue #399・2026-09-14）**
  - **Given** 病棟マップを表示している
  - **When** ベッドマスと画面下部の凡例（②バッジ）を確認する
  - **Then** 要報告（報）・預り金（金）のバッジはどの患者にも表示されず、凡例にも出ない（凡例は隔／拘／外／泊の 4 種）。カルテの患者ヘッダーにも「要報告 / 観察事項」アイコンは出ない
- [ ] **AC-3d: 隔離/拘束/外出/外泊バッジは起点操作で付く/外れる**
  - **Given** 病棟マップと、隔離拘束指示（[ep-05 us-11]）／外出外泊管理（`/outing`）を操作できる
  - **When** ある患者に隔離拘束指示（隔離/拘束）を登録する、または外出外泊管理で外出/外泊を新規申請する
  - **Then** 当該患者のベッドに対応バッジ（隔/拘/外/泊）が付く。解除指示または帰院入力を行うとバッジが外れる（継続中の指示・許可中の外出外泊がある間だけ点灯）
- [ ] **AC-3b: Dr観察ステータスは占有ベッドのみ4値で表示される**
  - **Given** 病棟マップを表示している
  - **When** 占有ベッド（患者あり）と非占有ベッド（空床/使用不可）が混在している
  - **Then** 占有ベッドには①ステータス（安定/観察中/不安定/重症のいずれか）が表示され、非占有ベッドには表示されない（代わりに③病床ステータス「空床/使用不可」を表示）
- [ ] **AC-3c: 救護区分が全患者に1文字バッジで表示される**
  - **Given** 病棟マップを表示している
  - **When** 占有ベッド（患者あり）を確認する
  - **Then** 各患者に④救護区分の1文字バッジ（担/護/独/未のいずれか）が必ず1つ表示され（未入力も「未」で表示）、画面下部の凡例（④救護区分）で各文字の意味が確認できる。非占有ベッドには表示されない

- [ ] **AC-4: ベッドから操作メニューを呼び出せる**
  - **Given** 病棟マップを表示している
  - **When** 患者名をクリックする
  - **Then** 画面下部に患者情報サマリと操作リンク（少なくともカルテ遷移・病床移動）が表示される

- [ ] **AC-5: 関連機能の入口が同一画面から呼び出せる**
  - **Given** 病棟マップを表示している
  - **When** 空床照会／入退院予定一覧／不在者一覧のいずれかを選択する
  - **Then** 該当機能のダイアログ・画面に遷移する（空床照会はカレンダー形式の空床状況、入退院予定は入院／退院をタブ切替）

## 状態遷移 / バリデーション

- 病棟タブ切替は副作用なし（保存を伴わない）
- 病床ステータス（③・空床/使用不可）は非占有ベッドのみ。使用不可はマスタ属性から導出（モックでは `Bed.bedStatus:'unavailable'` で代替）
- バッジ（②）は隔離/拘束/外出/外泊の 4 種で、複数同時付与可（各 on/off）。アイコン重畳順序は凡例の並び順に揃える。4 種とも**操作起点から導出**する（補足「②バッジの起点操作」参照）。要報告/預り金のバッジは設けない
- Dr観察ステータス（①・`PatientStatus`）は占有ベッドの患者のみが 1 つ持つ（安定/観察中/不安定/重症の排他 4 値）
- 患者操作メニューは患者選択中のみ表示。別の患者を選択したら内容を差し替え

## 補足

- 表示項目（性別・年齢・主治医の表示有無）はマスタ管理だが、本モックでは固定表示でよい
- **3 概念の分離（2026-08-18 整理）**: 従来 `PatientStatus` に混在していた「外出」「空床」を分離し、次の 3 軸に明確化した。
  - **① ステータス（`PatientStatus`）**: Dr が患者を観察した状態＝安定/観察中/不安定/重症（占有ベッドの患者のみ・排他4値）
  - **② バッジ（`BedFlag`）**: 操作起点の指示・状態＝隔離/拘束/外出/外泊（各 on/off・複数可）。**操作の結果を単一ソース**として導出し、ベッド（`Bed.flags`）にも `Patient` 型にも持たせない。要報告/預り金のバッジは設けない（issue #399・2026-09-14）
  - **③ 病床ステータス（`BedStatus` / `Bed.bedStatus`）**: ベッドの状態＝空床/使用不可（非占有ベッドのみ・2値。占有は「患者の有無」で判定）
  - 旧 `status:'outing'`（外出中）は②バッジ（外出/外泊）へ、旧 `status:'empty'`／`disabled` は③病床ステータス（空床/使用不可）へ移行。**不在（外出 or 外泊）判定はバッジ（`isAbsent(flags)`）を正とする**
- **② バッジの起点操作＝操作結果から導出（ver0.45・2026-09-14）**: 隔離/拘束/外出/外泊の4バッジは「どの操作で付くか」を明確にするため、**起点の指示・登録から導出**する（ベッドには持たせない＝単一ソース化）。起点データの無いバッジは表示しない（初期データで表示されるのは 隔離＝P003・P017／拘束＝P004／外泊＝P006／外出＝P015）。
  - **隔離/拘束** ← 継続中（終了日時なし）の隔離拘束指示（`ISOLATION_ORDERS`＋store `dynamicIsolationOrders`）。隔離拘束指示（[ep-05 us-11]）で登録すると付き、解除指示で外れる。導出＝`activeIsolationFlags`
  - **外出/外泊** ← 許可中かつ未帰院の外出外泊（`OUTING_RECORDS`＋store `dynamicOutings`／帰院上書き `outingReturns`）。外出外泊管理（`/outing`）の新規申請で付き、帰院入力で外れる。導出＝`activeOutingFlags`
  - ベッドの有効バッジは `effectiveBedFlags`（導出の隔離/拘束＋外出/外泊）で合成する。**要報告/預り金のバッジは設けない**（issue #399・2026-09-14 決定。以前は `Bed.flags` の seed で表示していたが、凡例・ベッド表示・カルテ患者ヘッダーの「要報告 / 観察事項」アイコンとも削除）
  - **病棟マップ右側「入院者情報」の隔離・拘束の人数**、**カルテの患者ヘッダーの隔離・拘束表示（[ep-16 us-44]）**も、継続中の隔離拘束指示から同じく判定する
  - **不在（外出 or 外泊）判定**（右サイドバー不在者一覧・空床照会の不在者・退院確定ガード）も同じ導出（`activeOutingFlags` に動的分を合成）を参照し、病棟マップのバッジと一致させる
  - モックのため動的分（追加した指示・外出）はセッション限定・非永続（リロードで seed 準拠へ戻る）
- **④ 救護区分（ver0.38・2026-08-26 追加）**: 移送時の介助度を表す患者属性（`Patient.reliefCategory`＝担送/護送/独歩/未入力・排他4値・未設定は「未入力」）。占有ベッドの各患者に **1 文字バッジ**（担/護/独/未）で必ず表示（未入力も表示）。値は患者情報の属性で設定し（[ep-15 us-34]）、store（`patientReliefCategories`）の上書き ＞ seed の `Patient.reliefCategory` ＞ 既定「未入力」の順で解決する。区分マスタ・配色・1文字（short）は `src/data/mockData.ts` の `RELIEF_CATEGORY_CONFIG` に集約（差し替え可能）。①②③とは別軸。
- 「表示」ボタンは現行モックに存在せずタブ切替で代用しているため、本 spec でもタブ切替方式を採用
- 別メニューから戻った際の初期表示病棟（前回病棟か固定か）は別途検討
- 「入退院情報ボタン」（表示病棟のサマリを開く関連機能エントリ）は使用しなくなったため削除（ver0.16 でサマリ＝稼働率・隔離・拘束・観察を右サイドバー「入院者情報」パネルへ統合済み）。※「入退院情報画面 (/admission)」とは別物で、そちらは現行どおり
- 入院者情報パネルの性別内訳（患者／在院者／不在者 各列）は男・女の2区分で表示する。旧実装にあった「他」区分は使用しなくなったため削除（ver0.18）
