## ユーザーストーリー

- **As a** 病棟事務
- **I want** 入院時にベッドが未指定の患者に病棟マップ上でベッドを割り当てたい
- **So that** 入院確定までに在床位置を確定させ、看護・配膳等の準備に支障が出ないようにする


## 振る舞い

- **未割当者一覧ボタンクリック**: パネル開閉。開いた状態で対象患者行を表示
- **未割当行の「移動」ボタン or 患者行ダブルクリック**: 転棟・転室ダイアログを割当モードで開く。フォームの初期値は患者の指定情報から導出
- **指定範囲外ベッドの選択**: 警告ダイアログ表示。続行で範囲外割当可、キャンセルで再選択
- **登録完了**: 当該患者を未割当一覧から除去し、病棟マップ上の対応ベッドに在床表示。割当済の状態でカルテ遷移可能
- **オーダリング運用時**: 隔離・拘束チェック項目を追加表示

## 受け入れ基準（AC）

- [ ] **AC-1: 未割当患者が一覧で表示される**
  - **Given** 病棟マップを開いている
  - **When** 画面右側の未割当者一覧を参照する
  - **Then** 入院確定指示が入力済みで、病棟・病室・ベッドのいずれかが「仮」の患者が一覧表示される

- [ ] **AC-2: 未割当患者を選択して転棟・転室ダイアログを開ける**
  - **Given** 未割当者一覧で患者を選択している
  - **When** 「移動」ボタンをクリックする、または患者氏名をダブルクリックする
  - **Then** 転棟・転室ダイアログが開かれる

- [ ] **AC-3: ベッドを割り当てて受け入れできる**
  - **Given** 転棟・転室ダイアログを表示している
  - **When** 割り当てる病室・ベッドと移動日時、配膳先変更日時を入力し登録する
  - **Then** 患者の在床ベッドが指定され、未割当一覧から消えて病棟マップに在床として反映される

- [ ] **AC-4: オーダリング利用時は隔離・拘束チェックが追加される**
  - **Given** オーダリング運用時に転棟・転室ダイアログを開いている
  - **When** ダイアログを表示する
  - **Then** 隔離・拘束の登録用チェック項目が追加で表示される

- [ ] **AC-5: 病棟・病室の指定がある場合は範囲外の割当を抑止する**
  - **Given** 患者に病棟・病室まで指定がある
  - **When** 指定範囲外のベッドを割り当てようとする
  - **Then** 警告が表示され、確認なしには割り当てられない

## 状態遷移 / バリデーション

- 未割当判定: 病棟「仮」 OR 病室「仮」 OR ベッド「仮」のいずれか
- 範囲外判定: 患者の指定病棟/病室と異なるベッドを選択した場合
- 範囲外確認: 警告ダイアログ表示 → 続行 / キャンセル
- ベッド選択肢: 該当病室の空きベッドのみ（在床/使用不可は除外）

## 補足

- 指示箋（移動・食事箋）の表示有無・名称・帳票レイアウトはマスタ設定
- 性別による病室制約のチェックは別ストーリーで検討（依存）
- ダイアログ本体は us-02 と共通、モード差異（新規/履歴/割当）でラベル・初期値・履歴欄表示を切替
