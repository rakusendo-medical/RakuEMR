## 前提（再設計方針）

- **病棟は入院オーダー時に必須・確定**する（[ep-03 us-08](../ep-03-admission-discharge-order/us-08-admission-order.spec.md)）。よって「病棟未割当」は発生しない。残る未確定は **病室未定（病室・ベッド未定）のみ**。
- 病室未定の患者は病棟マップ右サイドバーの **入院予定者パネル** に `[病室未]` バッジで表示される（旧「未割当者一覧パネル」は廃止）。
- 病室の確定（割り当て）は**看護師**が行い、確定後に**入院手続き**へ進める（手続き完了＝病室確定が前提。[ep-02 us-05](../ep-02-admission-discharge/us-05-admission-confirm.spec.md)）。
- ライフサイクル全体は画面設計書 [docs/design/screens/ep-01-bed-map/ward-map.md](../../design/screens/ep-01-bed-map/ward-map.md) のフローチャート参照。

## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 入院オーダー済で病室が未定の患者に、病棟マップから病室・ベッドを割り当てたい
- **So that** 入院手続き（本入院）までに在床位置を確定させ、看護・配膳等の準備に支障が出ないようにする

## 画面要素（要素ツリー）

```
- 病棟マップ画面（us-01参照）
  - 右サイドバー
    - 入院予定者パネル（選択中病棟スコープ）
      - 入院予定者行 × N: 入院オーダー済・手続き前の患者
        - 氏名
        - 病室バッジ: [病室未]（病室未定・黄＋?）/ 病室番号（病室確定・緑＋🚪）
        - 予定日: 入院予定日
        - 詳細ボタン: 入院指示ダイアログを開く（病室・ベッドの設定＝病室割り当てを行える）
        - 手続きボタン: 入院手続きダイアログを開く（病室確定済の行のみ表示）
- 入院指示ダイアログ（病室割り当て手段。ep-03 us-08 と共通）
  - 病室情報: 病棟（必須・確定）／病室セレクト／ベッドセレクト（空きベッドのみ）
  - 病室未定チェック: ON で病室・ベッドを未定のまま登録（病棟は必須）

  - 更新ボタン: 病室・ベッドを設定して指示を更新（病室確定）
```

## 振る舞い

- **入院予定者の病室バッジ**: 病室未定は `[病室未]`、病室確定済は病室番号を色＋アイコンで表示。
- **病室未定行の[詳細]クリック**: 入院指示ダイアログを開く。病室・ベッドを設定し更新すると病室が確定する（病室バッジが病室番号表示に変わる）。
- **「病室未定」チェック**: 入院指示ダイアログで ON にすると病室・ベッドのセレクトを無効化し、病室未定として登録（病棟は必須のため常に確定）。
- **病室確定後の[手続き]**: 病室確定済の入院予定者行に[手続き]が現れ、入院手続きダイアログ（[ep-02 us-05](../ep-02-admission-discharge/us-05-admission-confirm.spec.md)）を起動できる。
- **指定範囲外ベッドの選択**: 患者の指定病室と異なるベッドを選ぼうとした場合は警告（モックでは UI のみ）。
- **空きベッドのみ選択可**: 在床・使用不可ベッドは選択肢から除外。

## 受け入れ基準（AC）

- [ ] **AC-1: 病室未定の入院予定者が判別表示される**
  - **Given** 病棟マップの入院予定者パネルを参照している
  - **When** 病室未定の患者を確認する
  - **Then** 当該患者行に `[病室未]` バッジ（色＋アイコン）が表示され、病室確定済の患者（病室番号バッジ）と判別できる

- [ ] **AC-2: 病室未定の患者に病室・ベッドを割り当てられる**
  - **Given** 病室未定の入院予定者行の[詳細]から入院指示ダイアログを開いている
  - **When** 病室・ベッドを設定して更新する
  - **Then** 当該患者の病室が確定し、入院予定者行のバッジが病室番号表示に変わる

- [ ] **AC-3: 病棟は必須で、病室のみ未定にできる**
  - **Given** 入院指示ダイアログを開いている
  - **When** 病棟を選択せず登録しようとする / 「病室未定」をチェックする
  - **Then** 病棟は必須で未選択にできず、病室・ベッドのみ未定として登録できる（病棟未割当は発生しない）

- [ ] **AC-4: 病室確定済の入院予定者から入院手続きへ進める**
  - **Given** 病室が確定した入院予定者行
  - **When** [手続き]ボタンをクリックする
  - **Then** 入院手続きダイアログが開く（病室未定の行には[手続き]は表示されない）

- [ ] **AC-5: 空きベッドのみ割り当てられる**
  - **Given** 入院指示ダイアログで病室を選択している
  - **When** ベッドを選ぶ
  - **Then** 当該病室の空きベッドのみが選択肢に表示される（在床／使用不可は除外）

## 状態遷移 / バリデーション

- 病室確定判定: 病室・ベッドが実値で設定済（病棟は常に確定）。
- 病室未定: 病室「未」 OR ベッド「未」。**病棟「仮」は廃止**（病棟は入院オーダー時に必須）。
- ベッド選択肢: 該当病室の空きベッドのみ（在床／使用不可は除外）。

## 補足

- 既入院患者の病床移動（病棟内／病棟間）は [us-02 病床移動](./us-02-bed-move.spec.md) を参照。転棟・転室ダイアログ（割当モード）は将来的な再配置导线として残置するが、手続き前の入院予定者の病室確定は本ストーリーの入院指示ダイアログ経由に集約する。
- 指示箋（移動・食事箋）の表示有無・名称・帳票レイアウトはマスタ設定。
- 性別による病室制約のチェックは別ストーリーで検討（依存）。
