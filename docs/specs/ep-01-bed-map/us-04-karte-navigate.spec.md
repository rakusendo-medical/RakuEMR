## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 病棟マップ上の患者から直接カルテ画面に遷移したい
- **So that** 患者検索を経由せずに対象患者のカルテを開け、複数患者を順に確認できる

## 画面要素（要素ツリー）

```
- 病棟マップ画面（us-01参照）
  - メイン領域
    - 病室カードグリッド
      - 病室カード
        - ベッドリスト
          - ベッドマス（在床のみ）
            - カルテ遷移アイコン: 患者名横に表示。クリックでカルテへ
  - フッター領域
    - 患者操作メニュー（患者選択時）
      - 操作リンク群
        - カルテ遷移リンク
- カルテ画面（/karte-alpha/:patientId）
  - ヘッダー領域
    - 患者基本情報サマリ
    - 隣接患者ナビゲーション群（病棟マップ経由で開いた場合のみ表示）
      - 前患者ボタン: 「<」、病棟マップ表示順の前の患者へ
      - 次患者ボタン: 「>」、病棟マップ表示順の次の患者へ
    - 戻るボタン
  - メイン領域: 既存タブ群
    - 初期表示タブ: 標準診療種類による分岐
      - 標準診療種類=カルテ: カルテタブ
      - 標準診療種類=看護記録: 部門記録簿（看護記録）タブ
```

## 振る舞い

- **カルテアイコン／カルテ遷移リンククリック**: 当該患者のカルテ画面に遷移。標準診療種類が「看護記録」運用なら部門記録簿（看護記録）画面、それ以外はカルテ画面を初期表示
- **隣接患者ナビゲーション**: カルテ画面の `<` / `>` で病棟マップ表示順の前後患者のカルテへ遷移
- **外来患者カルテ**: 病棟マップ経由ではない開き方の場合、`<` / `>` ボタンを表示しない
- **空床選択**: カルテ遷移メニューを非表示／非活性

## 受け入れ基準（AC）

- [ ] **AC-1: カルテアイコンからカルテ画面に遷移できる**
  - **Given** 病棟マップで在床患者の行を表示している
  - **When** 患者名横のカルテアイコンをクリックする
  - **Then** 当該患者のカルテ画面が開かれる（患者メニュー [診療録] と同じ画面）

- [ ] **AC-2: 標準診療種類が看護記録の場合は部門記録簿が開く**
  - **Given** 標準診療種類が「看護記録」に設定されている運用
  - **When** カルテ遷移を実行する
  - **Then** 「部門記録簿（看護記録）」画面が開かれる

- [ ] **AC-3: ヘッダの矢印で隣接患者に遷移できる**
  - **Given** カルテ画面を開いている（病棟マップ経由）
  - **When** ヘッダ部の左矢印「<」または右矢印「>」をクリックする
  - **Then** 病棟マップの表示順に従って前後の患者のカルテに遷移する

- [ ] **AC-4: 外来患者には矢印が表示されない**
  - **Given** 病棟マップから遷移したのではない外来患者のカルテを開いている
  - **When** カルテ画面を表示する
  - **Then** 隣接患者遷移用の `<` `>` 矢印は表示されない

- [ ] **AC-5: 空床からは遷移できない**
  - **Given** 空床を選択している
  - **When** カルテ遷移操作を実行しようとする
  - **Then** カルテ遷移メニューは選択不可、または表示されない

## 状態遷移 / バリデーション

- 隣接患者ナビゲーション表示条件: 開いた経路が病棟マップ かつ 在床患者
- 病棟マップ表示順: 病室番号 → ベッド番号 の昇順
- 端患者の挙動: 先頭で `<`、末尾で `>` は非活性（または非表示）

## 補足

- カルテ画面の初期表示タブは利用ロールごとに別途検討（本 spec では標準診療種類設定のみ反映）
- 標準診療種類の設定はマスタ管理。本モックでは固定値で代替可
- 病棟マップから渡す情報は遷移元コンテキスト（経路 + 表示順）。ストアまたは URL クエリで受け渡し
