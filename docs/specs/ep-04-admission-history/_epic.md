## 概要

患者の入退院履歴を一元管理する。オーダ（入退院指示）に伴う情報は自動入力され、入院形態変更・入院取消・退院取消などの是正操作も本機能で行う。オーダを伴わない他病院での入退院は対象外（治療歴で扱う）。

## ゴール

- 患者の入退院履歴を時系列で参照できる
- オーダ起点の自動入力により二重入力を避ける
- 入院形態変更・入退院取消・形態変更取消といった是正操作を一元化する
- 関連の食事歴・移動歴・隔離歴へワンクリックで遷移できる

## スコープ

### 含む

- 入院歴／退院歴の参照（タブ切替）
- 入院決定の理由・退院決定の理由・退院後処置・帰住先の手動更新
- 入院形態変更（任意／医療保護／措置等）の追加
- 入院形態変更日時の更新（現在入院中のみ）
- 入院形態変更の取消（変更取消）
- 入院取消・退院取消（直近入院歴かつ現在入院中の場合のみ）

### 含まない

- 入退院指示そのもの（[ep-03 入退院指示]）
- 月次予定の参照（[ep-02 入退院手続き]）
- オーダを伴わない他病院での入退院（治療歴で対応）
- 食事歴・移動歴・隔離歴の編集（参照リンクのみ提供）

## 主要画面要素（エピック俯瞰）

```
- 入退院歴画面（/admission タブ「入院歴」）
  - ヘッダー領域
    - 患者選択（複数患者の履歴を参照可能、ブレッドクラム形式）
    - 入院時／退院時タブ
    - 関連履歴リンク群: 食事歴 / 移動歴 / 隔離歴
  - 左ペイン: 入院履歴リスト
    - 期間グループ × N: 1 入院期間（initial admit → discharge or 入院中）
      - 期間ヘッダー: 入院日 ～ 退院日（入院中なら「入院中」）
      - 形態レコード × N: 同一期間内の入院形態（initial + 形態変更履歴）
        - 形態名 + 形態適用期間（admitDate ～ this record's dischargeDate）
        - クリックで右ペインに詳細表示
  - 右ペイン: 詳細
    - 入院時タブ: 入院日・指示医・病棟（病室・ベッド）・入院形態・入院決定の理由
    - 退院時タブ: 退院日・指示医・退院区分・転帰・退院決定の理由・退院後処置・帰住先
    - 注意喚起: 期限管理文書は取消で削除されるため、事前ダウンロードを促す
    - 操作ボタン
      - 登録（理由等の更新）
      - 形態変更（最新形態のみ）
      - 変更取消（形態変更レコードのみ）
      - 入院取消（直近入院歴かつ現在入院中のみ）
      - 退院取消（直近退院歴のみ）
- 入院形態変更ダイアログ（形態変更ボタンから起動）
  - 新形態セレクト + 形態変更日時 + 入院時文書チェック群（形態に応じて変動）
  - 操作: 登録 / キャンセル
- 削除コメントダイアログ（取消・変更取消で起動、ep-03 の DeleteReasonDialog 再利用）
  - 分類セレクト + 理由テキスト
- 確認メッセージ
  - 入院時文書／退院時文書が追加されている場合の削除確認
  - 入院固有オーダが残っている場合の取消不可警告
```

## 完了条件

- 全子ストーリーの AC がチェック済み
- オーダ確定で履歴が自動生成される（ep-02/ep-03 の確定操作と連動）
- 入院・退院日時は本画面では変更不可（指示の更新で対応）
- 形態変更・取消操作が監査可能（削除コメントダイアログでの理由記録）

## 入口

- `/admission` 画面のタブ「入院歴」（ep-02 と画面共有）
- ep-01 病棟マップ・カルテ画面の患者基本情報からも将来的にリンクを設ける想定（フェーズ 2）

## 依存

- 入退院指示（ep-03）／入退院手続き（ep-02）— オーダ確定で履歴が生成される
- 患者基本情報、住居区分マスタ、期限管理マスタ、削除理由分類マスタ
- 入院形態マスタ（ADMIT_FORM_TYPES、ADMIT_DOCS_BY_FORM）

## オプション機能

- 外部精神科システム連携時は精神科入院有無・問診結果・退院後の所在の項目が追加表示
