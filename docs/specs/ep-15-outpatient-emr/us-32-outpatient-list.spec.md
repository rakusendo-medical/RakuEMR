## ユーザーストーリー

- **As a** 外来看護師（または外来受付）
- **I want** 当日の外来受診患者を一覧で確認し、選択した患者にカルテ・オーダー・文書登録などのアクションを実行したい
- **So that** 待機中・診察中・会計待ち・完了の状態を把握しながら受付業務とカルテ業務を行き来できる

## 画面要素（要素ツリー）

```text
- 外来一覧画面 (/outpatient)
  - ヘッダー部
    - タイトル: 「外来一覧」
    - 日付表示: 当日（モック固定）
    - ステータス集計 Chip 行: 待機中／診察中／会計待ち／完了 各件数（icon 併用）
  - フィルタタブ
    - すべて / 待機中 / 診察中 / 会計待ち / 完了
    - 各タブに件数併記（例: 「待機中 (3)」）
  - 患者一覧テーブル
    - 列: 受付# / 患者氏名 / 年齢 / 性別 / 区分（初診／再診） / 診療科 / 担当医 / 予約 / 受付 / 状態 / 備考
    - 行クリック: 行を選択ハイライト + アクションバー活性化
    - 行ダブルクリック: カルテ画面へ遷移
    - 状態列: ステータス Chip（色 + アイコン併用）
  - アクションバー（フッター固定）
    - 未選択時: 「患者行を選択してアクションを実行できます」
    - 選択時: 患者名・属性表示 + 操作ボタン群
      - 共通操作: カルテ（contained）／オーダー／文書登録／通知／予約／ORCA 送信
      - 状態依存:
        - 状態 = 待機中 or 診察中: 「会計完了」（contained・success）
        - 状態 = 待機中: 「チェックイン取消」（outlined・warning）
  - チェックイン取消確認ダイアログ
    - タイトル / 説明 / キャンセル + 取り消す（破壊的）
```

## 振る舞い

- **画面遷移直後**: フィルタ「すべて」で当日の全患者を表示。アクションバーは非活性（プレースホルダ表示）
- **フィルタタブ切替**: 該当ステータスの患者のみ表示。タブ件数は再計算しない（モックのため固定でも可）
- **行クリック**: 単一選択。アクションバーが患者属性で更新される
- **行ダブルクリック**: 該当患者のカルテ画面 `/karte/:patientId` へ遷移（段階 1 から最終形を先行採用）
- **「カルテ」ボタンクリック**: ダブルクリックと同じ遷移
- **「会計完了」クリック**: トーストで完了通知（モック）。状態を「完了」に更新
- **「チェックイン取消」クリック**: 確認ダイアログ → 「取り消す」でトースト通知 + 行を一覧から除外（モック）
- **「ORCA 送信」クリック**: トーストで完了通知のみ（外部連携モック）
- **通知／予約／文書登録**: トースト「準備中」または「完了」（別ストーリーで実装予定）

## 受け入れ基準（AC）

- [x] **AC-1: 当日の外来受診患者を一覧で確認できる**
  - **Given** `/outpatient` を開いている
  - **When** 既定状態（フィルタ「すべて」）
  - **Then** 受付#／氏名／年齢／性別／区分／診療科／担当医／予約／受付／状態／備考 の各列で当日受診者が表示される

- [x] **AC-2: ステータスで絞り込みできる**
  - **Given** フィルタタブが表示されている
  - **When** 「待機中／診察中／会計待ち／完了」のいずれかを選択
  - **Then** 該当ステータスの患者のみが表示され、タブには件数が併記される

- [x] **AC-3: ステータスはアイコン併用で識別できる（色覚配慮）**
  - **Given** 一覧に各ステータスが混在
  - **When** ステータス集計 Chip と表内状態列を表示
  - **Then** 待機中＝時計／診察中＝丸／会計待ち＝砂時計／完了＝チェック の各アイコンが Chip 内に併記される

- [x] **AC-4: 患者選択でアクションバーが活性化する**
  - **Given** 一覧でアクションバーが「患者行を選択して〜」表示
  - **When** 患者行をクリック
  - **Then** 行ハイライト + 患者属性表示 + カルテ／オーダー／文書登録／通知／予約／ORCA 送信 が有効化

- [x] **AC-5: 状態依存ボタンが表示される**
  - **Given** 患者を選択している
  - **When** 状態が「待機中」または「診察中」
  - **Then** 「会計完了」ボタンが contained・success 色で表示される
  - **Given** 状態が「待機中」
  - **Then** 「チェックイン取消」も outlined・warning で表示される

- [x] **AC-6: チェックイン取消は確認ダイアログを経る**
  - **Given** 待機中の患者を選択
  - **When** 「チェックイン取消」をクリック
  - **Then** 確認ダイアログが表示され、「取り消す」を選んだときのみ操作完了

- [x] **AC-7: 行ダブルクリックでカルテ画面へ遷移する**
  - **Given** 一覧で患者行を表示
  - **When** ダブルクリック
  - **Then** 該当患者のカルテ画面 `/karte/:patientId` へ遷移

- [x] **AC-8: 設計ルール準拠**
  - design-rules.md §3.2（MUI 標準ボタン配置）／§7.1（ステータス Chip）／§10（破壊的操作確認ダイアログ）に準拠

## 状態遷移 / バリデーション

ステータス遷移（モック想定）:

```text
待機中 ─会計完了─▶ 完了
   │
   └─チェックイン取消─▶ 一覧から除外

診察中 ─会計完了─▶ 完了

会計待ち ─会計完了─▶ 完了
```

## 補足

- 既実装は AC を概ね充足。`STATUS_CONFIG` 定数で色・アイコンを集中管理
- 段階 1 から `/karte/:patientId`（最終形）を先行採用。`/karte-outpatient/:patientId` は新設しない
- 通知／予約／文書登録／ORCA は別ストーリー扱い、本ストーリーではトースト出力で AC を満たす
