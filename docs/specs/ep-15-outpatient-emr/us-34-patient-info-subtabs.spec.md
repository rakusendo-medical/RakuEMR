## ユーザーストーリー

- **As a** 外来看護師（および主治医・受付）
- **I want** カルテ画面の「患者情報」タブで、基本情報・属性・保険・連絡先・病名・エピソード・メモ をサブタブで切り替えて閲覧／編集したい
- **So that** 診察中に患者の各情報を素早く参照・更新でき、編集単位ごとに保存できる

## 画面要素（要素ツリー）

```text
- カルテ画面 > 患者情報メインタブ
  - サブタブ Chip 群（横並び・小型）
    - 基本情報（既定選択）
    - 属性
    - 保険
    - 連絡先
    - 病名
    - エピソード
    - メモ
  - サブタブ内コンテンツ領域（サブタブごとに切替）
    - 基本情報サブタブ
      - 主訴セクション
      - アレルギーセクション（薬剤・食物含む。TriStateField + 詳細 ChipInput）
      - 感染症・既往セクション（肝炎／梅毒／HIV）
      - 服薬・基礎疾患セクション（他科薬／喘息／その他）
      - 問診表セクション
      - 現在の状態セクション（授乳／妊娠／フレイル）
      - その他セクション（宗教／メモ）
      - 預かり金セクション
    - 属性サブタブ
      - 共通: 生年月日／住所／職業／緊急連絡先（モック）
      - mode='inpatient' 追加: 入院日／病棟／病室／受け持ち看護師
    - 保険サブタブ: 保険情報（保険者番号／記号番号／本人家族区分）
    - 連絡先サブタブ: 電話／メール／緊急連絡先（家族構成含む）
    - 病名サブタブ: 主病名／副病名（ICD10）／開始日／転帰
    - エピソードサブタブ: 経過記録（外来／入院共通の時系列メモ）
    - メモサブタブ: 自由記述メモ
  - サブタブ内アクションバー
    - 「保存」（contained・current mode color）
    - 「キャンセル」（text）
    - 未保存変更検知 Chip（変更ありで表示）
- 未保存検知ダイアログ（カルテ画面の他タブ／戻るリンク操作時）
  - タイトル: 「保存していない変更があります」
  - 説明: 該当サブタブ名を提示
  - 操作: 「破棄して戻る」（warning） / 「編集に戻る」（cancel）
```

## 振る舞い

- **メインタブ「患者情報」初回表示**: サブタブ「基本情報」が選択される
- **サブタブ切替**: クリックでサブタブ切替。**現サブタブの未保存変更はメモリ内に保持**（破棄しない）
- **サブタブ内の編集操作**: フィールド変更で「変更あり」フラグを立てる
- **「保存」クリック**: 該当サブタブのみ保存（他サブタブの未保存変更は影響を受けない）。保存後フラグをクリア
- **「キャンセル」クリック**: 該当サブタブの未保存変更を破棄（確認ダイアログなし、現状値に戻す）
- **TriStateField（なし／あり／不明）**:
  - 「あり」を選択 → 詳細 TextField または ChipInput を条件表示
  - 「なし」「不明」 → 詳細領域は非表示
- **ChipInput**: Enter で追加、× で削除（既存 PatientBasicPage 実装と同じパターン）
- **メインタブ切替時に未保存変更がある**: 未保存検知ダイアログ → 「破棄して戻る」または「編集に戻る」
- **「一覧に戻る」クリック時に未保存変更がある**: 同上ダイアログ
- **mode='outpatient'**: エピソード／メモは外来／入院共通で表示
- **mode='inpatient'**: 属性サブタブに入院専用情報セクション（入院日・病棟・受け持ち看護師）が追加される

## 受け入れ基準（AC）

- [ ] **AC-1: 患者情報タブにサブタブが表示される**
  - **Given** カルテ画面の「患者情報」メインタブを選択している
  - **Then** Chip 風の小型サブタブが 7 つ（基本情報／属性／保険／連絡先／病名／エピソード／メモ）表示され、既定で「基本情報」が選択される

- [ ] **AC-2: 基本情報サブタブで主訴・アレルギー・感染症等を編集できる**
  - **Given** 「基本情報」サブタブを表示
  - **Then** 主訴／アレルギー／感染症・既往（肝炎／梅毒／HIV）／服薬・基礎疾患（他科薬／喘息／その他）／問診表／現在の状態（授乳／妊娠／フレイル）／その他（宗教／メモ）／預かり金 の各セクションが表示・編集可能
  - **Given** TriState 項目で「あり」を選択
  - **Then** 詳細入力フィールドが条件表示

- [ ] **AC-3: サブタブは Chip 風小型タブで階層が視覚的に区別される**
  - **Given** メインタブとサブタブが同時表示
  - **Then** メインタブ = 標準サイズ／太字、サブタブ = Chip 風小型表示

- [ ] **AC-4: 編集中の未保存変更はサブタブ切替で保持される**
  - **Given** 「基本情報」で変更を加えた状態
  - **When** 「保険」サブタブに切替、再度「基本情報」に戻る
  - **Then** 変更内容は保持されている（メモリ内）

- [ ] **AC-5: 編集単位ごとに保存できる**
  - **Given** いずれかのサブタブで変更を加えた
  - **When** タブ内アクションバーで「保存」クリック
  - **Then** 該当サブタブのみ保存され、他サブタブの未保存変更は影響を受けない

- [ ] **AC-6: 未保存変更がある状態でカルテ画面外に離脱しようとすると確認される**
  - **Given** あるサブタブに未保存変更がある
  - **When** 「一覧に戻る」または別メインタブをクリック
  - **Then** 「保存していない変更があります」確認ダイアログ表示。「破棄して戻る／編集に戻る」を選択

- [ ] **AC-7: 一部サブタブは外来／入院で表示が変わる**
  - **Given** `mode='outpatient'` で患者情報タブ表示
  - **Then** エピソードは共通表示
  - **Given** `mode='inpatient'` で患者情報タブ表示
  - **Then** 属性サブタブに入院専用情報（入院日・病棟・受け持ち看護師）セクションが追加表示

- [ ] **AC-8: 設計ルール準拠**
  - design-rules.md §3.2（アクションバー右寄せ）／§10（未保存確認ダイアログ）／§11（未保存検知）に準拠

## 状態遷移 / バリデーション

サブタブごとの未保存検知（独立）:

```text
サブタブ A: clean ─編集─▶ dirty ─保存─▶ clean
                              └─キャンセル─▶ clean
サブタブ B: 独立して同様
...
カルテ画面離脱: いずれかのサブタブが dirty なら確認ダイアログ
```

## 補足

- 既存 `PatientBasicPage` は AC-2 を概ね充足（TriStateField／ChipInput／未保存検知 Chip／編集セクション）。本ストーリーで「基本情報」サブタブのコンテンツとして取り込む
- ルート `/outpatient/:patientId/basic` は段階 1 終了時に **撤去** または **互換リダイレクト**（_epic.md「残 PM 確認事項」#5）
- 編集権限による read-only 制御は別ストーリー（権限系）で扱う
- 各サブタブの初期値は mock データから取得。永続化は localStorage（既存 useAppStore パターン踏襲）
- AC-7 の入院モード追加表示は段階 1 で実装枠だけ用意し、データ表示は段階 2 で詰める（既存入院 EP との整合確認のため）
