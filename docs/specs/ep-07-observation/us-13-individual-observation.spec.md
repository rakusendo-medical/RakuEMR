## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 行動制限下の患者個人の観察記録をフローシートから作成・更新したい
- **So that** 患者ごとの観察事項を時間軸に沿って詳細に残し、指示の継続要否判断や指定医評価に役立てられる

## 画面要素（要素ツリー）

```
- フローシート画面（隔離拘束サブタブ）
  - 共通情報欄（フローシート共通）
  - 診察記録行
    - [絞込設定] リンク → 絞込設定ダイアログ
    - 各日セルの [未診察] リンク → 診療録作成ダイアログ（カルテと同一の新規記録ダイアログを再利用）
  - 観察記録ヘッダ
    - 見出し「隔離拘束 観察記録」
    - 勤務帯切替トグル（24時間 / 日勤 / 夜勤）
  - 凡例（観察状態色 + 状態名。「セルクリックで観察記録を入力」の案内）
  - 観察グリッド
    - 縦軸: 時刻（0〜23 時、開始時刻表示。勤務帯フィルタで絞込 → 後述）
    - 横軸: 7 日（共通ヘッダの日付列と一致）
    - 各セル（時刻 × 日）

      - ホバー: セル内側に青枠（未来枠はホバー効果なし・カーソル `not-allowed`）
      - クリック → 観察記録ダイアログ（個別）。active 指示があれば区分（拘束優先 → 隔離）を継承、無ければ「その他」で起票（未来枠はクリック不可）

  - 観察間隔トグル（15分単位 / 30分単位）: フローシートグリッドから開いた場合のみ表示。切替で行を作り直す
  - 観察行リスト（既定は 2 行 = 00 分・30 分。フローシートグリッドから開いた場合）

    - 行ごとに:

      - 時間（HH:mm、観察回数で等分した開始時刻が初期表示）
      - 状態セレクト（隔離拘束状態マスタ、色付き。背景も観察状態色）
      - 内容テキスト（最大3000文字）
      - [文例1〜3] ボタン → 内容欄に文例を追記
      - タグチップ表示
      - 連携 [未連携] / [連携あり] → 連携設定ダイアログ
      - [削除] ボタン（行削除）
  - フッター: [登録] / [キャンセル]
  - 同一時間帯の既存記録があればプリロードし、[登録] 時に置き換える（重複・累積防止。フローシートグリッドから開いた場合）
```

## 振る舞い

- **隔離拘束サブタブ表示**: 外出・外泊行から下のサブタブで「隔離拘束」を選ぶと、診察記録行＋観察グリッドを表示する
- **勤務帯切替トグル**: 表示する時刻行を絞り込む（日勤 9〜16時 / 夜勤 17〜23時+0〜8時 / 24時間 0〜23時）
- **観察グリッドのセルクリック**: 観察記録ダイアログを当該時刻枠で起動。active 指示があれば区分（拘束優先 → 隔離）を継承、無ければ「その他」で起票。既定 2 行（00分・30分）。同一時間帯に既存記録があればプリロード
- **未来枠のセル**: 現在日時が当該 1 時間枠の開始時刻に達していない場合はグレー表示・クリック不可（ダイアログを開けない）。判定条件は [_epic.md 共通ルール: 未来日入力不可](./_epic.md) に従う
- **観察間隔トグル（15分/30分）**: 切替で行を等分スロットで作り直す（15分→4行 / 30分→2行）。作り直し後も未来枠の行は非活性のまま
- **状態選択**: 行背景が観察状態色になる。連携 ON 時は「処方処置」欄に状態定型文（マスタ）が自動記載される
- **[追加] クリック**: 行追加（最大 9 行）、各行の開始時刻を等分で再計算 / **[削除] クリック**: 該当行削除
- **[文例1〜3] クリック**: 内容欄に文例を追記
- **[内容一括入力] クリック**: 内容一括入力ダイアログ。表示中の全行へ同一内容・タグを反映
- **連携 [未連携] / [連携あり] クリック**: 連携設定ダイアログ。看護記録連携 ON 時、登録時に看護記録ストア（ep-10）へダブル書き込みし、部門記録簿の看護記録検索で表示対象となる
- **[登録] クリック**: 選択チェックされた行のみ `ObservationRecord` として `addObservationRecordsBulk` で store 登録（置き換えモードでは同時間帯の既存記録を削除してから登録）。色セグメントがグリッドに反映。未来枠の行は登録対象外
- **ダイアログ内の未来枠の行**: 現在日時が当該行の開始時刻に達していない行は [選択] チェックと入力欄（状態・内容・文例・連携）が非活性・未選択。時間欄のみ修正できるよう活性のまま残す。時間欄を未来時刻へ手入力して [登録] するとエラーとなり、登録は行われない（ダイアログは開いたまま）
- **同時間帯隔離・拘束重複時**: 拘束を優先して区分・観察状態色を表示
- **診察記録 [未診察] クリック**: 診療録作成ダイアログを起動 / **[絞込設定] クリック**: 絞込設定ダイアログ（初期は全項目チェック）

## 受け入れ基準（AC）

- [ ] **AC-1: フローシート／隔離拘束サブタブで観察グリッドを表示できる**
  - **Given** 患者カルテのフローシートを開いている
  - **When** 外出・外泊行から下のサブタブで「隔離拘束」を選択する
  - **Then** 時刻（縦・0〜23時）× 7日（横）の観察グリッドが表示される。active な指示下のセルは未記入色、指示なしは白で区別され、登録済セルは観察状態色セグメントで表示される

- [ ] **AC-2: 勤務帯で表示時間を切り替えられる**
  - **Given** 観察グリッドを表示している
  - **When** 勤務帯トグル（24時間 / 日勤 / 夜勤）を切り替える
  - **Then** 表示時刻行が絞り込まれる（日勤 9〜16時 / 夜勤 17〜23時+0〜8時 / 24時間 0〜23時）

- [ ] **AC-3: セルクリックで観察記録ダイアログを起動できる**
  - **Given** 観察グリッドを表示している
  - **When** いずれかのセルをクリックする
  - **Then** 観察記録ダイアログが当該時刻枠で開く。active 指示があれば区分（拘束優先 → 隔離）を継承、無ければ「その他」で起票され、既定 2 行（00分・30分）が生成される。同一時間帯に既存記録があればプリロードされる

- [ ] **AC-4: 観察記録ダイアログで状態と内容を登録できる**
  - **Given** セルをクリックして観察記録ダイアログを開いている
  - **When** 「選択」欄にチェック、状態を選択、内容を入力して [登録] する
  - **Then** 選択行のみが観察記録として登録され、グリッドの当該セルに観察状態色セグメントが反映される（同一時間帯の既存記録は置き換えられる）

- [ ] **AC-5: 観察回数・観察間隔を変更できる**
  - **Given** 観察記録ダイアログを開いている
  - **When** [追加]（最大 9 行）／[削除] を操作する、または観察間隔トグル（15分/30分）を切り替える
  - **Then** 行数が増減し、各行の開始時刻が等分で再計算される（間隔切替時は既定スロットで作り直し）

- [ ] **AC-6: 内容入力に文例・一括入力が使える**
  - **Given** 観察記録ダイアログの内容欄を編集している
  - **When** [文例1〜3] をクリックする、または [内容一括入力] をクリックする
  - **Then** 文例が内容欄に追記される／一括入力ダイアログから表示中の全行へ内容・タグが反映される

- [ ] **AC-7: 連携設定で看護記録・報告先と紐づけできる**
  - **Given** 観察記録ダイアログの連携欄を表示している
  - **When** [未連携] または [連携あり] をクリックして連携設定ダイアログを開き、看護記録連携や報告先（作成／確認／両方）を指定して [登録] する
  - **Then** 連携項目が設定され、登録時に看護記録ストアへ連携書き込みされ、部門記録簿の看護記録検索で当該観察記録が表示対象となる

- [ ] **AC-8: 同一時間帯で隔離と拘束が重複する場合は拘束が優先表示される**
  - **Given** 患者に隔離指示と拘束指示が同時間帯で重複している
  - **When** 観察グリッドを表示する
  - **Then** 拘束が優先されて区分・観察状態色が表示される

- [ ] **AC-9: 診察記録行から診療録作成・絞込設定を起動できる**
  - **Given** 隔離拘束サブタブの診察記録行を表示している
  - **When** 各日セルの [未診察] をクリックする、または [絞込設定] をクリックする
  - **Then** [未診察] では診療録作成ダイアログ、[絞込設定] では絞込設定ダイアログ（初期は全項目チェック）が開く

- [ ] **AC-10: 部門記録簿の看護記録に観察記録が連携表示される**
  - **Given** 観察記録を登録した（連携設定で看護記録連携 ON）
  - **When** 部門記録簿／看護記録を表示する
  - **Then** タイトル「観察記録（隔離拘束）」または「観察記録（その他）」で観察記録が記載され、選択状態の定型文が処方処置として表示される
  - **モック:** ep-10 看護記録基盤完成までは、ep-07 側ではタグ「観察記録」付与＋スナックバー通知のみ。実連携は ep-10 統合後

- [ ] **AC-11: 未来枠のセルは入力できない**
  - **Given** 観察グリッドを表示している（例: 現在時刻 16時29分）
  - **When** 現在日時が開始時刻に達していない時刻枠のセル（例: 17時枠）を確認・クリックする
  - **Then** 当該セルはグレー表示でクリックできず、観察記録ダイアログが開かない。開始時刻に達している枠（例: 16時枠）はクリックでき、ダイアログが開く

- [ ] **AC-12: ダイアログ内の未来枠の行は登録できない**
  - **Given** 現在時刻 16時29分に 16時枠の観察記録ダイアログを開き、観察間隔 15分（16:00 / 16:15 / 16:30 / 16:45 の 4 行）を表示している
  - **When** 各行の入力状態を確認して [登録] する
  - **Then** 16:00・16:15 の行は入力・登録できるが、16:30・16:45 の行は非活性・未選択で登録対象外となる（時間欄を未来時刻へ手入力して [登録] した場合はエラーとなり、登録は行われない）

## 状態遷移 / バリデーション

### セル背景の判定

| セルの状態 | 背景 | クリック |
| --- | --- | --- |
| 未来枠（現在日時 < 時刻枠の開始時刻） | グレー | 不可 |
| active な隔離/拘束指示下（開始日時 ≤ 時刻枠 ≤ 終了日時 or 現在） | 未記入色（指示下） | 可 |
| 指示なし | 白 | 可 |
| 登録済 | その時間帯の記録を時刻順に色セグメントで均等分割 | 可 |

- 未来枠の判定が最優先。未来枠以外のセルは、指示の有無にかかわらずクリックして起票できる

### 未来日入力不可

未来日（未到来の時間帯）への記載はできない。マスタ設定・オプション機能による ON/OFF はなく、常時この挙動で固定する（判定条件の正は [_epic.md 共通ルール](./_epic.md)）。

- **現在日時が記録枠の開始時刻に達していない場合は入力不可**
  - 入力可: `記録枠の開始時刻 ≤ 現在日時`
  - 入力不可: `現在日時 < 記録枠の開始時刻`
- 判定に使うのは **枠の開始時刻のみ**（終了時刻は使わない）。開始時刻に達していれば、その枠の途中でも入力できる
- 過去方向の制限はない
- 適用単位
  - **観察グリッドのセル**: 1 時間枠の開始時刻（`HH:00`）で判定 → 未到来ならグレー・クリック不可
  - **観察記録ダイアログの各行**: 観察間隔で等分した各行の開始時刻で判定 → 未到来の行は非活性・未選択・登録対象外
- 時刻経過で未来枠は入力可へ変わる（画面を開いたままでも一定間隔で再判定される）

#### 例: 15分枠における未来日入力不可の条件

| 現在時刻 | 16:15〜16:30 の枠 | 16:30〜16:45 の枠 | 16:45〜17:00 の枠 |
| --- | --- | --- | --- |
| 16時29分 | 入力OK | 入力NG | 入力NG |
| 16時30分 | 入力OK | 入力OK | 入力NG |
| 16時31分 | 入力OK | 入力OK | 入力NG |

- 16時29分時点では 16:30 開始の枠に現在時刻が達していないため入力不可
- 16時30分ちょうどで 16:30 開始の枠が入力可になる（開始時刻と同時刻は入力可）
- 16時31分でも 16:45 開始の枠は未到来のため入力不可

### 区分優先表示（同時刻に隔離/拘束両方が active）

- 拘束優先（区分・背景色は拘束側を使う。`subtype` で区別して保存）

### バリデーション

- 状態: 既定「落ち着き」。各行で選択
- 内容: 任意（最大 3000 文字）
- 時間: `HH:mm`（観察回数で等分した開始時刻が初期表示）。現在日時より未来の時刻は不可（上記「未来日入力不可」）
- 観察行: 最大 9 行
- [登録]: 「選択」チェックが 1 行も無い場合は警告（登録されない）。未来枠の行は選択できないため登録対象に含まれない

## 補足

- 観察項目セット・観察状態色・回数（分割数）はマスタ管理（隔離拘束状態マスタ／医療機関情報マスタの観察回数）。モックでは `MASTER_OBSERVATION_STATES` / `MASTER_OBSERVATION_FREQUENCY` を新規追加
- 報告先選択ダイアログは利用中のオプションにより連携項目が変動。モックでは固定 3 項目
- **ver0.13/0.14（梶井改修）で実装した観察グリッド**は `src/components/flowsheet/Flowsheet.tsx`（カルテのフローシート＝隔離拘束サブタブ）に配置。当初想定の「区分縦×1時間枠横マトリクス」を実装した `RestraintObservationMatrix.tsx` は現在どこからも参照されない（死にコード）。本 spec は実装済みグリッド（時刻縦×7日横）に合わせて改訂済み
- 開放時間アイコンは、ver0.12 で隔離拘束指示ダイアログから開放時間入力が削除された（[us-11] 参照）ため本 spec から除外
- **観察記録ダイアログ（`ObservationRecordDialog.tsx`）は個別[us-13]／一括[us-14] 共通**。ver0.13 で追加した props `defaultFrequency` / `showIntervalToggle` / `replaceExistingForHour` は **オプトイン**で、フローシートグリッドからの起動時のみ指定する。[us-14] 一括観察記録および旧個別呼び出しは props 未指定のため従来動作のまま（影響なし）
- 隔離拘束フローシートに戻る際、ダイアログ操作前のスクロール位置を保持する挙動を踏襲（モックでは未対応で OK）
