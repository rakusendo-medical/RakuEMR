## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 行動制限下の患者個人の観察記録をフローシートから作成・更新したい
- **So that** 患者ごとの観察事項を時間軸に沿って詳細に残し、指示の継続要否判断や指定医評価に役立てられる

## 振る舞い

- **隔離拘束タブ表示**: 患者の active な隔離・拘束指示から区分（隔離／拘束／隔離拘束）を導出し、対応する区分行を表示
- **マトリクス枠ホバー**:
  - 入力可能枠 → 薄青枠 + ツールチップ「時間・制限内容（隔離拘束/その他）・回数」
  - 入力対象外枠 → 理由表示ツールチップ（指示前／指示後／観察対象外）
  - 未来日抑止時 → 「未来日入力不可」ツールチップ
- **未記入枠クリック**: 観察記録ダイアログを当該時間枠で起動。1 時間内の観察回数分の行が初期生成
- **登録済枠クリック**: 観察記録ダイアログを編集モード（既存行プリロード）で起動
- **状態選択**: 状態色設定 + 「処方処置」欄に状態に紐づく定型文（マスタ）が自動記載
- **[追加] クリック**: 観察回数 +1（マスタの最大値まで）。1 時間内の開始・終了時間を再計算
- **[削除] クリック**: 該当行削除、観察回数 -1
- **[文例] クリック**: 文例ウィザード起動、選択した文例を内容欄に挿入
- **[タグを登録する] クリック**: タグ一覧ダイアログ、選択したタグを内容欄末尾に追加
- **タイトル横 [入力] クリック**: 内容一括入力ダイアログ。設定すると表示中の全入力欄に同一内容・タグが反映
- **連携 [未連携] / [連携あり] クリック**: 連携設定ダイアログ。看護記録連携 ON 時、部門記録簿の看護記録検索で当該観察記録が表示対象となる
- **[登録] クリック**: 選択チェックされた行のみ `ObservationRecord` として `addObservationRecord(s)` で store 登録。状態色がマトリクスに反映
- **同時間帯隔離・拘束重複時**: 拘束を優先して状態色を表示
- **開放時間アイコン**: 該当時間枠の右上にアイコン表示、ホバーで開放時間ツールチップ

## 受け入れ基準（AC）

- [ ] **AC-1: フローシート／隔離拘束タブで観察マトリクスを表示できる**
  - **Given** 患者カルテのフローシートを開いている
  - **When** 「隔離拘束」タブを選択する
  - **Then** 1時間枠×観察回数のマトリクスが表示される。入力対象外はグレー、未記入は白、登録済は状態色で区別される

- [ ] **AC-2: 観察可能な時間帯のみ入力できる**
  - **Given** マトリクス上の枠にカーソルをあてる
  - **When** 入力可能な時間帯にホバーする
  - **Then** 対象時間が薄青枠で表示され、時間と制限内容（隔離拘束／その他）、回数がツールチップ表示される。入力対象外時間帯はホバー時にも理由が表示される

- [ ] **AC-3: 未来日入力が抑止される（マスタ設定時）**
  - **Given** マスタ保守でプロパティ`validate.future`に未来日登録不可が設定されている（モックでは `optionalFeatures.observationFutureBlock`）
  - **When** 操作時間より未来の時間帯枠を表示する
  - **Then** 当該枠はグレー背景・非活性となり、クリックできない

- [ ] **AC-4: 観察記録ダイアログで状態と内容を登録できる**
  - **Given** 入力可能な時間枠をクリックして観察記録ダイアログを開いている
  - **When** 「選択」欄にチェック、状態を選択、内容を入力して [登録] する
  - **Then** 観察記録が登録される。フローシートの当該枠が選択した状態色で表示され、状態に紐づく定型文が処方処置として自動記載される

- [ ] **AC-5: 観察回数を追加・削除できる**
  - **Given** 観察記録ダイアログを開いている
  - **When** [追加] をクリックする、または既存行を [削除] する
  - **Then** 1時間の記録回数が増減し、未登録時間の開始・終了が自動再計算される（追加時1回目開始・最終回数終了は除く）

- [ ] **AC-6: 内容入力に文例・記事タグ・一括入力が使える**
  - **Given** 観察記録ダイアログの内容欄を編集している
  - **When** [文例] をクリック、またはタイトルの [入力] をクリック、または [タグを登録する] をクリックする
  - **Then** 文例ウィザード／一括入力ダイアログ／タグ一覧ダイアログが開かれ、対応する内容を入力・反映できる

- [ ] **AC-7: 連携設定で看護記録・報告先と紐づけできる**
  - **Given** 観察記録ダイアログの連携欄を表示している
  - **When** [未連携] または [連携あり] をクリックして連携設定ダイアログを開き、看護記録連携や報告先（作成／確認／両方）を指定して [登録] する
  - **Then** 連携項目が設定され、部門記録簿の看護記録検索で当該観察記録が表示対象となる

- [ ] **AC-8: 同一時間帯で隔離と拘束が重複する場合は拘束が優先表示される**
  - **Given** 患者に隔離指示と拘束指示が同時間帯で重複している
  - **When** マトリクスを表示する
  - **Then** 拘束が優先されて状態色が表示される

- [ ] **AC-9: 開放時間がアイコンで可視化される**
  - **Given** 隔離・拘束の開始指示で開放時間が登録されている
  - **When** 隔離拘束タブを表示する
  - **Then** 開放時間に該当する時間枠に開放時間アイコンが表示され、ホバーで開放時間がツールチップ表示される

- [ ] **AC-10: 部門記録簿の看護記録に観察記録が連携表示される**
  - **Given** 観察記録を登録した（連携設定で看護記録連携 ON）
  - **When** 部門記録簿／看護記録を表示する
  - **Then** タイトル「観察記録（隔離拘束）」または「観察記録（その他）」で観察記録が記載され、選択状態の定型文が処方処置として表示される
  - **モック:** ep-10 看護記録基盤完成までは、ep-07 側ではタグ「観察記録」付与＋スナックバー通知のみ。実連携は ep-10 統合後

## 状態遷移 / バリデーション

### 入力可能判定マトリクス

| 時間枠の位置 | 入力可否 |
| --- | --- |
| active な指示の開始日時 ≤ 時間枠 ≤ 終了日時 (or 現在) | ✅ 入力可 |
| 指示の開始日時より前 | ❌ 入力対象外（グレー） |
| 指示の終了日時より後 | ❌ 入力対象外（グレー） |
| 操作時間より未来かつ `observationFutureBlock` 有効 | ❌ 入力抑止（グレー＋非活性） |

### 区分優先表示（同時刻に隔離/拘束両方が active）

- 拘束優先（背景色は拘束の状態色を使う）
- 観察記録は両方に紐づけて保存（`subtype` で区別）
- マトリクス行は拘束行に表示、隔離行はサブ表示（または非表示、モックでは拘束行のみ）

### バリデーション

- 状態: 必須
- 内容: 任意（最大 3000 文字）
- 時間: 開始時間が時間枠内であること
- 観察回数: マスタ最大値以下

## 補足

- 観察項目セット・状態色・回数（分割数）はマスタ管理（隔離拘束状態マスタ／医療機関情報マスタの観察回数）。モックでは `MASTER_OBSERVATION_STATES` / `MASTER_OBSERVATION_FREQUENCY` を新規追加
- 報告先選択ダイアログは利用中のオプションにより連携項目が変動。モックでは固定 3 項目
- 隔離拘束フローシートに戻る際、ダイアログ操作前のスクロール位置を保持する挙動を踏襲（モックでは未対応で OK）
- **S3 との分担確認:** フローシート画面そのものは ep-10 が刷新中。「隔離拘束行のマトリクス／クリックハンドラ」は本 spec の責務だが、配置場所はフローシート側。実装着手前に分担を最終調整
