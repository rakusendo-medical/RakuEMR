## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 行動制限下の患者一覧から複数患者の観察記録を一括入力したい
- **So that** 高頻度の観察業務を、患者ごとの画面遷移を繰り返さずに済ませられる

## 振る舞い

- **「記録」タブ表示**: 検索条件適用後、記録対象患者の一覧と区分別マトリクスを表示
- **回数枠タイトル（[隔離 16時 1回目] 等）クリック**: 区分一括入力ダイアログ起動。当該区分・時間・回数で記録対象となる患者のみ一覧表示
- **患者個別の時間枠クリック**: 個別 ObservationRecordDialog 起動（us-13 と同じ）。複数回数分を一度に入力可
- **区分一括入力ダイアログ [入力] (内容)**: 内容一括入力ダイアログを起動。設定すると表示中の入力欄全てに同一内容・タグが反映
- **[登録]**: 選択チェックされた患者全員分を `addObservationRecordsBulk(records)` でストア登録。一覧側の対応回数枠が観察状態色で更新
- **隔離・拘束併用患者**: 観察回数が多い方（例: 隔離2回／拘束4回 → 拘束4回）が優先表示
- **解放時間に該当する時間枠で一括入力時**: 患者氏名横に解放時間が **赤字** で表示（隔離・拘束併用時は **拘束入力時のみ** 表示）
- **未来枠（未来日入力不可）**: 現在日時が回数枠の開始時刻に達していない枠は入力できない。一覧の当該回数枠はグレー表示・クリック不可とし、一括入力ダイアログにも入力可能な患者のみが表示される（表示 0 件の場合は警告メッセージ）。判定条件は [_epic.md 共通ルール: 未来日入力不可](./_epic.md) に従う

## 受け入れ基準（AC）

- [ ] **AC-1: 隔離拘束一覧の「記録」タブを表示できる**
  - **Given** 隔離拘束一覧画面を開いている
  - **When** 「記録」タブをクリックする
  - **Then** 行動制限下患者の一覧と、患者単位の3段（隔離／拘束／その他）の観察記録マトリクスが表示される

- [ ] **AC-2: 検索条件で対象を絞り込める**
  - **Given** 記録タブを表示している
  - **When** 日付・病棟・入院形態（条件設定ダイアログ）・診察記事絞込（絞込設定ダイアログ）を指定して [表示] をクリックする
  - **Then** 該当条件下の患者一覧が表示される

- [ ] **AC-3: 表示対象が記録要件どおり選定される**
  - **Given** 患者集合に観察記録対象とそうでない患者が混在する
  - **When** 一覧を表示する
  - **Then** 以下のいずれかを満たす患者のみ表示される
    - 隔離・拘束指示あり
    - 入院病棟が行動制限判定対象 ＋ 観察記録の記録対象
    - 行動範囲指示あり ＋（責任レベルが行動制限判定対象 ＋ 観察記録の記録対象、または、行動制限項目が観察記録の記録対象）
  - **モック:** ep-06 と同様、`MASTER_BEHAVIOR_RESTRICT_WARDS` の在棟患者と隔離・拘束指示ありの患者のみで近似

- [ ] **AC-4: 区分別の回数枠から一括入力ダイアログを開ける**
  - **Given** 一覧の隔離／拘束／その他のタイトル回数枠（例: 隔離の16時1回目）を表示している
  - **When** 当該回数枠をクリックする
  - **Then** 観察記録（区分）一括入力ダイアログが開かれ、選択した時間・回数で記録対象となる患者のみが一覧表示される（未登録患者は「選択」チェックあり、登録済は背景色グレー＋チェックなし）

- [ ] **AC-5: 一括入力ダイアログで複数患者分を登録できる**
  - **Given** 一括入力ダイアログを表示している
  - **When** 各患者の状態・内容（最大3000文字、文例ウィザード可）・連携・記録時間・記録者を入力して [登録] する
  - **Then** 選択チェックされた患者全員分の観察記録が同一観察日時で登録される。一覧側の対応回数枠が観察状態色で表示される

- [ ] **AC-6: 内容を一括入力できる**
  - **Given** 一括入力ダイアログを表示している
  - **When** 「内容」欄タイトルの [入力] をクリックして一括入力ダイアログで内容（タグ含む）を入力し [設定] する
  - **Then** 表示中の入力欄全てに同一内容・タグが反映される

- [ ] **AC-7: 個別の時間枠クリックで個別ダイアログが開く**
  - **Given** 一覧の特定患者の時間枠をクリックする
  - **When** 観察記録ダイアログが開かれる
  - **Then** 当該患者・対象時間の観察記録ダイアログ（個別、us-13 と同じ ObservationRecordDialog）が表示され、複数回数分を一度に入力できる

- [ ] **AC-8: 個別記録と一括記録のデータが同一モデルに収まる**
  - **Given** 同一患者に対する個別記録と一括記録が混在している
  - **When** フローシート／隔離拘束タブまたは部門記録簿で参照する
  - **Then** 入力経路を問わず時系列に統合表示される（同じ `dynamicObservationRecords` 配列に保存）

- [ ] **AC-9: 隔離・拘束併用時は観察回数が多い方が優先表示される**
  - **Given** 患者に隔離・拘束が同時指示されている（例: 隔離2回／拘束4回）
  - **When** マトリクスと観察記録ダイアログを表示する
  - **Then** 多い方（4回）が優先表示される

- [ ] **AC-10: 解放時間が一括入力時に赤字で示される**
  - **Given** 隔離・拘束併用患者の開始指示時に解放時間が登録されている
  - **When** 一括入力ダイアログで対象時間が解放時間に該当する
  - **Then** 患者氏名横に解放時間が赤字で表示される（隔離・拘束併用時は拘束入力時のみ表示）

- [ ] **AC-11: 未来枠は一括入力の対象にならない**
  - **Given** 記録タブを表示している（例: 現在時刻 16時30分、拘束 4 回 = 15分枠）
  - **When** 現在日時が開始時刻に達していない回数枠（例: 拘束 16時 3回目 = 16:30〜16:45 は入力可、4回目 = 16:45〜17:00 は未到来）を確認・クリックする
  - **Then** 未到来の回数枠はグレー表示・クリック不可となる。開始時刻に達した回数枠は一括入力ダイアログが開き、入力可能な患者のみが表示される（0 件の場合は警告表示）

## 状態遷移 / バリデーション

### 表示対象判定（記録タブ）

- ep-06「指示」タブと同じ基本ロジック + **観察記録の記録対象** 条件が追加
- モックでは `MASTER_BEHAVIOR_RESTRICT_WARDS` の患者を「観察記録対象」とみなし簡略化

### 区分回数枠の生成

- 区分（隔離 / 拘束 / その他）ごとに `MASTER_OBSERVATION_FREQUENCY` から回数を取得
- 1 時間 × 回数 のセルを表示（回数枠 = 1 時間を回数で等分した枠。例: 4 回 → 15分枠）
- セル状態: 未記入（白） / 登録済（観察状態色） / 入力対象外・未来枠（グレー）

### 未来日入力不可

- 現在日時が **回数枠の開始時刻** に達していない枠は入力不可（設定による ON/OFF はなく常時適用）
  - 入力可: `回数枠の開始時刻 ≤ 現在日時` / 入力不可: `現在日時 < 回数枠の開始時刻`
- 判定条件と 15分枠の具体例は [_epic.md 共通ルール: 未来日入力不可](./_epic.md) を参照

### 区分一括ダイアログの患者フィルタ

- 当該区分の active 指示あり患者
- 当該時間枠が入力対象（時間内 + 未来枠でない）
- 既登録患者は背景色グレー + チェック OFF + 表示のみ
- 未登録患者は「選択」チェック ON + 入力欄活性

### 解放時間ハイライト条件

- 患者の指示に開放時間設定あり
- 一括入力対象時間が開放時間に該当
- 隔離・拘束併用時は **拘束入力時のみ** 表示（隔離側ではハイライトしない）

## 補足

- 観察回数（分割数）は区分ごとにマスタ管理（隔離診察回数／拘束診察回数／その他診察回数）。モックでは `MASTER_OBSERVATION_FREQUENCY` で 3 値固定（例: 隔離 2 / 拘束 4 / その他 1）
- 一括時の必須項目は個別と同じ（状態・内容）。記録者初期値はログオン職員、変更可
- 解放時間ハイライト判定の「拘束入力時のみ」: 一括ダイアログのコンテキスト（区分）で判断
- 既存 `ep-06 IsolationRestraint.tsx tab=1` は ep-07 で全面改修される。ep-06 では tab=0 のみ改修したため、tab=1 は ep-06 着手前の簡易表示が残っているが、ep-07 で置き換える
