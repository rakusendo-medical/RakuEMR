## ユーザーストーリー

- **As a** 主治医・病棟看護師
- **I want** 患者の **治療歴・訪問看護・学歴経歴・エピソード・生活歴/現病歴** を年月軸に沿って一望したい
- **So that** 病歴を網羅的に把握でき、参考システム同等の業務密度（旧 KarteAlphaPage の生活歴タイムライン）を新カルテで再現できる

## 画面要素（要素ツリー）

```text
- LifeHistoryTimeline（折りたたみ Card）
  - SectionHeader「生活歴」（mode 別配色）
  - 凡例行: 該当ありの色帯 / 該当なしのグレー / 期間中継続の濃淡
  - 横軸: 月単位の日付軸（最近 12 ヶ月 + 任意拡張）
  - 縦軸（5 行）:
    1. 治療歴       — 過去〜現在の治療セッション・入院期間
    2. 訪問看護     — 訪問看護導入期間
    3. 学歴・経歴   — 学校 / 職歴 イベント
    4. エピソード   — 増悪・退院 等のイベントマーク
    5. 生活歴・現病歴 — 自由記述イベント
  - マス: 該当期間は色付きセル / 非該当はグレー
  - 空行: PM 指示「空行非表示」適用（その行に何もない場合は折りたたむ）
  - ホバー Tooltip: 詳細（期間・コメント）
```

## 振る舞い

- **タイムライン表示**: 6 行 × 12 ヶ月のマトリクスを表示
- **空行の非表示切替**: トグル「空行を表示する」/「空行を非表示」（既定: 非表示）
- **ホバー**: マスにマウスオーバーで Tooltip
- **クリック**: イベント詳細ダイアログ表示（mock・プレースホルダ）
