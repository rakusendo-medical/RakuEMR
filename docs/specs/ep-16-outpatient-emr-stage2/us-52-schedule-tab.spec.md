### 経緯

KartePage の `schedule` タブは段階 1 でプレースホルダ。本 us で **予約・受診計画** の最小可視化を実装する。本格的な予約作成・編集は別エピック（予約システム連携）扱い。

## ユーザーストーリー

- **As a** 主治医・看護師・受付
- **I want** カルテ画面の「スケジュール」タブで、その患者の **来院予約・入退院予定・主要イベント** を時系列で一覧したい
- **So that** カルテ閲覧中に直近の来院・入退院予定を即時把握でき、予約調整やフォローアップに繋げられる

## 画面要素（要素ツリー）

```text
- ScheduleTab（mode 別配色 SectionHeader）
  - 期間切替トグル: 今後 / 過去 / 全期間（既定: 今後）
  - 種別フィルタ Chip: 全て / 来院予約 / 入退院予定 / 検査予定 / その他
  - スケジュール一覧（タイムライン風・dense）:
    - 行ごとに: 日付（YYYY/MM/DD・曜日）/ 時刻 / 種別 Chip / タイトル / 担当医 / メモ
    - 「予定」（未来）と「実績」（過去）で背景色を分ける
  - 件数表示
  - 上部右: 「予約登録」ボタン（mock プレースホルダ・将来の予約システム連携への入口）
```

## 振る舞い

- **タブ初期表示**: 患者別の予定を期間切替（既定: 今後）で表示
- **期間切替**: 今後 / 過去 / 全期間
- **種別フィルタ**: クリックで絞込
- **「予約登録」**: クリックで mock ダイアログ（「予約システム連携は別エピック」プレースホルダ）
