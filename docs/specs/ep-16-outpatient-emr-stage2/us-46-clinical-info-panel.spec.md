## ユーザーストーリー

- **As a** 主治医・病棟看護師
- **I want** 患者ヘッダー直下で **保険・主病名・合併症・アレルギー・責任範囲・ADL/GAF・自立度** を 1 行 / 1 セクションで一望し、診断名・基本情報・GAF・院外文書・ファミリ・クリニカルパス・指示/入室 にサブタブで切替閲覧したい
- **So that** 業務上頻繁に確認する診療情報を、新カルテ画面の **常設パネル** として参考システム同等の密度で扱える

## 画面要素（要素ツリー）

```text
- ClinicalInfoPanel（折りたたみ Card）
  - SectionHeader「診療情報」（mode 別配色）
    - 右側: サブタブ切替（Chip 7 種）
  - パネル本体（選択中サブタブの内容を表示）
    - サブタブ「診断名」: 主病名行 + 合併症行 + アレルギー行
    - サブタブ「基本情報」: 保険情報行 + 責任範囲行 + ADL/GAF 行 + 自立度行
    - サブタブ「GAF」: GAF 推移グラフ（mock）+ 直近スコア
    - サブタブ「院外/状・診断書類」: 文書一覧（mock）
    - サブタブ「ファミリ」: 家族構成（mock・家系図描画は別ストーリー）
    - サブタブ「クリニカルパス」: パス選択 + 進捗（mock）
    - サブタブ「指示/入室」: 入退院指示・入室予定（mock）
```

各情報行のフォーマット（PM 指示 3.1〜3.7）:

| 行 | 内容 |
| --- | --- |
| 保険情報 | 保険名 / 有効期限 / 保険者番号 / 自己負担割合 を 1 行集約 |
| 主病名 | ICD コードバッジ（例: F31.0）+ 病名 + 発症日 |
| 合併症 | 同形式で列挙 |
| アレルギー | 薬剤・食物アレルギーを **赤系強調** + スラッシュ区切り |
| 責任範囲 | 「病棟内」「スタッフ同伴」等の行動制限ステータス |
| ADL/GAF | バーセル指数 + GAF スコア + 確定日 |
| 自立度 | 病棟管理ランク（A/B/C 等）+ 昼夜別管理レベル |

## 振る舞い

- **サブタブ切替**: 選択中サブタブの内容を即時表示
- **折りたたみ**: SectionHeader クリックでパネル全体を展開 / 収納
- **アレルギー強調**: 赤系背景 or テキスト色で視覚的に区別
