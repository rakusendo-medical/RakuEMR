## 要件

### 1. 期間切替（5.1）

タイムライン上部に期間切替トグルを追加:

- 「最近の6日分」（既定）/ 「最近の30日分」 / 「全件」 の 3 オプション
- ToggleButtonGroup で切替

### 2. タグベース Chip フィルタ（5.2）

カテゴリ Chip の下に **2 行目** としてタグ Chip 群を追加。旧版踏襲:

- 全体カンファレンス / NSTカンファレンス / 褥瘡カンファレンス / 臨床記録 / 行動範囲 / 外出/外泊 / 日勤帯記録

タグフィルタとカテゴリフィルタは AND 条件。

### 3. 「最初へ ▲」「続き ▼」動作（5.4）

- 「最初へ ▲」: タイムラインのスクロールを最上部へ（`scrollTop = 0`）
- 「続き ▼」: mock では「これ以上のレコードはありません」snackbar 通知
