- **I want** 患者ヘッダーで業務上必要な情報（病室・主治医・入院日・診断・隔離拘束ステータス・アレルギー / 感染症 / 状態 等のリスクピクトグラム）を一目で把握したい

## 要件（PM 指示・2026-05-07）

### 1. mode 別配色

ヘッダー全体の背景またはアクセント色を mode に応じて切替:

| mode | テーマ |
| --- | --- |
| `inpatient` | primary（青系・既存 `#1e3a5f` を踏襲） |
| `outpatient` | success（緑系） |
| `discharged` | neutral（グレー・退院済表示） |

### 2. ヘッダー左端: 入院ステータスバッジ強調

- mode='inpatient': 赤色「入院」バッジ（強調・視認性最優先）
- mode='outpatient': 緑色「外来」バッジ
- mode='discharged': グレー「退院済」バッジ

### 3. ヘッダー右端: 隔離・拘束状態インジケータ

- 隔離拘束対象患者: 赤色「隔離」「拘束」バッジ（活性時のみ表示）
- 非対象: 表示なし

### 4. 患者氏名行に病棟・病室・ベッド記号を併記

例: `山田 太郎（53歳・男）　第１病棟 102号室-A`

### 5. ヘッダー 2 段目: 主治医名

例: `Dr 森田 医師`

### 6. ヘッダー 2 段目: 入院日

例: `入院日: 2026-02-01`（mode='outpatient' / 'discharged' は表示しない or 「最終来院日」に置換）

### 7. ヘッダー 2 段目: 主病名

例: `診断: 双極性障害`

### 8. ピクトグラムアイコン 8 種（PM 指示）

ヘッダー右側または下段に **8 個のアイコンを並べて表示**。仕様:

- **既定: 灰色表示**（該当なし）
- **該当時: カラー表示**（赤・橙・青・紫など、リスクの種別に応じた色）
- マウスホバーで Tooltip に詳細説明

| # | アイコン | 名称 | 該当判定（mock） | カラー |
| --- | --- | --- | --- | --- |
| 1 | 薬剤 + 警告 | アレルギー | `Patient.allergyInfo` の禁忌薬 / 食物アレルギー が空でない | 赤 |
| 2 | 細菌 | 感染症 | mock: HBV / HCV / HIV / 結核のいずれかフラグあり | 橙 |
| 3 | 妊婦 | 妊娠 | mock: 妊娠フラグ true | 桃 |
| 4 | 転倒人 | 転倒・転落リスク | mock: 転倒リスク有 | 黄 |
| 5 | 拘束 | 隔離拘束 | `Bed.flags` に隔離・拘束のいずれかあり | 赤 |
| 6 | 食事 | 嚥下障害 / 食事制限 | mock: 嚥下障害フラグ true | 青 |
| 7 | 認知 | 認知機能低下 | mock: 認知症フラグ true | 紫 |
| 8 | 注意 | 観察事項 / 要報告 | mock: `Bed.flags` に「要報告」あり or 自殺リスク | 赤 |

判定ロジックの暫定実装:

- アレルギー: `Patient.allergyInfo` を参照（既存型）
- 隔離拘束: `Bed.flags` から判定（既存）
- 観察事項（要報告 / 自殺リスク）: `Bed.flags` の `report-required` を参照
- それ以外（感染症 / 妊娠 / 転倒 / 嚥下 / 認知）: **mock データに該当フラグがないため、`patient.id` のハッシュで擬似的に振る** か、新規 mock フィールドを `Patient` 型に追加する。後者は `types/index.ts` 変更となるので **本 us では擬似ハッシュで進める**（共有ファイル変更を回避）

### 9. 既存「外来」/「入院」Chip との関係

- 段階 1 で実装済の mode Chip（`<Chip color="primary" label="入院" />` 等）は **左端強調バッジに集約**（重複排除）

## 振る舞い

- **モード切替時**: 配色とバッジ・入院専用情報の表示が即時切替
- **ピクトグラムホバー**: Tooltip で「該当 = ◯◯」or「該当なし」を表示
- **隔離拘束バッジクリック**: 何もしない（mock）。将来 us-36 サブ B で隔離拘束ダイアログ起動に接続予定

## 状態遷移 / バリデーション

ピクトグラムの該当判定は **静的計算**（`patient` props から派生）。ユーザー操作で状態は変わらない。

## 補足

- **ピクトグラム判定ロジックは段階 2 では mock 実装**: 一部は patient.id ハッシュで擬似的に該当判定する。本格的な判定（`Patient` 型への新規フィールド追加）は段階 3 / 別エピックで対応
- **アイコン素材**: MUI icons から類似のものを採用（薬剤 = `Vaccines` / 細菌 = `Coronavirus` / 妊婦 = `PregnantWoman` / 転倒 = `PersonOff` / 拘束 = `Lock` / 食事 = `Restaurant` / 認知 = `Psychology` / 注意 = `Warning` 等）。最終確定は実装時に微調整
- **共有ファイル変更**: `KartePatientHeader.tsx` 単独ファイル更新の見込み。`Patient` 型追加は **本 us では行わない**（mock 内に閉じる）
