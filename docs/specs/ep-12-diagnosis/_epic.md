## 概要

看護過程画面（[ep-13]）から呼び出す看護診断ダイアログで、NANDA 診断を選定し患者個別の問題点（手入力）と組み合わせて看護計画明細に反映する。検索フィルタ + 領域フィルタ + 「よく使う診断」分類 + 問題点テキスト で簡潔に運用する。
過去診断は同じダイアログを **履歴参照モード** で開いて閲覧できる（編集不可、ページめくり）。

## ゴール

- 標準分類（NANDA）に基づく看護診断を簡潔に選定できる
- 患者個別の事情を加味した問題点記述を必ず併記する
- 過去診断履歴を時系列で参照できる

## スコープ

### 含む

- 看護診断ダイアログでの NANDA 選択 + 問題点テキスト入力
- 検索フィルタ（name / code 単一クエリ）
- 領域フィルタ（安全 / 身体 / 精神 / 社会 / 日常生活 / 服薬 / セルフケア）
- 「よく使う診断」分類表示（NandaDiagnosis.frequentlyUsed）
- 過去診断の履歴参照（読み取り専用、ページめくり）
- 適用日（立案日 = `ProblemItem.createdAt`） / 診断日（`ProblemItem.diagnosedAt`）の保持

### 含まない

- 看護診断セット（マスタ）からの一括取込 — マスタ管理エピックで別途検討
- 候補プール（候補化トグル）— 1 ダイアログ = 1 診断追加で運用
- 大分類 / 小分類 / 項目の階層編集 — マスタ側の問題、別途データ構造設計
- 看護計画の長期目標管理（[ep-13 看護計画]）
- 看護評価（[ep-14 看護評価]）

## 主要画面要素（エピック俯瞰）

```
- 看護過程画面 (/care-plan/patients/:patientId) [ep-13]
  - [看護計画を追加] / [編集] → 看護計画明細編集ダイアログ → 「NANDA 選択...」
  - 「過去診断を参照」リンク → 看護診断ダイアログ（履歴参照モード）

- 看護診断ダイアログ（通常モード）
  - フィルタ: キーワード入力 + 領域セレクト
  - 診断リスト: 「よく使う診断」+「すべての診断」（フィルタ後）
  - 問題点テキスト欄（必須・手入力可、NANDA 選択時に診断名で自動補完）
  - フッター: [キャンセル] / [選択]（NANDA + 問題点 両方必須）

- 看護診断ダイアログ（履歴参照モード）
  - 過去診断のページめくり閲覧（前へ / 次へ）
  - 編集不可
  - 表示項目: 領域 / コード / 名称 / 問題点テキスト / 立案日 / 診断日 / 立案者
```

## 完了条件

- 全子ストーリーの AC がチェック済み
- NANDA 選択 + 問題点記述で看護計画明細が生成される
- 過去診断履歴の参照ができる
- 立案日 / 診断日が記録される
