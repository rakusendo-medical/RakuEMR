## 概要

看護計画画面（[ep-13]）から呼び出す看護診断ダイアログで、領域診断の一覧から候補を選定し、診断項目の編集を経て確定する。確定した診断は看護計画明細として連携される。検索・セット・履歴の3機能を備え、過去診断の継続活用も可能とする。

## ゴール

- 患者状態を踏まえた看護診断を体系的に作成できる
- 過去の診断履歴・看護診断セットを再活用できる
- 診断確定から看護計画明細生成までを一連で完了できる

## スコープ

### 含む

- 看護診断ダイアログでの診断作成・確定
- 検索／セット／履歴の3タブ機能
- 診断候補の設定・クリア
- 診断詳細（大分類・小分類・項目）の編集・追加・削除
- 適用日指定による看護計画明細生成

### 含まない

- 看護計画の長期目標管理（[ep-13 看護計画]）
- 看護評価（[ep-14 看護評価]）

## 主要画面要素（エピック俯瞰）

```
- 看護計画画面 (/care-plan/patients/:patientId) [ep-13]
  - [看護診断より追加] ボタン → 看護診断ダイアログを開く
- 看護診断ダイアログ
  - ヘッダー: 患者基本情報サマリ + 前回診断候補選択情報（日時 / 操作者）
  - 機能タブ
    - 検索タブ: キーワード検索（複数AND条件）、空文字で全件、「候補のみ表示」「診断候補のクリア」
    - セットタブ: 看護診断セットマスタからセレクト、セット内表示、候補のみ表示、候補クリア
    - 履歴タブ: 過去登録診断の参照・編集（変更・削除・追加）
  - 診断閲覧領域
    - 領域診断一覧（領域ごと）
    - 各診断行: 選択アイコン（候補化マーク）+ 診断名 + 項目件数表示
  - 診断詳細内容編集領域（選択中の診断）
    - 大分類 / 小分類 / 項目（階層）
    - 項目アクションアイコン: 編集 / 削除 / 確定 / 中止
    - [新規] 項目追加
  - フッターアクション
    - 適用日入力 + [適用] → 看護計画明細生成
    - [診断] → 最終診断確定
    - [候補のみ表示] チェック
    - [診断候補のクリア] → 全候補初期化
    - [クリア] → 候補内容を破棄、マスタから再取得
    - [閉じる] → 候補を保存して閉じる（× 等での閉じはチェック内容破棄）
```

## 完了条件

- 全子ストーリーの AC がチェック済み
- 検索・セット・履歴の3タブで等価に診断候補を選定できる
- 確定後、看護計画明細として連携される
- 過去診断履歴の編集・更新・削除が監査可能

## 既存実装との乖離

`src/features/carePlan/components/NandaSelectDialog.tsx` は単純な NANDA 診断選択 UI で、本 spec の「3タブ + 候補管理 + 大分類/小分類/項目編集 + 適用日生成」とは大幅に異なる。

| 項目 | 既存実装 | 本 spec |
| --- | --- | --- |
| タブ構成 | なし（単一フィルタリスト） | **検索 / セット / 履歴 の 3 タブ** |
| 候補管理 | なし（直接選択） | **候補プール + チェック / 編集 / 削除 / 追加で候補化** |
| 詳細編集 | なし | **大分類・小分類・項目の階層を編集可能** |
| 看護診断セット | なし | **セットマスタから複数診断を一括取り込み** |
| 履歴参照 | なし | **過去登録診断の参照・編集・削除** |
| 計画明細生成 | shortTermGoal/OTE 入力済の問題項目を別経路で生成 | **適用日入力 + [適用] で看護計画明細を自動生成** |
| 閉じる挙動 | OK ボタンで親に値返却 | **[閉じる] = 候補保存 / × = 破棄 を区別** |

実装は既存 NandaSelectDialog の延長ではなく、新規ダイアログ `NursingDiagnosisDialog` として spec 準拠に作り直す想定。
