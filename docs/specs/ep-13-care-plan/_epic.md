## 概要

患者ごとの看護計画を **期間単位** で立案・運用する。1 期間に 1 計画、長期目標と複数の問題点（看護計画明細）で構成。
病状改善や増悪などのタイミングで期間を区切って新計画を立案できる（同期間に並立しない）。
看護診断（[ep-12]）との連携、テンプレートや過去計画からの引用コピー、月次評価への遷移、印刷を提供する。

## ゴール

- 期間単位で看護計画を立案・更新・クローズできる
- 計画明細を新規作成 / テンプレート引用 / 他患者引用 / 過去計画引用で柔軟に追加できる
- 計画明細単位でステータス管理（下書き / 有効 / 評価中 / 解決・中止・変更でクローズ）ができる
- 月次評価（[ep-14]）と看護経過記録（[ep-10]）と連携できる

## スコープ

### 含む

- **期間単位の複数計画モデル**（mock 改修フェーズ 2 で導入）
- 計画の新規作成・更新（立案日 / 長期目標）・クローズ
- 計画明細の追加（[新規追加] / [引用コピー]）
- 計画明細の編集・クローズ（解決 / 中止 / 変更の理由分類）
- 引用コピー（テンプレート / 他患者 / 過去計画 の 3 ソース統合 UI）
- 優先度（高 / 中 / 低）+ 立案順での自動ソート表示
- 解決済み計画明細のグレーアウト表示
- 印刷レイアウト
- 月次評価画面への遷移（[ep-14]）

### 含まない

- 看護診断ダイアログの内部仕様（[ep-12 看護診断]）
- 看護評価の詳細（[ep-14 看護評価]）
- アセスメント機能（採用しない）
- ラベルパターン1/2（採用しない）
- 並び替えダイアログ（手動並び替え）— 優先度自動ソートで運用
- 「看護診断より追加」独立フロー — NANDA は計画明細編集ダイアログのサブで完結

## 主要画面要素（エピック俯瞰）

```
- ダッシュボード（看護過程） (/care-plan)
  - 担当看護師フィルタ
  - 4 カテゴリ自動分類
    - 評価期限超過 / 今月評価必要 / 計画未立案 / 評価中のまま
  - 患者カード一覧（カテゴリ別）
    - クリック → 看護過程画面（または計画立案画面）

- 看護過程画面 (/care-plan/patients/:patientId)
  - 患者ヘッダー
  - 期間プルダウン（mock 改修フェーズ 2 で導入）
    - 既存計画を期間表示で並べ、選択で切替
    - 「新規期間」項目で新計画作成へ
  - 計画メタ操作
    - [看護過程を編集] = CarePlanEditDialog（立案日 + 長期目標 + 期間情報）
    - [印刷] = window.print() で PrintLayout を出力
    - [評価する] = MonthlyEvaluation 画面へ遷移
    - 「過去診断を参照」リンク = 看護診断ダイアログ履歴参照モード起動（[ep-12]）
  - 長期目標セクション（折りたたみ）
  - 有効計画明細セクション（優先度+#No 順）
    - 各カード: ステータス + 優先度 + 領域 + 問題点 + NANDA + 短期目標 + OTE（展開）
    - [編集] / [削除]
    - 全件展開 / 全件折りたたみ ボタン
  - 解決済み計画明細セクション（グレーアウト、折りたたみ）
  - 明細追加ボタン群
    - [看護計画を追加] = ProblemItemEditDialog (create mode)
    - [引用コピー] = CopyFromDialog（テンプレート / 他患者 / 過去計画 の 3 ソース統合 UI）

- 計画立案画面 (/care-plan/patients/:patientId/create)
  - 3 ステップワークフロー
    - ステップ 1: 長期目標入力 + テンプレート長期目標引用
    - ステップ 2: 計画明細を複数追加（同上ダイアログ群）
    - ステップ 3: 立案確定（下書き保存 / 有効化）

- 月次評価画面 (/care-plan/patients/:patientId/evaluate)
  - [ep-14 看護評価] 参照

- ProblemItemEditDialog
  - 領域 / 優先度 / 看護診断（NANDA）/ 問題点（手入力可、必須）/ 短期目標 / OTE
  - 内部呼出: NandaSelectDialog（[ep-12]）
  - [保存（下書き）] / [保存して有効化]
  - 編集モード時: [この看護計画をクローズ] メニュー（解決 / 中止 / 変更）

- CarePlanEditDialog
  - 立案日 / 長期目標 / 期間情報（mock 改修フェーズ 2 で拡張）
  - 編集後 → 当該計画のメタ情報を更新（評価期限には影響しない）

- CopyFromDialog（3 ソース統合 UI）
  - ソース選択タブ: テンプレート / 他患者 / 同一患者の過去計画
  - 検索フィルタ
  - 「長期目標も含めて取り込む」チェック（テンプレートのみ）
  - 取込明細の複数チェック
  - [取り込み] = 選択明細を draft で複写

- PrintLayout（印刷専用ビュー）
  - 患者情報 / 立案日 / 立案者 / 長期目標 / 計画明細毎の詳細
```
