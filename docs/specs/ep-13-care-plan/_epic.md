## 概要

長期目標を軸に看護計画を期間単位で立案・運用する。長期目標配下に複数の「看護計画明細」を持ち、登録・更新・削除を行う。同一期間に複数計画を持たせない制約を満たし、看護診断（[ep-12]）・看護評価（[ep-14]）と連携する。

## ゴール

- 長期目標として看護計画を期間単位で新規作成・更新・削除できる
- 長期目標内に複数の明細を登録・更新・削除できる
- 同一期間に複数計画が並立しないことを保証する
- 看護診断・テンプレート・看護経過記録と連携できる
- 計画明細から評価画面への遷移ができる

## スコープ

### 含む

- 看護計画（長期目標）の新規作成・更新・削除
- 期間管理（継続中チェック・終了日入力）
- 「前回の計画を引き継ぐ」での履歴コピー
- ラベルパターン（パターン1／2）の選択
- 計画明細の追加（[新規追加]／[テンプレートより追加]／[看護診断より追加]）
- 計画明細の更新・削除・並び替え
- 看護経過記録の作成（FOCUS連携時の自動関連付け含む）
- 評価画面への遷移（最終評価日リンク）

- 看護評価（[ep-14 看護評価]）
- アセスメント機能（別エピック・参考システム p.274-281）

## 既存実装との乖離

`src/features/carePlan/` には既存実装があり、以下の点で本 spec と乖離する。

| 項目 | 既存実装 | 本 spec |
| --- | --- | --- |
| 計画モデル | 1患者1看護計画（`status: 'draft' \| 'active' \| 'closed'`） | **期間単位で複数計画併存可**（期間プルダウンで切替） |
| 計画属性 | 長期目標のみ | **ラベルパターン1/2・継続中・終了日・前回引き継ぎ** |
| 明細追加 | 単一ダイアログ + テンプレート + 引用コピー | **新規追加 / テンプレートより追加 / 看護診断より追加 の 3 ボタン** |
| 並び替え | 優先度自動ソート | **手動の並び替えダイアログ** |
| 評価導線 | 別画面 (`/care-plan/patients/:patientId/evaluate`) で月次一括評価 | **計画明細毎の最終評価日リンクから評価画面へ** |

実装着手時は **既存実装のリファクタ範囲** を PM 経由で確認する。spec 準拠の再設計を行う場合、既存 `useCarePlanStore` のモデル変更（`CarePlan` を期間単位の複数化）が中核作業となる。
