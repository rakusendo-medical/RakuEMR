## ユーザーストーリー

- **As a** 主治医
- **I want** 処方オーダで、薬剤を検索して Rp（処方）に追加し、用量・単位・用法を設定して登録したい
- **So that** 自由記述ではなく、医薬品マスタから選んだ薬剤に定型の用法を付けて正確に処方できる

## スコープ

### 含む（モック）

- 種別＝**処方／入院定時**選択時に、汎用フォームに代えて **処方内容（Rp テーブル）** を表示
- 「**新しい Rp として薬剤を追加**」→ **処方追加ダイアログ**（かな検索で医薬品マスタ〈モック〉を絞り込み、候補から選択、用量・単位・用法を設定）
- **用法**は定型パターン（例: 1日1回 朝食後／1日3回 毎食後／頓服 など）から選択
- Rp テーブル: 追加した薬剤を行表示（Rp番号・名称・用量・単位・用法・削除）、一包化／後発品変更不可（全）のチェック
- 登録時、Rp 一覧から Order の `content`／`schedule` を合成して指示簿一覧に反映

### 含まない（モック簡略・後続）

- 医薬品マスタ本体連携（マスタはモックの固定リスト）、薬効分類タブ、院内/院外処方の区別（※処方セットはモックのマスタで対応済み）
- 用量チェック・薬剤換算値・禁忌副作用・保険選択・オーダシール・オーダ確認（※後発不可は薬剤単位・全一括ともに対応済み）
- 1 つの Rp 内への [薬剤の追加] ボタン（Rp のまとめ／新規は Rp セレクトで対応済み）、DO/セットオーダの新規登録・編集、入院定時の日数自動計算
- 数値入力キーパッド UI（用量は通常の数値入力欄で代替）
- 処方の中止・変更（別ストーリー）

## 画面要素（要素ツリー）

共通枠（種別セレクト・開始日・日数・担当医）は [us-53](./us-53-order-entry.spec.md) と共通。種別＝処方／入院定時 のとき、汎用「内容／スケジュール」に代えて以下を表示。
なお全オーダダイアログの見出しは共通 `OrderDialogTitle` により「濃紺バー＋『{種別}オーダ　対象患者: {患者番号}　{氏名}』」で統一。本ダイアログの見出しは種別に応じて **「処方オーダ」／「入院定時オーダ」**。
なお処方ダイアログの日付・日数は種別で異なる:
- **入院定時**: ダイアログ全体の **開始日＋日数＋終了日**（日数と終了日は双方向連動。終了日を空欄にすると日数0＝継続）。
- **処方（臨時）・注射**: 開始日はダイアログ全体、**日数（注射は「日分」）は Rp 単位**で設定（Rp 表の日数列。**各 Rp の先頭行に入力欄**を出し、同一 Rp の全薬剤に適用。継続行は「〃」。既定7）。終了日は無し。
- **content の表示**（作成中オーダ・指示簿・カルテ）: **1 薬品 1 行**（改行区切り）。**各 Rp の先頭行に「Rp{番号}」を付し、続く薬品はインデント**で揃えて Rp の区切りを明示。処方・注射は日数を **Rp ごとにまとめ**て各 Rp の最終行末尾に「×N日分」。入院定時は**最後に日数を 1 行**でまとめる（「N日分」／継続は「継続」）。オーダ送信画面の作成中オーダは下段に開始日のみ（日数は content 内）。

```
- オーダ内容（見出し「オーダ内容」・種別=処方/入院定時 のとき表示。注射も共通見出し）
  - Rp テーブル: 追加済み薬剤の一覧（0 件のときは空）。同一 Rp 番号の行は隣接して並ぶ
    - 行: Rp番号 / 名称（最大用量） / 用量 / 用法 / 一包化 / 後発不可 / 削除ボタン
      - Rp番号 (Select・薬剤単位): 行の Rp を変更できる。**既存の Rp 番号を選ぶとその Rp にまとめ、「＊(新規)」で新しい Rp（最大＋1）へ移す**。変更後は同一 Rp が隣接するよう Rp 番号順に整列
      - 一包化 (Select・薬剤単位): 一包化グループ番号。「なし（-）」または数字。同じ番号どうしが同一包。「＊(新規)」で最大番号＋1 の新グループを採番（マニュアル第5章第2部 一包化指示）
      - 後発不可 (Checkbox・薬剤単位): その薬剤を後発品変更不可にする
  - 「新しい Rp として薬剤を追加」ボタン: クリックで処方追加ダイアログを開く
  - 一包化 (Checkbox・全): ON で全薬剤を一包化グループ1、OFF で全薬剤を一包化なし。既定 ON。※薬剤単位の一包化列でグループ（数字／＊新規）を指定すると、この（全）チェックは自動で ON になる（マニュアル準拠）
  - 後発品変更不可（全）(Checkbox): 全薬剤の「後発不可」を一括 ON/OFF。既定 OFF
- 処方追加ダイアログ (Dialog): 「新しい Rp として薬剤を追加」で開く
  - 処方セット (Select): 処方セットマスタから選択。選ぶとセットに含まれる薬剤（用量・単位・用法込み）を選択薬剤テーブルへ一括追加。データは **処方セット → 処方マスタ（用量・単位・用法・日数）→ 医薬品マスタ（名称）** の 3 層で解決（`src/data/prescriptionSetMaster.ts`。参考システムの実マスタ入力ファイルから抽出した精神科向けセット。単位/用法は単位・用法マスタで解決済み）
  - 過去のオーダー (Select): **この患者が過去に作成した同種別オーダ（履歴＝seed の ORDERS ＋ セッションで登録した dynamicOrders）** を選ぶと、その薬剤（名称・用法。用量・単位は編集で調整）を選択薬剤テーブルへ復元して一括追加。過去オーダの `content`（「名称 用量単位（用法）」を ／ 連結）を薬剤行に復元する。マスタのサンプルではなく実際に作成したオーダを再作成する導線。**種別ごとに厳密**（処方は処方、入院定時は入院定時 のみ）。**過去のオーダー欄は常に表示**し、同種別の履歴が無いときは非活性（「過去のオーダーはありません」）。注射追加は注射オーダのみ
  - かな検索 (TextField)＋検索ボタン: 名称でモック医薬品マスタを絞り込み
  - 候補リスト (List): 検索結果の薬剤名。クリックで選択欄へ追加
  - 選択薬剤テーブル: 選択した薬剤ごとに
    - 名称 / 用量 (NumberField) / 単位 (Select: 錠・包・g・mg・mL 等) / 用法 (Select: 定型パターン) / 削除
  - 登録ボタン: 選択薬剤を Rp テーブルへ反映して閉じる
  - 閉じるボタン: 破棄して閉じる
```

## 振る舞い

- **処方内容を表示**: 種別＝処方／入院定時 → 処方内容（Rp テーブル＋「新しい Rp として薬剤を追加」）を表示。
- **薬剤を追加する**: 「新しい Rp として薬剤を追加」→ 処方追加ダイアログが開く。かな検索に文字を入れ検索 → 候補リスト表示 → 候補クリックで選択薬剤テーブルへ追加。用量・単位・用法を設定。
- **用法を選ぶ**: 用法セレクトから定型パターン（1日1回 朝食後 等、頓服系も含む）を選ぶ。
- **過去のオーダーからセット**: 処方追加（注射追加）ダイアログの「過去のオーダー」セレクトで、この患者が過去に作成した同種別オーダ（履歴）を選ぶと、その薬剤が選択薬剤テーブルへ復元・一括追加される。そのまま登録すれば過去のオーダを再作成できる。
- **処方追加を登録**: 登録 → 選択薬剤が Rp テーブルに行追加され、ダイアログが閉じる。**用法が同じ薬剤は同一 Rp、用法が異なる薬剤は別 Rp として採番する**（Rp 番号は既存の最大＋1 から用法ごとに連番）。
- **Rp を削除**: Rp テーブルの削除ボタンで当該行を除去。
- **オーダを登録**: Rp が 1 件以上あるとき登録ボタンが活性。登録すると Order（status=指示済）を作成し指示簿一覧へ反映。
  - `content` ＝ Rp 各行を「名称 用量単位（用法）」でまとめた文字列（複数行は「／」で連結）。薬剤ごとに一包化グループ（包N）・後発不可があれば「（包N・後発不可）」を付記。
  - `schedule` ＝ 先頭 Rp の用法（無ければ空）。
- **リロード**: モックのためセッション限定（[us-53](./us-53-order-entry.spec.md) と同じ非永続）。

## 受け入れ基準（AC）

- [ ] **AC-1: 処方種別で Rp テーブルと追加ボタンが出る**
  - **Given** オーダ入力ダイアログを開いている
  - **When** オーダ種別で「処方」（または「入院定時」）を選ぶ
  - **Then** 汎用の「内容／スケジュール」欄が消え、Rp テーブルと「新しい Rp として薬剤を追加」ボタンが表示される
- [ ] **AC-2: 薬剤を検索して選べる**
  - **Given** 処方追加ダイアログを開いている
  - **When** かな検索に薬剤名の一部を入れて検索する
  - **Then** 一致する医薬品候補がリスト表示され、クリックすると選択薬剤テーブルに追加される
- [ ] **AC-3: 用量・単位・用法を設定して Rp に反映**
  - **Given** 選択薬剤テーブルに薬剤があり、用量・単位・用法を入力した
  - **When** 処方追加ダイアログの登録を押す
  - **Then** 処方内容の Rp テーブルに「名称・用量・単位・用法」の行が追加される
- [ ] **AC-4: Rp が無いと登録不可・あると登録できて指示簿に反映**
  - **Given** 種別＝処方で Rp テーブルが空
  - **When** ダイアログの状態を見る
  - **Then** 登録ボタンは非活性。Rp を 1 件追加すると活性化し、登録すると指示簿一覧に薬剤名・用法を含む行が現れる
- [ ] **AC-5: 用法が異なる薬剤は別 Rp・同一 Rp は隣接**
  - **Given** 処方追加で用法の異なる薬剤を複数追加した
  - **When** Rp テーブルを見る
  - **Then** 用法が同じ薬剤は同一 Rp、異なる薬剤は別 Rp に採番され、同一 Rp の行は隣接して並ぶ
- [ ] **AC-6: 一包化グループ・後発不可（列と一括）**
  - **Given** Rp に薬剤がある
  - **When** 薬剤単位の一包化グループ／後発不可を操作、または下部「一包化（全）」「後発品変更不可（全）」を切り替える
  - **Then** 該当薬剤（全チェックは全薬剤）に反映される。薬剤単位で一包化グループを指定すると「一包化（全）」チェックが自動 ON になる
- [ ] **AC-7: Rp の変更（まとめ／新規）**
  - **Given** 複数 Rp がある
  - **When** 薬剤行の Rp セレクトで既存 Rp 番号を選ぶ／「＊(新規)」を選ぶ
  - **Then** 既存 Rp にまとめられる／新しい Rp へ移り、同一 Rp が隣接するよう整列される
- [ ] **AC-8: 処方セットマスタから一括セット**
  - **Given** 処方追加ダイアログを開いている
  - **When** 処方セットを選ぶ
  - **Then** セット（処方マスタ→医薬品マスタで解決）の薬剤が用量・単位・用法込みで選択欄へ一括追加される
- [ ] **AC-9: 日数・終了日（入院定時＝ダイアログ全体で双方向連動／処方・注射＝薬剤ごとの日数・日分）**
  - **Given** 入院定時の処方ダイアログを開いている（処方・注射はダイアログ全体の日数/終了日欄が無く、Rp 表に薬剤ごとの日数〈注射は「日分」〉列がある）
  - **When** 日数を変える／終了日をカレンダーで選ぶ
  - **Then** 開始日＋日数から終了日が算出され、終了日を変えると日数が逆算される（終了日を空欄にすると日数 0＝継続）
- [ ] **AC-10: 新規オーダは常に空で開く（未指示の下書きを自動復元しない）**
  - **Given** ある種別で処方を作成（登録）し作成中に積んだ（まだ指示していない）
  - **When** 次に同じ種別ボタンで処方ダイアログを開く
  - **Then** ダイアログは**空**で開く（前回内容を自動セットしない）。「前回どおり（DO）」は診療録（参照）の [DO] ボタン、または処方追加の「過去のオーダー」（指示済み履歴）から**明示的に**行う

## 補足

- 実装: オーダ送信画面（[us-55](./us-55-order-send-screen.spec.md)）の「処方」「入院定時」ボタンから `PrescriptionDialog` を起動。薬剤追加は `DrugAddDialog`。医薬品/用法/単位のモックは `src/data/prescriptionMaster.ts`、処方セットは `src/data/prescriptionSetMaster.ts`（実マスタ抽出・3 層）。破棄確認は `ConfirmDiscardDialog`（入力途中で閉じると確認）。
- 参考システムの「処方/用法選択」ダイアログ（食後/食前/内服分1-4/頓服/外用/インスリンのタブ）は、モックでは用法セレクト（定型パターンの一覧）で代替。タブ式の用法選択ダイアログ化は後続で検討。
- 旧「定時処方」種別は廃止し **入院定時**（入院専用の定時処方＝[us-59](./us-59-order-entry-inpatient-scheduled.spec.md)）へ統合済み。入院定時／処方の違い（定時 vs 頓服等）は用法パターンの選択で表現する（種別自体のフィールド差は持たない）。
- 注射は [us-56](./us-56-order-entry-injection.spec.md) で、本ダイアログ（`PrescriptionDialog`）と `DrugAddDialog` を props で汎用化して共用（`showPackaging=false`・注射マスタ/注射セット）。検査等も同方式で後続追加する。
