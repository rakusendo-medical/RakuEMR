## ユーザーストーリー

- **As a** 主治医
- **I want** セット名グループ（一般撮影／CT／MRI 等）からセット名（胸部・腹部…）を選ぶと、部位・手技・薬剤・フィルムの内容が既定でロードされる形で画像（放射線）をオーダしたい
- **So that** 撮影部位・手技・造影剤・フィルム条件を漏れなく、素早く指定して画像検査を指示できる

## スコープ

### 含む（モック）

- オーダ送信画面「画像」ボタン → **画像オーダダイアログ**（専用。処方/検査/ECT とは別構造）
- 見出しは共通 `OrderDialogTitle` で「画像オーダ　対象患者: {患者番号} {氏名}」（濃紺バー）
- 左＝**セット名グループ（プルダウン。一般撮影／CT／MRI）→ セット名一覧**（胸部・腹部…）
- 右＝**内容（部位／手技／薬剤／フィルムの 4 区分）**。最上部に**実施予定日（左寄せ）＋担当医併記**
- **セット名クリックで各区分に既定内容がロード**（前の内容は置き換え）。例: 胸部=部位「胸部　正面」／手技「胸部」／フィルム「撮影回数 1 回」
- 各区分の見出し直後に **[追加]をインライン配置**（ECT オーダと同一配置）。項目検索ダイアログ（かな名称検索＋コード｜名称一覧）からチェック付きで追加
- 薬剤（造影剤）は**用量入力**（単位はマスタ既定）、フィルムは**分画・撮影回数**を入力
- 各区分の行はチェックの ON/OFF・削除が可能
- 登録 → 作成中オーダ → [指示] → 指示簿へ `画像` で反映（内容は複数行、予定日＝実施予定日）
- 入力途中で閉じる際の破棄確認

### 含まない（モック簡略・後続）

- 画像オーダの受信・実施（撮影実施・読影レポート・所見入力）＝別ラウンド
- 保険選択・オーダシール/指示箋印刷・予約施設・別名（別名検索）・数値入力パレット
- 種別体系の拡張（`OrderType` は現行のまま。画像は種別「**画像**」で登録する）

## 画面要素（要素ツリー）

```
- 画像オーダダイアログ (Dialog, maxWidth=lg): OrderDialogTitle「画像オーダ」＋対象患者。左右 2 カラム
  - 左ペイン（幅 260）:
    - 「セット名称」見出し
    - セット名グループ (Select): 一般撮影／CT／MRI（変更でセット選択・内容をリセット）
    - セット名一覧 (List/ListItemButton): グループ配下のセット名（胸部・腹部…）。選択中をハイライト
  - 右ペイン:
    - 実施予定日 (date, required, 左寄せ・最上部)／担当医（ログイン医師）
    - 内容見出し（「［{グループ}］-［{セット}］」／未選択時は案内文）
    - 部位: 見出し＋[追加] / チェック行（チェック＋名称＋削除）
    - 手技: 見出し＋[追加] / チェック行（部位と同構造）
    - 薬剤: 見出し＋[追加] / チェック行（チェック＋名称＋用量 (number)＋単位＋削除）
    - フィルム: 見出し＋[追加] / チェック行（チェック＋名称＋分画＋撮影回数 (回)＋削除）
  - フッター: 閉じる（変更あれば破棄確認）／登録（いずれか 1 件以上チェック＋実施予定日ありで活性）
- 項目検索ダイアログ ([追加]で開く): 「{区分} の追加」・かな名称検索＋候補表（コード｜名称、行クリックで追加）
```

## 振る舞い

- **画像を開く**: オーダ送信画面「画像」（種別=`画像`）→ 画像オーダダイアログ。開くたびに実施予定日＝本日、グループ＝先頭（一般撮影）、セット未選択・内容空にリセット。
- **グループ切り替え**: セット名グループを変えるとセット選択と 4 区分の内容がクリアされる。
- **セット名で一括ロード**: セット名をクリックすると、部位・手技・薬剤・フィルムがテンプレートからチェック付きでロードされる（前の内容は置き換え）。例: 胸部=部位「胸部　正面」（チェック）／手技「胸部」／フィルム「撮影回数」1 回。
- **項目を追加/編集**: 各区分見出し直後の [追加] で項目検索ダイアログを開き、かな名称・名称で絞り込み、行クリックでチェック付き追加。薬剤は用量、フィルムは分画・撮影回数を入力。不要な行はチェックを外すか削除。
- **登録**: いずれかの区分に 1 件以上チェックがあり実施予定日が入っていれば登録可。checked 項目を区分ごとに連結した内容で `画像` オーダを作成し、作成中オーダに積む（予定日＝実施予定日）。
- **指示 → 反映**: [指示] で store へ追加 → 指示簿タブに `画像` で反映。
- **破棄確認**: セット選択済み、または各区分に行がある状態で閉じると破棄確認を表示する。

## 受け入れ基準（AC）

- [ ] **AC-1: 画像ボタンで画像オーダダイアログが開く（左=グループ/セット名／右=部位・手技・薬剤・フィルム）**
  - **Given** オーダ送信画面を開いている
  - **When** 種別「画像」ボタンを押す
  - **Then** タイトル「画像オーダ　対象患者: …」で、左にセット名グループ（プルダウン）＋セット名一覧、右に実施予定日・担当医と部位/手技/薬剤/フィルムの 4 区分が表示される
- [ ] **AC-2: グループ→セット選択で内容がチェック付きでロードされる**
  - **Given** 画像オーダダイアログを開いている
  - **When** グループ「一般撮影」でセット名「胸部」を選ぶ
  - **Then** 部位「胸部　正面」・手技「胸部」・フィルム「撮影回数」（1 回）がチェック付きでロードされる
- [ ] **AC-3: 区分の[追加]で項目検索から項目を追加できる**
  - **Given** いずれかの区分の [追加] を押して項目検索ダイアログを開いている
  - **When** かな名称で絞り込み、候補行をクリックする
  - **Then** 当該区分にチェック付きで項目が追加される（薬剤は用量、フィルムは分画・撮影回数を入力できる）
- [ ] **AC-4: 登録→指示で指示簿に反映される**
  - **Given** 1 件以上チェックし実施予定日を入力した
  - **When** 登録 → [指示]
  - **Then** 指示簿タブに `画像` で当該オーダ（「［グループ］-［セット］」＋部位/手技/薬剤/フィルムの複数行内容）が現れ、予定日＝実施予定日となる

## データ・状態

- **登録内容（content）**: 先頭行に `［{グループ}］-［{セット}］`（セット未選択時は `［{グループ}］`）、続けて checked 項目を区分ごとに 1 行ずつ連結。
  - `部位: {名称、…}` ／ `手技: {名称、…}`
  - `薬剤: {名称 用量+単位、…}`（用量未入力時は名称のみ）
  - `フィルム: {名称 {分画}分画 {回数}回、…}`（分画・回数は入力があるもののみ付与）
- **オーダ**: `type='画像'`、`status='指示済'`、`startDate=実施予定日`、`doctorName=ログイン医師`、`schedule=''`、`days=0`。
- **モックマスタ**（`src/data/imagingMaster.ts`）:
  - `IMAGING_GROUPS`: セット名グループ（一般撮影／CT／MRI）→ セット名一覧。胸部のみ詳細テンプレート（`CHEST_SET`）、他は既定テンプレート（`genSet`：部位「{名称}　正面」／手技「{名称}」／フィルム「撮影回数」1 回）。
  - `BUI_MASTER`（部位・74xxx）／`GIJUTSU_MASTER`（手技・71xxx 等）／`YAKUZAI_MASTER`（薬剤＝造影剤等・単位付き）／`FILM_MASTER`（フィルム・73xxx）。
  - `IMAGING_MASTER_OF`: 区分（部位／手技／薬剤／フィルム）→ 検索マスタの対応表。項目検索ダイアログはこれを名称・かなで絞り込む。

## 補足

- 画像オーダは ep-11（オーダ入力）の子ストーリーの一員（画像）。参考システムマニュアル第5章のオーダリング（画像）に相当する。
- 実施予定日の左寄せ・各区分見出し直後の [追加] インライン配置は、ECT オーダ（[us-58](./us-58-order-entry-ect.spec.md)）に配置を統一している。
- `imagingMaster.ts` は参考システムの画像オーダ画面の構造（セット名グループ→セット名→部位/手技/薬剤/フィルム）に合わせたワイヤーフレーム用固定データで、製品名・ベンダー名等の固有名詞は含まない。マスタはセッション限定（永続化しない）。
