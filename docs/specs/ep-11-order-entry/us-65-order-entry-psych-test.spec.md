## ユーザーストーリー

- **As a** 主治医
- **I want** 検査目的と心理検査項目をチェックボックスで選び、実施時期や注意事項を添えて心理検査をオーダしたい
- **So that** 心理検査の依頼内容（目的・項目・時期）を一枚の指示箋として素早く登録できる

## スコープ

### 含む（モック）

- オーダ送信画面「心理検査」ボタン → **心理検査ダイアログ**（1 カラム・区分別のチェックボックス群）
- **現在の状態像**（チェック＋自由記述）
- **検査目的**（複数選択チェックボックス＋その他・補足）
- **検査項目**（お任せ依頼／グループ→子項目のチェック／入院セット／その他・備考）
- **実施時期**（通常実施／急ぎの実施＋事情記述）
- **注意事項**（チェック＋自由記述）
- 登録 → 作成中オーダ → [指示] → 指示簿へ `心理検査` で反映（指示簿の区分は「**臨時**」にグルーピング）
- 入力途中で閉じる際の破棄確認

### 含まない（モック簡略・後続）

- 心理検査の実施・結果入力、所見・スコアリング、保険算定
- 検査項目マスタの検索・追加（項目は固定マスタ `psychTestMaster.ts`）
- 前回どおり（DO）・過去オーダーの引用

## 位置づけ（種別の整理）

- **心理検査は「検査」（[us-57](./us-57-order-entry-test.spec.md)）とは別種別**として共存する。`OrderType` 上も「心理検査」と「検査」は独立した種別で、オーダ送信画面にもそれぞれ独立したボタンがある。
- us-57 の記述に「心理検査を『検査』へ改名」とあるのは誤り。実際には改名しておらず、検体検査系の「検査」と、心理－指示箋系の「心理検査」は別々に存在する。心理検査は専用の `PsychTestOrderDialog` を用いる。

## 振る舞い

- **心理検査を開く**: オーダ送信画面「心理検査」ボタン → 心理検査ダイアログ。開くたびに全項目が初期化される。
- **項目を選ぶ**: 各区分のチェックボックスで選択。検査項目はグループ親・子項目・単独項目（お任せ依頼／入院セット）を任意に組み合わせて選べる。各補足欄は対応するチェックが ON のときのみ入力可（自由記述）。
- **実施時期**: 「急ぎの実施」を選ぶと事情・指定期日の記述欄が活性化する。
- **登録**: いずれかのチェックが 1 件以上入っていれば登録可。登録すると、選択内容（状態像／検査目的／検査項目／実施時期／注意事項）を改行連結した内容で `心理検査` オーダを作成し、作成中オーダに積む。実施時期に「急ぎの実施」を含む場合は schedule=「急ぎ」、それ以外は「通常」。
- **指示 → 反映**: [指示] で store へ追加 → 指示簿タブに反映。指示簿の種別グルーピングでは心理検査は「**臨時**」区分として表示される。
- **破棄確認**: 状態像・検査目的・検査項目・実施時期・注意事項のいずれかを操作済みの状態で閉じようとすると、破棄確認ダイアログを表示する。

## 受け入れ基準（AC）

- [ ] **AC-1: 心理検査ボタンで専用ダイアログが開く**
  - **Given** オーダ送信画面を開いている
  - **When** 種別「心理検査」ボタンを押す
  - **Then** 「心理検査オーダ 対象患者: …」の見出しで、現在の状態像・検査目的・検査項目・実施時期・注意事項の各区分を持つダイアログが開く
- [ ] **AC-2: 検査目的・検査項目を選んで登録できる**
  - **Given** 心理検査ダイアログを開いている
  - **When** 検査目的（例: 認知機能のアセスメント）と検査項目（例: 改訂長谷川式簡易評価スケール(HDS-R)）をチェックする
  - **Then** 登録ボタンが活性になり、押すと選択内容を含む `心理検査` オーダが作成中オーダに積まれる
- [ ] **AC-3: 未選択では登録できない**
  - **Given** 心理検査ダイアログを開いた直後（何もチェックしていない）
  - **When** フッターを見る
  - **Then** 登録ボタンは非活性である
- [ ] **AC-4: 指示で指示簿に臨時として反映**
  - **Given** 検査目的・項目を選んで登録した
  - **When** [指示] を実行する
  - **Then** 指示簿タブに `心理検査` のオーダが「臨時」区分で現れる
- [ ] **AC-5: 急ぎの実施で事情欄が活性化**
  - **Given** 心理検査ダイアログを開いている
  - **When** 実施時期で「急ぎの実施」をチェックする
  - **Then** 急ぎの事情・指定期日の記述欄が入力可能になる（登録時 schedule=「急ぎ」）

## データ・状態

- **検査目的マスタ** `PSYCH_PURPOSES`: 知能水準のアセスメント／性格傾向のアセスメント／発達障害のアセスメント／認知機能のアセスメント／診断補助のため／書類の申請のため／心理面接導入のため。
- **検査項目マスタ** `PSYCH_TEST_GROUPS`（親＝グループ名、子＝具体的検査）:
  - 発達及び知能検査: WAIS-4:16才～90才／WISC-4:16才まで／新版K式発達検査
  - 人格検査: ロールシャッハテスト／SCT／バウムテスト／PFスタディ／東大式エゴグラム(新版TEG3)
  - 認知機能検査: 改訂長谷川式簡易評価スケール(HDS-R)／精神状態短時間検査－改訂日本版(MMSE-J)／日本語版コグニスタット認知機能検査(COGNSTAT)／多面的初期認知症判定検査(MEDE)／前頭葉評価(FAB)
  - その他の心理検査: 自己評価式抑うつ性尺度(SDS)／状態・特性不安検査(STAI)／成人用自閉症スペクトラム指数(AQ):16才以上／児童用自閉症スペクトラム指数(AQ):保護者対象、15才まで／親面接式自閉スペクトラム症評定尺度改訂版(PARS-TR):保護者対象、3才以上／発達障害の要支援度評価尺度(MSPA):発達・思春期用、本人と保護者対象
  - その他の心理検査(非算定): 成人期ADHD検査(A-ADHD):18才以上／標準読み書きスクリーニング検査(STRAW-R):高校生まで／対人コミュニケーション質問紙(SCQ日本語版):保護者対象
- **単独項目**: `PSYCH_TEST_OMAKASE`＝「検査項目はお任せ依頼」／`PSYCH_TEST_ADMISSION_SET`＝「発達障害の2泊3日検査入院セット」。
- **登録されるオーダ**: `type='心理検査'`／`status='指示済'`／`startDate`＝当日／`days=0`／`schedule`＝「急ぎ」または「通常」／`content`＝選択内容の改行連結（未選択時のフォールバックは「心理検査」）。
- モック状態はセッション限定（画面遷移・リロードで初期化）。

## 補足

- 検査項目・検査目的は固定マスタ（`src/data/psychTestMaster.ts`）で、参考システム実機「心理－指示箋」の目的・項目に準拠する。検体検査（[us-57](./us-57-order-entry-test.spec.md)）のようなセット選択・かな検索は持たず、区分別のチェックボックス選択 UI（`PsychTestOrderDialog`）を用いる。
- 見出し文言は共通コンポーネント `OrderDialogTitle` により「心理検査オーダ」に統一している（旧称「心理－指示箋」から名称統一）。
- 指示簿（`src/components/karte/OrdersTab.tsx`）の種別グルーピングでは、心理検査は処方・注射・検査・画像・ECT と同じく「臨時」区分に含まれる。
