## ユーザーストーリー

- **As a** 主治医
- **I want** 定型のオーダに当てはまらない指示を、タイトルを付けて直接文章で入力・指示したい
- **So that** 連絡事項・観察依頼などを自由記述でカルテ記事・指示簿に残せる

## スコープ

### 含む（モック）

- オーダ送信画面「テキスト」ボタン → **テキストオーダ作成ダイアログ**（専用）
- **タイトル（必須・プルダウン）**: 病状説明／申し送り／連絡事項／観察依頼 等（伝票定義情報／文字オーダ のモック）
- **状態（任意）**／指示日
- **内容（必須・複数行）**: 直接文章を入力
- **継続する**（チェック）: 有り＝中止するまで指示簿に表示（継続オーダ＝日数0）／無し＝指示日のみ（日数1）
- 登録 → 作成中オーダ → [指示] → 指示簿へ `文字`（表示「テキスト」）で反映（内容＝「【タイトル】本文 ／ 状態: …」）
- 入力途中で閉じる際の破棄確認

### 含まない（モック簡略・後続）

- 記事タグ・添付ファイル・各項目連携（オプション連携）
- 受信オーダ画面での表示・指示箋/オーダシール出力（マニュアル通り文字オーダは帳票出力対象外）
- 継続オーダの終了（中止）操作・指示期間の記載＝実施/管理系

## 画面要素（要素ツリー）

```
- テキストオーダ作成ダイアログ (Dialog): 「テキストオーダ作成」・対象患者
  - タイトル (Select・必須)／指示日 (date)
  - 状態 (TextField・任意)
  - 内容 (multiline・必須)
  - 継続する (Checkbox)
  - フッター: 閉じる（変更あれば破棄確認）／登録（タイトル・内容が入力で活性）
```

## 振る舞い

- **テキストを開く**: オーダ送信画面「テキスト」→ テキストオーダ作成ダイアログ。
- **入力**: タイトル（必須）を選び、内容（必須）を入力。状態・指示日・継続するは任意。
- **継続する**: チェック有りで継続オーダ（中止まで指示簿表示・日数0）、無しで指示日のみ（日数1）。
- **登録 → 指示 → 反映**: 登録で作成中オーダに積み、[指示] で store へ追加 → 指示簿タブに `テキスト` で反映（内容＝「【タイトル】本文」）。

## 受け入れ基準（AC）

- [ ] **AC-1: テキストダイアログが開く**
  - **Given** オーダ送信画面を開いている
  - **When** 「テキスト」ボタンを押す
  - **Then** テキストオーダ作成ダイアログ（タイトル・状態・内容・継続する）が表示される
- [ ] **AC-2: タイトルと内容が必須で、揃うと登録できる**
  - **Given** テキストダイアログを開いている
  - **When** タイトルを選び、内容を入力する
  - **Then** 登録ボタンが活性化し、登録すると作成中オーダに積まれる
- [ ] **AC-3: 指示で指示簿に反映**
  - **Given** テキストオーダを作成中に積んだ
  - **When** [指示] を押す
  - **Then** 指示簿タブに `テキスト` で当該オーダ（【タイトル】本文）が現れる

## 補足

- タイトル候補のモック（`src/data/textOrderMaster.ts` の `TEXT_ORDER_TITLES`）。参考システムでは伝票定義情報／文字オーダ で設定するタイトルプルダウン。
- 内部の `OrderType` 値は「文字」、表示は「テキスト」（指示簿タブ・診療録のラベルマップに準拠）。
