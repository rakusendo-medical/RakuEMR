参考システムでは文字オーダ専用の作成ダイアログを用いるが、本モックでは UI を **診療録作成ダイアログの流用** で実現している（下記スコープ参照）。位置づけ（定型オーダに当てはまらない指示を自由記述で残す）はマニュアルの文字オーダに準拠する。

## ユーザーストーリー

- **As a** 主治医
- **I want** 定型のオーダに当てはまらない指示を、タイトルを付けて直接文章で入力・指示したい
- **So that** 連絡事項・観察依頼などを自由記述でカルテ記事・指示簿に残せる

## スコープ

### 含む（モック）

- オーダ送信画面「テキスト」ボタン → **テキストオーダ作成ダイアログ（診療録作成ダイアログ NewRecordDialog の流用）**
  - 見出しは共通 `OrderDialogTitle`（濃紺バー）を `titleNode` で差し込み、「テキストオーダ作成　対象患者: {患者番号}　{氏名}」と表示。
  - 流用時は**左の DO 引用パネル非表示**（`hideDoPanel`）・**本文の「前回カルテ取り込み」非表示**（`hideImportPrevious`）・**テンプレート非表示**（`hideTemplate`）・**面接フォーム非表示**（`hideInterviewForm`）。
- 残る入力欄（参考システムマニュアル 第5章第10部「文字オーダ作成」ダイアログ項目に対応）
  - **記載日時**（datetime-local。初期値は `MOCK_TODAY=2026-05-19` の午前 09:00。マニュアル①記載日）
  - **タイトル**（自由入力・TextField。マニュアル②タイトルは本来マスタ由来のプルダウンだが、本モックは自由入力で代替）
  - **タグ**（Enter で追加・複数可・チップ削除可。マニュアル⑤タグ＝記事タグ）
  - **指示日・継続する**（マニュアル⑥。タグと本文の間に配置。`orderFields` で表示）
    - **指示日**（date。オーダの指示日＝開始日。初期値は記載日時の日付＝モック当日）
    - **継続する**（Checkbox）: **有り**＝指示日以降、中止するまで「継続オーダ」として指示簿に表示。**無し**＝指示日のみ表示（翌日以降は非表示）
  - **本文**（フリーテキスト・必須。マニュアル⑦内容）
- フッターは**「キャンセル／登録」のみ**（診察終了・保存は出さない。`registerLabel="登録"`）。本文が空の間は登録ボタン非活性。
- 登録 → 「文字（表示「テキスト」）」オーダを**作成中のオーダへ追加**（`registerTextOrder`）。内容の組み立ては `【タイトル】本文` を基本に、面接フォーム／タグがあれば補足行を付す。予定日（`startDate`）＝**指示日**。
  - **継続する 有り**: `days=0`（継続）・`schedule='継続'`（中止まで指示簿に表示）
  - **継続する 無し**: `days=1`（指示日のみ）・`schedule=''`
- [指示] → カルテ記事作成（現在指示中）→ 指示簿・診療録タイムラインへ `テキスト` で反映。
- 入力途中で閉じる際の破棄確認（NewRecordDialog 内蔵の確認）。

### 含まない（モック簡略・後続）

- 添付ファイル（マニュアル⑧）・各項目連携（マニュアル④＝オプション連携）
- 受信オーダ画面での表示・指示箋／オーダシール出力（マニュアル通り文字オーダは帳票出力対象外）
- 継続オーダの**終了（中止）操作**（「文字オーダ編集」ダイアログの[終了]／指示簿の中止アイコン）と、中止時の**指示期間の診療録記載**（本モックは指示までを対象。継続フラグ自体は入力・保持する）

```
- テキストオーダ作成ダイアログ (NewRecordDialog 流用)
  - 見出し (OrderDialogTitle・濃紺バー): 「テキストオーダ作成　対象患者: {患者番号}　{氏名}」
  - 記載日時 (datetime-local・初期値 MOCK_TODAY 09:00)／タイトル (TextField・自由入力)
  - タグ (Enter で追加・チップ削除・複数)
```

## 振る舞い

- **テキストを開く**: オーダ送信画面「テキスト」ボタン → `kind:'freetext'` 分岐で NewRecordDialog を流用起動。
- **入力**: 本文（必須）を入力。タイトル・タグ・記載日時は任意。
- **指示日・継続する**: 指示日にオーダの指示日（開始日）を入力。「継続する」で継続オーダ／指示日のみを切り替える（マニュアル⑥）。
- **登録**: 登録ボタン（本文入力で活性）で `registerTextOrder` が実行され、`文字` オーダを作成中に積む。
  - 内容＝`【タイトル】本文` を 1 行目に、面接フォーム・タグがあれば `面接フォーム: …`／`タグ: …` の補足行を追加。
  - 予定日（`startDate`）＝**指示日**。継続する 有り→`days=0`・`schedule='継続'`、無し→`days=1`・`schedule=''`。
- **登録 → 指示 → 反映**: [指示] でカルテ記事作成（現在指示中）を経て store へ確定 → 指示簿・診療録タイムラインに `テキスト` で反映（`文字` → 表示「テキスト」）。

## 受け入れ基準（AC）

- [ ] **AC-1: テキストダイアログが開く**
  - **Given** オーダ送信画面を開いている
  - **When** 「テキスト」ボタンを押す
  - **Then** 濃紺バー見出し「テキストオーダ作成」のダイアログが開き、記載日時・タイトル・タグ・本文が表示される（DO 引用・前回カルテ取り込み・テンプレート・面接フォームは表示されない）
- [ ] **AC-2: 本文が必須で、入力すると登録できる**
  - **Given** テキストダイアログを開いている
  - **When** 本文を入力する
  - **Then** 登録ボタンが活性化し、登録すると `テキスト` オーダが作成中オーダに積まれる（内容は `【タイトル】本文`、タグ入力時は補足行付き）
- [ ] **AC-3: 指示で指示簿・診療録に反映**
  - **Given** テキストオーダを作成中に積んだ
  - **When** [指示] を押す
  - **Then** 指示簿タブ・診療録タイムラインに `テキスト` で当該オーダが現れる
- [ ] **AC-4: 指示日・継続する（マニュアル⑥準拠）**
  - **Given** テキストダイアログを開いている（タグと本文の間に指示日・継続する が表示される）
  - **When** 指示日を入力し、「継続する」を ON にして登録する
  - **Then** 予定日＝指示日で作成中に積まれ、継続オーダ（`days=0`・`schedule='継続'`）として扱われる。OFF の場合は指示日のみ（`days=1`）となる

## 補足

- テキストオーダは専用ダイアログではなく **診療録作成ダイアログ（`NewRecordDialog`）の流用**。オーダ用の見出し差し替えは `titleNode`（`OrderDialogTitle`）、不要要素の抑止は `hideDoPanel`／`hideImportPrevious`／`hideTemplate`／`hideInterviewForm`、フッター切替は `registerLabel`＋`onRegister`、**指示日・継続するの表示は `orderFields`** で行う。入力内容は `NewRecordData` 型（`orderDate`／`continuous` を含む）で親（`OrderSendScreen`）へ渡り、`registerTextOrder` が `文字` オーダへ組み立てる。
- **指示日・継続する（マニュアル 第5章第10部 ⑥）**: 「継続する」有り＝指示日以降、中止するまで継続オーダとして指示簿に表示／無し＝指示日のみ表示（翌日以降は非表示）。本モックは指示までを対象とし、中止操作・中止時の指示期間記載は未実装（[含まない] 参照）。この意味づけは旧 `TextOrderDialog`（マニュアル準拠）から踏襲している。
- 旧仕様（専用 `TextOrderDialog.tsx`：タイトル Select・内容 multiline・継続する Checkbox）は**オーダ送信画面のテキストボタンからは廃止**。ただし `TextOrderDialog.tsx` はファイルとして残存し、**IF オーダ（`IfOrderDialog`）のサブオーダ入力では引き続き使用**している。
- 内部の `OrderType` 値は「文字」、表示ラベルは「テキスト」（指示簿タブ・診療録の `ORDER_TYPE_DESCRIPTION`／作成中オーダのセクション見出しに準拠）。
- 面接フォームの選択肢は `MedicalRecordTab` の `INTERVIEW_FORMS` を共用する。モックはセッション限定（永続化なし）。
- **患者状態（5 段階カラー）は廃止**。診療録作成ダイアログの「状態」入力欄と、本文へ付していた `状態: …` の補足行を削除した。
