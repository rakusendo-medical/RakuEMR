## ユーザーストーリー

- **As a** 主治医
- **I want** 検査項目をチェックボックスで選び、検査セットを選ぶとその項目が一括でチェックされる形で検査をオーダしたい
- **So that** 多数の検査項目から必要なものを素早く選択・登録できる

## スコープ

### 含む（モック）

- オーダ送信画面「検査」ボタン → **検査ダイアログ**（検査は用量・用法を持たない＝項目名のみ）
- **検査項目のグループ別チェックボックス一覧**（検査マスタ・かな検索で絞り込み可）
- **検査セット**セレクト: 選ぶとセットに含まれる検査項目に**置き換わる**（前の選択はクリア）
- 予定日・担当医、登録 → 作成中オーダ → [指示] → 指示簿へ `検査` で反映
- 前回どおり（DO）: 前回チェックした項目を次回オープン時に初期チェック
- 入力途中で閉じる際の破棄確認

### 含まない（モック簡略・後続）

- 検査の実施・結果入力、検体・採取情報、保険、緊急/至急区分
- 種別体系の拡張（`OrderType` は 9 種のまま。検査は種別「**検査**」で登録する）

## 画面要素（要素ツリー）

```
- 検査ダイアログ (Dialog): 見出し「検査オーダ　対象患者: {患者番号}　{氏名}」（共通 `OrderDialogTitle`・濃紺バー）。左右 2 カラム
  - 左ペイン:
    - タブ [検査セット | 過去の検査オーダー]
    - かな検索 (TextField): 右の検査項目一覧を絞り込み
    - 検査セット一覧（検査セットタブ）: セット名をクリックでセットの項目をチェック
    - 過去の検査オーダー（過去タブ）: 前回オーダー（あれば）をクリックで項目をチェック
  - 右ペイン:
    - 実施予定日 (date)／担当医（ログイン医師）／選択件数
    - 検査内容: カテゴリ（生化Ⅰ／免疫／凝固／尿・糞便検査 等）別の**折り畳み（Accordion）**。各カテゴリ内に項目チェックボックス（選択数/総数を見出しに表示）
  - フッター: 閉じる（変更あれば破棄確認）／登録（1 件以上チェックで活性）
```

## 振る舞い

- **検査を開く**: オーダ送信画面「検査」→ 検査ダイアログ。
- **項目を選ぶ**: 検査項目のチェックボックスで選択。かな検索で一覧を絞り込める。
- **セットで一括チェック**: 検査セットを選ぶと、そのセットの項目に置き換わる（前の選択はクリア）。手動で追加・解除も可能。
- **登録**: 1 件以上チェックで登録可。登録すると checked 項目名を連結した内容で `検査` オーダを作成し、作成中オーダに積む。
- **指示 → 反映**: [指示] で store へ追加 → 指示簿タブに `検査` で反映。
- **前回どおり**: 次に同じ「検査」を開くと前回チェックした項目が初期チェックされる（予定日は本日にリセット）。

## 受け入れ基準（AC）

- [ ] **AC-1: 検査ダイアログが開く（左=セット一覧／右=カテゴリ折り畳み）**
  - **Given** オーダ送信画面を開いている
  - **When** 「検査」ボタンを押す
  - **Then** 左に検査セット一覧、右にカテゴリ別（折り畳み可）の検査項目チェックボックスが表示される
- [ ] **AC-2: 検査セット名を選ぶと項目がチェックされる**
  - **Given** 検査ダイアログを開いている
  - **When** 左の検査セット一覧からセット名を選ぶ
  - **Then** セットに含まれる検査項目のチェックボックスがチェックされる
- [ ] **AC-3: 登録→指示で指示簿に反映**
  - **Given** 検査項目を 1 件以上チェックした
  - **When** 登録 → [指示]
  - **Then** 指示簿タブに `検査` で当該オーダ（チェックした検査項目名）が現れる

## 補足

- 検査マスタ（11）・検査セットマスタ（12・有効フラグ=1）を実マスタ入力ファイルから抽出（`src/data/testSetMaster.ts`）。検査は項目名のみで用量・用法を持たないため、処方/注射（[us-54](./us-54-order-entry-prescription.spec.md)/[us-56](./us-56-order-entry-injection.spec.md)）の Rp テーブルとは別の**チェックボックス選択 UI**（`TestOrderDialog`）を用いる。
- 種別は `OrderType` の「**検査**」（検体検査＝総蛋白等）。予定オーダ欄の種名は「検」。検査マスタ（11）・検査セットマスタ（12）を利用。
- **検査と心理検査は別種別として共存**する（`OrderType` に「検査」「心理検査」の双方が存在）。本ストーリーは検体検査の「検査」を扱い、心理検査は専用ダイアログ（`PsychTestOrderDialog`）で別ストーリー **[us-65](./us-65-order-entry-psych-test.spec.md)（心理検査オーダ）** が扱う。心理検査は廃止・改名されていない。
