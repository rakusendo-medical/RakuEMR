## ユーザーストーリー

- **As a** 主治医／看護職員
- **I want** 患者の症状に応じたオーダ内容を入力し、各部門へ伝達＋カルテ記事として指示したい
- **So that** 「発熱時」「不眠時」等の症状に対する指示を素早く出せる

## スコープ

### 含む（モック）

- オーダ送信画面「IF」ボタン → **IF オーダダイアログ**（専用）
- **診療科**（精神科・固定表示）／指示日
- **症状（必須）**: 症状分類（発熱／疼痛／不眠 等）→ 症状（コメント候補）を選択（IF 症状条件のモック）
- **コメント（任意）**
- **オーダの内容（必須）**: 症状に応じた指示内容を入力（内容テンプレートをチップから挿入可）
- **用度伝票を印刷する**（モック・非機能）
- 登録 → 作成中オーダ → [指示] → 指示簿へ `IF` で反映（内容＝症状・コメント・オーダ内容を連結）
- 入力途中で閉じる際の破棄確認

### 含まない（モック簡略・後続）

- 指示歴（過去 IF オーダの一覧・変更・中止）／セット表示／個人オーダセット登録（DO は送信画面の診療録参照から可能）
- IF オーダ内での処方・注射など各種伝票の実追加（本モックは内容をテキストで代替）
- 代行入力認証・IF オーダの実施（看護記録側）・指示変更/中止

## 画面要素（要素ツリー）

```
- IF オーダダイアログ (Dialog): タイトル「IF オーダ」・対象患者
  - 診療科（精神科・固定）／指示日 (date)
  - 症状分類 (Select・必須) → 症状 (Select・必須。分類で候補が変わる)
  - コメント (TextField・任意)
  - オーダの内容 (multiline・必須)＋内容テンプレート（Chip・クリックで挿入）
  - 用度伝票を印刷する (Checkbox・モック)
  - フッター: 閉じる（変更あれば破棄確認）／登録（症状・オーダ内容が入力で活性）
```

## 振る舞い

- **IF を開く**: オーダ送信画面「IF」→ IF オーダダイアログ。
- **症状を選ぶ**: 症状分類を選ぶと症状（コメント候補）が切り替わる。両方必須。
- **オーダ内容を入力**: 症状に応じた指示内容を入力（テンプレートのチップをクリックで挿入も可）。
- **登録 → 指示 → 反映**: 登録で作成中オーダに積み、[指示] で store へ追加 → 指示簿タブに `IF` で反映（内容＝「症状: … ／ コメント: … ／ 内容: …」）。

## 受け入れ基準（AC）

- [ ] **AC-1: IF ダイアログが開く**
  - **Given** オーダ送信画面を開いている
  - **When** 「IF」ボタンを押す
  - **Then** IF オーダダイアログ（症状分類・症状・コメント・オーダの内容）が表示される
- [ ] **AC-2: 症状とオーダ内容が必須で、揃うと登録できる**
  - **Given** IF ダイアログを開いている
  - **When** 症状分類・症状を選び、オーダの内容を入力する
  - **Then** 登録ボタンが活性化し、登録すると作成中オーダに積まれる
- [ ] **AC-3: 指示で指示簿に反映**
  - **Given** IF オーダを作成中に積んだ
  - **When** [指示] を押す
  - **Then** 指示簿タブに `IF` で当該オーダ（症状・内容）が現れる

## 補足

- IF 症状条件のモック（`src/data/ifMaster.ts`）＝ `IF_SYMPTOMS`（分類→症状コメント候補）／`IF_ORDER_TEMPLATES`（分類ごとの内容サンプル）。参考システムマニュアルの「IF 症状条件選択（分類→コメント）」をワイヤーフレーム用に簡略化。
- マニュアルの IF オーダは、症状に応じて処方・注射等の各種伝票を束ねて指示し、指示歴での DO・変更・中止、代行入力認証等を持つ。本モックは**新規指示（症状＋オーダ内容テキスト）**に絞り、束ね／指示歴／変更中止は後続・実施系の範囲とした。過去 IF オーダの再作成は送信画面の診療録参照 [DO]（[us-55](./us-55-order-send-screen.spec.md)）で可能。
