## ユーザーストーリー

- **As a** 主治医／看護職員
- **I want** 患者の症状（頓用条件）に応じたオーダ内容を各種伝票で束ねて指示し、症状が出たら看護側で実施したい
- **So that** 「不眠時」「不穏時」等の症状に対する指示（処方・注射・検査 等）をあらかじめ用意し、必要時に素早く実施できる

## スコープ

### 含む（モック）

- オーダ送信画面「IF」ボタン → **IF オーダダイアログ**（専用・共通 `OrderDialogTitle`「IFオーダ／対象患者」）
- **症状（自由入力）**: TextField への直接入力、または **症状テンプレート選択（`IfSymptomPickerDialog`＝IF症状条件選択画面）** から挿入
- **コメント（任意）**: 複数行 TextField
- **種別ボタンでサブオーダを組み立て「束ねる」**: 処方／注射／検査／ECT／リハビリ／テキスト（IF・入院定時は除外）。各ボタンは対応するオーダ入力ダイアログを流用起動し、登録すると「内容（構成中のオーダ）」へ積む
- **左ペイン 指示歴／セット表示**（トグル）
  - **指示歴**: この患者の過去 IF オーダ（`ifCompositions`）を **[DO]** で症状・コメント・サブオーダごと復元
  - **セット表示**: 共通／個人トグル＋カテゴリ（`IF_SET_GROUPS`）で `IF_SETS` を絞り込み、クリックで登録済みサブオーダを取り込む
- 構成中サブオーダの個別削除
- フッター **[指示]**（サブオーダが 1 件以上で活性）→ 1 件の IF オーダとして「作成中のオーダ」へ積む
- 入力途中で閉じる際の破棄確認（`ConfirmDiscardDialog`）
- 指示確定（オーダ送信の [指示]）で **カルテ「IFオーダ」タブへ status='待機' で登録**（頓用のため即発行しない）
- カルテ「IFオーダ」タブから **[実施]** → チェックしたサブオーダを実オーダとして発行・即時実施済にし、**各オーダのカルテ記事（看護記録）を作成**、フローシート実施確認表／指示簿へ反映
- **IF は頓用（都度実施）** のため、[実施] は**何度でも押せる**（実施しても IF オーダ自体は待機のまま・無効化しない。実施ごとに一意 id の実オーダ＋カルテ記事を生成）

### 含まない（モック簡略・後続）

- 個人オーダセットの新規登録／編集（`IF_SETS` はモック固定データ）
- 代行入力認証
- IF オーダタブの部門連携（指示箋印刷／医事連携／看護記録の作成チェックは表示のみのモック）。※実施時に各オーダのカルテ記事（看護記録カテゴリ）を自動生成する点は実装済み（[実施] の振る舞い参照）
- 指示変更・中止（IFオーダタブの削除アイコンは表示のみ）

## 画面要素（要素ツリー）

### IF オーダダイアログ（`IfOrderDialog`）

```
- Dialog（maxWidth=lg・高さ 88vh）
  - OrderDialogTitle: 「IFオーダ」＋対象患者
  - 症状・コメント帯
    - 症状 (TextField・自由入力)＋テンプレート選択ボタン（虫眼鏡 → IfSymptomPickerDialog）
    - コメント (TextField・複数行・任意)
  - 本体（左右 2 ペイン）
    - 左: 指示歴 / セット表示（ToggleButtonGroup）
      - 指示歴: 過去 IF オーダ一覧（症状／サブオーダ種別）＋各行 [DO]
      - セット表示: 共通/個人トグル → カテゴリ Select（IF_SET_GROUPS）→ セット一覧（クリックで取り込み）
    - 右:
      - 種別ボタン列: 処方／注射／検査／ECT／リハビリ／テキスト
      - 内容（構成中のオーダ）: サブオーダを種別 Chip＋内容で列挙、各行に削除ボタン
  - フッター: 閉じる（dirty なら破棄確認）／指示（構成中サブオーダ ≥1 で活性）
```

### IF 症状条件選択画面（`IfSymptomPickerDialog`）

```
- Dialog（maxWidth=sm）
  - タイトル「IF症状条件選択画面」
  - 左: 分類（IF_SYMPTOMS の category 一覧。先頭「フリーコメント」）
  - 右: コメント（選択分類の comments 一覧。フリーコメントは自由入力案内）
  - フッター: 閉じる／登録（分類選択かつ非フリーはコメント選択で活性）
```

### カルテ「IFオーダ」タブ（`IfOrderTab`）

```
- 左: 症状（登録済み IF オーダ一覧・待機は淡黄／実施済はグレー）
- 右: 内容（選択 IF オーダのサブオーダを種別ごとに色分けセクション表示）
  - サブオーダ Checkbox（実施対象）＋備考欄
  - 実施バー: 指示箋印刷／医事連携／看護記録の作成（チェックのみ）・実施日・処方チェック・[実施]
```

## 振る舞い

- **IF を開く**: オーダ送信画面「IF」→ IF オーダダイアログ。開くたびに症状・コメント・構成中サブオーダをリセット。
- **症状を入れる**: 症状欄へ直接入力、または虫眼鏡から `IfSymptomPickerDialog` を開き、分類→コメントを選んで [登録] で症状欄へ反映（「フリーコメント」は空反映＝手入力用）。
- **サブオーダを束ねる**: 種別ボタン（処方／注射＝`PrescriptionDialog`、検査＝`TestOrderDialog`、ECT＝`EctOrderDialog`、リハビリ＝`RehaOrderDialog`、テキスト＝`TextOrderDialog`）で各オーダを入力・登録すると「内容（構成中のオーダ）」へ積む。IF は頓用のため日数・回数は非表示（`hideDays`）。
- **指示歴（DO）／セット取り込み**: 左ペイン指示歴の [DO] で過去 IF を丸ごと復元。セット表示で `IF_SETS` を選ぶと登録済みサブオーダを構成中に追加。
- **指示（束ねて積む）**: [指示] で構成中サブオーダを 1 件の IF オーダ（`type='IF'`・`schedule=症状`・内容＝コメント＋各サブオーダ）にまとめ、`onRegister` で「作成中のオーダ」へ。実施用内訳（症状・コメント・サブオーダ）も同時に親へ渡す。DO 用に `ifCompositions` へも保存。
- **確定 → 待機登録**: オーダ送信の [指示]（カルテ記事作成）確定時、IF オーダは発行せずカルテ「IFオーダ」タブへ `status='待機'` で登録する（`addIfOrder`）。
- **実施（頓用・都度実施）**: IFオーダタブで対象 IF を選び、実施するサブオーダにチェック → [実施] で各サブオーダを実オーダとして発行し即時実施済（`addOrder`＋`executeOrder`。実施ごとに一意 id）、**各オーダのカルテ記事（`appendMedicalRecord`・看護記録カテゴリ・カルテNo 連番）を作成**。フローシート実施確認表・指示簿へ実施済で反映。**IF は都度実施のため実施ボタンは何度でも押せ、IF オーダ自体は待機のまま残る**（`executeIfOrder` による恒久的な実施済化は行わない）。
- **指示簿からの遷移**: 指示簿タブ（[us-50]）で IF オーダの行をクリックすると、IFオーダタブへ遷移し、**同一 id の IF オーダを選択・表示**する（`IfOrderTab` の `focusOrderId`／`focusSignal` で受け取る。一覧に無い seed IF はタブ遷移のみ）。

## 受け入れ基準（AC）

- [ ] **AC-1: IF ダイアログが開く**
  - **Given** オーダ送信画面を開いている
  - **When** 「IF」ボタンを押す
  - **Then** IF オーダダイアログ（症状・コメント・左＝指示歴/セット表示・右＝種別ボタン＋構成中のオーダ）が表示される
- [ ] **AC-2: 症状テンプレートから症状を入れられる**
  - **Given** IF ダイアログを開いている
  - **When** 虫眼鏡から IF症状条件選択画面を開き、分類→コメントを選んで [登録] する
  - **Then** 選んだコメントが症状欄に反映される（自由入力も可）
- [ ] **AC-3: 種別ボタンでサブオーダを束ねられる**
  - **Given** IF ダイアログを開いている
  - **When** 種別ボタン（例: 処方）で内容を入力・登録する
  - **Then** 「内容（構成中のオーダ）」へ種別付きで追加され、削除もできる
- [ ] **AC-4: 指示で作成中オーダに積まれる**
  - **Given** サブオーダを 1 件以上構成した
  - **When** [指示] を押す
  - **Then** [指示] が活性化し、1 件の IF オーダとしてオーダ送信画面「作成中のオーダ」に積まれる
- [ ] **AC-5: 確定で IFオーダタブへ待機登録され、実施で反映**
  - **Given** IF オーダを作成中に積み、オーダ送信の [指示] で確定した
  - **When** カルテ「IFオーダ」タブで当該 IF を選び、サブオーダにチェックして [実施] する
  - **Then** タブに status='待機' で現れ、実施で実オーダがフローシート実施確認表・指示簿へ反映され、各オーダのカルテ記事（看護記録）が作成される
- [ ] **AC-6: IF は都度実施（実施ボタンを何度も押せる）**
  - **Given** ある IF オーダを一度 [実施] した
  - **When** 同じ IF オーダで再度サブオーダにチェックして [実施] する
  - **Then** 実施ボタンは無効化されず再実施でき、その都度 実オーダとカルテ記事が新規に作成される（IF オーダ自体は待機のまま）

## 補足

- IF モックマスタ（`src/data/ifMaster.ts`）:
  - `IF_SYMPTOMS`（分類 category → 症状コメント候補 comments。先頭「フリーコメント」は自由入力用）＝ IF症状条件選択画面のデータ。
  - `IF_SETS`（`IfSet`: name／scope=共通|個人／group／サブオーダ配列 `IfSubOrder`）＝ セット表示のデータ。`IF_SET_GROUPS` は `IF_SETS` の group 重複除去。
- 過去 IF オーダの再作成は、左ペイン指示歴の [DO]（患者ごとの `ifCompositions`）から症状・コメント・サブオーダ（医薬品含む）ごと復元できる。
- マニュアルの IF オーダは、症状に応じて処方・注射等の各種伝票を束ねて指示し、指示歴の DO・セット・頓用実施等を持つ。本モックはこの「束ね／指示歴 DO／セット取り込み／頓用の待機→実施」までを実装済みとし、個人セット登録・代行入力認証・指示変更中止は後続とした。
