## ユーザーストーリー

- **As a** 主治医
- **I want** 「オーダー入力」から、診療録を参照しつつ種別ごとにオーダを作成できる 1 画面（オーダ送信画面）を開きたい
- **So that** 過去の指示を見ながら、処方・注射・検査などのオーダをまとめて作成・指示できる

## スコープ

### 含む（本ラウンド）

- カルテ アクションバー「オーダー入力」→ **オーダ送信画面**（大きめダイアログ）を開く
- **左ペイン**: 診療録（参照）＝対象患者の既存オーダ一覧（seed＋登録分）を新しい順に読み取り専用表示。各オーダに **[DO] ボタン**（前回どおり）を備え、押すと同じ内容を本日・担当医=ログイン医師・status=指示済 で「作成中のオーダ」に複製する
- **右ペイン**: オーダ種別ボタン列（入院定時／処方／注射／検査／画像／心理検査／ECT／IF／テキスト。実装 `TYPE_BUTTONS` の並び順）＋「作成中のオーダ」一覧
  - 旧「**定時処方**」は「**入院定時**」に統合（廃止）。**画像・心理検査**を追加。**リハビリ**は種別ボタンから除外し、カルテ下部「**治療形態**」ボタンから起動（オーダではない扱い＝[us-61](./us-61-order-entry-reha.spec.md)）
- 「**処方**」「**入院定時**」ボタン → 処方ダイアログ（[us-54](./us-54-order-entry-prescription.spec.md)）を開き、登録すると「作成中のオーダ」に積まれる
- 「**セット一覧 ▼**」→ Popover（Portal）で **セット名グループのプルダウン → セット名リスト** を表示。セット名クリックで検査/画像/処方系オーダを「作成中のオーダ」へ一括展開（[実装済み](#受け入れ基準ac)）
- **下部**: 指示箋印刷／オーダ確認／処方チェック／多剤チェック のチェック（モック・非機能）＋[指示][閉じる]
- [**指示**] → 作成中のオーダをすべて確定（store へ追加）→ 指示簿一覧へ反映＋スナックバー
- [**閉じる**]／×: 作成中のオーダを破棄して閉じる

### 含まない（モック簡略・後続）

- セットオーダ編集／セット登録（引き続きモック・未実装）、外来/入院切替、科の切替、セット一覧の共通/個人タブ（本モックでは扱わない）
- 診療録タイムラインの実データ連携（既存オーダ一覧で代替）、検査結果タブ
- 下部チェックの機能化（指示箋印刷・オーダ確認・各種チェック）
- ※種別ボタンは 9 個（`TYPE_BUTTONS`）。各ボタンに対応する入力ダイアログを実装済み（入院定時=us-59／処方=us-54／注射=us-56／検査=us-57／画像=`ImagingOrderDialog`／心理検査=`PsychTestOrderDialog`／ECT=us-58／IF=us-60／テキスト=us-62）。リハビリ（[us-61](./us-61-order-entry-reha.spec.md)）はオーダではないためこの画面には置かず、カルテ下部「治療形態」ボタンから起動。未実装トーストのフォールバック（`compose` 未設定時）はコード上残置（将来種別追加用）

## 画面要素（要素ツリー）

```
- オーダ送信画面 (Dialog): 「オーダー入力」で開く
  - ヘッダ: 「オーダ送信［精神科］ 患者番号：氏名（病棟）」＋閉じる(×)
  - 左ペイン: 診療録（参照）
    - 既存オーダ一覧（読み取り専用）: 種別：内容 / 開始日・状態（新しい順）＋各行に [DO]（前回どおり）ボタン
  - 右ペイン:
    - ツールバー: セット一覧 ▼｜種別ボタン（入院定時/処方/注射/検査/画像/心理検査/ECT/IF/テキスト）
      - 入院定時・処方: 処方ダイアログ（入院定時=us-59／処方=us-54）／注射: 注射ダイアログ（us-56）／検査: 検査ダイアログ（us-57）／画像: 画像オーダダイアログ／心理検査: 心理検査オーダダイアログ を開く
      - ECT: ECT ダイアログ（us-58）／IF: IF オーダダイアログ（us-60）／テキスト: テキストオーダ作成ダイアログ（us-62）を開く
    - セット一覧 ▼ (Popover/Portal): セット名グループ（Select プルダウン）→ セット名リスト（ListItemButton＋">"）。セット名クリックで検査/画像/処方系オーダを「作成中のオーダ」へ一括展開（展開件数のスナックバー）。共通/個人タブは本モックでは扱わない
    - 作成中のオーダ一覧: 積まれたオーダ（種別チップ・内容・開始日/日数）と削除ボタン
  - 下部バー: [指示箋印刷][オーダ確認][処方チェック][多剤チェック]（チェックのみ・非機能）｜[閉じる][指示]
```

## 振る舞い

- **オーダ送信画面を開く**: アクションバー「オーダー入力」→ オーダ送信画面が開く。左に診療録参照、右に種別ボタン。作成中のオーダは空。
- **オーダを作成する**: 種別ボタン（9 個: 入院定時/処方/注射/検査/画像/心理検査/ECT/IF/テキスト）→ 各種別の入力ダイアログ（入院定時=us-59、処方=us-54、注射=us-56、検査=us-57、画像=画像オーダ、心理検査=心理検査オーダ、ECT=us-58、IF=us-60、テキスト=us-62）が開く。項目を追加/選択して登録 → 作成中のオーダ一覧に 1 件積まれる。ダイアログ見出しは共通 `OrderDialogTitle` により「{種別}オーダ 対象患者: …」で統一。
- **セット一覧を展開する**: 「セット一覧 ▼」→ Popover でセット名グループ（プルダウン）を選び、セット名をクリック → `resolveOrderSet` が検査/画像/処方系オーダを解決し「作成中のオーダ」へ一括展開。展開件数のスナックバー（展開できる内容が無ければ警告）。処方系は 2 行表示・クリックで再編集可能。
- **DO（前回どおり）**: 左の診療録（参照）の各オーダの [DO] を押すと、そのオーダと同じ内容を本日・担当医=ログイン医師・status=指示済 で作成中のオーダに複製する（スナックバーで通知）。ダイアログを開かずワンクリックで積める。
- **作成中を削除**: 作成中のオーダの削除ボタンで取り除く。
- **指示する**: [指示]（作成中が 1 件以上で活性）→ 作成中のオーダをすべて store へ追加し、指示簿一覧へ反映。スナックバー「オーダを登録しました（N件）」。画面を閉じる。
- **閉じる**: [閉じる]／×／背景クリック → **初期状態から変化がある（作成中のオーダがある）場合は破棄確認（注意文）を表示**し、「破棄して閉じる」で閉じる／「キャンセル」で戻る。変化が無ければそのまま閉じる。指示簿は変化しない。
  - この破棄確認は処方ダイアログ（[us-54](./us-54-order-entry-prescription.spec.md)）・処方追加ダイアログにも適用（入力途中で閉じようとすると確認）。`window.confirm` は使わず MUI ダイアログで表示。

## 受け入れ基準（AC）

- [ ] **AC-1: オーダ送信画面が開く**
  - **Given** カルテ画面（`/karte/:patientId`）を開いている
  - **When** アクションバー「オーダー入力」を押す
  - **Then** オーダ送信画面が開き、種別ボタン（入院定時／処方／注射／検査／画像／心理検査／ECT／IF／テキスト）が表示される
- [ ] **AC-2: 全種別ボタンから入力ダイアログが開く**
  - **Given** オーダ送信画面を開いている
  - **When** 各種別ボタン（入院定時／処方／注射／検査／画像／心理検査／ECT／IF／テキスト）を押す
  - **Then** それぞれの入力ダイアログが開く（9 種すべて実装済み。未実装トーストのフォールバックはコード上残置）
- [ ] **AC-2b: セット一覧からオーダを一括展開する**
  - **Given** オーダ送信画面を開いている
  - **When** 「セット一覧 ▼」を押し、セット名グループ（例: 検査・オーダーセット）を選んでセット名（例: 一般入院時検査）をクリックする
  - **Then** セット内容（検査・画像・処方系）が「作成中のオーダ」へ一括展開され、展開件数のスナックバーが表示される
- [ ] **AC-3: 処方を作成すると作成中に積まれる**
  - **Given** オーダ送信画面で「処方」→ 処方ダイアログで薬剤を Rp に追加した
  - **When** 処方ダイアログの登録を押す
  - **Then** 作成中のオーダ一覧に当該処方が 1 件積まれる
- [ ] **AC-4: 指示で確定して指示簿へ反映**
  - **Given** 作成中のオーダが 1 件以上ある
  - **When** [指示] を押す
  - **Then** 画面が閉じ「オーダを登録しました（N件）」が表示され、指示簿タブに当該オーダが status=指示済 で現れる
- [ ] **AC-5: 閉じるで破棄確認 → 破棄で閉じる**
  - **Given** 作成中のオーダがある
  - **When** [閉じる]／×／背景クリックする
  - **Then** 破棄確認（注意文）が表示され、「破棄して閉じる」で画面が閉じ指示簿には追加されない／「キャンセル」で画面に戻る（作成中は保持）

## 補足

- 処方ダイアログ＝[us-54](./us-54-order-entry-prescription.spec.md)。[us-53](./us-53-order-entry.spec.md) の汎用フォーム（種別セレクト単体ダイアログ）は本画面の登場により起点としては非採用（`OrderEntryDialog` は患者メインの未ルーティング画面にのみ残置）。
- 各種別ダイアログ: 注射 [us-56](./us-56-order-entry-injection.spec.md)、検査 [us-57](./us-57-order-entry-test.spec.md)、ECT [us-58](./us-58-order-entry-ect.spec.md)、入院定時 [us-59](./us-59-order-entry-inpatient-scheduled.spec.md)、IF [us-60](./us-60-order-entry-if.spec.md)、テキスト [us-62](./us-62-order-entry-text.spec.md)、画像 (`ImagingOrderDialog`)、心理検査 (`PsychTestOrderDialog`)。リハビリ [us-61](./us-61-order-entry-reha.spec.md) はオーダではないためこの画面には置かず、カルテ下部「治療形態」ボタンから起動。**この画面の 9 種別ボタンの入力ダイアログを実装済み**。
- ダイアログ見出しは共通コンポーネント `OrderDialogTitle` により「{種別}オーダ　対象患者: …」で統一されている。
- セット一覧マスタ＝`src/data/orderSetMaster.ts`（`ORDER_SET_GROUPS`）。グループ「検査・オーダーセット」＝一般入院時検査／外来検査一般、「頓用処方」＝不眠時／睡眠導入／不安時／不穏時。「一般入院時検査」は検体検査＋画像（胸部/腹部）を既存マスタから展開する。「セットオーダ編集」「セット登録」は引き続き未実装（モック）。
