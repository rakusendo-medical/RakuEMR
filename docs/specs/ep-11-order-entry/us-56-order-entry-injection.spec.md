## ユーザーストーリー

- **As a** 主治医
- **I want** オーダ送信画面の「注射」から、注射薬を検索または注射セットで追加して登録したい
- **So that** 処方と同じ操作感で注射オーダを素早く作成できる

## スコープ

### 含む（モック）

- オーダ送信画面の「注射」ボタン → **注射ダイアログ**（処方ダイアログと同型。ただし**一包化・後発不可の列／チェックは持たない**）
- **注射追加ダイアログ**: かな検索で **注射マスタ**（モック）を絞り込み、候補を選択、用量・単位・用法（＝手技/経路）を設定
- **注射セットマスタ**から一括セット（注射セット→注射マスタで名称・単位、セットが持つ用量・用法を解決）
- Rp テーブル（用法別採番・隣接整列・Rp 変更）、開始日・日数・終了日（双方向）、前回どおり（DO）は処方と共通
- 登録 → 作成中オーダ → [指示] → 指示簿へ `注射` で反映

### 含まない（モック簡略・後続）

- 投与経路・投与速度・混注・希釈・ボトル構成などの注射固有の詳細項目（用法＝手技名で代替）
- 注射マスタ本体連携（マスタは抽出モック）・薬効分類検索・セットオーダの新規登録

## 画面要素（要素ツリー）

処方ダイアログ（[us-54](./us-54-order-entry-prescription.spec.md)）と共通。差分のみ記す。

```
- 注射ダイアログ (Dialog): 見出し「注射オーダ　対象患者: {患者番号}　{氏名}」（共通 `OrderDialogTitle`・濃紺バー）
  - オーダ内容（Rp テーブル）: Rp番号 / 名称 / 用量 / 用法 / 削除（※一包化・後発不可の列は無し）
  - 「新しい Rp として薬剤を追加」→ 注射追加ダイアログ
  - （一包化・後発品変更不可（全）チェックは無し）
- 注射追加ダイアログ (Dialog): タイトル「注射追加」
  - 注射セット (Select): 注射セットマスタ（モック）から一括追加
  - かな検索＋候補リスト: 注射マスタを絞り込み
  - 選択薬剤テーブル: 名称 / 用量 / 単位 / 用法（手技） / 削除
```

## 振る舞い

- **注射を開く**: オーダ送信画面「注射」→ 注射ダイアログ（一包化/後発なし）。
- **注射を追加**: 「新しい Rp として薬剤を追加」→ 注射追加ダイアログ。かな検索で注射薬を探して追加、または注射セットで一括追加。用量・単位・用法（手技）を設定して登録。
- **Rp/日付/DO**: 処方と同じ（用法別 Rp・隣接整列・Rp 変更・終了日双方向・前回どおり）。
- **登録 → 指示**: 作成中に積み、[指示]で store へ追加 → 指示簿タブに `注射` で反映。

## 受け入れ基準（AC）

- [ ] **AC-1: 注射ダイアログが開く（一包化/後発なし）**
  - **Given** オーダ送信画面を開いている
  - **When** 「注射」ボタンを押す
  - **Then** 注射ダイアログが開き、Rp テーブルに一包化・後発不可の列／「後発品変更不可（全）」チェックが無い
- [ ] **AC-2: 注射セットから一括追加できる**
  - **Given** 注射追加ダイアログを開いている
  - **When** 注射セットを選ぶ
  - **Then** セットの注射薬が用量・用法込みで選択欄へ一括追加される
- [ ] **AC-3: 登録→指示で指示簿に注射が反映**
  - **Given** 注射を作成した
  - **When** 登録 → [指示] を押す
  - **Then** 指示簿タブに `注射` で当該オーダが現れる

## 補足

- 実装は処方ダイアログ（`PrescriptionDialog`）と `DrugAddDialog` を **props で汎用化**して共用（`showPackaging=false`、注射マスタ・注射セット・見出しを差し替え）。
- 注射マスタ（08）・注射セットマスタ（09・有効フラグ=1）を実マスタ入力ファイルから抽出（`src/data/injectionSetMaster.ts`）。用法は用法マスタ（23）で手技名（自己注射／インスリン皮下注射／腕(点滴)／腕(注射) 等）に解決。
- 検査・処置・画像・検査等の種別も同じ汎用ダイアログで後続追加できる。
