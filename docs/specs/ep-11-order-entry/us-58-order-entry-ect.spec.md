## ユーザーストーリー

- **As a** 主治医
- **I want** ECT（修正型電気けいれん療法・m-ECT）を、セット／サブセットから手技・前処置・通電時間・後処置を選び、用量や理由・所見・承諾を付けて指示したい
- **So that** 手技・麻酔・通電条件を漏れなく、指示理由と所見を添えてオーダできる

## スコープ

### 含む（モック）

- オーダ送信画面「ECT」ボタン → **ECT ダイアログ**（専用。検査のチェックボックス UI とは別構造）
- 左＝**ECT セット → サブセット**（サブセットを選ぶと右へ内容がチェック付きでロード）
- 右＝実施予定日／担当医、**手技（チェック）／前処置（チェック＋用量・単位）／通電時間（秒）／後処置（チェック＋用量・単位）**
- 各区分の **[追加]**＝「ECT 項目検索」（かな検索でマスタから追加。マニュアルの項目追加に相当）
- **指示情報**: 理由（プルダウン）＋ **[文章生成]** で所見欄へ自動入力（任意修正可）／承諾（チェック）／備考
- 登録 → 作成中オーダ → [指示] → 指示簿へ `ECT` で反映（内容＝手技・前処置・通電・後処置を連結、schedule＝理由名）
- 入力途中で閉じる際の破棄確認

### 含まない（モック簡略・後続）

- ECT オーダ実施（受信オーダ／オーダ実施：実施前・実施中・実施後状態の所見入力、済/止）＝別ラウンド
- 保険選択・オーダシール/指示箋印刷・オーダ確認・予約施設/オーダ計画・実施日未定の指示簿背景色
- 数値入力パレット（用量・通電時間は通常の数値入力欄で代替）・別名（別名1〜4）検索

## 画面要素（要素ツリー）

```
- ECT ダイアログ (Dialog): タイトル「ECT」・対象患者。左右 2 カラム
  - 左ペイン: ECT セット（Accordion）→ サブセット（ListItemButton）
  - 右ペイン:
    - 実施予定日 (date)／担当医（ログイン医師）
    - 手技: チェックボックス群＋[追加]
    - 前処置: 表（実施チェック／名称／用量 (number)／単位／削除）＋[追加]
    - 通電時間: 数値 (秒)
    - 後処置: 前処置と同じ表＋[追加]
    - 指示情報: 理由 (Select)＋[文章生成]／所見 (multiline)／承諾 (Checkbox)／備考 (TextField)
  - フッター: 閉じる（変更あれば破棄確認）／登録（手技・前処置・後処置のいずれか 1 件以上チェックで活性）
- ECT 項目検索ダイアログ ([追加]で開く): かな検索＋候補リスト（区分で絞り込み）
```

## 振る舞い

- **ECT を開く**: オーダ送信画面「ECT」→ ECT ダイアログ。
- **サブセットで一括ロード**: 左のセット→サブセットを選ぶと、手技・前処置・通電時間・後処置がチェック付きで右にロードされる（前の内容は置き換え）。
- **項目を追加/編集**: 各区分の [追加]（ECT 項目検索・かな検索）で項目を追加。前処置・後処置は用量を入力、実施しないものはチェックを外す。通電時間（秒）を入力。
- **理由→所見**: 理由をプルダウンで選び [文章生成] を押すと所見欄に定型文が入る（任意修正可）。承諾・備考も入力できる。
- **登録**: 1 件以上チェックで登録可。checked 項目を連結した内容で `ECT` オーダを作成し、作成中オーダに積む（schedule＝理由名）。
- **指示 → 反映**: [指示] で store へ追加 → 指示簿タブに `ECT` で反映。

## 受け入れ基準（AC）

- [ ] **AC-1: ECT ダイアログが開く（左=セット/サブセット／右=手技・前処置・通電時間・後処置・指示情報）**
  - **Given** オーダ送信画面を開いている
  - **When** 「ECT」ボタンを押す
  - **Then** 左に ECT セット/サブセット、右に手技・前処置・通電時間・後処置＋理由/所見/承諾が表示される
- [ ] **AC-2: サブセットを選ぶと内容がチェック付きでロードされる**
  - **Given** ECT ダイアログを開いている
  - **When** 左のサブセット「両側・標準」を選ぶ
  - **Then** 手技（両側前頭側頭部 通電）・前処置・通電時間（5 秒）等がチェック付きでロードされる
- [ ] **AC-3: 理由→[文章生成]で所見が入る／登録→指示で指示簿に反映**
  - **Given** サブセットをロードし、理由を選んで [文章生成] した
  - **When** 登録 → [指示]
  - **Then** 所見に定型文が入り、指示簿タブに `ECT` で当該オーダ（手技名等）が現れる
