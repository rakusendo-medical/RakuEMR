### 参考

> 参考システムの実機（オーダ送信時のカルテ作成）に準拠。[指示] 時に「カルテ記事作成（&gt;&gt;&gt; 現在指示中 &lt;&lt;&lt;）」ダイアログが開き、指示するオーダを種別ごとにまとめ、[実行] でオーダ確定＋カルテ記事を作成する。オーダ毎にカルテNo が発行される。

## ユーザーストーリー

- **As a** 主治医
- **I want** オーダを指示するときに、指示内容を種別ごとにまとめて確認し、実行と同時にカルテ記事を残したい
- **So that** 指示内容が診療録に記録され、オーダ毎のカルテNo で追跡できる

## スコープ

### 含む（モック）

- オーダ送信画面 [指示] → **カルテ記事作成ダイアログ**（現在指示中）
  - 指示するオーダを**種別ごとにセクション**（区分色の帯）で表示。内容は 1 薬品 1 行（Rp 番号付き）表記
  - 各種別に **所見**（任意）入力欄
  - フッター: [実行]（オーダ確定＋カルテ記事作成）／[閉じる]
- **[実行]**:
  - **オーダ毎にカルテNo（NO.xxx）を連番発行**（`nextKarteNo` から。非永続）
  - **オーダ（カルテNo）毎に別々のカルテ記事（医師記録）を診療録に作成**（`appendMedicalRecord`）。各記事は「【オーダ指示】／［種別］／内容／所見」＋発行カルテNo（`orderNumber`）
  - オーダを確定（store へ追加）→ 指示簿へ反映＋スナックバー
- **指示簿**: 各オーダに発行された**カルテNo 列**を表示
- **診療録（診療録タブ）**: 作成されたカルテ記事「【オーダ指示】…」がタイムラインに現れる（`dynamicMedicalRecords` を合成）

### 含まない（モック簡略・後続）

- 薬剤換算値（イミプラミン/CP/BP/DAP 換算）・指示箋/オーダシール印刷の機能化
- カルテ記事の編集・削除、記事タグの詳細、承認フロー
- カルテNo の採番ルール（施設・年度連番等）の厳密化（本モックは 865 からの単純連番）

## 画面要素（要素ツリー）

```
- カルテ記事作成ダイアログ (Dialog): ヘッダ「カルテ記事作成」＋「>>> 現在指示中 <<<」
  - 種別セクション（区分色の帯）×N:
    - ［種別名］
    - オーダ内容（1 薬品 1 行・Rp 番号付き）×n
    - 所見 (TextField・任意)
  - フッター: 基本記事（件数）｜[閉じる][実行]
```

## 振る舞い

- **指示 → カルテ記事作成**: [指示]（作成中が 1 件以上）→ カルテ記事作成ダイアログ。種別ごとにオーダがまとまって表示される。
- **実行**: [実行] → オーダ毎にカルテNo 発行 → カルテ記事（医師記録・診療録）作成 → オーダ確定（指示簿反映）→ スナックバー「オーダを登録しました（N件）」→ 画面クローズ。
- **閉じる**: [閉じる] → カルテ記事作成をキャンセル（オーダ送信画面に戻る。作成中は保持）。

## 受け入れ基準（AC）

- [ ] **AC-1: 指示でカルテ記事作成ダイアログが開く**
  - **Given** 作成中のオーダが 1 件以上ある
  - **When** [指示] を押す
  - **Then** 「カルテ記事作成（現在指示中）」ダイアログが開き、オーダが種別ごとに表示される
- [ ] **AC-2: 実行で診療録にオーダ毎のカルテ記事が作成される**
  - **Given** 作成中のオーダが複数ある状態でカルテ記事作成ダイアログを開いている
  - **When** [実行] を押す
  - **Then** 診療録タブに「【オーダ指示】…」のカルテ記事が**オーダ毎に別々**に現れ、オーダが指示簿に反映される
- [ ] **AC-3: オーダ毎にカルテNo が発行される**
  - **Given** [実行] でオーダを確定した
  - **When** 指示簿タブを見る
  - **Then** 各オーダに「NO.xxx」のカルテNo が付いている

## 補足

- カルテNo は `useAppStore.orderKarteNos`（オーダid→NO.xxx）＋ `nextKarteNo`（基準865の連番）。`assignKarteNos` で一括発行（非永続）。
- 診療録の合成: `MedicalRecordTab` が `dynamicMedicalRecords`（`appendMedicalRecord` 由来）をタイムラインへマージ表示。カルテ記事の `orderNumber` は発行したカルテNo（複数は範囲表記）。
- 個々のオーダは指示簿（[us-50](../ep-16-outpatient-emr-stage2/us-50-orders-tab.spec.md)）に、まとめたカルテ記事は診療録に、という役割分担（参考システム準拠）。
