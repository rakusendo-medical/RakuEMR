### 診断病名・病名 欄の仕様（マニュアル準拠：基本システム編 第6章 治療形態指示 p.1360-1363, 1369）

治療形態（作業療法／服薬指導／栄養指導ほか）の各指示画面に共通する「診断病名」欄・「病名」欄の仕様。

| 欄 | 参照元マスタ | 操作 | 特記 |
| --- | --- | --- | --- |
| **診断病名** | カルテ「診断名」に登録済みの**有効な診断病名**（上段プルダウンに一覧） | 上段プルダウンで選択 →**［プレビュー］**で下段の編集領域へ転記 → 編集可（下段へ直接ワープロ入力も可）。複数は選択＋プレビューを繰り返す | 下段に確定した内容が指示・診療録に反映 |
| **病名** | カルテ「診断名」に登録済みの**病名**（**初期表示＝主病名**・上段プルダウンに一覧） | 診断病名欄と**同一操作**（プルダウン選択→プレビュー転記→編集／直接入力） | **病名欄の値のみ**が給食／リハビリ接続システムへ送信される |

- **2欄の違い**: ①参照元が別（診断病名リスト vs 病名リスト・病名は主病名を初期表示）②**外部システム連携は病名欄のみ**（給食・リハビリ接続へ送信）。操作方法は両欄で同一。
- **「プレビュー」の意味**: 上段で選んだ病名を下段の編集領域（指示・登録・診療録記載に使われる欄）へ書き出す**転記ボタン**。転記後に自由編集できる（下書き／確認用途）。
- **文字数制限**: マニュアルに明示なし（本モック UI 上の「全角100文字まで」は実装側の想定値。マニュアル規定ではない）。
- **例外**: **食事療法の場合のみ**、診断病名・病名は診療録に記載されない（第6章 第2部 p.1369）。
- **実装（マニュアル準拠）**: `RehaOrderDialog` は両欄とも**上段プルダウン（カルテ診断名モック `REHA_DIAGNOSES`＋患者の主病名）＋［プレビュー］ボタン→下段編集テキスト**で実装。プレビューは下段へ転記（既存内容があれば読点で追記）、下段は直接入力・編集可。病名の下段は主病名（`patient.diagnosis`）を初期表示。

## ユーザーストーリー

- **As a** 主治医
- **I want** 患者に対して活動種目（作業療法・SST 等）と頻度・目標を指定してリハビリを指示したい
- **So that** 精神科リハビリの指示を素早く出し、指示簿・カルテ記事に反映できる

## スコープ

### 含む（モック）

- オーダ送信画面「リハビリ」ボタン → **リハビリオーダダイアログ**（専用）
- **指示日**（必須）／実施頻度（週N回）／担当医
- **活動種目（必須）**: カテゴリ別（作業療法／生活技能訓練／心理教育／運動・レク・芸術）のチェックボックス（リハビリプログラムマスタのモック）
- **目標・指示内容（任意）**: 指示箋マスタ項目相当のテキスト（カルテ記事に記載）
- **指示箋を印刷する**（モック・非機能）
- 登録 → 作成中オーダ → [指示] → 指示簿へ `リハビリ` で反映（内容＝種目・頻度・目標を連結）
- 入力途中で閉じる際の破棄確認

### 含まない（モック簡略・後続）

- パターン（指示箋マスタのバージョン）・診断病名/発症日・通達先／通達メニュー・指示箋レイアウト
- 転帰区分（継続/軽快/終了/中止）による終了・継続の自動新規作成、指示変更・削除
- **終了日**（新規指示には無い）: マニュアル（04 リハビリ支援オプション p.263, 266-267）では、新規指示の指示履歴は「**指示日〜未定**」で終了日欄は持たない。終了は「指示内容の終了」操作で **終了日（カレンダー）＋転帰区分** を指定して行い、転帰区分「継続」なら終了翌日を指示日とする新規指示が自動作成される。これらは指示変更・終了フロー＝後続／実施系の範囲
- 予定（週次スケジュール）・部門記録簿（実施記録）・医事算定＝別エピック（リハビリ実施）

## 画面要素（要素ツリー）

```
- リハビリオーダダイアログ (Dialog): タイトル「リハビリ（リハビリ指示）」・対象患者
  - 指示日 (date・必須)／実施頻度 (Select)／選択件数
  - 活動種目 (必須): カテゴリ別 Accordion のチェックボックス（選択数/総数）
  - 目標・指示内容 (multiline・任意)
  - 指示箋を印刷する (Checkbox・モック)／担当医
  - フッター: 閉じる（変更あれば破棄確認）／登録（種目 1 件以上で活性）
```

## 振る舞い

- **リハビリを開く**: オーダ送信画面「リハビリ」→ リハビリオーダダイアログ。
- **活動種目を選ぶ**: カテゴリ別チェックボックスで 1 件以上選択（必須）。実施頻度・目標を入力。
- **登録 → 指示 → 反映**: 登録で作成中オーダに積み、[指示] で store へ追加 → 指示簿タブに `リハビリ` で反映（内容＝「種目・…（頻度）／ 目標: …」）。

## 受け入れ基準（AC）

- [ ] **AC-1: リハビリダイアログが開く（活動種目のカテゴリ別チェック）**
  - **Given** オーダ送信画面を開いている
  - **When** 「リハビリ」ボタンを押す
  - **Then** 指示日・実施頻度・活動種目（カテゴリ別）・目標が表示される
- [ ] **AC-2: 種目が必須で、選ぶと登録できる**
  - **Given** リハビリダイアログを開いている
  - **When** 活動種目を 1 件以上チェックする
  - **Then** 登録ボタンが活性化し、登録すると作成中オーダに積まれる
- [ ] **AC-3: 指示で指示簿に反映**
  - **Given** リハビリオーダを作成中に積んだ
  - **When** [指示] を押す
  - **Then** 指示簿タブに `リハビリ` で当該オーダ（活動種目・頻度）が現れる

## 補足

- リハビリプログラム（活動種目）のモック（`src/data/rehaMaster.ts`）＝ `REHA_PROGRAMS`（カテゴリ別種目）／`REHA_FREQUENCIES`（頻度）／`REHA_OUTCOMES`（転帰区分・後続用）。参考システムのリハビリプログラムマスタ（第37部）を精神科リハビリ向けに簡略化。
- マニュアルのリハビリ指示は治療形態からの指示で、パターン（指示箋マスタ）・診断病名・通達・転帰区分・予定・部門記録簿（実施）まで含む。本モックは**新規指示（活動種目＋頻度＋目標）**に絞り、通達・転帰・予定・実施は後続／実施系の範囲とした。
