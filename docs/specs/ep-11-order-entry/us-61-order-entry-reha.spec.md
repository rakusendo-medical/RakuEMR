### 診断病名・病名 欄の仕様（マニュアル準拠：基本システム編 第6章 治療形態指示 p.1360-1363, 1369）

治療形態（作業療法／服薬指導／栄養指導ほか）の各指示画面に共通する「診断病名」欄・「病名」欄の仕様。

| 欄 | 参照元マスタ | 操作 | 特記 |
| --- | --- | --- | --- |
| **診断病名** | カルテ「診断名」に登録済みの**有効な診断病名**（上段プルダウンに一覧） | 上段プルダウンで選択 →**［プレビュー］**で下段の編集領域へ転記 → 編集可（下段へ直接ワープロ入力も可）。複数は選択＋プレビューを繰り返す | 下段に確定した内容が指示・診療録に反映 |
| **病名** | カルテ「診断名」に登録済みの**病名**（**初期表示＝主病名**・上段プルダウンに一覧） | 診断病名欄と**同一操作**（プルダウン選択→プレビュー転記→編集／直接入力） | **病名欄の値のみ**が給食／リハビリ接続システムへ送信される |

- **2欄の違い**: ①参照元が別（診断病名リスト vs 病名リスト・病名は主病名を初期表示）②**外部システム連携は病名欄のみ**（給食・リハビリ接続へ送信）。操作方法は両欄で同一。
- **「プレビュー」の意味**: 上段で選んだ病名を下段の編集領域（指示・登録・診療録記載に使われる欄）へ書き出す**転記ボタン**。転記後に自由編集できる（下書き／確認用途）。
- **文字数制限**: マニュアルに明示なし（本モック UI 上の「全角100文字まで」は実装側の想定値。マニュアル規定ではない）。
- **例外**: **食事療法の場合のみ**、診断病名・病名は診療録に記載されない（第6章 第2部 p.1369）。
- **実装（マニュアル準拠）**: `RehaOrderDialog` は両欄とも**上段プルダウン（カルテ診断名モック `REHA_DIAGNOSES`＋患者の主病名）＋［プレビュー］ボタン→下段編集テキスト**で実装。プレビューは下段へ転記（既存内容があれば読点で追記）、下段は直接入力・編集可。病名の下段は主病名（`patient.diagnosis`）を初期表示。

## ユーザーストーリー

- **As a** 主治医
- **I want** 患者に対して治療形態（作業療法／服薬指導／栄養指導）を切替えながら、依頼目的・主症状・指導内容・指示食種などを指定して指示したい
- **So that** 精神科リハビリ・服薬指導・栄養指導の指示を 1 画面で素早く出し、指示簿・カルテ記事（定期オーダ）に反映できる

## スコープ

### 含む（モック）

- カルテ下部アクションバー「治療形態」ボタン → **治療形態ダイアログ**（専用・共通 `OrderDialogTitle` で「治療形態　対象患者: …」）
- **治療形態 3 画面の切替**: 上部ボタン **作業療法／服薬指導／栄養指導**（初期＝作業療法）。切替時、共通項目（病棟／病室／身長／体重／診断病名／病名／指示日）は引き継ぐ
- **左に指示履歴**: 「新規」ボタン＋過去の指示（治療形態・登録日・担当医）を一覧。行クリックで内容を復元（`useAppStore.rehaCompositions[patient.id]`）
- **共通項目**: 病棟／病室（患者情報から表示・読取専用）、身長／体重（数値入力・患者情報から初期化）、診断病名・病名（上段プルダウン＋[プレビュー]で下段編集欄へ転記／直接入力可・病名下段は主病名を初期表示）、指示日（date・必須）、通達先（治療形態から自動表示・読取専用）
- **作業療法**: 依頼目的／主症状／注意事項（各カテゴリのチェック＋「その他」自由入力）、自殺企図歴（無/有）、希死念慮（無/有）
- **服薬指導**: 依頼内容（チェック＋その他）、薬剤師に伝えておきたい事項（複数行テキスト）
- **栄養指導**: 指導内容（チェック＋自由コメント）、BMI測定日、検査結果（項目チェック＋値入力）、指示食種（チェック）、エネルギー／蛋白質／脂質／炭水化物／塩分（単一選択）、指示栄養量（水分）なし/あり＋値
- 担当医＝ログイン医師（表示のみ）
- [指示] → 指示履歴へ登録＋作成中オーダを積む → 指示簿へ `リハビリ` 種別で反映（内容＝`rehaFormSummary` の要約、`schedule`＝治療形態名）。カルテ記事「【定期オーダ指示】」も作成（KartePage 側でカルテNo発行）
- 入力途中で閉じる際の破棄確認（`ConfirmDiscardDialog`）

### 含まない（モック簡略・後続）

- パターン（指示箋マスタのバージョン）・発症日・通達メニュー・指示箋レイアウト・指示箋印刷
- 転帰区分（継続/軽快/終了/中止）による終了・継続の自動新規作成、指示変更・削除
- **終了日**（新規指示には無い）: マニュアル（04 リハビリ支援オプション p.263, 266-267）では、新規指示の指示履歴は「**指示日〜未定**」で終了日欄は持たない。終了は「指示内容の終了」操作で **終了日（カレンダー）＋転帰区分** を指定して行い、転帰区分「継続」なら終了翌日を指示日とする新規指示が自動作成される。これらは指示変更・終了フロー＝後続／実施系の範囲
- 予定（週次スケジュール）・部門記録簿（実施記録）・医事算定＝別エピック（リハビリ実施）

## 振る舞い

- **治療形態を開く**: カルテ下部「治療形態」ボタン → 治療形態ダイアログ（初期＝作業療法）。
- **治療形態を切替える**: 上部ボタンで作業療法／服薬指導／栄養指導を切替。共通項目（病棟／病室／身長／体重／診断病名／病名／指示日）は引き継ぎ、治療形態固有の入力欄のみ差し替わる。
- **診断病名・病名を入れる**: 上段プルダウンで選び[プレビュー]で下段編集欄へ転記（既存があれば読点で追記）、または下段へ直接入力。病名下段は主病名を初期表示。
- **履歴から復元する**: 左ペインの過去指示をクリックすると当時のフォーム内容が復元される。「新規」で空フォームに戻す。
- **指示 → 反映**: [指示] で指示履歴へ登録し、作成中オーダを onRegister へ渡す → 指示簿タブに `リハビリ` 種別（`schedule`＝治療形態名、内容＝`rehaFormSummary` の要約）で反映。KartePage 側で定期オーダのカルテ記事「【定期オーダ指示】」も作成。

## 受け入れ基準（AC）

- [ ] **AC-1: 治療形態ダイアログが開く（3 画面切替・初期＝作業療法）**
  - **Given** カルテを開いている
  - **When** 下部アクションバー「治療形態」ボタンを押す
  - **Then** 治療形態ダイアログが開き、上部に作業療法／服薬指導／栄養指導の切替ボタン（初期＝作業療法）と共通項目（病棟・病室・身長・体重・診断病名・病名・指示日）が表示される
- [ ] **AC-2: 治療形態を切替えても共通項目は保持される**
  - **Given** 治療形態ダイアログを開いている
  - **When** 上部ボタンで服薬指導／栄養指導へ切替える
  - **Then** 治療形態固有の入力欄が差し替わり、共通項目（診断病名・病名・身長・体重・指示日 等）は保持される
- [ ] **AC-3: 診断病名・病名を[プレビュー]で下段へ転記できる**
  - **Given** 治療形態ダイアログを開いている
  - **When** 上段プルダウンで病名を選び[プレビュー]を押す
  - **Then** 下段の編集欄へ転記され（既存があれば読点で追記）、直接編集もできる
- [ ] **AC-4: 指示日が入力済みなら[指示]で指示簿・カルテに反映**
  - **Given** 指示日が入力済みで各治療形態の項目を入力した
  - **When** [指示] を押す
  - **Then** 指示履歴へ登録され、指示簿タブに `リハビリ` 種別（`schedule`＝治療形態名）で反映され、カルテ記事「【定期オーダ指示】」が作成される
- [ ] **AC-5: 入力途中の破棄確認**
  - **Given** 何らかの項目を入力した（dirty）
  - **When** 「閉じる」を押す
  - **Then** 破棄確認ダイアログが表示され、確定するまで閉じない

## 補足

- モックマスタ（`src/data/rehaMaster.ts`）:
  - `REHA_TREATMENTS`（治療形態 3 種＝作業療法／服薬指導／栄養指導）・`REHA_DESTINATION`（治療形態→通達先: 作業療法室／薬局／栄養科）
  - `REHA_DIAGNOSES`（診断病名・病名プルダウンの候補。実際の上段候補は患者の主病名を先頭に本配列を結合）
  - 作業療法: `OT_PURPOSES`（依頼目的）／`OT_SYMPTOMS`（主症状）／`OT_CAUTIONS`（注意事項）
  - 服薬指導: `MED_REQUESTS`（依頼内容）
  - 栄養指導: `NUTRI_TOPICS`（指導内容）／`NUTRI_LABS`（検査項目）／`NUTRI_DIETS`（指示食種）／`NUTRI_ENERGY`・`NUTRI_PROTEIN`・`NUTRI_FAT`・`NUTRI_CARB`・`NUTRI_SALT`（栄養量の単一選択候補）
  - フォーム型 `RehaForm`・空フォーム生成 `emptyRehaForm`・要約生成 `rehaFormSummary`（指示簿 content 用）
  - なお `REHA_PROGRAMS`（活動種目）／`REHA_FREQUENCIES`（実施頻度）／`REHA_OUTCOMES`（転帰区分）は旧版（活動種目 Accordion＋頻度＋転帰）の名残で **現行ダイアログでは未使用**。
- マニュアルのリハビリ指示は治療形態からの指示で、パターン（指示箋マスタ）・通達メニュー・転帰区分・予定・部門記録簿（実施）まで含む。本モックは **新規指示（治療形態 3 画面＋診断病名/病名＋各項目）** に絞り、パターン・転帰・予定・実施は後続／実施系の範囲とした。
- 起動導線: `src/components/karte/KarteActionBar.tsx`（`{ id: 'treatment-form', label: '治療形態' }`）→ `KartePage.tsx` の `treatment-form` ハンドラで `RehaOrderDialog` を開く。リハビリはオーダ送信画面（us-55）の種別には含めず、専用ボタンから直接起動する。
