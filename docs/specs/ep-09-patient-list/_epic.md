## 概要

入院中の患者集合を一画面で把握し、業務の起点（カルテ・報告・診察終了等）として機能する共通基盤画面。日付・病棟・主治医・担当職員でフィルタし、当日担当する患者をすぐ取り出せるようにする。

## ゴール

- 入院中の患者集合を一覧で参照できる
- 担当職員・主治医・病棟・日付フィルタで自分の関与する患者をすぐ表示できる
- 検索条件をセッション中保持して再表示の手間を減らす
- 一覧から各機能（カルテ、報告一覧、診察終了等）へ遷移できる

## スコープ

### 含む

- 入院患者の一覧表示と検索条件指定
- 担当職員（1〜10）による絞り込み（全てに一致／いずれかに一致）
- 主治医・診察医・病棟・日付による絞り込み
- 一覧からのカルテ画面遷移、診察終了の操作、報告一覧遷移
- 検索条件の保持（ログアウトまで）
- ウィンドウ幅 1100px 未満で副次列を非表示にするレスポンシブ挙動

### 含まない

- 病床配置の可視化（[ep-01 病棟マップ]）
- カルテ詳細・看護記録の編集
- 外来患者一覧（別画面 `/outpatient`）
- 報告一覧画面そのもの（遷移先未実装。本エピックでは導線のみ）

## 主要画面要素（エピック俯瞰）

```
- 入院患者一覧画面 (/patients)
  - 検索条件バー
    - 日付セレクト: カレンダーダイアログで対象日選択
    - 病棟セレクト
    - 主治医セレクト（医師ログオン時は自分が初期選択）
    - 担当職員フィルタ: 担当職員1〜10、職員選択ダイアログ起動 + 全/いずれかに一致トグル
    - 「診察医登録分も表示」チェック
    - 検索ボタン / クリアボタン
  - 一覧テーブル
    - 病棟・病室列（タイトルクリックで並び替え。順序は病床管理マスタ）
    - 患者番号列（クリックでカルテ遷移）
    - 氏名（年齢）列（性別アイコン・状態色・カルテアイコン）
    - 入院日列（入院日数表示、ヘッダクリックで日数降順並び替え）
    - 入院形態列（直近、形態変更後の値）
    - ICD10・病名列（ウィンドウ幅 < 1100px で非表示）
    - 責任レベル列（< 1100px で非表示）
    - 報告列（報告アイコン、クリックで報告一覧遷移）
    - 主治医列（ヘッダクリックで主治医順並び替え）
    - 終了列（診察終了状態アイコン、クリックで切替）
  - フッター
    - 件数表示
- 担当職員選択ダイアログ
  - 職員選択リスト（複数選択可）
  - 「全てに一致／いずれかに一致」ラジオ
  - 確定 / キャンセル
- 日付選択ダイアログ
  - カレンダー（MUI DatePicker または独自実装）
```

## 段階的実装方針（並行セッション運用上の注意）

ep-09 は共有ファイル（`src/types/index.ts` の Patient 型・`src/data/mockData.ts` の MASTER 系・`src/stores/useAppStore.ts`）に追加が必要な要素を含むため、以下の Phase 分けで進める。

### Phase 1（共有ファイル無修正）

既存 Patient 型のフィールドのみで実装可能な範囲を先行実装する。

- 日付フィルタ（一覧の見た目フィルタとしてのみ機能。在院判定に使用）
- 病棟フィルタ（既存 `WardFilterTabs` を維持。タブ UI で他画面と整合）
- 主治医プルダウン（`PATIENTS` から重複排除して動的生成）
- 並び替え: 病棟・病室／入院日／主治医
- 患者番号クリックでカルテ遷移
- ウィンドウ幅 < 1100px で副次列を非表示
- 検索条件保持: コンポーネント内 state（ページ離脱で消える）
- フリーキーワード検索（既存挙動維持）

### Phase 2（共有ファイル変更必要・MASTER と要協調）

別ラウンドで対応。担当エピックは ep-09 だが、Patient 型変更は ep-04（入退院歴）と整合を取る必要がある。

- 担当職員1〜10 → `Patient.assignedStaffIds: string[]` + `MASTER_STAFF`
- 入院形態 → `Patient.admissionFormType`（ep-04 と要協調）
- 責任レベル → `Patient.responsibilityLevel`
- 診察終了状態 → `useAppStore.consultationFinishedMap`
- 報告連携 → 既存報告データ集約 or 報告ストア新設
- 検索条件のセッション永続化 → `useAppStore.patientListSearchCondition`
- 担当職員選択ダイアログ → `src/components/common/StaffSelectDialog.tsx`
- 日付選択ダイアログ → MUI DatePicker 採用検討
