## ユーザーストーリー

- **As a** 病棟看護師（または主治医）
- **I want** 入院中の患者を日付・病棟・主治医・担当職員でフィルタして一覧で見たい
- **So that** 業務開始時に自分が関与する患者集合をすぐ取り出し、各機能（カルテ、報告、診察終了）への入口として使える

## 画面要素（要素ツリー）

```
- 入院患者一覧画面 (/patients)
  - 検索条件バー
    - 日付セレクト: 表示対象日（カレンダーダイアログで選択）
    - 病棟セレクト: 全病棟／第1病棟／第2病棟（Phase 1: タブ UI 維持、Phase 2 でプルダウン化検討）
    - 主治医セレクト: 全主治医／個別。医師ログオン時は自分が初期選択（Phase 1: 重複排除した一覧から選択）
    - 担当職員フィルタ条件設定ボタン (Phase 2): 職員選択ダイアログを開く
      - ダイアログ内: 職員リスト＋複数選択＋「全てに一致／いずれかに一致」ラジオ
    - 「診察医登録分も表示」チェック (Phase 2)
    - キーワード検索（既存）: 氏名・患者番号・担当医・診断名のいずれかに部分一致
  - 一覧テーブル
    - 病棟・病室列: 病棟名 + 病室番号。タイトルクリックで病床管理マスタ順に並び替え
    - 患者番号列: クリックで `/karte-alpha/:patientId` へ遷移
    - 氏名（年齢）列:
      - 性別アイコン (♂♀)
      - 氏名
      - 年齢
      - 患者状態色（StatusBadge を併設）
      - カルテアイコン (Phase 2): 標準診療種類画面へ遷移
    - 入院日列: 入院日 + 入院日数（n日目）。ヘッダクリックで日数降順並び替え
    - 入院形態列 (Phase 2): 直近の入院形態と開始日
    - ICD10・病名列: 主病名（diagnosis）。ウィンドウ幅 < 1100px で非表示
    - 責任レベル列 (Phase 2): ウィンドウ幅 < 1100px で非表示
    - 報告列 (Phase 2): 報告ありで報告アイコン、クリックで報告一覧へ
    - 主治医列: ヘッダクリックで主治医名順並び替え
    - 終了列 (Phase 2): 診察終了状態アイコン。クリックで診察終了・解除（ツールチップで職員名・時刻）
  - フッター
    - 件数表示
- 担当職員選択ダイアログ (Phase 2)
  - 職員選択リスト
  - 「全てに一致／いずれかに一致」ラジオ
  - 確定 / キャンセル
```

## 振る舞い

- **画面表示**: 既定では入院中（`admissionState !== 'discharged'`）の患者を全件表示。日付フィルタは在院判定（`admitDate <= 日付`）に使用
- **病棟フィルタ変更**: 即座にリスト絞込み
- **主治医セレクト変更**: 即座にリスト絞込み（「全主治医」選択で解除）
- **キーワード入力**: 1文字単位でリスト絞込み（debounce なし）
- **病棟・病室ヘッダクリック**: ascending → descending → なし のサイクルで並び替え
- **入院日ヘッダクリック**: 入院日数降順 → 昇順 → なし
- **主治医ヘッダクリック**: 主治医名 ascending / descending
- **患者番号クリック**: `/karte-alpha/:patientId` へ遷移
- **行クリック**（既存）: 患者番号と同じくカルテ画面へ遷移
- **ウィンドウ幅変動**: ResizeObserver / matchMedia で監視し、< 1100px で「ICD10・病名」「責任レベル（Phase 2）」を CSS 非表示

### Phase 2 のみの振る舞い

- **担当職員 [条件設定]**: 担当職員選択ダイアログを開く
  - 複数職員選択 + 「全てに一致／いずれかに一致」を指定して確定
  - フィルタ表示は「、」区切り、超過分はツールチップ
- **「診察医登録分も表示」チェック**: 主治医に加えて診察医として登録されている患者も含める
- **報告アイコンクリック**: 報告一覧画面へ遷移（patientId クエリ付与）
- **終了アイコンクリック**: 診察終了 / 解除を切替（職員名・時刻を保存）

## 受け入れ基準（AC）

### Phase 1（本ラウンドで完了）

- [ ] **AC-1: 入院患者一覧を病棟フィルタで絞り込める**
  - **Given** 患者一覧画面を開いている
  - **When** 病棟タブを切り替える（全病棟／第1病棟／第2病棟）
  - **Then** 当該病棟の入院患者のみが表示される

- [ ] **AC-2: 主治医プルダウンで絞り込める**
  - **Given** 患者一覧画面を開いている
  - **When** 主治医セレクトで個別の医師を選択する
  - **Then** 当該主治医の担当患者のみが表示される。「全主治医」選択で絞込み解除

- [ ] **AC-3: 日付フィルタで在院患者を絞り込める**
  - **Given** 患者一覧画面を開いている
  - **When** 日付を選択する
  - **Then** その日付時点で在院していた患者（admitDate <= 指定日）のみが表示される

- [ ] **AC-4: キーワード検索で絞り込める（既存維持）**
  - **Given** 患者一覧画面を開いている
  - **When** 氏名・患者番号・主治医名・診断名のいずれかに含まれるキーワードを入力する
  - **Then** 該当患者のみが表示される

- [ ] **AC-5: 病棟・病室ヘッダで並び替えできる**
  - **Given** 患者一覧を表示している
  - **When** 病棟・病室列ヘッダをクリックする
  - **Then** 病棟・病室順（病床管理マスタ順）で昇順/降順/解除のサイクルで並び替えられる

- [ ] **AC-6: 入院日ヘッダで日数降順に並び替えできる**
  - **Given** 患者一覧を表示している
  - **When** 入院日ヘッダをクリックする
  - **Then** 入院日数の降順／昇順／解除のサイクルで並び替えられる

- [ ] **AC-7: 主治医ヘッダで主治医名順に並び替えできる**
  - **Given** 患者一覧を表示している
  - **When** 主治医ヘッダをクリックする
  - **Then** 主治医名順／逆順／解除のサイクルで並び替えられる

- [ ] **AC-8: 患者番号クリックでカルテ画面へ遷移できる**
  - **Given** 患者一覧の特定行を表示している
  - **When** 患者番号セルをクリックする
  - **Then** `/karte-alpha/:patientId` に遷移する

- [ ] **AC-9: ウィンドウ幅 < 1100px で副次列が自動非表示になる**
  - **Given** 患者一覧を表示している
  - **When** ウィンドウ幅を 1100px 未満にリサイズする
  - **Then** ICD10・病名列が非表示になる（Phase 2 で責任レベル列も追加対象）

### Phase 2（後続ラウンド）

- [ ] **AC-10: 担当職員フィルタで「全てに一致／いずれかに一致」が動作する**
- [ ] **AC-11: 「診察医登録分も表示」チェックで主治医外の患者も含まれる**
- [ ] **AC-12: 報告アイコンから報告一覧へ遷移できる**
- [ ] **AC-13: 終了列クリックで診察終了状態を切替できる（職員名・時刻記録）**

- [ ] **AC-15: 入院形態列・責任レベル列が表示される**

## 状態遷移 / バリデーション

- 入院形態の表示は「直近、形態変更後」の値（Phase 2: ep-04 入退院歴の形態変更履歴と連動）
- 並び替えのサイクル: ascending → descending → none（複数列ソート不可）
- 日付フィルタ既定値: 操作日（today）

## 補足

- 本ストーリーは **Phase 1**（共有ファイル無修正）と **Phase 2**（共有ファイル変更要・MASTER 調整必須）に分割。Phase 1 のみ本ラウンドで AC-1〜AC-9 をクリアする
- 病棟フィルタは既存 `WardFilterTabs`（タブ UI）を維持し、他画面との UI 統一性を優先する。spec のプルダウン化は Phase 2 検討事項
- 報告データは既存実装に統合点が見当たらないため、Phase 2 で報告ストア／報告一覧画面と一体で設計する
- 既存実装（`src/components/patientList/PatientList.tsx`）は `WardFilterTabs` + キーワード検索 + テーブル表示の最低限機能のみ。Phase 1 はこれに日付・主治医セレクト・並び替え・レスポンシブ列・件数強調を追加する
