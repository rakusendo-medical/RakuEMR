## 画面要素（要素ツリー）

実装に近い階層構造で記述する。レイアウト・配色には触れず、各要素について **役割・データソース・表示条件** を簡潔に書く。

```
- ルート要素
  - 子要素A: 役割／データ（表示条件）
    - 孫要素A1: 役割
    - 孫要素A2: 役割
  - 子要素B: 役割
    - ...
```

> 表示条件は `(条件)` の形でカッコ書きで添える。動的に有無が変わる要素は明示する。
