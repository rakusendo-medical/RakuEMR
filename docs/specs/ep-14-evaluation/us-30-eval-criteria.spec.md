## ユーザーストーリー

- **As a** 受け持ち看護師
- **I want** 評価を登録する際の評価項目を事前に立案したい
- **So that** 定期評価の入力時に、対象患者・計画に合わせた評価項目を選択肢として用意できる

## 画面要素（要素ツリー）

```
- 評価画面 (/care-plan/patients/:patientId/evaluate?problemItemId=...)
  - 計画明細毎の評価項目領域
    - 計画明細サマリ（番号・看護診断・短期目標）
    - 評価項目選択アイコン
      - 未登録: 白抜きアイコン
      - 登録済: 色変アイコン
      - クリックで評価項目選択ダイアログを開く
    - 立案済評価項目一覧（既に立案済の場合のみ）
      - 各評価項目: 名称 + 評価レベル合計（[us-31]）
- 評価項目選択ダイアログ
  - ヘッダー: 患者・計画明細サマリ
  - 選択可能な項目一覧
    - マスタ保守／定期評価項目セット／看護
    - 定期評価項目マスタ／看護
    - 各項目: チェックボックス + 項目名 + 説明
  - 選択中件数
  - [設定] ボタン: 立案を確定
  - [キャンセル] ボタン
```

## 振る舞い

- **画面初期表示**: 計画明細毎に評価項目選択アイコンを表示。立案済の場合は色変、評価項目一覧を併記
- **評価項目選択アイコンクリック（未登録）**: 評価項目選択ダイアログを開く（選択可能な項目一覧、チェック未選択状態）
- **評価項目選択アイコンクリック（登録済）**: 評価項目選択ダイアログを開く（既存立案項目をチェック済で表示）
- **項目チェック ON**: 立案候補に追加
- **項目チェック OFF**: 立案候補から除外
- **[設定] クリック**:
  - チェック済の項目を立案として確定
  - 評価画面に戻り、評価項目選択アイコンが色変に。立案項目一覧が表示される
  - 既存立案項目を再編集した場合は変更日時・操作者を記録
- **[キャンセル] / × クリック**: 立案変更を破棄して閉じる
- **立案項目の評価登録**: 立案した評価項目をクリックすると評価入力ダイアログが開く（[us-31]）

## 受け入れ基準（AC）

- [ ] **AC-1: 評価画面から評価項目選択ダイアログを開ける**
  - **Given** 看護計画画面で計画明細の最終評価日（または「評価」タブ）をクリックして評価画面を開いている
  - **When** 評価項目選択アイコン（未登録時は白抜き）をクリックする
  - **Then** 評価項目選択ダイアログが開かれ、選択可能な項目一覧が表示される

- [ ] **AC-2: 評価項目を立案できる**
  - **Given** 評価項目選択ダイアログを表示している
  - **When** 「選択可能な項目」から評価項目を選択して [設定] をクリックする
  - **Then** ダイアログが閉じ、選択した評価項目が評価画面に表示される。評価項目選択アイコンが登録済（色変）に変わる

- [ ] **AC-3: 立案済み評価項目が定期評価で選択肢になる**
  - **Given** 評価項目を立案済み
  - **When** 同患者・同計画で定期評価入力を行う [us-31]
  - **Then** 立案した評価項目が選択肢として表れる

- [ ] **AC-4: 立案項目はマスタから取得される**
  - **Given** 評価項目選択ダイアログを開いている
  - **When** 選択可能な項目を確認する
  - **Then** マスタ保守／定期評価項目セット／看護、および定期評価項目マスタ／看護で定義された項目が表示される

- [ ] **AC-5: 立案済み項目を変更・削除できる**
  - **Given** 既に立案された評価項目を表示している
  - **When** 評価項目選択アイコンを再度クリックして編集する
  - **Then** 立案項目の追加・削除が可能。変更日時・操作者が記録される

## 状態遷移 / バリデーション

- 評価項目選択アイコンの状態: 未登録（白抜き）/ 登録済（色変）の2状態
- 立案件数 0 で [設定]: 「立案項目なし」状態となる（[キャンセル] と同等の効果）
- 立案項目は計画明細単位で管理（patientId × carePlanId × problemItemId × evalCriterionId）

## 補足

- 看護計画明細との紐付け仕様は明細単位で 1 対 多
- 立案を省略しても、初期選択評価項目（部門単位に1項目）で評価登録は可能（[us-31] のシナリオ）
- 評価項目マスタの構造: ID / 名称 / 評価レベルマスタ参照（任意）/ 説明 / 部門
