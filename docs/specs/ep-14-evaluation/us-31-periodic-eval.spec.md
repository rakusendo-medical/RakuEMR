## ユーザーストーリー

- **As a** 受け持ち看護師
- **I want** 定期評価を登録・参照・更新・削除し、必要に応じて特記報告やカルテ記事として連携したい
- **So that** 立案した評価項目に沿って計画の達成度を継続的に記録・確認し、関係者に共有できる

## 画面要素（要素ツリー）

```
- 評価画面 (/care-plan/patients/:patientId/evaluate?problemItemId=...)
  - 計画明細毎の評価項目領域
    - 立案済評価項目一覧（[us-30] で立案）
      - 各評価項目: 名称 + 評価レベルの評価点数合計
      - クリックで評価入力ダイアログ
      - 過去評価実施日リスト（時系列降順）
        - 評価実施日アイコン（クリックで該当評価の参照／更新）
    - 立案なしエリア（背景薄青色＋ハンドカーソル）
      - クリックで初期選択評価項目で評価入力ダイアログ
- 評価入力ダイアログ
  - ヘッダー: 患者・計画明細サマリ + 評価項目名 + 評価日
  - 評価レベル
    - レベルマスタからセレクト（マスタ未登録時は非表示）
    - レベルコメント（任意）
  - 評価内容（必須、テキストエリア）
  - 添付ファイル
    - 添付追加ボタン（複数可）
    - 添付一覧（ファイル名・サイズ・削除）
  - 備考（任意、テキストエリア）
  - 特記報告チェック
    - チェック ON で [特記報告ダイアログ] を起動
    - カルテ記事作成チェック ON 時は非活性
  - カルテ記事作成チェック
    - チェック ON で [カルテ記事作成ダイアログ] を起動
    - 特記報告チェック ON 時は非活性
  - フッター
    - [登録] ボタン: 新規評価登録
    - [更新] ボタン: 既存評価更新（既存評価表示時のみ）
    - [削除] ボタン: 既存評価削除（既存評価表示時のみ、確認メッセージ）
    - [キャンセル] ボタン
- 特記報告ダイアログ
  - 報告先: 初期=主治医、[検索] で職員選択ダイアログ
  - 種別: ラジオまたはセグメント
    - [作] 作成依頼
    - [確] 確認依頼
    - [両] 両方
  - 所見: 計画明細・評価内容を取込（編集可）
  - [登録] / [キャンセル]
- カルテ記事作成ダイアログ
  - ログオン者の標準診療種類に応じた起動
  - 標準診療種類が「看護経過記録」の場合: フリー形式で評価内容を本文に取込（看護経過記録ダイアログ起動）
  - その他の場合: 該当の記事作成ダイアログを開き、評価内容を取込
- 添付ファイルダウンロード
  - 評価詳細の添付ファイルアイコンクリックでダウンロード
```

## 振る舞い

- **画面表示**: 計画明細毎に立案済評価項目一覧 + 過去評価実施日リスト + 立案なしエリアを表示
- **立案済評価項目クリック（新規登録）**: 評価入力ダイアログ（新規モード）を開く
- **過去評価実施日アイコンクリック**: 評価入力ダイアログ（参照／更新モード）を開く
- **立案なしエリアクリック**: マスタの初期選択評価項目で評価入力ダイアログ（新規モード）を開く。登録後は評価項目選択アイコンが登録済になる
- **評価レベル未登録項目**: 評価入力ダイアログでは評価内容と添付ファイルのみ表示（評価レベル欄非表示）
- **特記報告チェック ON**: カルテ記事作成チェックを非活性化
- **カルテ記事作成チェック ON**: 特記報告チェックを非活性化
- **[登録]**:
  - 評価データを登録（評価レベル・レベルコメント・評価内容・添付ファイル・備考）
  - 特記報告チェック ON: 特記報告ダイアログを連続起動 → 報告先・種別を指定して [登録]
  - カルテ記事作成チェック ON: カルテ記事作成ダイアログを連続起動 → 標準診療種類に応じた記事を作成
  - 評価画面に戻る、評価点数合計が更新される
- **[更新]**: 既存評価の内容を変更
- **[削除]**: 確認メッセージ → 評価を削除
- **添付ファイルアイコンクリック**: 添付ファイルダウンロード

## 受け入れ基準（AC）

- [ ] **AC-1: 評価画面から評価入力ダイアログを開ける**
  - **Given** 評価画面を表示している
  - **When** 立案済の評価項目をクリックする
  - **Then** 評価入力ダイアログが開かれる

- [ ] **AC-2: 評価レベル・評価内容・添付ファイルを登録できる**
  - **Given** 評価入力ダイアログを表示している
  - **When** 評価レベル、評価内容、（必要に応じて）添付ファイルを入力して [登録] する
  - **Then** 評価が登録され、評価画面に反映される。評価レベルの評価点数合計も更新される

- [ ] **AC-3: 評価レベルが未登録の評価項目では内容のみ登録できる**
  - **Given** 評価項目で評価レベルが未登録の場合
  - **When** 評価入力ダイアログを開く
  - **Then** 評価内容と添付ファイルのみが表示される

- [ ] **AC-4: 立案なしで初期選択評価項目で評価登録できる**
  - **Given** 評価項目を立案していない
  - **When** 評価画面の評価領域をクリックする（背景薄青色＋ハンドカーソル）
  - **Then** マスタの初期選択評価項目で評価入力ダイアログが開かれ、登録可能。登録後は評価項目選択アイコンが登録済になる

- [ ] **AC-5: 特記報告で関係者に評価を報告できる**
  - **Given** 評価入力ダイアログを開いている
  - **When** [特記報告] にチェックして登録する
  - **Then** 特記報告ダイアログが開き、所見に計画明細と評価内容が取り込まれる。報告先（初期: 主治医、[検索] で職員選択可）と種別（[作]作成／[確]確認／[両]両方）を指定して報告できる

- [ ] **AC-6: カルテ記事作成連携ができる**
  - **Given** 評価入力ダイアログを開いている
  - **When** [カルテ記事作成] にチェックして登録する
  - **Then** ログオン者の標準診療種類に応じたカルテ記事作成ダイアログが表示される（標準診療種類が看護経過記録の場合は看護経過記録ダイアログがフリー形式で評価内容を本文に取り込んだ状態で開く）。チェック時 [特記報告] は非活性

- [ ] **AC-7: 添付ファイルをダウンロードできる**
  - **Given** 評価詳細に添付ファイルがある
  - **When** 添付ファイルアイコンをクリックする
  - **Then** 添付ファイルがダウンロードされる

- [ ] **AC-8: 過去の評価を時系列で参照できる**
  - **Given** 過去の定期評価が登録されている
  - **When** 評価画面を開く
  - **Then** 評価実施日順に過去評価が表示され、評価レベル・コメント・評価内容・備考・添付ファイル・評価点数合計が確認できる

- [ ] **AC-9: 評価を更新できる**
  - **Given** 既存の評価を表示している
  - **When** 評価をクリックして評価入力ダイアログを開き、内容を変更して [更新] する
  - **Then** 評価画面に変更が反映される

- [ ] **AC-10: 評価を削除できる**
  - **Given** 既存の評価を表示している
  - **When** 評価入力ダイアログで [削除] をクリックする
  - **Then** 確認メッセージ後、評価が削除される

## 状態遷移 / バリデーション

- 評価入力ダイアログのモード: 新規 / 参照・更新
- 評価レベル: 未登録項目では非表示。マスタから取得した評価レベルマスタの選択肢から1つ選択
- 評価点数合計: 計画明細単位で全評価項目の評価レベル点数を合算
- 特記報告とカルテ記事作成は排他（同時 ON 不可）
- 削除確認: モーダル確認 1 段階

## 補足

- 評価サイクル（毎週／毎月など）の運用ルールは別途整理
- 報告先選択時の「作成依頼／確認依頼／両方」は職員選択ダイアログで指定
- 病床管理画面からも定期評価への入口があるが本ストーリーは看護計画／評価画面からの導線を対象（病床管理経由のフローは別途整理）
- 既存実装（`MonthlyEvaluation.tsx`）の単純評価モデル（`achievement` / `findings` / `nextStatus`）から、本 spec の「評価レベル + レベルコメント + 評価内容 + 添付 + 備考 + 連携先」モデルへの移行が中核作業
