## ユーザーストーリー

- **As a** 受け持ち看護師
- **I want** 看護計画明細毎に達成度・所見・次ステータスを入力して定期評価を完了したい
- **So that** 計画の達成状況を記録し、次の対応（継続 / 修正 / クローズ）に繋げられる

## 画面要素（要素ツリー）

```
- 月次評価画面 (/care-plan/patients/:patientId/evaluate)
  - 患者ヘッダー（PatientHeader）
    - 患者番号 / 氏名 / 年齢 / 性別 / 病室 / 主診断 / 受け持ち看護師 / 入院日
  - 計画サマリ
    - 長期目標（長期目標の表示）
    - 立案日 / 立案者
    - 評価日入力（基準日、初期 = 操作日）
  - 計画明細毎の評価フォーム（EvaluationForm）× N
    - 計画明細サマリ
      - 番号 / ステータス / 優先度 / 領域
      - 看護診断（NANDA コード + 名称）
      - 問題点（problemStatement）
      - 短期目標
    - 評価入力エリア
      - 達成度ラジオ: 達成 / 一部達成 / 未達
      - 所見テキストエリア（最大 2000 文字想定）
      - 次ステータスセレクト
        - 継続（active のまま）
        - 修正して継続（evaluating）
        - 解決でクローズ（closed_resolved）
        - 中止でクローズ（closed_cancelled）
        - 変更でクローズ（closed_changed）
    - 前回評価履歴サマリ（折りたたみ）
      - 過去評価リスト: 評価日 / 達成度 / 所見抜粋 / 評価者
  - スティッキー操作バー（画面下部固定）
    - 入力済み件数 / 総件数 表示（例: 「2 / 3 件入力済」）
    - [すべて保存して評価完了] ボタン
      - クリック: 入力済み評価を一括登録 + 看護経過記録転記ダイアログを開く

- 看護経過記録への転記ダイアログ（評価完了時）
  - 転記内容プレビュー（buildTransferText で組立）
    - タイトル: 「看護過程月次評価」
    - 評価日 / 評価者 / 長期目標
    - 計画明細毎: 番号 / 看護診断 / 短期目標 / 達成度 / 所見
  - [看護経過記録に転記] = useNursingRecordStore.addRecord で看護経過記録（フリー形式）として保存
  - [スキップして閉じる] = 評価のみ完了、看護経過記録には転記しない
```

## 振る舞い

- **画面初期表示**: 当該患者の有効計画を取得し、計画明細を順次評価フォームで表示。前回評価履歴があれば折りたたみで併記
- **評価日変更**: 各評価フォームの evaluatedAt にこの日付を使用（個別変更は不可、画面共通）
- **達成度ラジオクリック**: 当該明細の達成度を更新
- **所見テキスト入力**: 当該明細の所見を更新
- **次ステータスセレクト変更**: 当該明細の次ステータスを更新
- **[すべて保存して評価完了] クリック**:
  1. 入力済み（達成度・所見が記入された）明細について `createEvaluation` を呼出
     - 各明細の status = nextStatus に遷移
     - lastEvaluatedAt = 評価日
     - nextEvaluationDueAt = 評価日 + 1 ヶ月
     - closed_* の場合は closedAt = 評価日
  2. 看護経過記録転記ダイアログを開く
- **[看護経過記録に転記]**: buildTransferText で生成したテキストを `useNursingRecordStore.addRecord` でフリー形式の看護経過記録として保存
- **[スキップして閉じる]**: 評価のみ完了、看護経過記録には書込まない
- **完了後**: ダッシュボード [ep-13] に戻る、または看護過程画面に戻る

## 受け入れ基準（AC）

- [ ] **AC-1: 評価画面を開ける**
  - **Given** 看護過程画面で [評価する] をクリックしている
  - **When** 評価画面に遷移する
  - **Then** 当該患者の有効計画明細が一覧表示され、計画明細毎の評価フォームが用意される

- [ ] **AC-2: 達成度・所見・次ステータスを入力できる**
  - **Given** 評価フォームを表示している
  - **When** 達成度ラジオを選択し、所見を入力し、次ステータスを選択する
  - **Then** 各入力値が画面上で保持される

- [ ] **AC-3: 達成度は 3 値固定**
  - **Given** 評価フォームを表示している
  - **When** 達成度ラジオを確認する
  - **Then** 「達成」「一部達成」「未達」の 3 値のみ選択可能

- [ ] **AC-4: 次ステータス選択肢が定められている**
  - **Given** 評価フォームを表示している
  - **When** 次ステータスセレクトを開く
  - **Then** 「継続」「修正して継続」「解決でクローズ」「中止でクローズ」「変更でクローズ」の 5 値が選択可能

- [ ] **AC-5: 過去評価履歴が参照できる**
  - **Given** 過去評価が登録されている
  - **When** 評価フォームの「前回評価履歴」を展開する
  - **Then** 過去評価が時系列降順で表示される（評価日・達成度・所見抜粋・評価者）

- [ ] **AC-6: 一括保存できる**
  - **Given** 1 件以上の評価フォームに入力済み
  - **When** [すべて保存して評価完了] をクリックする
  - **Then** 入力済み明細の評価が一括登録され、各明細の status / lastEvaluatedAt / nextEvaluationDueAt が更新される

- [ ] **AC-7: 評価完了で次回期限が更新される**
  - **Given** 評価を保存した
  - **When** 計画明細を確認する
  - **Then** lastEvaluatedAt = 評価日、nextEvaluationDueAt = 評価日 + 1 ヶ月

- [ ] **AC-8: クローズ系の次ステータスで closedAt が設定される**
  - **Given** 次ステータスを「解決でクローズ」「中止でクローズ」「変更でクローズ」のいずれかに選択して保存
  - **When** 計画明細を確認する
  - **Then** status = closed_*、closedAt = 評価日が記録される

- [ ] **AC-9: 看護経過記録への転記ダイアログが表示される**
  - **Given** [すべて保存して評価完了] をクリックして評価が登録された
  - **When** 自動で看護経過記録転記ダイアログが開く
  - **Then** ダイアログ内に転記内容プレビューが表示される（評価日・評価者・長期目標・計画明細毎の達成度・所見）

- [ ] **AC-10: 看護経過記録に転記できる**
  - **Given** 看護経過記録転記ダイアログを表示している
  - **When** [看護経過記録に転記] をクリックする
  - **Then** フリー形式の看護経過記録として `useNursingRecordStore.addRecord` で保存される

- [ ] **AC-11: 転記をスキップできる**
  - **Given** 看護経過記録転記ダイアログを表示している
  - **When** [スキップして閉じる] をクリックする
  - **Then** 評価のみ完了、看護経過記録には書込まずダイアログが閉じる

## 状態遷移 / バリデーション

- 評価フォームの入力済み判定: 達成度が選択されている AND 所見が空でない
- 一括保存対象: 入力済みの評価フォームのみ。未入力の明細はスキップ
- 評価日: 画面共通（個別評価ごとに変更不可）
- 次ステータス遷移マトリクス:

| 現 status | 選択可能な次ステータス |
| --- | --- |
| active | 継続 / 修正して継続 / 解決 / 中止 / 変更 |
| evaluating | 継続 / 修正して継続 / 解決 / 中止 / 変更 |
| draft | （評価対象外、画面に表示しない） |
| closed_* | （評価対象外、画面に表示しない） |
