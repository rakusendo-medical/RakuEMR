## 概要

看護過程の定期評価フェーズ。計画明細毎に達成度・所見・次ステータスを入力して一括保存し、評価結果を看護経過記録に転記する。
mock 既存実装の流れに揃えてシンプルに運用する：明細 = 評価対象、評価レベルは達成度 3 値固定、評価結果は看護経過記録（フリー形式）に自動転記。

## ゴール

- 計画明細毎の達成度・所見を効率的に入力できる
- 評価結果に応じて明細のステータスを遷移させ、次回評価期限を自動更新できる
- 評価結果を看護経過記録に転記して記録の一貫性を保てる

## スコープ

### 含む

- 計画明細毎の評価フォーム（達成度ラジオ・所見テキスト・次ステータス）
- 一括保存（[すべて保存して評価完了]）
- 評価日基準（画面共通の評価日入力）
- 過去評価履歴の参照（折りたたみサマリ）
- 評価完了時の看護経過記録への転記（フリー形式、buildTransferText で組立）
- ステータス遷移（active / evaluating → closed_resolved / closed_cancelled / closed_changed）
- 次回評価期限の自動更新（lastEvaluatedAt + 1 ヶ月）

### 含まない

- 評価項目立案（旧 us-30）— 採用しない
- 添付ファイル — 将来検討
- 特記報告ダイアログ — 将来検討
- 評価点数合計（スコア計算）— 将来検討
- 評価レベル + レベルコメント抽象モデル — 将来検討
- 評価項目マスタ / セットマスタ — 別エピック
