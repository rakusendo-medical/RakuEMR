## 概要

看護計画（[ep-13]）に対する評価運用を担うエピック。評価項目の事前立案、定期評価の登録・参照、特記報告／カルテ記事連携を扱う。立案なしでも初期選択評価項目で評価登録できる柔軟性を備える。

## ゴール

- 評価登録時に使用する評価項目を計画ごとに立案できる
- 立案した項目に沿って定期評価を登録・参照・更新・削除できる
- 評価結果を特記報告・カルテ記事として連携できる
- 立案を省略しても初期選択評価項目で評価できる

## スコープ

### 含む

- 評価項目の立案（評価項目選択ダイアログ）
- 定期評価の登録（評価レベル・評価内容・添付ファイル）
- 定期評価の更新・削除
- 立案なしの評価登録（初期選択評価項目）
- 特記報告での報告先連携
- カルテ記事作成連携

### 含まない

- 看護計画（[ep-13 看護計画]）
- 看護診断（[ep-12 看護診断]）

```

  - ヘッダー: 患者基本情報サマリ + 計画期間 + 長期目標
  - 計画明細毎の評価項目領域（複数）
    - 計画明細サマリ（番号・看護診断・短期目標）
    - 評価項目領域（評価項目毎）
      - 評価項目選択アイコン（白抜き=未登録、登録済=色変、クリックで評価項目選択ダイアログ）
      - 評価レベルの評価点数合計
      - 評価内容詳細（評価レベル、レベルコメント、添付ファイル、評価内容、備考）
      - 評価実施日リストとアイコン（クリックで評価入力ダイアログを開く）
      - 添付ファイルアイコン（クリックでダウンロード）
    - 立案なしエリア（背景薄青色＋ハンドカーソル）クリックで初期選択評価項目で登録 [us-31]
- 評価項目選択ダイアログ（[us-30] スコープ）
  - 選択可能な項目一覧（マスタ保守／定期評価項目セット／定期評価項目マスタを参照）
  - チェック選択
  - [設定] / [キャンセル]
- 評価入力ダイアログ（[us-31] スコープ）
  - 評価レベル（マスタ管理、レベルコメント可）
  - 評価内容
  - 添付ファイル（複数）
  - 備考
  - 特記報告チェック（チェックで特記報告ダイアログ）
  - カルテ記事作成チェック（特記報告と排他、チェック時 特記報告非活性）
  - [登録] / [更新] / [削除] / [キャンセル]
- 特記報告ダイアログ
  - 報告先: 初期=主治医、[検索] で職員選択ダイアログ
```

## 完了条件

- 全子ストーリーの AC がチェック済み
- 立案した評価項目が定期評価入力画面で選択肢として表れる
- 過去の定期評価を時系列で参照できる
- 特記報告／カルテ記事作成連携が機能する

## 既存実装との乖離

`src/features/carePlan/pages/MonthlyEvaluation.tsx` は「月次に全明細を一括評価する」画面で、本 spec の「計画明細毎の評価項目立案 + 個別評価ダイアログ + 特記報告 / カルテ連携」とは大幅に異なる。

| 項目 | 既存実装 | 本 spec |
| --- | --- | --- |
| 画面構造 | 全明細を縦に並べた一括評価フォーム | **計画明細毎の評価項目領域 + 評価項目選択ダイアログ起動** |
| 評価モデル | achievement / findings / nextStatus の単純評価 | **評価レベル + レベルコメント + 評価内容 + 添付ファイル + 備考** |
| 立案ステップ | なし | **評価項目立案（マスタから選択）→ 立案項目で評価登録** |
| 立案なし運用 | なし（全 patientId × 計画で同形式評価） | **立案なしでも「初期選択評価項目」で評価可能** |
| 特記報告 | なし（看護記録への一括転記のみ） | **特記報告ダイアログ（報告先・種別指定）** |
| カルテ連携 | 看護記録への自動転記 | **カルテ記事作成ダイアログ起動（標準診療種類連動）** |
| 添付ファイル | なし | **複数添付・ダウンロード** |
| 評価レベルマスタ | なし（固定 3 値: 達成/一部達成/未達） | **マスタ管理（評価点数合計の計算可）** |

実装着手時は既存 MonthlyEvaluation を廃止し、評価画面 (`/care-plan/patients/:patientId/evaluate`) を spec 準拠に作り直す想定。
