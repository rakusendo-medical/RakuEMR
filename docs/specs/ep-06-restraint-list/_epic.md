## 概要

行動制限下にある患者を病棟横断で一覧化し、看護師長等の管理者がカルテ記事・看護記録・指示受けサインの状態を一画面で把握・操作できるようにする。ガバナンス警告（精神保健指定医以外による指示／12時間超過）を可視化し、行動制限一覧性台帳の Excel 出力までを担う。

## ゴール

- 行動制限下患者を「指示」タブで病棟横断一覧化（病棟→病室→ベッド昇順）
- 一覧の各行から **指示記事の作成／編集／看護記録の作成／指示受けサインの登録** を起動できる
- 精神保健指定医以外の指示・12時間超過を **赤字** で警告表示
- 行動制限一覧性台帳（Excel）を一覧画面から出力できる

## スコープ

### 含む

- 隔離拘束一覧画面「指示」タブの行表示
- 検索条件（期間／病棟／終了者を表示しない／入院形態フィルタ）と [表示] / [印刷] アクション
- 一覧からのカルテ記事 [未] [済] クリックで開始／終了指示ダイアログ起動（ep-05 `RestraintOrderDialog` を再利用）
- 一覧からの看護記録 [未] [済] クリックで看護記録ダイアログ起動（カルテ済が前提）
- 指示受けサインの一次／二次の登録・更新・削除（サイン入力ダイアログ）
- 入院形態フィルタの条件設定ダイアログ
- 患者番号クリック → 転棟・転室ダイアログ（既存 `BedMoveDialog` 再利用）
- カルテアイコンクリック → 標準診療種類のカルテ画面遷移（既存パターン踏襲）
- 行動制限一覧性台帳の Excel 出力（モックでは XLSX 風 CSV ダウンロード or スナックバー通知）

### 含まない

- 行動制限指示そのものの発行ロジック（[ep-05 隔離拘束指示]）
- 観察記録の入力（[ep-07 観察記録]、隔離拘束一覧の「記録」タブ）
- 隔離拘束歴の参照（[ep-08 隔離拘束歴]）
- 職員マスタ・台帳レイアウトマスタの保守

## 主要画面要素（エピック俯瞰）

```
- 隔離拘束一覧画面 (/isolation)
  - タブ切替: [指示] / [記録]（記録は ep-07）
  - 検索条件バー
    - 期間 (from / to、初期値: 操作日〜操作日)
    - 病棟セレクト（全病棟／第１病棟／第２病棟）
    - [終了者を表示しない] チェック
    - [条件設定] ボタン → 条件設定ダイアログ
    - [表示] ボタン
    - [印刷] ボタン → 行動制限一覧性台帳 Excel 出力
  - 一覧テーブル（指示タブ）
    - ヘッダ: 患者番号 / 氏名(年齢) / 入院形態 / 区分 / 開始日時 / 開始指示医
              / カルテ(開始) / 看護(開始) / 指示受け(開始)
              / 終了日時 / 終了指示医
              / カルテ(終了) / 看護(終了) / 指示受け(終了)
    - 各行: 行動制限下患者
      - 患者番号: クリックで BedMoveDialog 起動
      - 氏名横カルテアイコン: クリックでカルテ画面遷移
      - 入院形態列ヘッダ: クリックで並び替え（入院形態→病棟→病室→ベッド）
      - 区分: 隔離 / 拘束 / 隔・拘 / その他
      - 開始日時: 12時間超過時 赤字
      - 開始/終了指示医: 精神保健指定医=黒 / 以外=赤
      - カルテ(開始/終了) [未]→RestraintOrderDialog（開始/終了）／[済]→編集モード
      - 看護(開始/終了) [未]→看護記録ダイアログ（カルテ済時のみ） /[済]→編集
      - 指示受け(開始/終了) 上段一次／下段二次 → SignInputDialog
      - 終了日時: 継続・変更指示時は「-」表示
- 条件設定ダイアログ
  - 入院形態複数選択（マスタ参照）
  - [OK] / [キャンセル]
- サイン入力ダイアログ
  - 職員プルダウン（ログオン職員初期表示、マスタ）
  - [登録] / [更新] / [削除] / [キャンセル]
- 行動制限一覧性台帳出力（Excel／モックでは CSV）
```
