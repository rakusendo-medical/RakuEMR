## ユーザーストーリー

- **As a** 病棟看護師長
- **I want** 行動制限下にある患者を一覧で把握し、指示受けサイン・カルテ記事・看護記録の状態を管理し、行動制限一覧性台帳を出力したい
- **So that** 病棟全体の行動制限状況をガバナンス基準で把握し、規程に基づく台帳提出と指示受け運用を行える

## 振る舞い

- **画面初期表示**: 期間=操作日〜操作日／病棟=全病棟／終了者を表示しない=ON で自動表示
- **[表示] クリック**: 検索条件で再フェッチして一覧更新
- **[条件設定] クリック**: 条件設定ダイアログを開く。OK で入院形態フィルタ反映、入院形態欄にバッジ表示
- **入院形態欄ホバー**: 選択中の入院形態を全件ツールチップ表示
- **入院形態列ヘッダクリック**: 並び替え順を「入院形態→病棟→病室→ベッド」昇順に変更（再クリックで降順）
- **患者番号クリック**: 既存 `BedMoveDialog` を起動（転棟・転室）
- **カルテアイコンクリック**: `KarteAlphaPage` へ遷移（標準診療種類が `nursing-record` の場合は `/nursing` へ）
- **カルテ(開始) [未] クリック**: ep-05 `RestraintOrderDialog` を該当区分の「開始」タイトル固定で開く
- **カルテ(開始) [済] クリック**: ep-05 `RestraintOrderDialog` を編集モードで開く（既存指示の値プリロード）
- **カルテ(終了) [未] クリック**: ep-05 `RestraintOrderDialog` を該当区分の「解除」タイトル固定で開く
- **看護(開始/終了) [未] クリック**: カルテ欄が [済] の場合のみ看護記録ダイアログを開く。[未] の場合は disabled
- **看護(開始/終了) [済] クリック**: 既存看護記録の編集ダイアログを開く
- **指示受け [未] / 既存名 クリック**: `SignInputDialog` を該当の一次／二次区分で開く
- **SignInputDialog [登録]**: 職員選択して `upsertConfirmSign(orderId, kind, sign)` でストア保存
- **SignInputDialog [更新]**: 既存サインを上書き
- **SignInputDialog [削除]**: 該当サインを `removeConfirmSign(orderId, kind)` で削除
- **[印刷] クリック**: 期間 from の月を対象月として行動制限一覧性台帳を出力（モックではスナックバー）
- **継続・変更指示中の終了日時表示**: `IsolationOrder.operation === '継続' | '変更'` かつ `endDatetime` 未設定の場合「-」表示

## 受け入れ基準（AC）

- [ ] **AC-1: 行動制限下の患者を一覧で確認できる**
  - **Given** 隔離拘束一覧画面の「指示」タブを開いている
  - **When** 病棟・期間・終了者表示有無・入院形態（その他用）を指定して [表示] をクリックする
  - **Then** 該当条件下の患者が、患者番号・氏名(年齢)・入院形態・区分（隔離／拘束／隔・拘／その他）・開始/終了日時・指示医・カルテ／看護／指示受けの状態とともに病棟→病室→ベッド昇順で一覧表示される

- [ ] **AC-2: 表示対象患者が要件どおり選定される**
  - **Given** 患者集合に複数のステータスが混在する
  - **When** 一覧を表示する
  - **Then** 以下のいずれかを満たす患者のみ表示される
    - 隔離・拘束の指示あり（区分: 隔離／拘束／隔・拘）
    - 入院病棟が行動制限判定対象（区分: その他）
    - 行動範囲の指示あり、かつ責任レベルが行動制限判定対象または行動制限項目が観察記録の記録対象（区分: その他）

- [ ] **AC-3: ガバナンス警告が色分け表示される**
  - **Given** 一覧に患者が表示されている
  - **When** 開始指示医が精神保健指定医以外、または開始日時から12時間を超過している
  - **Then** 開始指示医は赤字、12時間超過時は開始日時も赤字で表示される

- [ ] **AC-4: 一覧から開始／終了のカルテ記事を作成・更新できる**
  - **Given** 一覧の「カルテ(開始)」「カルテ(終了)」欄を確認している
  - **When** [未] をクリックする、または [済] をクリックする
  - **Then** [未]: ep-05 `RestraintOrderDialog` が該当指示種別の初期状態で開かれる。[済]: 編集モードで登録済記事を表示・更新できる。終了側の [未] からは隔離拘束の終了指示も発行できる

- [ ] **AC-5: 看護記録を作成・更新できる（カルテ済が前提）**
  - **Given** 一覧の「看護(開始)」「看護(終了)」欄を確認している
  - **When** [未] をクリックする
  - **Then** カルテ欄が [済] の場合のみ看護記録ダイアログが開かれる。FOCUS／SOAP／フリー形式で本文を入力して登録できる。カルテが [未] の場合は看護記録を作成できない（ボタン disabled）。[済] クリックで編集も可能

- [ ] **AC-6: 指示受けサインを登録・変更・削除できる**
  - **Given** 一覧の「指示受け」欄を確認している
  - **When** [未] または既存の指示受け者名をクリックする
  - **Then** サイン入力ダイアログが開かれ、職員選択後に [登録]／[更新]／[削除] で操作できる。一次サイン（上段）／二次サイン（下段）の二段階で運用される

- [ ] **AC-7: 入院形態フィルタを条件設定ダイアログで指定できる**
  - **Given** その他区分の患者を入院形態で絞り込みたい
  - **When** [条件設定] をクリックして条件設定ダイアログで入院形態を選択する
  - **Then** 指定した入院形態が検索条件に反映され、入院形態欄にホバーすると全条件がツールチップ表示される

- [ ] **AC-8: 患者番号／カルテアイコンから関連画面へ遷移できる**
  - **Given** 一覧で患者を確認している
  - **When** 患者番号またはカルテアイコンをクリックする
  - **Then** 患者番号: 転棟・転室ダイアログ（既存 `BedMoveDialog`）。カルテアイコン: 標準診療種類のカルテ画面（職員マスタの標準診療種類設定に従う、`Patient.primaryRecordType` で分岐）

- [ ] **AC-9: 終了日時が継続・変更指示時は「-」表示となる**
  - **Given** 隔離拘束に継続・変更指示が入っている（`operation === '継続' | '変更'` かつ `endDatetime` 未設定）
  - **When** 一覧を表示する
  - **Then** 終了日時欄は「-」となり、終了が確定するまで表示されない

- [ ] **AC-10: 行動制限一覧性台帳を Excel で出力できる**
  - **Given** 一覧画面で期間（開始日）と病棟を指定している
  - **When** [印刷] をクリックする
  - **Then** 期間の開始日に該当する月を対象月として、対象病棟の行動制限一覧性台帳が Excel で出力される（モックではスナックバー通知 + 集計サマリ表示）。患者単位で隔離・拘束それぞれの日次累計時間・継続最大時間が集計される

## 状態遷移 / バリデーション

### 表示対象患者の選定ロジック

```
表示対象 ← 以下のいずれかを満たす患者:
  1. IsolationOrder.subtype ∈ {'隔離','拘束','隔離拘束'} かつ active (endDatetime 未設定 OR operation ∈ {'継続','変更'})
  2. Patient.wardId が MASTER_BEHAVIOR_RESTRICT_WARDS に含まれる（その他）
  3. BehaviorRange.level が責任レベル「行動制限判定対象」 OR 観察記録対象（その他）

「終了者を表示しない」ON: 1 のうち endDatetime が設定済 (解除済) を除外
```

### ガバナンス警告

- 開始指示医が精神保健指定医ではない（マスタ `MASTER_STAFF_FOR_SIGN[].isPsychiatristCertified === false`）→ 開始指示医セル赤字
- 開始日時から現在時刻まで > 12 時間（かつ active）→ 開始日時セル赤字

### サイン入力モード

- 既存サインなし → [登録] のみ有効
- 既存サインあり → [更新] / [削除] 有効、[登録] disabled

### 看護記録ボタン状態

- カルテ欄 [未] → 看護欄ボタン disabled
- カルテ欄 [済] かつ 看護欄 [未] → 看護欄ボタン enabled（[未] 表示）
- カルテ欄 [済] かつ 看護欄 [済] → 看護欄 [済] 表示（クリックで編集）

## 補足

- 台帳のレイアウト・タグはマスタ管理。タグ詳細は文書キャビネットタグ一覧に従う（モックでは集計サマリのスナックバー通知のみ）
- 「指示」タブと「記録」タブで区分「その他」の表示患者が異なる場合がある。本ストーリーは「指示」タブのみを対象（記録タブは ep-07）
- ログオン職員以外をサイン入力ダイアログのプルダウンに表示する設定はマスタで制御（モックでは全職員表示）
- 既存 `IsolationRestraint.tsx` の「指示」タブは現在の固定表示から本 spec の構成へ全面改修。「観察記録」タブ／「隔離歴」タブ／「行動制限台帳」タブは ep-07 / ep-08 で再整理
- 既存 `ISOLATION_ORDERS` モックは `confirmSigns` フィールドの追加が必要（ep-05 で型拡張済）。サンプルデータも数件付与
