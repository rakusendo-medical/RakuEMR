## ユーザーストーリー

- **As a** 病棟事務
- **I want** 退院予定の患者を確定処理したい
- **So that** 退院が事実として記録され、病床が空床として開放される

## 画面要素（要素ツリー）

```
- 入退院情報画面 (/admission, us-07参照)
```

## 振る舞い

- **退院予定患者氏名クリック (赤文字)** / **日付未定者一覧の患者番号クリック**: 退院手続きダイアログを開く
- **退院日変更**: 食事終了日が医療機関情報マスタの食事時間設定に従って自動連動更新される
- **食事終了日変更**: 食事終了日時から退院日時までの間に「食無し」指示（マスタ設定により「臨時欠食」）が自動生成される
- **食事を伴わない退院日入力時**: 食事終了日項目は編集不可
- **退院確定実行**:
  1. 退院日が未来日時 → エラー（確定不可）
  2. 未実施の入院専用オーダ + 移動・給食オーダ → オーダ確認ダイアログ
  3. 食事終了日時が変更されている AND 操作者が医師でない AND オーダ中止操作を行う → 代行入力認証ダイアログ
  4. 確定: 患者氏名表示が赤→黒、カルテ画面・医師指示簿に書込、未実施の移動・給食オーダ削除
- **更新ボタン**: 入力内容を保存し未確定のまま閉じる
- **指示箋印刷チェック**: 確定／更新と同時に食事箋・移動箋を印刷扱い（モックは UI のみ）

## 受け入れ基準（AC）

- [ ] **AC-1: 退院予定患者から手続き画面を開ける**
  - **Given** 入退院情報画面または病棟マップを表示している
  - **When** 退院予定患者の氏名（赤文字）をクリックする、または日付未定者一覧から患者番号をクリックする
  - **Then** 退院手続きダイアログが開かれ、退院指示時の入力（退院日・転帰・食事終了日・紹介医療機関・退院決定理由・指示内容・帰住先など）が初期表示される（退院時文書は取り扱わない）

- [ ] **AC-2: 退院日変更で食事終了日が連動する**
  - **Given** 退院手続きダイアログを開いている
  - **When** 退院日を変更する
  - **Then** 食事終了日が医療機関情報マスタの食事時間設定に従って自動的に連動更新される

- [ ] **AC-3: 食事終了日を入院期間内で個別調整できる**
  - **Given** 食事終了日を退院日と異なる時刻にする必要がある
  - **When** 入院期間内で食事終了日時を変更する
  - **Then** 食事終了日時から退院日時までの間に「食無し」指示（マスタ設定により「臨時欠食」）が自動生成される

- [ ] **AC-4: 食事を伴わない退院日付の場合は食事終了日を編集できない**
  - **Given** 食事を伴わない退院となる退院日が入力されている
  - **When** 食事終了日項目を表示する
  - **Then** 食事終了日は編集不可となる

- [ ] **AC-5: 退院確定すると未実施オーダの確認が出る**
  - **Given** 患者に未実施の入院専用オーダおよび移動・給食オーダが残っている
  - **When** 退院確定を実行する
  - **Then** 退院確定時のオーダ確認ダイアログが表示され、選択チェックでオーダを中止できる。リハビリオーダ中止時は転帰区分を指定できる

- [ ] **AC-6: 退院確定後に未実施移動・給食オーダが削除される**
  - **Given** 退院確定を実行した
  - **When** 確定処理が完了する
  - **Then** 未実施の移動・給食オーダは削除される

- [ ] **AC-7: 退院確定後の状態が反映される**
  - **Given** 退院確定が完了した
  - **When** 各画面を確認する
  - **Then** 患者氏名表示が赤→黒に変わり、カルテ画面・医師指示簿に確定内容が書き込まれる

- [ ] **AC-8: 未来日付では退院確定できない**
  - **Given** 退院日に未来日付が設定されている
  - **When** 退院確定を実行しようとする
  - **Then** 確定できない（指示の更新は可能）

- [ ] **AC-9: 医師以外が食事終了日を変更すると代行依頼指示となる**
  - **Given** 医師以外の職員が退院確定を行う
  - **When** 食事終了日時を変更している
  - **Then** 当該食事療法は退院指示医による代行依頼指示として登録される（オーダ中止操作を伴う場合は代行入力認証ダイアログが表示され、認証医を選択する）

- [ ] **AC-10: 指示箋印刷チェックで食事箋・移動箋を出力できる**
  - **Given** 指示箋を印刷するチェックを付けて確定／更新する
  - **When** 操作ボタンをクリックする
  - **Then** 食事箋・移動箋が印刷される

## 状態遷移 / バリデーション

- 確定可否判定:
  - 退院日 ≤ 現在 → 確定可
  - 退院日 > 現在 → 確定不可、更新のみ可
- 食事終了日 ≤ 退院日 を保証
- 食事を伴わない退院日 (例: 朝食前退院、深夜退院など医療機関情報マスタ判定) → 食事終了日 disabled
- 退院日 - 食事終了日 > 0 の場合、自動で「食無し」指示生成（モックではイベント記録）
