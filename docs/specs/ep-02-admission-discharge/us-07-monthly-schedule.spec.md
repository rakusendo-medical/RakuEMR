## ユーザーストーリー

- **As a** 病棟看護師長
- **I want** 月単位で患者の入退院予定をカレンダーで確認したい
- **So that** 翌月の在床推移を予測し、人員配置や病室運用の準備を行える

## 画面要素（要素ツリー）

```
- 入退院情報画面 (/admission)
  - ヘッダー領域
    - 病棟プルダウン: 全病棟 / 第１病棟 / 第２病棟 で絞り込み
    - 種別タブ: 入院予定 / 退院予定 で表示切替
    - カレンダーナビ
      - 前月ボタン (<<)
      - 今月ボタン (現在)
      - 翌月ボタン (>>)
      - 表示中年月ラベル
  - カレンダー本体
    - 曜日ヘッダー: 日〜土
    - 日付マス × 当月日数
      - 日付ラベル: 本日マスはハイライト
      - 予定患者リスト
        - 患者行 × N
          - 患者番号 / 氏名 / 病棟 / ベッド
          - 表示色: 確定済 = 青／黒、未確定 = 赤
          - クリック挙動: 未確定 → 入院/退院手続きダイアログ、確定済 → カルテ画面
  - 日付未定者パネル
    - パネルヘッダー: 「日付未定者」+ 件数
    - 患者行 × N: 種別（入院/退院）・患者番号・氏名・主治医・病棟
    - 患者番号クリック: 入院/退院手続きダイアログを開く
  - 凡例
    - 入院確定（青）／入院指示（赤）／退院確定（黒）／退院指示（赤）
- ※ 既存の他タブ（入院歴・移動歴・新規入退院指示）は別エピック (ep-03/ep-04) のスコープ
```

## 振る舞い

- **病棟プルダウン**: 選択病棟のみカレンダー＋日付未定者を絞り込み（"全病棟" 選択で全表示）
- **種別タブ切替**: 入院予定／退院予定をマスごとに切替表示
- **カレンダーナビ**: <<／現在／>> で前月／今月／翌月へ移動
- **未確定患者氏名クリック (赤文字)**: 入院手続き or 退院手続きダイアログを開く
- **確定済患者氏名クリック (青/黒文字)**: カルテ画面に遷移
- **日付未定者一覧の患者番号クリック**: 種別に応じた手続きダイアログを開く

## 受け入れ基準（AC）

- [ ] **AC-1: 月単位で入退院予定をカレンダー表示できる**
  - **Given** 入退院情報画面を開いている
  - **When** 入院／退院タブを切り替え、対象月を指定する
  - **Then** 当該月のカレンダー上に入院予定／退院予定患者が日付ごとに表示される

- [ ] **AC-2: カレンダーナビで月を移動できる**
  - **Given** 入退院情報画面を開いている
  - **When** カレンダーの「<<」「現在」「>>」をクリックする
  - **Then** それぞれ前月／今月／翌月の表示に切り替わる

- [ ] **AC-3: 確定状態が色分けで判別できる**
  - **Given** カレンダーに入退院予定が表示されている
  - **When** 確定済の患者と未確定の患者が混在している
  - **Then** 確定済は青文字、未確定は赤文字で表示される（凡例で意味を確認できる）

- [ ] **AC-4: 病棟ごとに絞り込める**
  - **Given** 入退院情報画面で対象月を選択している
  - **When** 病棟プルダウンで病棟を指定する
  - **Then** 当該病棟のみの入退院予定に絞り込まれる

- [ ] **AC-5: 日付未定者を別枠で参照できる**
  - **Given** 入退院情報画面を表示している
  - **When** 日付未定者一覧を確認する
  - **Then** 入院日・退院日が未定の患者が一覧表示される（カレンダーには出ない）

- [ ] **AC-6: カレンダーから手続き画面に遷移できる**
  - **Given** カレンダーまたは日付未定者一覧を表示している
  - **When** 患者氏名（または患者番号）をクリックする
  - **Then** 入院手続きまたは退院手続きダイアログが開かれる

- [ ] **AC-7: 確定済患者からカルテに遷移できる**
  - **Given** カレンダーに確定済（青文字）の患者が表示されている
  - **When** 当該患者氏名をクリックする
  - **Then** カルテ画面に遷移する

## 状態遷移 / バリデーション

- 月切替: 前月／翌月の境界を超える患者は表示されない（複数月にまたがる予定は当該月の日付のみ表示）
- 種別タブ初期値: 入院予定
- 病棟プルダウン初期値: 全病棟
- 「現在」ボタン: 表示月を today に戻す

## 補足

- 表示形式（カレンダー／テーブル）はカレンダー優先で確定。一覧形式の補助表示が必要かは別途検討
- 病棟マップ画面からも入退院手続きダイアログへ遷移可能なため、入口選択は運用次第
- 既存実装の `/admission` 画面は ep-03/ep-04 スコープのタブ（入院歴・移動歴・新規入退院指示）も含む。本エピック実装ではこれらを残置し、当該エピックで再整理する
