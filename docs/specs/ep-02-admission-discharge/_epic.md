## 概要

入院予定・退院予定の患者を確定処理し、月単位で入退院スケジュールをカレンダーで把握できるようにする。指示系（医師の入退院指示）と分離し、確定オペレーションに特化したエピック。

## ゴール

- 当日入院・当日退院患者の確定処理を漏れなく実行できる
- 月次の入退院ボリュームを病棟・病床管理者が事前に把握できる
- 確定操作と同時に未実施オーダ（外来／入院専用、移動・給食、リハビリ）の整理ができる

## スコープ

### 含む

- 入院予定患者の確定処理（入院日・食事開始日・病室・記事・指示箋印刷の取り扱い）
- 退院予定患者の確定処理（退院日・転帰・食事終了日・帰住先・指示箋印刷の取り扱い）
- ※**入院時文書・退院時文書は現時点では電子カルテで取り扱わないため本エピックから除外（2026-08-17）**
- 月単位の入退院予定の参照（カレンダー＋日付未定者一覧）
- 確定時オーダ確認ダイアログによる未実施オーダの中止
- 医師以外の職員が確定する際の代行入力認証

### 含まない

- 入退院指示の発行（[ep-03 入退院指示]）
- 病床割り当て（[ep-01 病棟マップ]）
- 入退院歴の保守（[ep-04 入退院歴]）

## 主要画面要素（エピック俯瞰）

```
- 入退院情報画面 (/admission)
  - ヘッダー: 病棟プルダウン / カレンダーナビ / 入院・退院タブ [us-07]
  - カレンダー本体: 月マス内に予定患者を確定/未確定の色分け表示 [us-07]
  - 日付未定者一覧 [us-07]
  - 凡例（入院確定/退院確定/入院指示/退院指示） [us-07]
- 入院手続きダイアログ [us-05]
  - 入院情報フォーム（入院日・食事開始日・病室・紹介医療機関 等。※文書は取り扱わない）
  - 空床照会ボタン → 空床照会ダイアログ
  - 操作: 更新 / 入院確定
- 退院手続きダイアログ [us-06]
  - 退院情報フォーム（退院日・転帰・食事終了日・帰住先 等）
  - 操作: 更新 / 退院確定
- オーダ確認ダイアログ（入院/退院共通） [us-05, us-06]
  - 未実施オーダ一覧（中止チェック）
  - リハビリ転帰区分指定（退院時）
- 代行入力認証ダイアログ [us-05, us-06]
```

## 完了条件

- 全子ストーリーの AC がチェック済み
- 当日入退院の確定が事務担当の通常業務フローに収まる
- 月次予定が翌月までカレンダー形式で確認できる
- 確定後にカルテ記事および医師指示簿へ記録され、患者氏名表示色が確定状態に変化する

## 入口

- 病棟マップで在床患者を選択時の操作メニュー（[us-01] 患者操作メニュー）からも将来的に手続き画面を起動できる
- 入退院情報画面のカレンダーまたは日付未定者一覧から手続きダイアログを起動

> 病棟マップの「入退院情報」ボタン経由の入口は、ボタンが使用しなくなった（ver0.16 廃止）ため削除。

## 依存

- 入退院指示（指示時の入力が初期値となる）
- 患者基本情報、期限管理マスタ、医療機関情報マスタ、病床マスタ
- 食事時間設定（医療機関情報マスタ）
