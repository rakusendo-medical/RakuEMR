## 概要

精神科病棟等で必要となる隔離・拘束について、主治医が **開始／解除／継続／変更** を統一フォーマットの指示として記録し、同時に告知書（隔離拘束指示箋）を発行できるようにする。法令・院内規程に基づく行動制限の起点を担い、後続の **観察記録（ep-07）／一覧（ep-06）／履歴（ep-08）** にデータを波及させる。

## ゴール

- 主治医がカルテ画面から隔離・拘束（および両者併用「隔離拘束」）の **開始／解除／継続／変更** を発行できる
- 拘束部位・開放時間・期限管理対象文書・告知書印刷が同一ダイアログで一貫して扱える
- 指示が患者ヘッダー、フローシート、隔離拘束一覧、隔離拘束歴、患者スケジュール、病床管理マップに即時反映される

## スコープ

### 含む

- 隔離指示（開始／解除）／拘束指示（開始／解除）／隔離拘束指示（開始／解除）
- 継続・変更指示（マスタ「隔離拘束変更=する」設定有効時、隔離・拘束・隔離拘束それぞれ）
- 拘束部位入力（拘束・隔離拘束系の開始／継続／変更指示時のみ、解除指示には記載しない）
- 開放時間入力（最大9件、テンプレート読込・追加・削除可、開始時間以前は不可）
- 期限管理対象の隔離拘束時文書チェック（タイトル「開始」時のみ表示）
- 告知書（隔離拘束指示箋）の印刷と内容編集（再印刷時は内容変更不可）
- 確定後の関連画面反映（患者ヘッダー（隔）（拘）（隔拘）アイコン／フローシート／隔離拘束一覧／隔離拘束歴／患者スケジュール／病床管理マップ）

### 含まない

- 観察記録の入力・参照（[ep-07 観察記録]）
- 一覧台帳の出力（[ep-06 隔離拘束一覧]）
- 履歴ダイアログの参照（[ep-08 隔離拘束歴]）
- 入院形態・拘束部位マスタ等のマスタ保守（マスタ管理エピック未着手のためモックでは固定値）
- 病床管理／病床移動からの開始・解除フロー（オーダリング運用前提のため対象外。電子カルテ運用に限定）
- 「現在開放閉鎖区分」の入力 UI 提供（2017年度以降は不要のため、後方互換情報として spec のみで記載）

## 主要画面要素（エピック俯瞰）

```
- カルテ画面 (/karte-alpha/:patientId)
  - 診療録セクションの隔離拘束指示リンク群（最大12種、マスタ設定で表示変動）
    - [隔離開始] [隔離解除] [拘束開始] [拘束解除] [隔離拘束開始] [隔離拘束解除]
    - [隔離継続] [隔離変更] [拘束継続] [拘束変更] [隔離拘束継続] [隔離拘束変更]
      （マスタ保守／医療機関情報／その他「隔離拘束変更=する」有効時のみ）
- カルテ記事作成ダイアログ（隔離拘束指示） [us-11]
  - タイトルセレクト（区分 × 操作 = 最大12種）
  - 開始日時 / 終了日時（タイトルに応じて表示切替）
  - 拘束部位（拘束・隔離拘束系の開始／継続／変更時のみ、複数選択可、マスタ）
  - 開放時間入力エリア（開始／継続／変更指示時のみ）
    - [開放時間を入力] / [テンプレート読込] / [+追加] / [削除]
    - 最大9件、開始時間以前は不可
  - 文書チェック群（タイトル「開始」時のみ、入院形態 × 区分でマスタ参照）
  - 所見（カルテ本文）
  - 「告知書を印刷する」チェック（マスタで表示・名称・初期値制御）
  - 操作: [作成] / [キャンセル]
- 隔離拘束指示箋印刷ダイアログ [us-11]
  - 指示日 / 開始日時 / 面接フォーム
  - 内容（カルテ所見が初期表示、文例機能あり）
  - [印刷] / [閉じる]（閉じるは印刷せず指示のみ確定）
  - 再印刷モード時は内容欄が表示のみ
```

## 完了条件

- 全子ストーリーの AC がチェック済み
- 開始・解除・継続・変更が **同一ダイアログ** で扱え、タイトル切替で表示項目が連動する
- 拘束部位・開放時間がカルテ記事に反映される（解除記事に拘束部位は記載しない）
- 確定後、以下に即時反映される
  - 患者ヘッダー氏名横の（隔）／（拘）／（隔拘）アイコン（カルテ再表示後）
  - フローシート／隔離拘束タブの状態表示と観察記録入力可
  - 隔離・拘束歴ダイアログ
  - 患者スケジュール
  - 病床管理画面・隔離拘束一覧画面の隔離／拘束アイコン

## 依存

- 患者基本情報、カルテ記事
- 拘束部位マスタ、隔離拘束時文書マスタ（期限管理）、開放時間テンプレートマスタ
- 表示ラベルマスタ、帳票定義情報マスタ、面接書式マスタ
- `Bed.flags`（既存：'isolation' / 'restraint' を活用）／`BedFlagIcons` 凡例
- `IsolationOrder` 型（既存、フィールド拡張が必要）
- `useAppStore.dynamicMedicalRecords`（カルテ記事の動的追加）

## オプション機能 / 前提

- 電子カルテ運用での操作を対象とする（オーダリング運用時の病床管理／移動からの開始・解除は別途検討）
- 「現在開放閉鎖区分」は2015〜2016年度の精神科統計用。2017年度以降は不要のため UI は提供しない（必要なら後方互換項目としてデータには残置可）
- マスタ「隔離拘束変更=する」設定 → 継続／変更指示リンクの表示有無
