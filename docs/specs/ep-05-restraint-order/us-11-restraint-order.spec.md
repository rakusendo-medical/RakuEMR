## ユーザーストーリー

- **As a** 主治医
- **I want** 隔離・拘束の開始・解除・継続・変更を統一した指示画面で発行したい
- **So that** 法令・院内規程に従った行動制限の起点を、漏れなく時系列で記録できる

## 画面要素（要素ツリー）

```
- カルテ画面 (/karte-alpha/:patientId)
  - 診療録セクション ヘッダ右側「指示リンク」エリア（隔離拘束指示）
    - [隔離開始] / [隔離解除]                  : 常時表示
    - [拘束開始] / [拘束解除]                  : 常時表示
    - [隔離拘束開始] / [隔離拘束解除]          : 常時表示
    - [隔離継続] / [隔離変更]                  : マスタ「隔離拘束変更=する」有効時
    - [拘束継続] / [拘束変更]                  : マスタ「隔離拘束変更=する」有効時
    - [隔離拘束継続] / [隔離拘束変更]          : マスタ「隔離拘束変更=する」有効時
    - 解除／継続／変更系は **対応する区分が現在 active な場合のみ非グレー化**
- 隔離拘束指示ダイアログ
  - ヘッダー
    - 患者基本情報サマリ: 患者番号・氏名・性別・年齢
    - 編集チップ: 既存指示を開いた場合のみ「編集」を表示
  - タイトルセレクト: 隔離・拘束・隔離拘束 × 開始・解除・継続・変更（全 12 種を常時選択可。リンクから開いた場合は初期値固定）
    - タイトル変更で下記項目が動的に表示／非表示
  - 移動先セレクト（全タイトル共通・常時表示）
    - 移動先 病棟: 全病棟から選択
    - 移動先 病室: 選択病棟の病室から選択（病棟変更でリセット）
    - 移動先 ベッド: 選択病室の空きベッドのみ（病室未選択時は非活性、空きが無ければ「空きベッドなし」、病室変更でリセット）
  - 開始日時: `datetime-local` 入力（開始／継続／変更時のみ）
  - 配膳先変更日時: `datetime-local` 入力（開始／継続／変更時のみ）
  - 終了日時: `datetime-local` 入力（解除時のみ）
  - 拘束部位: 区分マスタからチップで複数選択（拘束系・隔離拘束系の開始／継続／変更時のみ）
  - 「告知書を印刷する（隔離拘束指示箋）」チェック: 初期 OFF
  - フッターアクション
    - [作成]／[更新] ボタン: 移動先 病室・ベッドが未選択の間は **非活性**。確定 → 告知書チェック ON 時は印刷ダイアログ起動（既存指示を開いた編集モードでは「更新」表示）
    - [キャンセル] ボタン
- 隔離拘束指示箋印刷ダイアログ
  - 指示日: 表示のみ
  - 開始日時: 表示のみ
  - 面接フォームセレクト: マスタ参照（モックでは固定値2〜3件）
  - 内容テキスト: 初期は空欄、編集可（ver0.12 で所見欄が廃止されたため初期表示なし。再印刷モード時は表示のみ）
  - 文例ウィザードボタン: 内容欄にテンプレ挿入（モックでは固定3件）
  - フッター
    - [印刷] ボタン: 印刷フローへ（モックではスナックバー）
    - [閉じる] ボタン: 印刷せず指示のみ確定
- 完了通知（指示確定後）
  - スナックバー: カルテ記事登録通知
  - 患者ヘッダー氏名横に（隔）／（拘）／（隔拘）アイコン表示（カルテ再表示後）
  - フローシート／隔離拘束タブで開始日以降オレンジ背景＋観察記録入力可
```

## 振る舞い

- **指示リンク [○○開始] クリック**: 隔離拘束指示ダイアログをタイトル固定（例: "隔離開始"）で開く。区分・操作に応じて表示項目が初期化
- **指示リンク [○○解除] クリック**: 該当区分の active 指示があるときのみ有効。ダイアログを解除モードで開き、既存指示の開始日時・拘束部位を表示
- **指示リンク [○○継続／変更] クリック**: マスタ有効時のみ表示。既存 active 指示をベースに継続／変更モードで開く（拘束部位の編集可）
- **タイトルセレクト変更**: 開始日時・配膳先変更日時・終了日時・拘束部位の表示有無が連動
- **移動先 病棟変更**: 病室・ベッドの選択をリセット。**移動先 病室変更**: ベッドの選択をリセット
- **拘束部位選択**: マスタからチップで複数選択（手首左右／足首左右／体幹／肩 など）
- **[作成]／[更新] クリック**: 入力検証 → カルテ記事登録（`useAppStore.appendMedicalRecord`／カテゴリ「医師記録」＋タグ「隔離拘束」）→ `IsolationOrder` をストアに追加／更新（解除タイトルは `releaseIsolationOrder`）→ 告知書印刷チェック ON ならば印刷ダイアログ起動 → 完了通知
  - 移動先 病室・ベッドが未選択の間は [作成]／[更新] ボタンが非活性で送信できない
- **告知書印刷ダイアログ [印刷]**: 内容を保存して印刷フロー（モックではスナックバー）。指示は確定済み
- **告知書印刷ダイアログ [閉じる]**: 印刷せず指示確定。次回過去記事から再開も可能
- **過去指示記事から再印刷**: 印刷ダイアログを **再印刷モード** で開く。内容欄は表示のみ（編集不可）

## 受け入れ基準（AC）

- [ ] **AC-1: カルテ画面の指示リンクからダイアログを開ける**
  - **Given** 患者カルテの診療録を表示している
  - **When** 隔離拘束関連の指示リンク（[隔離開始]／[隔離解除]／[拘束開始]／[拘束解除]／[隔離拘束開始]／[隔離拘束解除]、およびマスタ設定有効時は[隔離継続]／[隔離変更]／[拘束継続]／[拘束変更]／[隔離拘束継続]／[隔離拘束変更]）をクリックする
  - **Then** 隔離拘束指示ダイアログが指示種別に応じた初期状態で開かれる

- [ ] **AC-2: 開始指示を発行できる**
  - **Given** 隔離拘束指示ダイアログを「開始」タイトルで開いている
  - **When** 移動先（病棟・病室・ベッド）、開始日時、配膳先変更日時、（拘束系の場合）拘束部位を入力し [作成] をクリックする
  - **Then** 開始記事がカルテ（カテゴリ「医師記録」＋タグ「隔離拘束」）に記載され、患者は行動制限下となる。患者ヘッダー氏名に（隔）／（拘）／（隔拘）が付与される（カルテ再表示後）

- [ ] **AC-3: 解除指示を発行できる**
  - **Given** 行動制限下の患者を選択し、解除指示でダイアログを開いている
  - **When** 終了日時を入力し [作成] をクリックする
  - **Then** 解除記事が記載され、当該行動制限が解除状態となる（解除記事には拘束部位は記載されない）。患者ヘッダーの該当アイコンが非表示となる

- [ ] **AC-4: 継続・変更指示を発行できる（マスタ有効時）**
  - **Given** マスタ「隔離拘束変更=する」が設定されており、行動制限下の患者を選択している
  - **When** 継続または変更（種別・部位等）の指示でダイアログを開き、必要項目を入力し [更新] をクリックする
  - **Then** 継続／変更記事がカルテに記録され、変更内容（拘束部位等）が現行指示に反映される

- [ ] **AC-5: 拘束部位を選択できる**
  - **Given** 拘束または隔離拘束の開始／継続／変更指示でダイアログを開いている
  - **When** 拘束部位欄から区分マスタの値を選択する
  - **Then** 拘束部位が指示に紐づき、開始指示のカルテ記事に記載される（複数選択可、解除記事には記載されない）

- [ ] **AC-6: 移動先を選択しないと指示を確定できない**
  - **Given** 隔離拘束指示ダイアログを開いている
  - **When** 移動先 病室・ベッドのいずれかが未選択である
  - **Then** [作成]／[更新] ボタンは非活性で、指示を確定できない。移動先 病棟→病室→ベッドの順に選択すると活性化する

- [ ] **AC-7: 告知書を印刷できる**
  - **Given** ダイアログで「告知書を印刷する（隔離拘束指示箋）」にチェックを入れて [作成] をクリックした
  - **When** 隔離拘束指示箋印刷ダイアログが開く
  - **Then** 指示日、開始日時が初期表示される。内容を編集して [印刷] すると告知書（隔離拘束指示箋）が出力される。[閉じる] では印刷せず指示のみ確定する

- [ ] **AC-8: 告知書再印刷時は内容を変更できない**
  - **Given** 過去の指示記事から告知書を再印刷する
  - **When** 隔離拘束指示箋印刷ダイアログを開く
  - **Then** 内容欄は表示のみで編集できない

- [ ] **AC-9: 指示が関連画面に即時反映される**
  - **Given** 隔離拘束指示を確定した
  - **When** 関連画面を開く
  - **Then** 以下に反映される
    - フローシート／隔離拘束タブで開始日以降オレンジ背景＋観察記録入力可能となる
    - 隔離・拘束歴ダイアログに履歴が追加される
    - 患者スケジュールに指示内容が記載される
    - 病床管理画面・隔離拘束一覧画面に拘束／隔離アイコンが表示される

## 状態遷移 / バリデーション

### タイトルと表示項目の対応

| タイトル | 開始日時 | 配膳先変更日時 | 終了日時 | 拘束部位 |
| --- | --- | --- | --- | --- |
| 隔離開始 | ✅ | ✅ | - | - |
| 隔離解除 | - | - | ✅ | - |
| 隔離継続/変更 | ✅ | ✅ | - | - |
| 拘束開始 | ✅ | ✅ | - | ✅ |
| 拘束解除 | - | - | ✅ | - |
| 拘束継続/変更 | ✅ | ✅ | - | ✅ |
| 隔離拘束開始 | ✅ | ✅ | - | ✅ |
| 隔離拘束解除 | - | - | ✅ | - |
| 隔離拘束継続/変更 | ✅ | ✅ | - | ✅ |

- 移動先（病棟・病室・ベッド）はタイトルに依らず常時表示・選択必須（[作成]／[更新] の活性条件）。

### バリデーション

- 開始／継続／変更指示: 開始日時 必須
- 解除指示: 終了日時 必須
- 拘束部位: 拘束系・隔離拘束系の開始／継続／変更指示で 1件以上選択必須（解除では非表示）
- 移動先 病室・ベッド: 未選択の間は [作成]／[更新] を非活性とし、送信できない
- 開始指示: 終了日時は持たない
- ※ 終了日時 ≥ 開始日時 の前後関係チェックはモック未実装

### モード遷移

- 新規（指示リンクから）→ [作成] → 確定 → 告知書チェック ON ならば印刷ダイアログ
- 既存指示から開く（編集）→ [更新] で内容更新（解除タイトルの場合は `releaseIsolationOrder`）
- 過去指示記事から印刷 → 印刷ダイアログ（再印刷モード、内容編集不可）

## 補足

- ver0.12（梶井改修）で本ダイアログから **開放時間入力エリア・文書チェック群・所見テキストを削除**し、**移動先 病棟・病室・ベッドのセレクトと配膳先変更日時を追加**、開始/終了日時を `datetime-local` に統一した。開放時間・期限管理文書まわりの仕様（旧 AC-6〜9 相当）は本 spec から除外
- 移動先 病棟・病室・ベッド／配膳先変更日時は現状 UI 入力のみで、`IsolationOrder`・カルテ記事には保存していない（モック範囲）。[作成]／[更新] の活性判定にのみ使用
- 拘束部位マスタはマスタ管理（実装は別ストーリー）。モックでは `MASTER_*` 定数で固定値を提供
- 「現在開放閉鎖区分」は2015〜2016年度の精神科統計用。2017年度以降は不要のため UI からは削除（spec として後方互換情報のみ記載）
- オーダリング運用では病床管理／移動からの開始・解除フローも存在するが本ストーリーは電子カルテ運用を対象
- 既存 `Bed.flags` の `'isolation'` / `'restraint'` フラグは表示用として活用。「隔離拘束」（両者併用）は両フラグが同時に立つ状態として表現
- `IsolationOrder` 型は `subtype` / `operation` / `restraintParts` 等を後方互換（オプショナル追加）で拡張済み。開放時間・期限管理文書（旧 `releaseTimes` / `linkedDocumentChecks`）は ver0.12 で UI から外れたため本ストーリーでは扱わない
- カルテ記事カテゴリは「医師記録」＋タグ「隔離拘束」で登録する（`appendMedicalRecord`）
