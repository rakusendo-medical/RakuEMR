## ユーザーストーリー

- **As a** 主治医
- **I want** 隔離・拘束の開始・解除・継続・変更を統一した指示画面で発行したい
- **So that** 法令・院内規程に従った行動制限の起点を、漏れなく時系列で記録できる

## 画面要素（要素ツリー）

```
- カルテ画面 (/karte-alpha/:patientId)
  - 診療録セクション ヘッダ右側「指示リンク」エリア（隔離拘束指示）
    - [隔離開始] / [隔離解除]                  : 常時表示
    - [拘束開始] / [拘束解除]                  : 常時表示
    - [隔離拘束開始] / [隔離拘束解除]          : 常時表示
    - [隔離継続] / [隔離変更]                  : マスタ「隔離拘束変更=する」有効時
    - [拘束継続] / [拘束変更]                  : マスタ「隔離拘束変更=する」有効時
    - [隔離拘束継続] / [隔離拘束変更]          : マスタ「隔離拘束変更=する」有効時
    - 解除／継続／変更系は **対応する区分が現在 active な場合のみ非グレー化**
- 隔離拘束指示ダイアログ
  - ヘッダー
    - 患者基本情報サマリ: 患者番号・氏名・年齢・性別
    - モード表示: 新規（指示種別に応じた初期）／変更／中止
  - タイトルセレクト: 隔離・拘束・隔離拘束 × 開始・継続・変更・解除（リンクから開いた場合は初期値固定）
    - タイトル変更で下記項目が動的に表示／非表示
  - 開始日時: 日時入力（開始／継続／変更時のみ）
  - 終了日時: 日時入力（解除時のみ）
  - 拘束部位: 区分マスタから複数選択（拘束系・隔離拘束系の開始／継続／変更時のみ）
  - 開放時間入力エリア: 開始／継続／変更時のみ
    - [開放時間を入力] ボタン: 初回クリックでテンプレート初期値読込
    - [テンプレート読込] ボタン: 確認後、既存入力をクリアして上書き
    - 入力行 × 最大9件: 開放開始時間／開放終了時間／削除ボタン（ゴミ箱）
    - [+追加] ボタン: 9件未満なら有効
  - 文書チェック群: タイトル「開始」時のみ表示
    - 入院形態 × 区分（隔離／拘束／隔離拘束）でマスタが定義する文書群を縦リスト
    - 各行: チェック ON/OFF（ON のものは期限管理対象として登録）
  - 所見テキスト: カルテ本文として記録
  - 「告知書を印刷する」チェック: マスタで表示／名称／初期値制御（モックではトグル可能・初期 OFF）
  - フッターアクション
    - [作成] ボタン: 指示確定 → 告知書チェック ON 時は印刷ダイアログ起動
    - [変更] ボタン (既存指示閲覧時のみ): 内容を更新
    - [中止] ボタン (既存指示閲覧時のみ): 既存指示を取消（解除指示とは別概念。モックではモード切替のみ）
    - [キャンセル] ボタン
- 隔離拘束指示箋印刷ダイアログ
  - 指示日: 表示のみ
  - 開始日時: 表示のみ
  - 面接フォームセレクト: マスタ参照（モックでは固定値2〜3件）
  - 内容テキスト: カルテ所見が初期表示、編集可（再印刷モード時は表示のみ）
  - 文例ウィザードボタン: 内容欄にテンプレ挿入（モックでは固定3件）
  - フッター
    - [印刷] ボタン: 印刷フローへ（モックではスナックバー）
    - [閉じる] ボタン: 印刷せず指示のみ確定
- 完了通知（指示確定後）
  - スナックバー: カルテ記事登録通知
  - 患者ヘッダー氏名横に（隔）／（拘）／（隔拘）アイコン表示（カルテ再表示後）
  - フローシート／隔離拘束タブで開始日以降オレンジ背景＋観察記録入力可
  - 隔離・拘束歴ダイアログ／患者スケジュール／病床管理マップ・隔離拘束一覧へ即時反映
```

## 振る舞い

- **指示リンク [○○開始] クリック**: 隔離拘束指示ダイアログをタイトル固定（例: "隔離開始"）で開く。区分・操作に応じて表示項目が初期化
- **指示リンク [○○解除] クリック**: 該当区分の active 指示があるときのみ有効。ダイアログを解除モードで開き、既存指示の開始日時・拘束部位を表示
- **指示リンク [○○継続／変更] クリック**: マスタ有効時のみ表示。既存 active 指示をベースに継続／変更モードで開く（拘束部位・開放時間の編集可）
- **タイトルセレクト変更**: 拘束部位・開放時間・文書チェックの表示有無が連動
- **拘束部位選択**: マスタから複数選択（手首左右／足首左右／体幹／肩 など）
- **[開放時間を入力] クリック**: 開放時間入力エリアを展開。テンプレートが設定されていれば初期 N 行を自動投入
- **[テンプレート読込] クリック**: 入力中があれば確認 → クリア → テンプレ行を投入
- **開放時間 [+追加]**: 9件未満で行追加。9件到達でボタン disabled
- **開放時間 ゴミ箱**: 該当行削除
- **開放時間バリデーション**: 各行の開始時間が指示開始時間以前なら入力不可（赤字＋エラーメッセージ）
- **文書チェック表示条件**: タイトル「開始」かつ患者入院形態が確定している場合のみ表示。区分 × 入院形態でマスタ参照
- **[作成] クリック**: 入力検証 → カルテ記事登録（`useAppStore.dynamicMedicalRecords` に追加）→ `IsolationOrder` をストアに追加／更新 → 告知書印刷チェック ON ならば印刷ダイアログ起動 → 完了通知
- **告知書印刷ダイアログ [印刷]**: 内容を保存して印刷フロー（モックではスナックバー）。指示は確定済み
- **告知書印刷ダイアログ [閉じる]**: 印刷せず指示確定。次回過去記事から再開も可能
- **過去指示記事から再印刷**: 印刷ダイアログを **再印刷モード** で開く。内容欄は表示のみ（編集不可）

## 受け入れ基準（AC）

- [ ] **AC-1: カルテ画面の指示リンクからダイアログを開ける**
  - **Given** 患者カルテの診療録を表示している
  - **When** 隔離拘束関連の指示リンク（[隔離開始]／[隔離解除]／[拘束開始]／[拘束解除]／[隔離拘束開始]／[隔離拘束解除]、およびマスタ設定有効時は[隔離継続]／[隔離変更]／[拘束継続]／[拘束変更]／[隔離拘束継続]／[隔離拘束変更]）をクリックする
  - **Then** 隔離拘束指示ダイアログが指示種別に応じた初期状態で開かれる

- [ ] **AC-2: 開始指示を発行できる**
  - **Given** 隔離拘束指示ダイアログを「開始」タイトルで開いている
  - **When** 開始日時、（拘束系の場合）拘束部位、必要に応じて開放時間、文書チェック、所見を入力し [作成] をクリックする
  - **Then** 開始記事がカルテに記載され、患者は行動制限下となる。患者ヘッダー氏名に（隔）／（拘）／（隔拘）が付与される（カルテ再表示後）

- [ ] **AC-3: 解除指示を発行できる**
  - **Given** 行動制限下の患者を選択し、解除指示でダイアログを開いている
  - **When** 終了日時と所見を入力し [作成] をクリックする
  - **Then** 解除記事が記載され、当該行動制限が解除状態となる（解除記事には拘束部位は記載されない）。患者ヘッダーの該当アイコンが非表示となる

- [ ] **AC-4: 継続・変更指示を発行できる（マスタ有効時）**
  - **Given** マスタ「隔離拘束変更=する」が設定されており、行動制限下の患者を選択している
  - **When** 継続または変更（種別・部位・開放時間等）の指示でダイアログを開き、必要項目を入力し [作成] をクリックする
  - **Then** 継続／変更記事がカルテに記録され、変更内容（拘束部位や開放時間等）が現行指示に反映される

- [ ] **AC-5: 拘束部位を選択できる**
  - **Given** 拘束または隔離拘束の開始／継続／変更指示でダイアログを開いている
  - **When** 拘束部位欄から区分マスタの値を選択する
  - **Then** 拘束部位が指示に紐づき、開始指示のカルテ記事に記載される（複数選択可、解除記事には記載されない）

- [ ] **AC-6: 開放時間を入力できる**
  - **Given** 開始／継続／変更指示でダイアログを開いている
  - **When** [開放時間を入力] をクリックして開放開始・終了時間を入力する（[追加] で行追加、ゴミ箱で削除、最大9件）
  - **Then** 開放時間がカルテ記事に記載され、フローシート／隔離拘束タブにアイコン表示される

- [ ] **AC-7: 開放時間テンプレートを利用できる**
  - **Given** 開放時間テンプレートがマスタに設定されている
  - **When** [開放時間を入力] をクリックする、または [テンプレート読込] をクリックする
  - **Then** テンプレートで定義された開放時間が初期表示される（[テンプレート読込] 時は確認後に既存入力をクリアして上書き）

- [ ] **AC-8: 開放時間の制約が守られる**
  - **Given** 開放時間を入力している
  - **When** 隔離拘束開始時間以前の時間帯を指定しようとする
  - **Then** 設定できない（バリデーションでブロック・赤字エラー表示）

- [ ] **AC-9: 期限管理対象の文書をチェックできる**
  - **Given** タイトルで「開始」を選択し、ダイアログを開いている
  - **When** 文書チェック欄を表示する
  - **Then** 隔離拘束区分（隔離／拘束／隔離拘束）と入院形態に応じて、期限管理マスタが定義する隔離拘束時文書がチェック一覧として表示される。チェックした文書は期限管理対象として登録される

- [ ] **AC-10: 告知書を印刷できる**
  - **Given** ダイアログで「告知書を印刷する」にチェックを入れて [作成] をクリックした
  - **When** 隔離拘束指示箋印刷ダイアログが開く
  - **Then** 指示日、開始日時、所見が初期表示される。内容を編集して [印刷] すると告知書（隔離拘束指示箋）が出力される。[閉じる] では印刷せず指示のみ確定する

- [ ] **AC-11: 告知書再印刷時は内容を変更できない**
  - **Given** 過去の指示記事から告知書を再印刷する
  - **When** 隔離拘束指示箋印刷ダイアログを開く
  - **Then** 内容欄は表示のみで編集できない

- [ ] **AC-12: 指示が関連画面に即時反映される**
  - **Given** 隔離拘束指示を確定した
  - **When** 関連画面を開く
  - **Then** 以下に反映される
    - フローシート／隔離拘束タブで開始日以降オレンジ背景＋観察記録入力可能となる
    - 隔離・拘束歴ダイアログに履歴が追加される
    - 患者スケジュールに指示内容が記載される
    - 病床管理画面・隔離拘束一覧画面に拘束／隔離アイコンが表示される

## 状態遷移 / バリデーション

### タイトルと表示項目の対応

| タイトル | 開始日時 | 終了日時 | 拘束部位 | 開放時間 | 文書チェック |
| --- | --- | --- | --- | --- | --- |
| 隔離開始 | ✅ | - | - | ✅ | ✅ |
| 隔離解除 | - | ✅ | - | - | - |
| 隔離継続/変更 | ✅ | - | - | ✅ | - |
| 拘束開始 | ✅ | - | ✅ | ✅ | ✅ |
| 拘束解除 | - | ✅ | - | - | - |
| 拘束継続/変更 | ✅ | - | ✅ | ✅ | - |
| 隔離拘束開始 | ✅ | - | ✅ | ✅ | ✅ |
| 隔離拘束解除 | - | ✅ | - | - | - |
| 隔離拘束継続/変更 | ✅ | - | ✅ | ✅ | - |

### バリデーション

- 解除指示: 終了日時 ≥ 既存開始日時 を保証
- 開始指示: 終了日時は持たない
- 開放時間: 各行 開放開始時間 ≥ 指示開始時間（指示開始時間以前は不可）
- 開放時間: 各行 開放開始時間 < 開放終了時間
- 開放時間: 最大9件まで
- 拘束部位: 拘束系・隔離拘束系の開始／継続／変更指示で 1件以上選択必須（解除では非表示）
- 文書チェック: 入院形態が未確定の場合は表示しない（注意メッセージのみ）

### モード遷移

- 新規（指示リンクから）→ [作成] → 確定 → 告知書チェック ON ならば印刷ダイアログ
- 既存指示から開く（変更／中止）→ [変更] で更新／[中止] で削除（モックでは status のみ変更）
- 過去指示記事から印刷 → 印刷ダイアログ（再印刷モード、内容編集不可）

## 補足

- 拘束部位マスタ・隔離拘束時文書マスタ・開放時間テンプレートはマスタ管理（実装は別ストーリー）。モックでは `MASTER_*` 定数で固定値を提供
- 「現在開放閉鎖区分」は2015〜2016年度の精神科統計用。2017年度以降は不要のため UI からは削除（spec として後方互換情報のみ記載）
- オーダリング運用では病床管理／移動からの開始・解除フローも存在するが本ストーリーは電子カルテ運用を対象
- 既存 `Bed.flags` の `'isolation'` / `'restraint'` フラグは表示用として活用。「隔離拘束」（両者併用）は両フラグが同時に立つ状態として表現
- 既存 `IsolationOrder` 型はフィールド拡張が必要（`subtype` / `operation` / `restraintParts` / `releaseTimes` / `linkedDocumentChecks` 等）。MASTER と擦り合わせの上、後方互換となる形（オプショナル追加）で拡張する
- カルテ記事カテゴリは新規に「隔離拘束指示」を追加するか、既存「医師記録」に分類タグで吸収するかは実装時に検討（モックでは「医師記録」+ タグ「隔離拘束」を採用予定）
