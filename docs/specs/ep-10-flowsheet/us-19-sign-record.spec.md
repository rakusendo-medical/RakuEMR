## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 深夜・日勤・準夜の 3 勤務帯ごとにフローシート記録のサインを登録・変更・削除したい
- **So that** 勤務帯ごとの記録責任者を明示し、紙運用を電子化できる

## 画面要素（要素ツリー）

```
- サイン入力ダイアログ
  - 対象日付・対象勤務帯（深夜／日勤／準夜）の表示
  - サイン入力者プルダウン
    - 初期値: ログオン者
    - 候補: マスタ「実施者ロック」設定で
      - 「ログオン者のみ」→ 自分のみ
      - 「ログオン者以外も」→ 所属区分の職員並び順で他職員を含む
  - フッター: [登録] [更新] [削除] [キャンセル]
  - 削除確認サブダイアログ
- フローシート画面のサイン欄
  - 列: 深夜 / 日勤 / 準夜
  - クリックでサイン入力ダイアログ起動
  - 未来勤務帯の制御: **常に不可（固定・マスタ設定によらない）**でクリック不可（グレー表示）
```

## 振る舞い

- **ダイアログ起動**: サイン欄の勤務帯セルクリック → ログオン者を初期選択した状態で開く。
- **登録**: 入力者選択 → [登録] → サイン欄に表示。
- **更新**: 既存サインのセルクリック → 入力者を変更 → [更新] → 反映。
- **削除**: [削除] → 確認サブダイアログ「サインを削除します。よろしいですか？」→ OK で削除。
- **未来日不可**: **常に**（固定・マスタ設定によらない）、翌日以降の勤務帯セルはクリック不可。
- **候補制御**: マスタ「実施者ロック」設定で他職員選択可否を切替。
- **上書き禁止**: 別職員のサインがある勤務帯に新規サインしようとしても自動上書きせず、明示的な [更新] が必要。

## 受け入れ基準（AC）

- [ ] **AC-1: ダイアログ起動とログオン者初期選択**
  - **Given** ログオン中職員が「山田 看護師」
  - **When** サイン欄の「日勤」セルをクリックする
  - **Then** ダイアログが開き、入力者プルダウンの初期値が「山田 看護師」
- [ ] **AC-2: 登録**
  - **Given** ダイアログを開いている（未登録勤務帯）
  - **When** [登録] をクリックする
  - **Then** 当該勤務帯のサイン欄に職員名が表示される
- [ ] **AC-3: 更新**
  - **Given** 「日勤」に既存サインあり
  - **When** ダイアログを開き別職員を選択 → [更新]
  - **Then** サインが新職員に変更される
- [ ] **AC-4: 削除確認**
  - **Given** 既存サインあり
  - **When** [削除] をクリックする
  - **Then** 確認サブダイアログが出る。OK でサイン削除、キャンセルで何も起きない
- [ ] **AC-5: 未来日不可（常に固定）**
  - **Given** 操作日 `2026-05-02`（マスタ設定によらない）
  - **When** `2026-05-03` の勤務帯をクリックしようとする
  - **Then** クリック不可（グレー表示）
- [ ] **AC-6: 実施者ロック切替**
  - **Given** マスタ「実施者ロック」=「ログオン者のみ」
  - **When** ダイアログを開きプルダウンを確認する
  - **Then** ログオン者のみ表示。「ログオン者以外も」設定では所属区分の他職員も並ぶ
- [ ] **AC-7: 上書き禁止**
  - **Given** 既存サインのある勤務帯セルをクリックして別職員を選んだ
  - **When** [登録] ボタンを探す
  - **Then** 既存サイン状態では [更新] のみ表示。別職員へは [更新] 操作で明示的に切り替え
- [ ] **AC-8: スクロール位置保持**
  - **Given** フローシート画面でスクロール後にサインを入力した
  - **When** ダイアログを閉じる
  - **Then** スクロール位置が変わらない

## 状態遷移 / バリデーション

- サイン状態: `unsigned` → `signed (by X)` → `signed (by Y)` → `unsigned`
- 削除は確認必須
