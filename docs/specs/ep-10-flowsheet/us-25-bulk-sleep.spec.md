## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 睡眠表で病棟・病室単位の患者リストに対して睡眠活動を一括入力したい
- **So that** 夜間ラウンドの観察結果を、複数患者まとめて短時間で記録できる

## 画面要素（要素ツリー）

```
- 睡眠表画面 (/nursing/sleep-table)
  - 検索条件バー
    - 病棟プルダウン（ログオン職員所属に応じた初期値）
    - 病室プルダウン
    - 日付ピッカー
    - [表示] ボタン
  - 睡眠表グリッド
    - 行: 各患者
    - 列: 12 時間軸（マスタ「バイタルチェック時間（寝）」基準）
      - タイトル列クリック → 同時間枠の一括入力（複数患者）
    - 各セル: 睡眠状態（マスタで選択肢管理）
      - クリック: 選択枠が薄赤色 → 睡眠・活動記録ダイアログ起動
      - ドラッグ: 開始〜終了時間枠を選択 → ダイアログに範囲反映
      - ホバー: 選択枠の情報ツールチップ
- 睡眠・活動記録ダイアログ
  - 個別モード（特定患者の特定時間枠）
    - 患者・開始時間・終了時間
    - 睡眠・活動状態選択
    - フローシート [us-17] の「睡眠・活動」タブ入力と同等
  - 一括モード（タイトル列クリック起動）
    - 患者リストに表示中の全患者を一覧
    - 各患者の状態選択
    - 選択チェック ON で [登録] → チェック患者一括登録
```

## 振る舞い

- **画面表示**: 検索条件指定 → 該当範囲の患者リストが時間軸（12 時間）で表示。
- **病棟初期表示**: ログオン職員の所属区分が病棟名 → 対象病棟、そうでなければプルダウン先頭。
- **個別入力**: 任意患者の任意時間枠クリック → セルが薄赤色 → 睡眠・活動記録ダイアログ。
- **連続時間ドラッグ**: 開始〜終了時間枠をドラッグ → ダイアログに範囲反映 → 同一状態で一括登録。
- **同一時間枠一括入力**: タイトル列クリック → 患者リスト表示中の全患者一覧でダイアログ → 各患者状態を設定 → 選択チェック付き患者を一括登録。
- **整合性**: 睡眠活動はフローシート [us-17] の「睡眠・活動」タブと同モデル。一括分も個別分もフローシート上で確認できる。
- **タブ間条件保持なし**: 一括入力メニュー内で別タブに移動して戻ると、病棟・病室・日付の表示条件は保持されない（再指定が必要）。
- **時間枠ホバー**: 選択枠の情報がツールチップで表示。

## 受け入れ基準（AC）

- [ ] **AC-1: 画面表示**
  - **Given** 病棟「北 3 階」、病室「301」、日付「2026-05-02」を指定
  - **When** 睡眠表画面に遷移する
  - **Then** 該当患者リストがマスタ「バイタルチェック時間（寝）」基準の 12 時間軸で表示される
- [ ] **AC-2: ログオン所属での病棟初期表示**
  - **Given** ログオン職員の所属区分が「北 3 階」
  - **When** 睡眠表画面を開く
  - **Then** 病棟プルダウンの初期値が「北 3 階」
- [ ] **AC-3: 個別入力**
  - **Given** 睡眠表に患者表示中
  - **When** 任意患者の任意時間枠をクリック
  - **Then** セル薄赤色 → 睡眠・活動記録ダイアログが個別モードで開く
- [ ] **AC-4: 連続時間ドラッグ**
  - **Given** 同状態で連続時間を登録したい
  - **When** 開始〜終了時間枠をドラッグ
  - **Then** ダイアログに開始・終了時間が初期表示され、同一状態で一括登録できる
- [ ] **AC-5: 同一時間枠一括入力**
  - **Given** 睡眠表に複数患者表示中
  - **When** タイトル列の任意時間枠をクリック
  - **Then** ダイアログが一括モードで開き、表示中の全患者一覧が表示される
- [ ] **AC-6: 一括登録**
  - **Given** ダイアログ一括モードで複数患者の状態を設定
  - **When** 選択チェック付きの患者で [登録]
  - **Then** チェック付き患者の状態が一括登録される
- [ ] **AC-7: フローシート連携**
  - **Given** 一括入力で睡眠活動を保存
  - **When** 同患者のフローシート [us-17] →「睡眠・活動」タブを開く
  - **Then** 該当時間帯に睡眠活動が反映されている
- [ ] **AC-8: タブ間条件非保持**
  - **Given** 一括入力メニュー内で別タブに移動
  - **When** 再度睡眠表タブに戻る
  - **Then** 病棟・病室・日付の表示条件が保持されていない（再指定が必要）
- [ ] **AC-9: 時間枠ホバー**
  - **Given** 時間枠を選択しようとしている
  - **When** カーソルをあてる
  - **Then** 選択枠の情報がツールチップ表示される

## 状態遷移 / バリデーション

- セル状態: `empty` → `selected (薄赤)` → ダイアログ確定で `recorded (状態色)` → `empty`
- ドラッグ範囲: 開始 ≤ 終了
- 同患者の同時間枠重複: 上書き（最新で更新）

## 補足

- 睡眠状態の選択肢（入眠／覚醒／離床等）はマスタ管理。仕様は実装時に確定
- 12 時間表示が原則。日中の睡眠記録など 24 時間運用が必要な場合は別途検討
