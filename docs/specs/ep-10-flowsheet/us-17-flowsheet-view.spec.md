## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートで 7 日分のバイタル・ケア内容・行動制限有無・オーダ予定・検査結果を 1 画面で参照したい
- **So that** 患者の状態と本日やるべきことを時間軸に沿って把握できる

## 画面要素（要素ツリー）

```
- フローシート画面
  - ヘッダー
    - 患者ヘッダー（氏名・年齢・性別・主病名・在院日数）
    - 入力切替タブ: フローシート／隔離拘束／睡眠・活動／観察（観察は医療観察法対象者のみ）
    - 表示日コントロール
      - 日付ピッカー＋[表示] ボタン
      - クイックリンク: 当日／＜／＞／＜＜（7 日前）／＞＞（7 日後）
    - パターンボックス: 適用パターン名／全パターン表示切替（[us-21] と連動）
    - フローシートアイコン／バイタルアイコン（編集ダイアログ起動 [us-18, us-20]）
  - 移動状況表示部（入院患者のみ）
    - 病室／隔離／拘束／行動制限（その他）／外出・外泊
    - 期間オレンジ背景表示、ホバーでツールチップ（開始日時〜終了日時）
  - 体温表
    - 7 日 × 時間軸の格子状グラフ（BP・R・P・T・S）
    - 実施点ホバー：測定値ツールチップ
    - 体温表クリック：当日のバイタル測定値拡大図表示
  - 予定オーダ欄
    - オーダ種名 1 文字表示（薬／注／検／処／画／心／E）
    - 未実施: 赤字／実施済: グレー／実施済オーダがある場合: 背景オレンジ
    - 「一覧」リンク → 指示状況ダイアログ（操作日 1 ヶ月分のオーダ状況、参照のみ）
    - 予定オーダクリック → 実施確認表ダイアログ（未実施オーダ実施可）
  - 検査結果欄
    - 登録済み伝票名表示（結果ステータス「待ち」は非表示）
    - 伝票名クリック → 検査結果グラフ表示ダイアログ
    - [設定] → グラフ表示項目設定ダイアログ
  - 看護記録欄
    - 看護記録タイトル表示（クリックで看護記録ダイアログ [us-22]）
    - [新規作成] リンク（[us-23] へ）
  - サイン欄
    - 深夜・日勤・準夜の 3 列、勤務帯ごとの記録者名表示
    - 勤務帯クリック → サイン入力ダイアログ [us-19]
  - 未来日入力枠（条件: `validate.future` 設定時）
    - フローシートアイコン／バイタルアイコンがグレー表示・クリック不可
```

## 振る舞い

- **画面初期表示**: ルート遷移時、入院患者は操作日含む前 1 週間、外来患者は操作日と記録記載のある日付の合計 7 日（不足時は入院期間も含む）。
- **表示日変更**: 日付ピッカーで日付を選び [表示] → 7 日表示の最終日が選択日となる。
- **クイックナビ**: 当日／＜／＞／＜＜／＞＞ で 0／-1／+1／-7／+7 日にシフト。
- **入力切替タブ**: フローシート／隔離拘束（[ep-07] 連携）／睡眠・活動／観察（医療観察法対象者のみ）。
- **移動状況ホバー**: 期間バーのホバーで開始日時〜終了日時のツールチップ。
- **体温表クリック**: バイタル拡大図ダイアログ。
- **予定オーダ「一覧」**: 操作日 1 ヶ月分の指示状況ダイアログ（参照のみ）。
- **予定オーダ単体クリック**: 実施確認表ダイアログ → 未実施オーダクリックで実施操作 → 実施済表示に切替。
- **検査結果伝票名クリック**: 検査結果グラフ表示ダイアログ。
- **検査結果 [設定]**: グラフ表示項目を選択するダイアログ。
- **看護記録タイトルクリック**: 看護記録ダイアログ（参照、[us-22]）。
- **未来日入力制御**: マスタ `validate.future` で未来枠が非活性。

## 受け入れ基準（AC）

- [ ] **AC-1: 7 日表示の起点**
  - **Given** 操作日が `2026-05-02`、患者が入院中
  - **When** フローシート画面を表示する
  - **Then** `2026-04-26`〜`2026-05-02` の 7 日が日付軸に並ぶ
- [ ] **AC-2: クイックナビ**
  - **Given** フローシートを表示している
  - **When** ＜＜（7 日前）リンクをクリックする
  - **Then** 表示が 7 日前を最終日とする 7 日表示に切り替わる
- [ ] **AC-3: 入力切替タブ**
  - **Given** 医療観察法対象患者のフローシートを表示している
  - **When** タブ群を確認する
  - **Then** フローシート／隔離拘束／睡眠・活動／観察の 4 タブが並ぶ。非対象患者では「観察」タブが非表示
- [ ] **AC-4: 移動状況**
  - **Given** 入院患者で同期間に病室移動・外出が発生している
  - **When** 移動状況表示部を確認する
  - **Then** 病室／外出 の期間がオレンジバーで表示。バーホバーで開始〜終了のツールチップが出る
- [ ] **AC-5: 予定オーダ表示**
  - **Given** 対象日に薬剤オーダ（一部実施済、一部未実施）がある
  - **When** 予定オーダ欄を確認する
  - **Then** オーダ種名「薬」が 1 文字表示。未実施部分は赤字、実施済はグレー、実施済オーダがある日のセル背景はオレンジ
- [ ] **AC-6: 指示状況ダイアログ**
  - **Given** フローシートを表示している
  - **When** 予定オーダ欄タイトルの「一覧」をクリックする
  - **Then** 操作日 1 ヶ月分のオーダ状況ダイアログが開かれ、参照のみ可（新規指示・DO 不可）
- [ ] **AC-7: 実施確認表で未実施オーダを実施**
  - **Given** フローシートに未実施オーダがある
  - **When** 予定オーダ欄をクリック → 実施確認表ダイアログ → 未実施オーダクリックで実施操作
  - **Then** オーダが実施済となり、フローシート上で「グレー＋背景オレンジ」表示に切り替わる
- [ ] **AC-8: 検査結果グラフ**
  - **Given** 検査結果欄に登録済み伝票名がある
  - **When** 伝票名をクリックする
  - **Then** 検査結果グラフ表示ダイアログが開かれる。結果ステータス「待ち」の伝票名はそもそも欄に出ない
- [ ] **AC-9: 未来日非活性**
  - **Given** マスタ `validate.future` が ON
  - **When** 未来日のフローシートアイコン／バイタルアイコンを確認する
  - **Then** グレー表示・クリック不可

## 状態遷移 / バリデーション

- 表示日範囲: 入院患者は `[displayDate - 6日, displayDate]`、外来は記録存在日の合計 7 日
- 未来日入力: `validate.future = on` → アイコン非活性
- 観察タブ表示条件: `patient.isMedicalObservation === true`

## 補足

- 一画面構成のため、レイアウトは ep-01 病棟マップと同様にビューポートを 100% 使う前提
- 表示時間幅（24h／勤務帯単位）の切替は本ストーリースコープ外（補足ストーリーで検討）
- パターンボックスの表示切替操作は [us-21] で扱う
