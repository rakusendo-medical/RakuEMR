## ユーザーストーリー

- **As a** 主治医・看護職員
- **I want** オーダ入力（オーダ送信画面）で作成したオーダを、フローシートの予定オーダ欄に開始日の列で確認したい
- **So that** フローシート上で当該日のオーダ有無を種名で把握できる

## スコープ

### 含む（モック）

- フローシート「予定オーダ」欄を、静的モックの直書き種名から、**その患者のオーダ（seed `ORDERS` ＋ オーダ入力で作成した `dynamicOrders`）由来の種名1文字**に連携
- **オーダ種別 → 種名1文字マッピング（マニュアル準拠）**:

  | 種名 | OrderType |
  | --- | --- |
  | 薬 | 処方・入院定時 |
  | 注 | 注射 |
  | 検 | 検査 |
  | 画 | 画像 |
  | 心 | 心理検査 |
  | E | ECT |

  - 種名「処」（処置）は種名表にあるが、対応する OrderType が本モックに無いため未使用
  - リハビリ／IF／文字（テキスト）は予定オーダ欄の種名表に無いため**対象外**（表示しない）
  - 旧「定時処方」は廃止され「入院定時」へ統合済み（いずれも種名「薬」）
- オーダの **開始日** がフローシート表示範囲（7日窓）内の日に、その日の列へ種名を表示。**同日同種名は1文字に集約**（マニュアル準拠）
- 既存の静的モック種名と**合成**（union・重複集約）して表示（デモ用の見た目を維持しつつ、新規作成分を追加）

- **「一覧」→ 指示状況ダイアログ（参照のみ）**: その患者のオーダ（seed + オーダ入力）を新しい順に一覧表示（開始日／種別／内容／状態）。「参照のみ・DO/新規指示不可」の注記（マニュアル準拠）
- **予定オーダのセルクリック → 実施確認表ダイアログ（1週間カレンダー）**: フローシートの 7 日窓（当日を右端・ハイライト）を列に、期間内に実施予定のオーダを行に表示。**実施予定日のセルに実施回数（用法「1日N回」から推定）**を表示（未実施＝赤／実施済＝グレー）。内容はオーダ内容と同じ 1 薬品 1 行（Rp 番号付き）表記。実施予定は処方系＝開始日〜日数、単発（検査/ECT/IF/文字/日数0）＝開始日のみ、継続処方＝窓内すべて。
- **未実施オーダの実施（マニュアル準拠 02 p.24-26）**: 実施確認表で**未実施の実施回数セルをクリック → 実施ダイアログ**（種別・内容・予定日・指示医・実施日時・実施者）→ **[実施]** でオーダを実施。実施すると実施確認表で**実施済（グレー）**表示になる。
- **実施状況の反映**: 実施すると予定オーダ欄の**セル背景がオレンジ**、その種名は**同日同種が全件実施済でグレー**（1件でも未実施なら赤）。実施記録は `useAppStore.orderExecutions`（オーダid→実施日時/実施者・非永続）。

### 含まない（本ラウンド・後続）

- 実施の取消・実施記録のカルテ記事化・受信オーダ画面（別系統）との同期
- 検査結果グラフ表示（設定）・食事カレンダー 等の他欄
- フローシート表示日の自動追従（既定は mock の 2026/5/13〜5/19。オーダの開始日をこの範囲にすると反映）
- 種別「処」（処置）の OrderType 追加（本モックの OrderType には無い。検査・画像は OrderType あり）
- feature 版フローシート（`src/features/flowsheet/`）との統合（別課題）

## 振る舞い

- **反映**: オーダ入力でオーダを作成（[指示]）→ 当該患者・開始日の列に種名1文字が加わる（`dynamicOrders` は非永続のためリロードで消える）。
- **集約**: 同日に同じ種名のオーダが複数あっても種名は1文字（例: 処方＋入院定時 → 「薬」1つ）。
- **対象外種別**: リハビリ／IF／テキストは種名表に無いため予定オーダ欄には出ない。

## 受け入れ基準（AC）

- [ ] **AC-1: オーダ入力で作成したオーダが予定オーダ欄に種名で反映**
  - **Given** カルテのフローシートで、ある日の予定オーダ欄に種名「検」が無い
  - **When** オーダ入力で検査オーダを、その日の開始日で作成し[指示]する
  - **Then** フローシートの予定オーダ欄・当該日の列に「検」が表示される
- [ ] **AC-2: 種名マッピング（マニュアル準拠）**
  - 処方/入院定時→薬、注射→注、検査→検、画像→画、心理検査→心、ECT→E。リハビリ/IF/テキストは表示されない
- [ ] **AC-3: 同日同種名は1文字集約**
  - 同日に同じ種名のオーダが複数あっても、種名は1文字のみ表示される

## 補足

- 実装: `src/components/flowsheet/Flowsheet.tsx` に `ORDER_KIND_OF`（OrderType→種名）と `orderKindsByIso`（患者のオーダを開始日ISO→種名[] に集約）を追加。予定オーダ行のレンダリングで静的種名と合成。データ源は `src/data/mockData` の `ORDERS` ＋ `useAppStore.dynamicOrders`。
- カルテのフローシートタブは `src/components/flowsheet/Flowsheet.tsx`（KartePage が描画）。feature 版 `src/features/flowsheet/`（`ScheduledOrder` モデル・実施・一覧ダイアログ）とは別系統で、本 US は前者を対象とする。
- 予定オーダの「作成」はフローシート内では行わない（マニュアル準拠。作成はオーダ入力 [ep-11](../ep-11-order-entry/_epic.md)）。フローシートは反映（表示）のみ。
