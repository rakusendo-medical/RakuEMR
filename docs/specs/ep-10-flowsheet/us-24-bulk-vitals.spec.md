## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 病棟・病室・種類・記録日を指定して一括入力画面でバイタルを複数患者分まとめて入力したい
- **So that** ラウンド時に複数患者のバイタルを連続して効率的に登録できる

## 画面要素（要素ツリー）

```
- 一括バイタル入力画面 (/nursing/bulk-vitals)
  - 検索条件バー
    - 病棟プルダウン（ログオン職員所属に応じた初期値）
    - 病室プルダウン
    - 種類プルダウン（マスタ「ケア項目マスタ」、例: 基本昼）
    - 記録日ピッカー
    - [入力対象患者のみ] チェックボックス（マスタで初期チェック・名称設定）
    - [表示] ボタン
  - 患者リストテーブル
    - 行: 各患者
      - 更新チェック（値入力時自動付与、行背景=薄青）
      - 患者番号（クリックで個別フローシート遷移 [us-17]）
      - 氏名・病室
      - 種類項目列（複数列、項目数に応じて `<<` `<` `>` `>>` ナビゲーション）
        - 値入力枠（項目タイプ別: テキスト／ラジオ／コンボ／チェックボックス）
        - 入力時間外: 背景グレー（入力不可）
        - 患者にパターン未設定: 背景グレー（入力不可）
        - 登録済プルダウン項目: 背景薄赤
    - 一括操作行
      - [全て選択] [クリア]（更新チェック）
      - [設定]（更新チェック付き行を一括登録）
      - [クリア]（登録済項目を削除）
      - [フローシートへサインする] チェック（登録時間に該当する勤務帯のサインを連動登録、マスタで表示有無・初期チェック設定）
- 一括入力ダイアログ（パターン項目用、複数チェック対応）
- 時間設定ダイアログ
  - 現在時刻初期値、[設定] で一括設定
```

## 振る舞い

- **検索**: 病棟・病室・種類・記録日を指定 → [表示] → 該当患者一覧。
- **病棟初期表示**: ログオン職員の所属区分が病棟名なら対象病棟、そうでなければプルダウン先頭。
- **入力対象患者のみ**: フローシートパターンで対象項目が設定されている患者のみ表示。
- **項目タイプ別 UI**: テキスト／ラジオ／コンボ／チェックボックス（複数or単項目）。
- **更新チェック自動付与**: 値入力で行の更新チェックが自動 ON、背景薄青。
- **一括操作**:
  - [全て選択] / [クリア] でチェック ON/OFF
  - [設定] で更新チェック付き行を一括登録
  - [クリア] で登録済項目を削除
- **入力時間外項目**: 入力可能時間外なら背景グレー、入力不可。
- **未設定項目**: 患者にパターン未設定の項目はグレー。
- **フローシートサイン連動**: チェックで登録時間に該当する勤務帯のサインを [us-19] と同モデルで登録。
- **整合性**: 一括登録分はフローシート画面 [us-17] と個別バイタル画面 [us-20] の両方に反映。個別履歴一覧にも一括分が表示される。
- **患者番号クリック**: 個別フローシート遷移 [us-17]。
- **項目ナビゲーション**: 表示項目の前後がある場合、`<<` `<` `>` `>>` で切替。

## 受け入れ基準（AC）

- [ ] **AC-1: 検索表示**
  - **Given** 病棟「北 3 階」、病室「301」、種類「基本昼」、記録日「2026-05-02」を指定
  - **When** [表示] をクリック
  - **Then** 該当患者リストが表示される
- [ ] **AC-2: 病棟初期表示**
  - **Given** ログオン職員の所属区分が「北 3 階」
  - **When** 一括バイタル入力画面を開く
  - **Then** 病棟プルダウンの初期値が「北 3 階」
- [ ] **AC-3: 入力対象患者のみフィルタ**
  - **Given** 対象項目（基本昼）にパターン未設定の患者を含む
  - **When** [入力対象患者のみ] チェックして [表示]
  - **Then** 対象項目に値を入力できる患者のみ表示
- [ ] **AC-4: 項目タイプ別 UI**
  - **Given** 種類に「テキスト／ラジオ／コンボ／チェックボックス」混在
  - **When** 値入力枠を確認する
  - **Then** タイプに応じた UI（テキスト入力／コンボ／パターン項目ダイアログ）が表示される
- [ ] **AC-5: 更新チェック自動付与**
  - **Given** 患者リストに 5 名表示中
  - **When** 任意の患者で値を 1 つ入力
  - **Then** 当該患者の更新チェックが自動 ON、行背景が薄青に変化
- [ ] **AC-6: 全選択／クリア**
  - **Given** 5 名表示
  - **When** [全て選択] / [クリア] を押す
  - **Then** 全行の更新チェックが ON / OFF される
- [ ] **AC-7: [設定] で一括登録**
  - **Given** 値入力済みで更新チェック ON の行が複数
  - **When** [設定] を押す
  - **Then** 当該入力項目が登録される。プルダウン項目の登録済セル背景は薄赤
- [ ] **AC-8: [クリア] で登録済削除**
  - **Given** 登録済項目を選んだ行
  - **When** [クリア] を押す
  - **Then** 当該登録済項目が削除される
- [ ] **AC-9: 入力時間外**
  - **Given** 入力可能時間 (10:00-12:00) が設定された項目、操作時刻 13:00
  - **When** その項目を確認する
  - **Then** 背景グレーで入力不可
- [ ] **AC-10: フローシートへサイン連動**
  - **Given** 種類にサイン項目が含まれる
  - **When** [フローシートへサインする] チェックして [設定]
  - **Then** 登録時間に該当する勤務帯のサインがフローシートに登録される
- [ ] **AC-11: 個別画面との整合**
  - **Given** 一括入力でバイタルを保存
  - **When** 同患者のフローシート [us-17] ／個別バイタル [us-20] を開く
  - **Then** 一括分の値が反映、個別履歴一覧にも表示される
- [ ] **AC-12: 患者番号クリック**
  - **Given** 患者リスト表示中
  - **When** 患者番号をクリック
  - **Then** 当該患者のフローシート画面に遷移

## 状態遷移 / バリデーション

- 行状態: `untouched` → 値入力で `dirty (更新チェック ON, 薄青)` → [設定] で `committed (薄赤)` → [クリア] で `untouched`
- 入力可能時間外・パターン未設定: グレー、入力不可
- フローシートサイン連動: `[フローシートへサインする]` ON で登録時間の勤務帯にサイン登録（[us-19] と同モデル）

## 補足

- 入力速度向上のキーボードショートカット仕様は別ストーリーで検討
- 種類はマスタ「ケア項目マスタ」で管理
- 項目数が多い場合の `<<` `<` `>` `>>` ナビゲーション仕様は実装時に詳細化
