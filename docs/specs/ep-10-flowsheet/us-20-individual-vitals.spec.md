## ユーザーストーリー

- **As a** 病棟看護師
- **I want** バイタル編集ダイアログで BP（上下）／R／P／T／S／W を個別入力し、更新履歴（日時・記録者・操作種別）を確認したい
- **So that** 計測の都度すぐに記録でき、過去の修正経緯も追跡できる

## 画面要素（要素ツリー）

```
- バイタル編集ダイアログ
  - 対象日付ヘッダー
  - 入力テーブル（複数行可）
    - 列: 時間（必須・HH:mm）／BP（上）／BP（下）／R／P／T／S／W／記録者
    - [+] 行追加ボタン
    - [×] 行削除ボタン
  - フッター: [登録] [キャンセル]
  - 更新履歴一覧
    - 列: 更新日時／更新者／更新内容（時刻 + 値ダイジェスト）／操作（登録／更新）
    - 並び: 更新日時降順
```

## 振る舞い

- **ダイアログ起動**: 対象日のバイタルアイコンクリック → 既存値があれば時刻順に並んだ状態で表示。
- **新規行追加**: [+] で行追加 → 時刻と任意の測定値を入力。
- **複数行任意順入力**: 時刻順でない入力も許容、表示時に時刻昇順ソート。
- **時刻空欄**: その行は登録対象から除外（既存行の場合は削除扱い）。
- **登録**: [登録] → 値が体温表に反映。記録者は登録時に操作者が自動入力。
- **更新**: 既存行の時刻に対して値を変更 → [登録] → 履歴に「更新」エントリ。新時刻の追加は「登録」エントリ。
- **削除**: 全入力をクリアして [登録]、または時刻欄を空に → 削除扱い。
- **未来日時制御**:
  - `validate.future` ON: 現在日時より未来の時刻は登録不可（エラーメッセージ）
  - `confirm.future` ON: 確認メッセージで進行可否を選べる
- **スクロール位置保持**: ダイアログ open/close 前後でフローシート画面のスクロール位置を保持。

## 受け入れ基準（AC）

- [ ] **AC-1: ダイアログ起動と既存表示**
  - **Given** 対象日に時刻 09:00 のバイタル登録あり
  - **When** バイタルアイコンをクリックする
  - **Then** 09:00 の行が表示される（必須欄は時間、BP・R・P・T・S・W は登録値）
- [ ] **AC-2: 新規登録**
  - **Given** ダイアログを開いて新規行を追加
  - **When** 時刻 14:00、BP 上 130、下 80、T 36.8 を入力 → [登録]
  - **Then** 体温表の 14:00 列に値が表示される。記録者は操作者
- [ ] **AC-3: 任意順入力でも昇順表示**
  - **Given** 14:00 → 09:00 → 21:00 の順で入力
  - **When** 登録後にダイアログを再度開く
  - **Then** 行が 09:00 → 14:00 → 21:00 の順で並ぶ
- [ ] **AC-4: 時刻空欄は登録対象外**
  - **Given** 3 行入力するが 1 行は時刻空欄
  - **When** [登録] をクリック
  - **Then** 時刻空欄行は登録されない（既存だった場合は削除扱い）
- [ ] **AC-5: 更新と履歴**
  - **Given** 09:00 に T=36.5 で登録済み
  - **When** T=36.8 に変更 → [登録]
  - **Then** 履歴に「更新」エントリが追加（操作=更新、内容に旧→新値）
- [ ] **AC-6: 新時刻追加は登録扱い**
  - **Given** 09:00 のみ既登録
  - **When** 14:00 行を追加して [登録]
  - **Then** 履歴に「登録」エントリ（操作=登録）
- [ ] **AC-7: 全クリア削除**
  - **Given** 09:00, 14:00 が登録済み
  - **When** 両行の値をクリアして [登録]
  - **Then** 体温表から両時刻のバイタルが消える
- [ ] **AC-8: 未来日エラー**
  - **Given** マスタ `validate.future` = ON、操作日時 2026-05-02 10:00
  - **When** 11:00 行を入力して [登録]（未来）
  - **Then** エラーメッセージが出て登録されない
- [ ] **AC-9: 未来日確認**
  - **Given** マスタ `confirm.future` = ON
  - **When** 未来時刻で [登録]
  - **Then** 確認メッセージ → OK で登録可、キャンセルで戻る
- [ ] **AC-10: スクロール位置保持**
  - **Given** フローシート画面でスクロール後に編集
  - **When** ダイアログを閉じる
  - **Then** スクロール位置が変わらない

## 状態遷移 / バリデーション

- 操作分類:
  - 既存にない時刻 + 値登録 → `登録`
  - 既存時刻の値変更 → `更新`
  - 既存時刻の全値クリア／時刻空欄化 → `更新`（削除サブケース）
- 時刻フォーマット: `HH:mm`、24h 表記、必須
- 未来日マスタ:
  - `validate.future`: ハードガード
  - `confirm.future`: ソフトガード（確認）

## 補足

- バイタル種別ごとの入力単位・桁数（例: T は小数 1 桁）は実装時に確定
- 体重 W はバイタル編集ダイアログで入力（フローシート編集 [us-18] では入力不可）
- 異常値ハイライト・上下限警告は将来ストーリーで検討
