## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 看護記録を SOAP／経時記録の形式で新規作成・更新・削除し、連携先（フローシート、申し送り、病棟日誌、報告先など）を設定して時系列で参照したい
- **So that** 個別の観察・思考プロセスを記録に残し、関連する記事をたどって経過を追える

> **記録形式の確定（2026-08-24 先方合意）**: 記録形式は **SOAP／経時記録の 2 形式のみ** とする（従来案の FOCUS／フリーは廃止）。
> 本文は 1 つの入力欄（平文テキスト）で、各形式の**定型文**を挿入して記入する方式。
> - SOAP 定型文: `S`／`O`／`A`／`P` の見出し 4 行
> - 経時記録 定型文: 行頭に時刻（`HH:mm `）を付けた行（例: `00:00 意識消失` `00:03 Dr へ電話`）
>
> SOAP 各欄・経時記録の「時刻＋本文」行構造といった**構造化入力の仕組みは現時点では実装スコープ外**。
> ただし将来は看護記録に限らず**多職種の部門診療録全てを対象**とした共通の仕組みとして導入する可能性があるため、
> データモデル（`NursingRecordBody` の formType 別 union）には拡張余地を残す（設計メモ）。
> 経時記録は専用の標準 UI が存在しないため、SOAP と同じ平文入力に **[時刻行を追加]**（現在時刻の行頭挿入）の補助を添える。

## 画面要素（要素ツリー）

```
- 看護経過記録ダイアログ
  - ヘッダー
    - タイトル入力（最大 20 文字）
    - 記載日／勤務帯セレクト
    - 記録形式タブ: SOAP／経時記録
  - 本文域（1 つの平文テキストエリア。形式ごとの定型文を挿入して記入）
    - SOAP: 定型文「S／O／A／P」の見出し 4 行
    - 経時記録: 行頭に時刻（HH:mm）を付けた行。[時刻行を追加] で現在時刻の行を挿入
  - 入力支援
    - [文例] → 文例ウィザードダイアログ
    - [テンプレート呼出] → テンプレート一覧メニュー → 本文へ展開
    - [時刻行を追加]（経時記録タブのみ）→ 本文末尾に現在時刻の行頭（HH:mm ）を挿入
    - [一括入力] → 一括入力ダイアログ
  - タグ（テンプレート呼出の直下に配置・本文の上）
    - タグ入力欄（自由入力・プレースホルダ「タグを追加 (Enter)」）
    - Enter でタグを確定しチップとして追加（複数付与可）
    - 付与済みタグはチップ表示。チップの [×] で個別削除
    - 参照モードはチップ表示のみ（入力欄は非表示）
  - 連携
    - フローシート／申し送り／病棟日誌／面接実施／報告先
    - 報告先: [検索] → 職員選択ダイアログ → 報告種別 [作]作成／[確]確認／[両]両方
  - 記録者欄
  - フッター: [登録] [更新] [削除] [キャンセル]
- 関連付け（時系列連鎖閲覧）
  - 既存看護記録から「関連付け」を設定可
  - 部門記録簿で関連記事を時系列で連鎖表示
```

## 振る舞い

- **複数経路からの起動**:
  - 部門記録簿の [看護記録]
  - カルテ画面 [看護記録（実施）]
  - フローシート看護経過記録欄 [新規作成]
- **新規作成**: タイトル・記載日・勤務帯・形式・本文・連携・タグ・記録者を入力 → [登録] → 部門記録簿の時系列に追加。
- **形式切替**: SOAP／経時記録をタブで切替。本文が空または定型文のままなら切替先の定型文を自動挿入し、編集済みなら上書き確認のうえ置き換える。
- **テンプレート呼出**: [テンプレート呼出] → テンプレート一覧から選択 → 記録形式を切り替え、選択したテンプレートを本文へ展開する（現在の本文は置き換え）。
- **タグ付与**: テンプレート呼出の直下（本文の上）のタグ入力欄に自由入力し Enter で確定 → タグをチップとして追加する。複数タグを付与でき、同一タグは重複追加しない（空文字は無視）。チップの [×] で個別削除。参照モードではチップ表示のみで入力欄は出さない。付与したタグは記事に保存され、**部門記録簿（[us-22]）でタグ検索・絞り込みに利用する（実装済み）**。
- **連携設定**: チェックで該当画面・機能から記事参照可。フローシート連携 OFF の場合はフローシートに表示されない。
- **報告先指定**: [検索] → 職員選択 → 報告種別を指定 → 報告先で記事を表示した際にボタン表示。
- **記事更新／削除**: 部門記録簿でタイトルクリック → 編集ダイアログで内容変更／削除。操作者・日時を監査用に記録。「全て」表示で履歴記事を確認可。
- **関連付け**: 既存記事に「関連付け」を設定 → 部門記録簿で連鎖表示。
- **未来日制御**: 未来日時は**常に登録不可（固定・マスタ設定によらない）**。旧 `validate.future` / `confirm.future` による制御は廃止（2026-08-17）。

## 受け入れ基準（AC）

- [ ] **AC-1: 複数経路からの起動**
  - **Given** 患者を選択している
  - **When** 部門記録簿 [看護記録] ／カルテ [看護記録（実施）] ／フローシート [新規作成] のいずれかをクリック
  - **Then** 看護経過記録ダイアログが新規作成モードで開く
- [ ] **AC-2: 新規作成（SOAP）**
  - **Given** ダイアログを開いて記録形式を SOAP にする
  - **When** 定型文（S／O／A／P の見出し 4 行）に沿って本文を入力 → [登録]
  - **Then** 部門記録簿の時系列に追加される
- [ ] **AC-3: 形式切替（定型文の挿入）**
  - **Given** 記録形式タブは SOAP／経時記録 の 2 つのみ表示される
  - **When** SOAP → 経時記録 に切替（本文が未編集の場合）
  - **Then** 本文の定型文が S/O/A/P 見出しから時刻行頭（HH:mm ）に置き換わる。本文編集済みの場合は上書き確認が表示される
- [ ] **AC-3b: 経時記録の時刻行挿入**
  - **Given** 記録形式タブを経時記録にしている
  - **When** [時刻行を追加] をクリック
  - **Then** 本文末尾に現在時刻の行頭（HH:mm ）が改行して挿入される
- [ ] **AC-4: テンプレート呼出**
  - **Given** 看護経過記録ダイアログを開いている
  - **When** [テンプレート呼出] → テンプレート一覧から選択する
  - **Then** 記録形式が切り替わり、選択したテンプレートが本文へ展開される（現在の本文は置き換え）
- [ ] **AC-5: 連携設定**
  - **Given** ダイアログ編集中
  - **When** フローシート連携にチェックを入れて [登録]
  - **Then** フローシートの看護経過記録欄に記事タイトルが表示される（OFF 時は表示されない）
- [ ] **AC-6: 報告先指定**
  - **Given** 連携の [検索] から職員を選び、報告種別 [両] を指定
  - **When** [登録]
  - **Then** 報告先で記事を表示した際に「作成・確認」ボタンが表示される
- [ ] **AC-8: 更新・削除**
  - **Given** 部門記録簿で既存看護記録を表示中
  - **When** タイトルクリック → 編集ダイアログで内容変更 → [更新]、または [削除]
  - **Then** 反映され、操作者・日時が監査記録に残る。「全て」表示で履歴記事を確認可
- [ ] **AC-9: 関連付け**
  - **Given** 既存看護記録に「関連付け」設定済み
  - **When** 部門記録簿で記事の関連付けを表示する
  - **Then** 関連記事が時系列で連鎖表示される
- [ ] **AC-10: 未来日不可（常に固定）**
  - **Given** フローシートを表示している（マスタ設定によらない）
  - **When** 未来日時で記載日時を入力 → [登録]
  - **Then** エラーメッセージで登録不可（未来日時は常に登録不可）
- [ ] **AC-11: タグ付与（テンプレート呼出の下・自由入力＋Enter・複数）**
  - **Given** ダイアログを新規作成で開いている（テンプレート呼出の直下にタグ入力欄がある）
  - **When** タグ入力欄に文字を入力し Enter を押す操作を複数回行う
  - **Then** 入力した各タグがチップとして表示される（複数付与）。既に同じタグがある場合は追加されない。チップの [×] で削除できる。参照モードでは入力欄は表示されずチップのみ表示される

## 状態遷移 / バリデーション

- 記録形式: `soap`（SOAP） / `chronological`（経時記録）
- 連携: 複数チェック可（フローシート／申し送り／病棟日誌／面接実施／報告先）
- 報告種別: `[作]` / `[確]` / `[両]`
- 削除は物理／論理いずれか（実装時に確定）

## 補足

- 関連記事は同一患者内に限るかは別途検討（本モックは同一患者内）
- 記録形式の初期値はマスタ「部門側記事形式」で設定
- **定型文（テンプレ）の定義**: 記録形式のテンプレは「1 つの本文入力欄へ挿入される定型文」として定義する（形式ごとの専用入力欄は設けない）
- **構造化入力はスコープ外（設計メモ）**: SOAP 各欄・経時記録の「時刻＋本文」行構造の構造化入力は、将来は看護記録を除く多職種の部門診療録全てを対象にした共通の仕組みとして検討の余地を残すが、現時点では実装しない。`NursingRecordBody` は formType 別 union とし拡張余地を確保する
- **公開/非公開設定は削除（2026-08-24）**: 「記事を公開する」チェック（非公開時の看護メニュー限定表示・薄赤背景）は、参照範囲の使い方が定まらないため Spec・画面・データモデルから削除した。必要になれば参照範囲の定義（看護部門内共有か記載職員のみか）を先方確認のうえ再検討する。AC-7 欠番はこの削除によるもの
- テンプレート・文例ウィザードは独立したマスタ管理（[ep-07] 観察記録の文例ウィザードと共有可能）
- タグは**フリータグ（自由入力＋Enter で付与）で実装する方針で確定**。これに伴い、従来想定していた**タグマスタ（記事タグの選択マスタ）は不要となった**（廃止）。
  - 将来サジェスト（過去入力タグの候補表示・使用頻度順など）を足す場合も、マスタ管理ではなく**入力履歴ベース**で検討する。
- タグ入力欄の配置は**テンプレート呼出の直下・本文の上**（PM 指定。E2E: `e2e/flowsheet.spec.ts`「看護経過記録: テンプレート呼出の下のタグ欄…」で検証）
