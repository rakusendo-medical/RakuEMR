## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートパターンを切り替えて表示・入力項目を変更し、適用履歴も追跡したい
- **So that** 患者の状態に応じて必要なケア項目だけを扱い、不要項目を画面から排除できる

## 画面要素（要素ツリー）

```
- パターンボックス（フローシート画面ヘッダー）
  - 表示モードトグル: [全パターン] / [適用パターン名]
  - [パターン変更] ボタン → パターン変更ダイアログ
- フローシートパターン変更ダイアログ
  - 適用済みパターン一覧
    - 列: 開始日／パターン名／削除アクション
    - 行クリックで編集モード
  - 新規適用行
    - 開始日入力／パターン選択（マスタ「フローシートパターンマスタ」）
    - [登録]
  - [履歴] → パターン編集履歴ダイアログ
  - [キャンセル]
  - データ削除確認サブダイアログ（適用日以降のケアメニューデータが削除される）
- フローシートパターン編集履歴ダイアログ
  - 全変更履歴一覧（参照のみ）
- フローシート編集ダイアログ（[us-18]）の連動
  - 適用パターンに応じてケア項目欄が切り替わる
  - 履歴のパターン名欄: 未適用は「パターンなし」表示
```

## 振る舞い

- **新規適用**: ダイアログで開始日とパターンを選択 → [登録] → 確認サブダイアログ「適用日以降のケアメニューデータは削除されます。よろしいですか？」→ OK で適用。
- **複数パターン同日適用**: 同日内に複数行のパターン設定可。日内のパターン数分の行で表示。
- **適用日以降のフローシート編集**: 編集ダイアログには適用パターンの項目のみが表示・入力可能。
- **パターン変更**: 既存パターン行の値を変更 → 同様に確認サブダイアログ後反映。
- **パターン削除**: 削除アクション → 確認 → 反映（「未適用扱い」になり、その後の編集は「パターンなし」）。
- **履歴参照**: [履歴] ボタンで参照専用ダイアログ。
- **マスタ管理**: マスタ「フローシートパターンマスタ」で複数パターンを管理。

## 受け入れ基準（AC）

- [ ] **AC-1: 新規適用**
  - **Given** パターン未適用、操作日 `2026-05-02`
  - **When** 開始日 `2026-05-02`、パターン「精神科基本」を選択 → [登録]
  - **Then** 確認サブダイアログ → OK で `2026-05-02` 以降のフローシート編集ダイアログ項目が「精神科基本」に切替
- [ ] **AC-2: 同日内複数パターン**
  - **Given** ダイアログ表示中
  - **When** 同日 `2026-05-02` に「精神科基本」「精神科隔離」の 2 行を設定
  - **Then** 一覧上は同日 2 行で表示・登録される
- [ ] **AC-3: 適用日以降のデータ削除**
  - **Given** `2026-05-01` の編集ダイアログでケアメニュー入力済み
  - **When** `2026-05-01` 開始のパターン適用 → OK
  - **Then** `2026-05-01` 以降の既存ケアメニュー入力データが消える（フローシート上は空欄）
- [ ] **AC-4: 編集ダイアログの項目連動**
  - **Given** パターン「精神科基本」適用済み
  - **When** 適用日以降のフローシートアイコンをクリック
  - **Then** 編集ダイアログの入力欄は「精神科基本」のみ
- [ ] **AC-5: パターン変更**
  - **Given** パターン適用済み
  - **When** 一覧で行を選択し別パターンに変更 → [登録] → OK
  - **Then** 反映され、編集ダイアログの項目が新パターンに切替
- [ ] **AC-6: パターン削除**
  - **Given** パターン適用済み
  - **When** 削除アクション → 確認 OK
  - **Then** 適用解除（「パターンなし」状態）になり、履歴のパターン名欄は「パターンなし」表示
- [ ] **AC-7: 履歴参照**
  - **Given** 過去 3 回パターン変更
  - **When** [履歴] をクリック
  - **Then** 編集履歴ダイアログ（参照のみ）が開かれ、3 件の履歴が時系列で表示される
- [ ] **AC-8: 確認メッセージのキャンセル**
  - **Given** パターン適用フローを進めている
  - **When** 確認サブダイアログでキャンセル
  - **Then** 何も適用されない（既存データも保持）
- [ ] **AC-9: マスタ管理**
  - **Given** マスタにパターン「精神科基本」「精神科隔離」「身体管理」を登録
  - **When** ダイアログのパターンプルダウンを開く
  - **Then** 3 パターンが選択肢として並ぶ

## 状態遷移 / バリデーション

- パターン状態: `unapplied` → `applied(name=X, since=Y)` → `applied(name=X', since=Y)` → `unapplied`
- 適用日以降のケアメニューデータは適用時に物理削除（不可逆。確認サブダイアログ必須）
- パターンマスタは固定マスタ（マスタ編集 UI は別ストーリー）

## 補足

- パターンマスタ自体の編集 UI は別ストーリーで検討（本モックは固定マスタ）
- パターン切替時のデータ削除は不可逆。誤操作防止の確認 UI は実装時に詳細化
