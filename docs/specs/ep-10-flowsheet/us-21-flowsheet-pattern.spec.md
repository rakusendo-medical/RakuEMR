## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートパターンを切り替えて表示・入力項目を変更したい
- **So that** 患者の状態に応じて必要なケア項目だけを扱い、不要項目を画面から排除できる

## 画面要素（要素ツリー）

```
- パターンボックス（フローシートサブタブ最下部・本体テーブルに統合）
  - 表示モードトグル: [適用パターン名]（既定） / [全パターン]
  - [パターン変更] ボタン → パターン変更ダイアログ
  - ※ 隔離拘束サブタブでは非表示。サイン行の下に配置
- フローシートパターン変更ダイアログ
  - 新規適用ヘッダー
    - 開始日入力／終了日入力（任意）／パターン選択（マスタ「フローシートパターンマスタ」）／[登録]
  - 適用済みパターン一覧（適用期間テーブル）
    - 列: 開始日／終了日／パターン名／削除アクション
    - 行クリックで編集モード（開始日・終了日・パターンを編集 → [更新]）
    - [新規]
  - [キャンセル]
  - 確認サブダイアログ
    - 新規適用／変更: 「適用日以降のケアメニューデータは削除されます。よろしいですか？」
    - 削除: 「〜を適用解除します（パターンなし状態になります）。よろしいですか？」
- パターン入力ダイアログ（各パターン見出しの [入力] ／ 日付のフローシートアイコンから起動）
  - 日付＋適用パターンの各項目（項目ごとにプルダウン／自由入力）→ [登録]
  - 本体テーブルのセルは読み取り専用（登録値を表示・直接入力不可）
```

## 振る舞い

- **表示モードトグル**: 「適用パターン名」＝適用中パターンのみ表示（既定）。「全パターン」＝マスタの全パターンを表示（未適用は薄グレー・入力不可）。
- **新規適用**: ヘッダーで開始日（＋任意で終了日）とパターンを選択 → [登録]／[新規] → 確認サブダイアログ「適用日以降のケアメニューデータは削除されます。よろしいですか？」→ OK で適用。
- **複数パターン同日適用**: [新規] で同日内に複数行のパターン設定可。
- **適用期間と入力可否**: 入力可能日付は「開始日〜終了日」。終了日なしは開始日以降すべて。開始日より前・終了日より後は入力不可（薄グレー・[入力]なし）。
- **入力**: 各パターン見出しの [入力]、または日付のフローシートアイコンから入力ダイアログを開く。ダイアログには**適用中パターンの項目のみ**が表示され、項目ごとにプルダウン／自由入力で入力する。本体セルは読み取り専用で登録値を表示（直接入力不可）。
- **パターン変更**: 一覧の行をクリックして編集モードに入り、開始日・終了日・パターンを変更 → [更新] → 確認サブダイアログ後に反映。
- **パターン削除**: [削除] → 確認 → 適用解除（「パターンなし」状態）。ただし**入力済みの値があるパターンは削除不可**（警告を表示し、確認を開かない）。
- **マスタ管理**: マスタ「フローシートパターンマスタ」で複数パターンを管理（固定マスタ）。

## 受け入れ基準（AC）

- [ ] **AC-1: 新規適用**
  - **Given** パターン未適用、操作日 `X`
  - **When** 開始日 `X`、パターンを選択 → [登録]
  - **Then** 確認サブダイアログ → OK で `X` 以降にそのパターンが適用される
- [ ] **AC-2: 同日内複数パターン**
  - **Given** ダイアログ表示中
  - **When** [新規] で同日に複数パターン行を設定
  - **Then** 一覧に複数行で表示・登録される
- [ ] **AC-3: 適用日以降のデータ削除**
  - **Given** 適用日にケアメニュー入力済み
  - **When** 同日開始のパターン適用 → OK
  - **Then** 適用日以降の既存ケアメニュー入力データが消える（フローシート上は空欄）
- [ ] **AC-4: 入力ダイアログの項目連動**
  - **Given** パターン適用済み
  - **When** その日の見出し [入力] ／ フローシートアイコンをクリック
  - **Then** 入力ダイアログの入力欄は適用中パターンの項目のみ
- [ ] **AC-5: パターン変更**
  - **Given** パターン適用済み
  - **When** 一覧の行をクリックして編集 → 別パターン／開始日／終了日に変更 → [更新] → OK
  - **Then** 反映され、以降の入力項目・入力可否が新しい値に切り替わる
- [ ] **AC-6: パターン削除**
  - **Given** パターン適用済み（入力値なし）
  - **When** [削除] → 確認 OK
  - **Then** 適用解除（「パターンなし」状態）になり、一覧・グリッドから消える
- [ ] **AC-7: 終了日以降は入力不可**
  - **Given** パターンに終了日 `E` を設定
  - **When** フローシートを表示
  - **Then** `E` まで（含む）は [入力] 可、`E` より後は [入力] なし（薄グレー）
- [ ] **AC-8: 確認メッセージのキャンセル**
  - **Given** 新規適用／変更／削除のフローを進めている
  - **When** 確認サブダイアログでキャンセル
  - **Then** 何も反映されない（既存データも保持）
- [ ] **AC-9: マスタ管理**
  - **Given** マスタにパターン「精神科基本」「精神科隔離」「身体管理」を登録
  - **When** ダイアログのパターンプルダウンを開く
  - **Then** 3 パターンが選択肢として並ぶ
- [ ] **AC-10: 入力値ありは削除不可**
  - **Given** パターンに入力済みの値がある
  - **When** [削除] を押す
  - **Then** 削除確認は開かず、警告を表示し、パターンは残る

## 状態遷移 / バリデーション

- パターン状態: `unapplied` → `applied(name=X, start=S, end=E?)` → `applied(name=X', …)` → `unapplied`
- 入力可能範囲: 開始日 ≤ 日付 ≤ 終了日（終了日なしは開始日以降すべて）
- 適用日以降のケアメニューデータは適用・変更時に物理削除（不可逆。確認サブダイアログ必須）
- 入力済みの値があるパターンは削除不可
- パターンマスタは固定マスタ（マスタ編集 UI は別ストーリー）

## 補足

- 実装は `components/flowsheet`（カルテ内ワイヤーフレーム）。パターン欄はフローシートサブタブ最下部・サイン行の下に配置し、隔離拘束サブタブでは非表示。
- パターンボックスの表示モードトグルは、最下部グリッドに表示するパターン行の範囲（適用中のみ／全パターン）を切り替える。
- **初版 SPEC からの追加**: 終了日（適用期間の終了日と、終了日以降の入力不可）、入力値ありは削除不可（AC-10）。
- **初版 SPEC から未提供**: 編集履歴（[履歴]／フローシートパターン編集履歴ダイアログ／「履歴のパターン名＝パターンなし」表示）は本実装ではスコープ外（旧 AC-7「履歴参照」は撤回）。
