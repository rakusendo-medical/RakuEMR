## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 指定日のフローシートでケア内容を入力・更新・削除し、更新履歴を確認したい
- **So that** 実施記録を当日中に画面上で完了し、過去の修正経緯も追跡できる

## 画面要素（要素ツリー）

```
- フローシート編集ダイアログ
  - ヘッダー
    - 対象日付・適用パターン名
  - ケア項目入力域（適用パターンに応じて項目が変動）
    - 食事欄
    - 服薬欄
      - 投薬者初期表示（マスタ「投薬者初期表示」: 空白／ログオン者）
    - 看護記録下段〜サイン上段の各ケア項目
    - 体重欄: 入力不可（バイタル編集ダイアログ [us-20] で入力）
  - フッター
    - [登録] [更新] [削除] [キャンセル]
  - 更新履歴一覧
    - 列: 登録日時／パターン名／登録職員／区分（登録／更新）
    - 並び: 登録日時降順
    - 行クリック → フローシート履歴ダイアログ（参照のみ）
- フローシート履歴ダイアログ
  - 編集ダイアログのスナップショット（参照のみ、編集不可）
```

## 振る舞い

- **ダイアログ起動**: フローシート画面の対象日フローシートアイコンクリック → 適用パターンに従う項目で表示。
- **新規登録**: 値を入力 → [登録] → フローシートに反映 + 更新履歴に「登録」。
- **更新**: 既存行で値を編集 → [登録] → 反映 + 更新履歴に「更新」。
- **削除**: [削除] → 内容クリア + 更新履歴に「更新」（区分は更新だが値は空欄）。
- **体重入力不可**: 体重欄は入力不可、バイタル編集ダイアログ誘導。
- **投薬者初期表示**: マスタ「投薬者初期表示」によって空白／ログオン者切替。
- **禁則文字**: `#` `@` 等は入力不可（IME 確定時にバリデーション）。
- **履歴行クリック**: フローシート履歴ダイアログ（参照のみ）。
- **パターン未適用**: 履歴のパターン名欄に「パターンなし」表示。
- **スクロール位置保持**: ダイアログ open/close 前後でフローシート画面のスクロール位置を保持。

## 受け入れ基準（AC）

- [ ] **AC-1: ダイアログ起動と項目連動**
  - **Given** パターン「精神科基本」が適用済みのフローシートを表示している
  - **When** 対象日のフローシートアイコンをクリックする
  - **Then** 編集ダイアログが開き、入力欄は「精神科基本」パターンの項目のみ
- [ ] **AC-2: 新規登録**
  - **Given** 編集ダイアログで未入力状態
  - **When** ケア項目を入力 → [登録]
  - **Then** フローシートに値が反映され、履歴一覧の先頭に「登録」エントリが追加される
- [ ] **AC-3: 更新**
  - **Given** 既存記録あり
  - **When** 値を変更 → [登録]
  - **Then** 反映され、履歴一覧に「更新」エントリが追加される
- [ ] **AC-4: 削除**
  - **Given** 既存記録あり
  - **When** [削除] → 確認 OK
  - **Then** 値が空欄化され、履歴は「更新」区分で空欄スナップショットが残る
- [ ] **AC-5: 体重入力不可**
  - **Given** 編集ダイアログを開いている
  - **When** 体重欄を確認する
  - **Then** 体重欄は入力不可（注記でバイタル編集を促す）
- [ ] **AC-6: 投薬者初期表示**
  - **Given** マスタ「投薬者初期表示」=「ログオン者」
  - **When** 編集ダイアログを開く
  - **Then** 投薬者欄にログオン中の職員名が初期表示される
- [ ] **AC-7: 禁則文字**
  - **Given** ケア項目テキスト欄を編集中
  - **When** `#` を入力しようとする
  - **Then** 当該文字は入力されない
- [ ] **AC-8: 履歴閲覧**
  - **Given** 過去 3 回更新済み
  - **When** 履歴一覧の登録日時をクリックする
  - **Then** フローシート履歴ダイアログ（参照のみ）が開かれる
- [ ] **AC-9: パターンなし表示**
  - **Given** パターン未適用で登録した記録
  - **When** 履歴一覧を確認する
  - **Then** パターン名列に「パターンなし」と表示される
- [ ] **AC-10: スクロール位置保持**
  - **Given** フローシート画面を中段までスクロールして編集ダイアログを開いた
  - **When** 操作を終えてダイアログを閉じる
  - **Then** スクロール位置は変わらない

## 状態遷移 / バリデーション

- 区分: `登録`（新規）／`更新`（既存変更・削除）。「削除」専用区分は持たず、空欄値の更新で表現する
- 禁則文字: `#`, `@`（その他はマスタ管理予定。本モックではこの 2 文字を最低限）
- 履歴 ID は `${epoch}-${incrementing}` で安定ソート

## 補足

- 値の上下限警告（バイタルの異常値）は [us-20] 側で扱う
- 一括入力 [us-24]（バイタル）／[us-26]（看護記録）から登録された記録も、本ダイアログの履歴一覧に表示される
