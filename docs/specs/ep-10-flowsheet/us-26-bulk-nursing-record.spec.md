## ユーザーストーリー

- **As a** 病棟看護師
- **I want** 病棟・病室・記録日を指定して、複数患者の看護記録（FOCUS／SOAP／フリー）を勤務帯・時間・本文・連携・公開設定とともに一括入力したい
- **So that** 同様の所見が複数患者にまたがる場合に、効率的に記録できる

```

```

## 振る舞い

- **検索表示**: 日付・病棟・病室を指定 → [表示] → 該当患者一覧。
- **共通設定**: 記事タイトル（全患者共通）、記事形式（マスタ初期値）。
- **勤務帯一括**: タイトル部勤務帯 → 勤務帯設定ダイアログで選択 → [設定] → 一覧に一括反映（個別変更可）。
- **時間一括**: タイトル部時間 → 時間設定ダイアログ（現在時刻初期値）→ [設定] → 一覧時間に一括反映。勤務帯も時間に応じて自動連動。空白で [設定] するとエラー。
- **本文一括**: タイトル部 [入力] → 一括入力ダイアログで本文編集（テンプレート [呼出] ／文例ウィザード）→ 同形式の患者の本文に一括反映。
- **個別本文**: 各行で [文例] または直接入力で個別編集。
- **連携設定**: 行の連携欄 → 連携設定ダイアログでチェック → 一括登録時に該当連携先で記事表示。
- **公開切替**: 行ごとに公開チェック。チェック有=全職員参照可、無=記載職員のみ参照可。
- **選択チェック登録**: チェック ON 患者のみ [登録] で登録。[全て選択]／[クリア] で一括操作。
- **記録状態表示**: 表示日付に記録なし=「未」、ある場合は数値（クリックで新規作成）。
- **整合性**: 一括分も個別 [us-23] と同一データモデルに保存され、部門記録簿 [us-22] にも時系列に表れる。
- **未来日制御**: 未来日時は**常にエラー（登録不可・固定・マスタ設定によらない）**。旧 `validate.future` / `confirm.future` による制御は廃止（2026-08-17）。
- **氏名タイトル部クリック**: かな順で並び替え（昇順 ↔ 降順）。

## 受け入れ基準（AC）

- [ ] **AC-1: 検索表示**
  - **Given** 日付「2026-05-02」、病棟「北 3 階」、病室「301」を指定
  - **When** [表示]
  - **Then** 該当範囲の患者リストが表示される
- [ ] **AC-2: 共通設定（タイトル・形式）**
  - **Given** 一括看護記録画面表示中
  - **When** 記事タイトルを入力し、記事形式を選択
  - **Then** タイトルは全患者共通、形式は記事形式マスタ初期値と切替可
- [ ] **AC-3: 勤務帯一括設定**
  - **Given** 患者リスト表示中
  - **When** タイトル部勤務帯クリック → 勤務帯設定ダイアログ → 任意勤務帯選択 → [設定]
  - **Then** 一覧の勤務帯が一括反映（個別変更可）
- [ ] **AC-4: 時間一括設定**
  - **Given** 一括看護記録画面表示中
  - **When** タイトル部時間クリック → 時間設定ダイアログで現在時刻を確認 → [設定]
  - **Then** 一覧時間が一括反映、勤務帯が自動連動。空白の場合はエラー
- [ ] **AC-5: 本文一括入力**
  - **Given** 同形式（SOAP）の患者が複数表示
  - **When** タイトル部 [入力] → 一括入力ダイアログで本文を入力 → [登録]
  - **Then** 同形式患者の本文に一括反映される
- [ ] **AC-6: 個別本文編集**
  - **Given** 一括入力後、特定患者だけ本文を変えたい
  - **When** 該当行の本文欄で [文例] または直接編集
  - **Then** 当該患者のみ個別編集される
- [ ] **AC-7: 連携設定**
  - **Given** 患者行の連携欄をクリック
  - **When** 連携設定ダイアログでフローシート・申し送りにチェック → [登録]
  - **Then** 一括登録時に該当連携先で記事が表示される
- [ ] **AC-8: 公開切替**
  - **Given** 患者行の公開チェック操作
  - **When** チェック有り／無しで [登録]
  - **Then** 有: 全職員参照可。無: 記載職員のみ参照可
- [ ] **AC-9: 選択チェック登録**
  - **Given** 入力済み患者複数のうち、選択チェック ON が 2 名
  - **When** [登録]
  - **Then** チェック ON の 2 名のみ看護記録が登録される
- [ ] **AC-10: 記録状態表示**
  - **Given** 患者リストに当日記録 0 件と 2 件の患者が混在
  - **When** 記録欄を確認する
  - **Then** 記録 0 件は「未」、2 件は「2」と表示。クリックで新規作成（背景白）
- [ ] **AC-11: 個別記録との整合**
  - **Given** 一括看護記録で記事を保存
  - **When** 同患者の部門記録簿 [us-22] / 個別看護記録 [us-23] を表示
  - **Then** 一括分の記事が時系列に表示される
- [ ] **AC-12: 未来日不可（常に固定）**
  - **Given** 一括看護経過記録を表示している（マスタ設定によらない）
  - **When** 未来日時で [登録]
  - **Then** エラーメッセージで登録不可（未来日時は常に登録不可）
- [ ] **AC-13: かな順並び替え**
  - **Given** 患者リスト複数表示
  - **When** 氏名タイトル部クリック
  - **Then** かな順で昇順 ↔ 降順切替

## 状態遷移 / バリデーション

- 行状態: `untouched` → `editing (本文/勤務帯/時間/連携/公開設定中)` → `selected (チェック ON)` → [登録] で `committed`
- 時間空白 [設定]: エラー
- 未来日: **常にハードガード（登録不可）で固定**。マスタ `validate.future` / `confirm.future` による制御は廃止（2026-08-17）

## 補足

- 一括入力時のテンプレートは点数表分類マスタ／看護記録で管理
- 個別記録 [us-23] と一括記録の連携設定 UI は共通
- 並び替えは氏名（かな順）のみ。他キー（病室番号等）の並び替えは別ストーリーで検討
