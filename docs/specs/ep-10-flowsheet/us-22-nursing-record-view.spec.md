## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートから部門記録簿の看護記録を呼び出して参照したい
- **So that** バイタル・ケア記録と看護記録（叙述）を行き来して患者像を把握できる

```
- 部門記録簿画面 (/nursing/records)
```

## 振る舞い

- **フローシートからのダイアログ起動**: 看護経過記録欄のタイトルクリック → 看護経過記録ダイアログを参照モードで起動。
- **部門記録簿の表示**: 患者指定 → 一月毎に括った記事リスト。最大 9 日分の直近記事（マスタで日数設定）。
- **記載時刻の勤務帯色**: 日勤=青、準夜=緑、深夜=赤。
- **記事表示切替**: 「通常」=削除・修正・未来日予定は非表示、「全て」=これらも含めて表示（修正・削除前の元記事は赤文字タイトル）。
- **キーワード検索**: 検索ボックスに入力した語で、**タイトル・本文・タグ**を横断して絞り込む。
- **タグ絞り込み**: 選択中患者の記録から集約したタグをチップ表示し、クリックで絞り込む。**複数選択は AND（選択タグをすべて含む記事のみ）**。[クリア]で解除。**表示モード（通常/全て）切替・患者切替でタグ選択はリセット**（候補タグが変わるため）。タグの候補はマスタではなく既存記録から動的に集約（フリータグ方針。[us-23] 参照）。
- **記録形式チップの配色**: 記録形式（SOAP/経時記録）を塗り＋配色のチップで表示し、タグ（アウトライン）と視覚的に区別する。文字ラベルも併記し色覚に依存しない。
- **ページ遷移**: 前ページ／次ページ／最新ページ。前後ページがない場合はリンク非活性または非表示。
- **患者状態色**: 日付横にカルテ記事入力された患者状態を 5 段階の色で表示。

## 受け入れ基準（AC）

- [ ] **AC-1: フローシートからダイアログ起動**
  - **Given** フローシートに看護記録のタイトルがある
  - **When** タイトルをクリックする
  - **Then** 看護経過記録ダイアログが参照モードで開かれ、当該記事の内容が表示される
- [ ] **AC-2: 部門記録簿の表示**
  - **Given** 患者を指定して部門記録簿を開く
  - **When** リスト表示を確認する
  - **Then** 一月毎の括りで記事が並び、最大 9 日分の直近記事が表示される
- [ ] **AC-3: 勤務帯色**
  - **Given** 日勤（10:00）／準夜（17:00）／深夜（02:00）の記事がある
  - **When** 各記事の記載時刻欄を確認する
  - **Then** 日勤=青、準夜=緑、深夜=赤の文字色で表示される
- [ ] **AC-4: 記事表示切替**
  - **Given** 削除・修正記事が混在している
  - **When** 切替を「全て」にする
  - **Then** 削除・修正記事および未来日の予定記事が表示される（修正・削除前の元記事は赤文字タイトル）。「通常」では非表示
- [ ] **AC-5: キーワード検索（タイトル・本文・タグ）**
  - **Given** 部門記録簿を表示している
  - **When** 検索ボックスにキーワード（タグ名を含む）を入力する
  - **Then** タイトル・本文・タグのいずれかに一致する記事のみに絞り込まれる
- [ ] **AC-6: 記事メタ情報**
  - **Given** 看護記録を参照中
  - **When** 記事を確認する
  - **Then** 記事タイトル・連携項目・記事タグ・作成者の職種・氏名・日時・修正者・日時が表示される
- [ ] **AC-7: ページ遷移**
  - **Given** 複数の看護記録が存在する
  - **When** ページ遷移リンクをクリックする
  - **Then** それぞれ前／次／最新ページに遷移。前後ページがないときは非活性または非表示
- [ ] **AC-8: 患者状態色表示**
  - **Given** カルテ記事に患者状態が入力されている
  - **When** 部門記録簿の日付横を確認する
  - **Then** 状態が 5 段階の色で表示される
- [ ] **AC-9: タグチップ絞り込み（AND）**
  - **Given** 複数のタグが付いた記録が存在する
  - **When** ヘッダーのタグ絞り込みチップを 1 つ以上選択する
  - **Then** 選択したタグをすべて含む記事のみ表示される（AND）。[クリア]で解除できる
- [ ] **AC-10: 表示モード切替でタグ絞り込みリセット**
  - **Given** タグで絞り込み中
  - **When** 表示モードを「通常」↔「全て」に切り替える
  - **Then** タグ選択がリセットされ、絞り込みが解除される（患者切替でも同様）
- [ ] **AC-11: 記録形式チップの区別**
  - **Given** 記事一覧を表示している
  - **When** 記録形式チップとタグチップを見る
  - **Then** 記録形式（SOAP/経時記録）は配色（塗り）、タグはアウトラインで表示され、視覚的に区別できる

## 状態遷移 / バリデーション

- 表示モード: `通常` ↔ `全て`
- 「全て」時の赤文字タイトル: 修正・削除前の元記事

## 補足

- 部門記録簿の他職種記録（医師記録等）との関係は別途整理（本ストーリーは看護記録参照のみ）
- 「いいね」「コメントする」機能は別ストーリーで扱う
- 患者状態色分け基準はマスタで管理
- タグはフリータグ（自由入力）で付与（[us-23]）。検索・絞り込みの候補はタグマスタではなく既存記録から動的集約する。対象範囲は選択中患者の記録内（全患者横断は将来検討）
- E2E: `e2e/flowsheet.spec.ts`「部門記録簿: タグチップで記事を絞り込める（複数選択はAND）」「表示モード切替でタグ絞り込みがリセットされる」「検索ボックスでタグ名でも検索できる」
