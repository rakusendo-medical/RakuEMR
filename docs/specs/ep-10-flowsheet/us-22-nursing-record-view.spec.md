## ユーザーストーリー

- **As a** 病棟看護師
- **I want** フローシートから部門記録簿の看護記録を呼び出して参照したい
- **So that** バイタル・ケア記録と看護記録（叙述）を行き来して患者像を把握できる

## 画面要素（要素ツリー）

```
- 部門記録簿画面 (/nursing/records)
  - ヘッダー
    - 患者選択
    - 記事表示切替: [通常] / [全て]
    - 記事選択及び検索ボタン
    - ページ遷移リンク: `<<` `<` `>` `>>` ／ [前へ] [次へ] [最新へ]
  - メインリスト
    - 一月毎の括り（医療機関情報マスタの設定日数まで、最大 9 日分の直近記事）
    - 記事カード
      - 記載時刻（勤務帯色: 日勤=青／準夜=緑／深夜=赤）
      - 記事タイトル
      - 記事メタ情報（連携項目、記事タグ、作成者の職種・氏名・日時、修正者・日時）
      - 患者状態色（5 段階）
      - 「全て」モード時: 削除・修正・未来日予定記事も含む（赤文字タイトルは修正・削除前の元記事）
- フローシート画面の看護記録欄
  - 看護記録タイトルクリック → 看護記録ダイアログ（参照モード）
  - [新規作成] → [us-23] へ遷移
- 看護記録ダイアログ（参照モード）
  - タイトル／勤務帯／記録形式／本文／連携／タグ／公開／作成者・修正者
```

## 振る舞い

- **フローシートからのダイアログ起動**: 看護記録欄のタイトルクリック → 看護記録ダイアログを参照モードで起動。
- **部門記録簿の表示**: 患者指定 → 一月毎に括った記事リスト。最大 9 日分の直近記事（マスタで日数設定）。
- **記載時刻の勤務帯色**: 日勤=青、準夜=緑、深夜=赤。
- **記事表示切替**: 「通常」=削除・修正・未来日予定は非表示、「全て」=これらも含めて表示（修正・削除前の元記事は赤文字タイトル）。
- **記事選択及び検索**: クリックでカルテ記事検索機能と共通の検索条件設定ダイアログ。
- **ページ遷移**: 前ページ／次ページ／最新ページ。前後ページがない場合はリンク非活性または非表示。
- **患者状態色**: 日付横にカルテ記事入力された患者状態を 5 段階の色で表示。

## 受け入れ基準（AC）

- [ ] **AC-1: フローシートからダイアログ起動**
  - **Given** フローシートに看護記録のタイトルがある
  - **When** タイトルをクリックする
  - **Then** 看護記録ダイアログが参照モードで開かれ、当該記事の内容が表示される
- [ ] **AC-2: 部門記録簿の表示**
  - **Given** 患者を指定して部門記録簿を開く
  - **When** リスト表示を確認する
  - **Then** 一月毎の括りで記事が並び、最大 9 日分の直近記事が表示される
- [ ] **AC-3: 勤務帯色**
  - **Given** 日勤（10:00）／準夜（17:00）／深夜（02:00）の記事がある
  - **When** 各記事の記載時刻欄を確認する
  - **Then** 日勤=青、準夜=緑、深夜=赤の文字色で表示される
- [ ] **AC-4: 記事表示切替**
  - **Given** 削除・修正記事が混在している
  - **When** 切替を「全て」にする
  - **Then** 削除・修正記事および未来日の予定記事が表示される（修正・削除前の元記事は赤文字タイトル）。「通常」では非表示
- [ ] **AC-5: 検索絞り込み**
  - **Given** 部門記録簿を表示している
  - **When** 記事選択及び検索をクリックして条件を設定する
  - **Then** 表示記事が条件に応じて絞り込まれる
- [ ] **AC-6: 記事メタ情報**
  - **Given** 看護記録を参照中
  - **When** 記事を確認する
  - **Then** 記事タイトル・連携項目・記事タグ・作成者の職種・氏名・日時・修正者・日時が表示される
- [ ] **AC-7: ページ遷移**
  - **Given** 複数の看護記録が存在する
  - **When** ページ遷移リンクをクリックする
  - **Then** それぞれ前／次／最新ページに遷移。前後ページがないときは非活性または非表示
- [ ] **AC-8: 患者状態色表示**
  - **Given** カルテ記事に患者状態が入力されている
  - **When** 部門記録簿の日付横を確認する
  - **Then** 状態が 5 段階の色で表示される

## 状態遷移 / バリデーション

- 表示モード: `通常` ↔ `全て`
- 「全て」時の赤文字タイトル: 修正・削除前の元記事

## 補足

- 部門記録簿の他職種記録（医師記録等）との関係は別途整理（本ストーリーは看護記録参照のみ）
- 「いいね」「コメントする」機能は別ストーリーで扱う
- 患者状態色分け基準はマスタで管理
