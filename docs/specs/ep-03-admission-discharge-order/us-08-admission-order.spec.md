## ユーザーストーリー

- **As a** 主治医
- **I want** 入院指示を発行する際に紹介元医療機関と紹介経路を入力したい
- **So that** 地域医療連携の起点情報を指示と一体で記録し、後続の事務手続き・診療情報提供書発行で再入力を不要にできる

## 振る舞い

- **カルテ [入院指示] クリック**: 入院指示ダイアログを開く
- **入院日入力**: 医療機関情報マスタの食事時間設定に基づき食事開始日を自動設定
- **食事開始日変更**: 自動値より後の時間帯にすると、入院日時から指定時刻までの間に「食無し」指示（マスタ切替で「臨時欠食」）を自動生成（モックでは Alert 通知）
- **食事開始日 = 当日 + 過去時間帯**: 選択不可。赤字表示の時間帯選択時は確認メッセージで備考タグ付き指示として登録
- **紹介元医療機関 [検索]**: 検索ダイアログで医療機関を選択し欄に設定
- **[治療歴から複写]**: 直近入院歴の退院紹介医療機関 → 紹介元医療機関の優先順で取得（モックは固定値）
- **紹介経路セレクト**: 6 区分から選択。医療観察法オプションありのみ「医療観察入院処遇中の転院」を表示
- **[空床照会]**: 空床照会ダイアログを開く（ep-01/ep-02 と共通）
- **[指示] ボタン**: 指示登録。外来患者のまま、入退院情報カレンダーに赤字（未確定）で表示。未来日・当日・過去日いずれも可
- **[入院確定] ボタン**: 即時確定。
  1. 入院日が未来 → 確定不可
  2. 未実施の外来専用オーダ → 入院確定時のオーダ確認ダイアログ
  3. 確定: 患者状態が「入院患者」、入退院情報カレンダーは青字
- **オーダ確認ダイアログ - 個別中止**: 中止アイコンで伝票単位の削除理由入力ダイアログ
- **既存指示の [変更]**: 値を編集して更新
- **既存指示の [中止]**: 削除理由ダイアログで分類（必須）と理由（任意）を入力 → 指示が取り消される。削除指示箋印刷可

## 受け入れ基準（AC）

- [ ] **AC-1: 入院指示画面を開ける**
  - **Given** 患者カルテを表示している
  - **When** 診療録の [入院指示] をクリックする
  - **Then** 入院指示画面が開かれ、入院日・食事開始日・病室情報・紹介元医療機関・紹介経路・入院決定理由・入院後の診療・指示内容を入力できる（入院時文書は取り扱わない）

- [ ] **AC-2: 入院日に応じて食事開始日が自動設定される**
  - **Given** 入院指示画面を開いている
  - **When** 入院日を入力する
  - **Then** 医療機関情報マスタの食事時間設定に基づいて食事開始日時が自動設定される

- [ ] **AC-3: 食事開始日を変更すると食無し／臨時欠食指示が自動生成される**
  - **Given** 自動設定された食事開始日時より後の時間帯に変更した
  - **When** 入院確定する
  - **Then** 入院日時から設定した食事開始日時までの間に「食無し」指示（マスタ切替で「臨時欠食」）が自動生成される

- [ ] **AC-4: 食事開始日の選択肢は現在時刻に依存する**
  - **Given** 入院日を当日に設定する
  - **When** 食事開始日の時間帯を選択する
  - **Then** 現在時刻の直前以前の時間帯は選択できない（赤字表示の時間帯を選んだ場合は確認メッセージで備考タグ付き指示として登録される）

- [ ] **AC-5: 紹介元医療機関を検索または治療歴から複写できる**
  - **Given** 入院指示画面を開いている
  - **When** [検索] をクリックして検索ダイアログから医療機関を選択する、または [治療歴から複写] をクリックする
  - **Then** 紹介元医療機関欄に値が設定される

- [ ] **AC-6: 紹介経路をプルダウンから選択できる**
  - **Given** 入院指示画面を開いている
  - **When** 紹介経路欄を選択する
  - **Then** 「直接入院／自院通院からの入院／自院入院からの入院／他院通院からの転入院／他院入院からの転入院／医療観察入院処遇中の転院」から選択できる

- [ ] **AC-7: 病室情報の空床照会ができる**
  - **Given** 入院指示画面を開いている
  - **When** [空床照会] をクリックする
  - **Then** 空床照会ダイアログがカレンダー形式で病棟の空床状況を表示する

- [ ] **AC-8: 「指示」段階で発行できる（入院手続き待ち。病棟は指示時に確定）**
  - **Given** 入院指示画面で必要項目を入力している
  - **When** [指示] ボタンをクリックする
  - **Then** 入院指示が登録される。患者は外来患者のまま、入退院情報の入院予定として赤字表示される。未来日・当日・過去日いずれも可

- [ ] **AC-9: 「入院確定」で即時状態変化させられる**
  - **Given** 入院指示画面で必要項目を入力している
  - **When** [入院確定] ボタンをクリックする
  - **Then** 患者状態が即座に「入院患者」となる。未実施の外来専用オーダがあれば入院確定時のオーダ確認ダイアログが表示される。未来日付では確定不可

- [ ] **AC-10: 入院確定時のオーダ確認ダイアログでオーダを一括中止できる**
  - **Given** 患者に未実施の外来専用オーダがある
  - **When** 入院確定時のオーダ確認ダイアログで対象オーダを選択チェックし、入院確定する
  - **Then** 選択したオーダが中止される。中止箋・削除箋の印刷チェックで関連箋を出力できる

- [ ] **AC-11: 入院指示の更新・中止ができる**
  - **Given** 「指示」段階で登録済みの入院指示がある
  - **When** 診療録または指示簿の内容欄から入院指示画面を開き、[変更] または [中止] をクリックする
  - **Then** 変更時は内容を修正して更新できる。中止時は削除理由ダイアログで分類（必須）と理由（任意）を入力すると指示が取り消される。削除指示箋の印刷も可

- [ ] **AC-12: 確定後の状態が反映される**
  - **Given** 入院確定が完了した
  - **When** 各画面を確認する
  - **Then** カルテ記事・医師指示簿に確定内容が記録され、入院歴・治療歴に履歴が追加される。入退院情報画面では患者氏名が青字（確定）表示される

## 状態遷移 / バリデーション

- ダイアログモード: 新規 / 変更 / 中止
- 病棟: **必須**（未選択不可。病棟未指定での入院オーダーは不可＝「病棟未割当」は発生しない）
- 病室・ベッド: 「病室未定」チェックで未定のまま登録可（病室の確定・割り当ては [us-03](../ep-01-bed-map/us-03-bed-assign.spec.md) で看護師が実施）
- 「指示」: 未来日・当日・過去日 すべて可
- 「入院確定」: 未来日不可、当日・過去日のみ可
- 食事開始日 ≥ 入院日 を保証
- 食事開始日 - 入院日 > 0 → 食無し／臨時欠食 自動生成（モックは Alert 通知）
- 当日入院 + 現在時刻以前の食事時間帯 → 選択不可（disabled）
- 中止操作 → 削除理由ダイアログで分類入力必須

## 補足

- 入院日の初期表示（空欄／操作日時）はマスタ依存（モックは操作日時）
- 「指示箋を印刷する」: 食事指示箋・移動指示箋出力（マスタ設定。モックは UI のみ）
- **入院時文書は現時点では電子カルテで取り扱わないため、本仕様から除外（2026-08-17）**。以前は入院形態の選択で入院時文書チェック一覧が切り替わったが、UI・データ（`ADMIT_DOCS_BY_FORM`）とも削除済み。入院形態セレクト自体は残す。
- 入院取消は入院歴画面で行う（本機能では不可）
- 医療観察法オプション利用時は紹介経路に「医療観察入院処遇中の転院」が追加（モックではトグルで切替）
- 外部精神科システム連携時は精神科入院有無項目が追加（モックでは表示分岐のみ）
