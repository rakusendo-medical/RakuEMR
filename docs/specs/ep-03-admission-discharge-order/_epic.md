## 概要

主治医による入院・退院の指示発行を、紹介元／紹介先医療機関と紹介経路の情報を含めて記録できるようにする。「指示」と「確定」の二段階運用で、地域医療連携に必要な情報を指示時点で確定させる。

## ゴール

- 主治医がカルテ画面から入院指示・退院指示を発行できる
- 紹介元／紹介先・紹介経路を指示と紐づけて記録できる
- 指示が事務側の入退院手続き（ep-02）にシームレスに連携する
- 「指示」（病棟確定待ち）と「確定」（即時状態変化）を運用に応じて使い分けできる

## スコープ

### 含む

- 入院指示の発行（紹介元医療機関・紹介経路・入院形態・入院理由・指示内容を含む）
- 退院指示の発行（紹介先医療機関・紹介経路・転帰・退院理由・カルテ記載を含む）
- 「指示」段階での発行（外来患者のまま、未来日付可、病棟が後から確定）
- 「確定」段階での発行（過去・当日のみ、即時状態変化）
- 指示後の変更・中止（削除理由ダイアログ）
- 確定時のオーダ一括中止（外来専用／入院専用、移動・給食、リハビリ）
- 紹介元・紹介先医療機関の検索／治療歴からの複写
- 食事開始・食事終了日の自動設定とずれた期間の食無し／臨時欠食指示自動生成

### 含まない

- 入退院手続きの確定処理（[ep-02 入退院手続き]）
- 紹介元／紹介先医療機関マスタの保守
- 入院取消・退院取消（[ep-04 入退院歴]）

## 主要画面要素（エピック俯瞰）

```
- カルテ画面 (/karte-alpha/:patientId)
  - クイック操作領域
    - 入院指示ボタン → 入院指示ダイアログ [us-08]
    - 退院指示ボタン (入院患者のみ表示) → 退院指示ダイアログ [us-09]
- 入院指示ダイアログ [us-08]
  - 入院日 / 食事開始日 / 病室情報 / 備考
  - 入院時文書チェック群
  - 紹介元医療機関セレクト + 検索ボタン + 治療歴複写ボタン
  - 紹介経路セレクト
  - 入院決定理由 / 入院後の診療 / 指示内容
  - 指示箋印刷チェック
  - 操作: 指示 / 入院確定 / キャンセル
- 退院指示ダイアログ [us-09]
  - 退院日 / 転帰 / 食事終了日 / 備考
  - 退院時文書チェック群（診療区分: 不要/通院/転院 で内容が変わる）
  - 紹介先医療機関セレクト + 検索ボタン + 治療歴複写ボタン
  - 紹介経路セレクト
  - 退院決定理由 / 退院後の診療 / カルテ記載
  - 指示箋印刷チェック
  - 操作: 指示 / 退院確定 / キャンセル
- オーダ確認ダイアログ（ep-02 と共通） [us-08, us-09]
- 削除理由ダイアログ [us-08, us-09]
- 医療機関検索ダイアログ [us-08, us-09]
```

## 完了条件

- 全子ストーリーの AC がチェック済み
- 紹介元／紹介先・紹介経路が指示と一体で記録される
- 指示が確定すると事務側の入退院手続き（ep-02 カレンダー）候補に表れる
- 指示後の変更・中止が監査可能な形で残る

## 依存

- 患者基本情報、医療機関マスタ（紹介医療機関）、紹介経路マスタ
- 転帰区分マスタ、期限管理マスタ、表示ラベルマスタ
- 帳票定義情報マスタ、伝票定義情報マスタ
- 区分マスタ（削除理由・転帰区分_リハビリ）

## オプション機能

- 医療観察法: 紹介経路に「医療観察入院処遇中の転院」を追加
- 外部精神科システム連携: 入院指示に「精神科入院有無」項目を追加

> 地域連携（逆紹介）オプションは不要のため削除（元は退院指示に「逆紹介する」チェック＋カルテ閲覧期限を表示）。
